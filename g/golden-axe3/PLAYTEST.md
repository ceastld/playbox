玩法：标题页「斧三」。选「斧三」打三关（宁村→瀑窟→骑殿，骑殿尽头是骑煞）；选「斧核」同三关但每包更密、更快、更肉。沿带状走（左右推进、上下换深度），C / Shift 起跳，空格 / Z 挥剑三连（直斩→上挑→旋落），空中空格是跳斩（一跳一次）。X 花 1 格魔法召天雷，从天上砸到近处敌人。没有坐骑可抢。体力打空扣一命。点顶栏「重开」或按 R：标题页进斧三；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「斧核」开斧核。M 静音，写入 playbox-golden-axe3-mute。弹层打开时方向键不走路、空格不斩、C 不跳、X 不放魔法；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。可走带宽 y=222–322。镜头跟在人右前方，遇兵和骑煞锁在当前段。人约 16 宽 30 高，走约 176，纵深约 112，跳约 72 高。标题页背后演示右进挥剑跳斩打天雷，不算分、不掉血。

斧三三关：宁村（狼兵/刃卫，烤肉/魔壶/金币）/ 瀑窟（咒羽丢羽、骑奴冲撞）/ 骑殿（混编后头目骑煞 26 血，马上冲撞并砸地波；半血摔下夜兽，夜兽继续冲，骑煞落马后还会召狼卫）。过关保留命、体、魔法、分。斧核同景，每包多 1～2 人，敌速约 ×1.12，血量约 ×1.16。

挥剑：空格三连 直斩(1伤)→上挑(2伤、把人挑起来)→旋落(3伤、击倒)。空中空格跳斩（2伤、击倒），一跳一次。X 花 1 格魔法（上限 6，开局 2），天雷落到近处敌人身上，各吃 4 伤（骑煞 2 伤），约 70ms 顿帧 + 雷柱。魔法空了会提示「魔法空了」。

敌人：狼兵贴脸 3 血、更快；刃卫剑击 6 血；咒羽远丢暗羽 4 血；骑奴 5 血、骑夜兽冲撞（打死不留可骑坐骑）；夜兽 8 血，只冲不砍；骑煞 26 血（斧核随倍率加血），马上冲更沉，半血摔骑。体力条打空倒地再起身；起身一小段不挨打。跳起来可躲低处拳和羽，躲不开砸地波。

道具：烤肉 +4 体力（上限 12）；魔壶 +1 格（上限 6）；金币 250×倍率。

得分：命中按伤害计连击倍率分，击杀狼兵 180 / 刃卫 320 / 咒羽 260 / 骑奴 400 / 夜兽 500 / 骑煞 8000×倍率，过关 2000×关，打掉骑煞后再加 8000。连击为连续命中，约 1.5 秒无命中则断。倍率 = 1 + min(4, floor((连击-1)/2))。每 18000 分 1UP，命上限 6。最高分写入 playbox-golden-axe3-best，不存盘面；本局超过即更新。

失败：体力打空扣一命（无敌除外）。约 0.85s 后原地满体重生，1.35s 闪烁无敌。三命扣完弹出「摔了 / 被撞倒了 / 被狼兵打中了 / 被刃卫打中了 / 被咒羽刺了 / 被夜兽撞了 / 被骑煞碾了 / 被骑煞砸了」等。弹层打开时方向键不再斩；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → ↑ ↓ / WASD 走（上下换深度），空格 / Z / J 挥剑，C / Shift 跳，X 魔法。点画布同挥剑。触屏 上 / 下 / 左 / 右 / 跳 / 斩 / 雷。标题页 斧三 / 斧核，Enter/空格/1 斧三，2 斧核。R 重开，M 静音。无手柄。与斧二不同：有跳和跳斩，空格是斩但 C 是跳，魔法是天上砸下来的天雷不是往前飞的雷火波，没有岩兽金龙可骑，关卡是宁村/瀑窟/骑殿不是废堡/熔喉/魔塔，头目是马上的骑煞不是暗君。与战斧不同：空格是斩不是跳，魔法是天雷不是全屏火柱，没有鸡腿兽/火蜥，模式是斧三/斧核不是远征/角斗。与终斗不同：有跳有魔法，核心是挥剑跳斩天雷，幻想村庄不是香港巴黎罗马。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不顿帧、不抖屏、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：斩必有三层——听（剑风噪声+金属撞击）、看（金屑、火花、分数蹦出）、触（约 45–75ms 顿帧 + 镜头踢）。旋落和跳斩更沉。天雷：雷声 + 落雷柱 + 70ms 顿帧。落地有闷响和挤压。连击升档金闪、大字 ×N。失败与重开都是一键 R。
