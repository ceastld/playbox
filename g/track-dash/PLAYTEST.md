玩法：标题页「田赛」。选「全能」连打 100米 → 跳远 → 标枪，每项必须达标才进下一项；选「冲刺」只跑 100米，对手更快、达标更紧。点「重开」或 R 开新局（标题页 R 进全能；局中或结算重开回当前模式）。M 静音，写入 playbox-track-dash-mute。
100米：预备阶段可猛按积力，枪声后才起步。A / D（或 ← →）交替猛按加速，连按同一键也能跑但稍弱。点按画布按一下算一次拍。力量条会涨、抖、爆表。虚拟 100 米，成绩精确到百分之一秒。全能达标 13.50，冲刺 12.30。对手分道跑；从后方追上会「超越」。
跳远：助跑猛按，白板（约 22m）起跳。空格或「跳」在板前按下。踩过白板红边算犯规，成绩 0。起跳距离 = 腾空水平位移，从板沿起算。板前（约 16cm 内）提示「板前」并加分。达标 6.00m。
标枪：助跑猛按，右侧角度针在约 20–70° 间摆。空格或「投」掷出。金区约 40–50°（起飞角）。踩过起掷线犯规。落点距起掷线为成绩。达标 50.00m。
得分：100米按时间、名次、超越、节奏连打计；跳远/标枪按距离，板前/起飞角有加分。连续达标有倍率。最高分按模式分记，写入 playbox-track-dash-best，JSON `{a,s}`（全能 / 冲刺）；本局超过即更新。
胜利：全能三项都达标弹出「三项达标」；冲刺跑进 12.30 弹出「冲线」。新纪录时角标 BEST。
失败：未达标或犯规弹出「未达标 / 犯规出局」，该模式结束。弹层 `pointer-events: none`（只有面板可点），不挡顶栏重开；R 在窗口级监听，弹层打开时随时可用。
操作：键盘 A D / ← → 猛按，Z C X 也可。空格 / K / J 起跳或掷枪。触屏显示 A / D / 跳|投。点按画布猛按。标题页 1/Enter/空格 全能，2 冲刺。结算 Enter/空格 再赛。无手柄。无自动。
限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不顿帧、不抖屏。触控画布 `touch-action: none`。标题页背后是演示 100米，到端会重置，不算分。
爽感：每下猛按有脚步火花、力量条回弹、音高随节奏爬、低频震动。枪声白闪。起跳/掷枪 50–80ms 顿帧 + 镜头踢 + 粒子。超越短顿和青闪。达标Crowd 琶音。犯规红闪+蜂鸣。失败与重开都是一键 R。
什么变难：力量停按就掉。跳远要在白板前起跳，早了没远度，过了犯规。标枪要在金角出手，太高太低都短。冲刺对手约 9–9.6m/s，只慢跑会吃尾尘。
