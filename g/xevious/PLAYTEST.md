玩法：标题页「泽空」。选「泽空」打三区（林泽 → 荒原 → 空核），每区中核与关底空核城；选「空核」同三区但卷轴更快、对空更密、Boss 多约 22% 血、额外补波。点顶栏「重开」或按 R：标题页直接开泽空；对局中或结束层重开同一模式。结束层「再来」同模式；机毁「换模式」回标题；通关「空核」开空核（空核通关则「换模式」回标题）。M 静音，写入 playbox-xevious-mute。方向键 / WSD 八向飞（A 留给自动），空格打空（可按住连射），Shift / Z 投弹砸地。画布拖动跟机，按下打空。触屏右下「弹」投弹。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 泽空、2 空核。

自动：点「自动」或按 A 开关托管（开着时按钮呈按下态并显示「停下」）。开着时忽略方向键、W/S/D、触屏跟机；A / R / M / 重开仍可用。开关不写入存储，刷新后关闭；重开不会关掉自动。标题页开着会自动开泽空；机毁/通关层会自动再来同一模式。速度滑条 1–4 为 慢 / 中 / 快 / 极快（默认快），写入 playbox-xevious-auto-speed，改速立刻生效。AI 会躲弹与旋障、空弹打飞碟、准星锁地核再投弹，不是左右晃。

场地：虚拟场 480×720。泽隼开局 y=630、x=240，夹在 22–458 / 40–692。准星固定在机头前 86。泽空巡航约 80（关卡与连击再加），空核约 112；中/关底在屏时降到约 26–34。移速约 272（空核 308）再加火力等级。空弹相对机向上 700。点按或按住空格打空。未解锁音频前无声。

两层：空弹只打飞的（环碟、翼鳐、锥蜂、双环、运核）；投弹只砸地核（地炮、掩体、核井、隐核、中核、关底空核城）。地面可飞越，只吃它们的对空弹。旋障无敌，空弹刮出火星，撞上扣命。隐核平时几乎看不见，准星扫过「发现」再砸。

火力：默认隼 0 单发，冷却约 0.110s。吃菱形「泽」胶囊加宽：1 双平行 0.099s、2 三向 0.088s、3 五向 0.077s、4 七向 MAX 0.066s。满级再吃 +500×倍率。运核必掉泽。被弹若有火力会掉一枚泽可再捡，火力归零。投弹无限弹药，冷却约 0.42s（每级火力 −0.035s）；锁上时弹头追核，爆心更大。

关卡：第 1 区林泽中核「泽塔」36 血、关底「林核堡」88；第 2 区荒原「荒台」48 / 「荒核城」118；第 3 区空核「核门」62 / 「安德核」164。空核模式血量 ×1.22。中核在场时波次计时暂停。编队环碟、侧翼翼鳐、俯冲锥蜂、双环、旋障、地炮/掩体/核井、隐核、运核。林核堡半血后扇扫；荒核城旋转弹幕；安德核双环弹+瞄准。关底是空中要塞，但核心按地面结算，必须投弹。

得分：击杀基础分 × 连击倍率。环碟 50、翼鳐 60、锥蜂 80、双环 120、地炮 150、掩体 180、核井 200、隐核 250、运核 300、中核 2000、关底 4000+1500×区。连击为连续击杀，约 1.38 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。击坠关底再加 1500×区。三区打穿 +8000 并「空核已破」。每 20000 分 1UP，命上限 6。最高分写入 playbox-xevious-best，不存盘面；本局超过即更新。

胜利：泽空/空核打掉第 3 区安德核后约 2.1s 结算胜利。
失败：敌弹碰到自己，或空中机体（含旋障）相撞，扣一命（重生无敌除外）。约 0.95s 爆炸后重生，1.55s 闪烁无敌，场上敌弹清空。三命（顶栏青点）扣完弹出「机毁了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WSD 飞，空格打空。Shift / Z 投弹。点按画布打空并跟机。标题页 Enter/空格/1 泽空，2 空核。A 自动，R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：空弹枪口闪 + 升频方波。投弹落锯齿 + 爆心砂石碎屑 + 约 40–56ms 顿帧。准星锁核金闪双音。击中粒子爆开 + 短顿帧（约 34–72ms）+ 镜头微震 + 连击数字往上窜。发现隐核提示「发现」。吃泽金闪。坠机洋红大爆。失败与重开都是一键 R。
