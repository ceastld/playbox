玩法：标题页「岩变」。选「岩变」横场绕回、常速绿黏稍后入场；选「乱飞」绿黏更勤，最多四只，大黏还会滴小黏。点顶栏「重开」或按 R：标题页直接开岩变；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-blasteroids-mute。A D 与 ← → 转向，W / ↑ 推进，空格开火（可按住），C 变身在快艇 / 战机 / 重炮 间循环（默认战机，下一档重炮）。触屏：左下 ↺ ▲ ↻，右下 变 / 火。点按画布也可开火。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 岩变、2 乱飞。标题页 C 也可预览变身。
场地：虚拟场 800×480 横场。船、弹、岩、黏、能量全部出边绕回（九宫绘制近边残影）。三种船体半径约 7.4 / 10 / 14.4。点按或按住空格开火，未解锁音频前无声。
船体：C 切换，冷却约 0.34s。快艇转向 5.45、推进 372、最快约 472、极轻阻尼 0.042，细弹 650、寿命 0.66s、最多 6 发、冷却 0.09s、威力 1。战机转向 3.62、推进 250、最快约 336、阻尼 0.082，弹 528、寿命 0.8s、最多 4 发、冷却 0.138s、威力 2。重炮转向 2.32、推进 158、最快约 226、阻尼 0.165，粗弹 382、寿命 1.04s、最多 3 发、冷却 0.24s、威力 4；重炮弹可穿透小岩继续飞。乱飞最多再 +1 发、冷却 ×0.9。变身保留速度（快艇上限更高，切重炮会立刻被压速）。
岩石：大 / 中 / 小半径约 40 / 23 / 12。击中大裂成两中、中裂成两小、小消失。大 20、中 50、小 100，再乘连击倍率。乱飞初速 ×1.14，每波再 +5.5%。清波后立刻进下一波：岩变 4、5…最多 8 颗大岩；乱飞 4、5…最多 9。清波奖励 200×刚结束的波次。碎岩有概率掉能量（大 24%、中 13%、小 6%，乱飞再 +5%）。
绿黏：岩变约 11–18 秒后出现（第一波更晚），场上最多 1 只，第 3 波起最多 2。乱飞约 3.4–7 秒、最多 2+⌊波/2⌋ 封顶 4。小 / 中 / 大半径 12 / 22 / 34，血 2 / 4 / 8，分 150 / 320 / 700。会慢慢追船、出边绕回。吃掉能量或小岩会变大；两只同级小/中相撞合体升一级。用威力不够的弹打到 0 血会裂成两只更小的（中黏需威力 3 才砸干净，大黏需 4，即重炮）。快艇打大黏只会越打越碎。乱飞里大黏偶尔滴出小黏。绿黏飞出不算离场。
能量：速射 8.2s（冷却 ×0.52）、散射 8.2s（左右各 +1 发）、穿甲 6.8s（弹再穿 1 个目标）、护盾（叠 2 层，挡一次碰撞）、加命。捡到 +80×倍率。绿黏吃掉能量会变大。护盾被撞碎约 1.15s 闪烁无敌。
得分：击碎 / 砸黏 / 捡能量基础分 × 连击倍率。连击为连续打中（子弹飞完未命中则窗口收到约 0.16s），1.32 秒无击杀也断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 10000 分额外一命（可超过三命）。最高分写入 playbox-blasteroids-best，不存盘面；本局超过即更新。
胜利：没有终局胜利，清波立刻进下一波并提示「第 n 波 · 加速」。残留绿黏会带到下一波。
失败：岩或绿黏打中船扣一命（护盾可挡一次）。约 1.22s 爆炸后在场心重生为战机，需周围约 72px 无岩无黏，1.85s 闪烁无敌。能量状态清空。三命（顶栏青点）扣完弹出「船碎了」。若本局刷新最高分弹层写「新纪录」。弹层打开时转向不再开打；顶栏重开与 R 随时可用。
限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、子弹不拖尾。触控时画布与虚拟键 `touch-action: none` 并 preventDefault，避免页面跟着滚。
爽感：开火枪口闪 + 三船体不同音色（快艇尖、战机中、重炮沉）；击中岩石向量碎线飞出 + 粒子爆 + 短顿帧（约 34–74ms）+ 镜头微震 + 连击数字往上窜；C 变身全屏色闪 + 残影旧船体 + 散环；绿黏被砸出汁、裂开或砸干净各有不同噪声；推进按船体喷青 / 金 / 品红火焰。
