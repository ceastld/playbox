玩法：标题页选「斜坡」或「暴走」。等距格子一次 hop 一格，先爬密林斜坡追上猩猩，再进草原过河躲犀牛和蛇，再追上一次。点「重开」或 R 开新局（标题页 R 进斜坡；局中或结算重开回当前模式第 1 轮密林）。M 静音，写入 playbox-congo-bongo-mute。

格子与跳跃：角色一次跳一格，四向等距（右上 / 右下 / 左下 / 左上）。逻辑在起跳时改目标格，约 148ms 弧线只是画。不能斜着跨两格。点当前格只挤一下。点不相邻的块无效。hop 途中（约 18%–78% 腾空）与椰子/犀牛/蛇错身不算撞，可以跳过去。落地或站着同格才判撞。

密林（第 1 屏）：8×7 斜坡，底格出生，顶两格是猩猩台。猩猩和两只猴子往下扔椰子，椰子只往山下跳，掉进水或空格会砸碎。第 4 行有一条蛇来回 hop。水格落地即死。跳下斜坡「掉下去了」。踏上猩猩台即「追上了」，猩猩跳走，切草原。

草原（第 2 屏）：9×7。岸 → 两行荷叶河 → 蛇岸 → 两行犀牛道 → 营地。每条河 3 片荷叶来回漂，必须踩上去过河（距荷叶中心超过约 0.82 格会落水）。犀牛沿行冲，腾空跃过算「跃」加分。蛇在第 4、7 行巡逻。再踏上猩猩台「抓到了」，回密林并进入下一轮（危害加快）。

得分：每次安全落地 +10×当前连跳。连跳约 1.58 秒内不落地会断。椰子砸在刚离开的格上「险跳」+30×连跳。跃过犀牛同样。追上猩猩 +500+200×(轮-1)；草原抓到再加清屏 700+200×轮。最高分按模式分记，写入 localStorage 键 playbox-congo-bongo-best，JSON `{s,r}`（斜坡 / 暴走）。本局超过即更新。

生命：3 条，顶栏绿块。被椰子砸「被椰子砸了」，被犀牛撞「被犀牛撞了」，被蛇咬「被蛇咬了」，落水「落水了」，掉下台「掉下去了」。扣命后约 0.88 秒无敌，出生格重生。三命用尽弹出「命尽」。弹层打开时方向键不再跳，顶栏重开与 R 随时可用（弹层 `pointer-events: none`，不挡重开）。

模式：斜坡按轮加速。暴走椰子更密更快、荷叶犀牛蛇都更快（约 1.4 倍）。两套最高分不共用。

操作：W / ↑ 右上 · D / → / E 右下 · S / ↓ 左下 · A / ← / Q 左上。点相邻顶面；滑动超过约 24px 按等距四向跳。触屏右下四键。标题页 Enter/空格/1 斜坡，2 暴走。R 重开，M 静音。无手柄。无自动。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、跳跃无弧。触控棋盘 `touch-action: none`，避免页面跟着滚。

爽感：每次起跳都有跳声 + 拉伸。落地必有三层：听（落地鼓，连跳音高往上爬）、看（格子回弹、尘、环、分数蹦出）、触（约 32ms 顿帧 + 镜头微踢 + 落地压扁回弹）。椰子砸中约 72ms 顿帧、碎壳、震一下。险跳/跃过金闪光。失败与重开都是一键 R。
