玩法：标题页「钢魂」。选「钢魂」打三关短推进（废岛 → 钢廊 → 核芯，关底 Boss）；选「巷战」同三关但更密更快，Boss 更厚，速度约 ×1.28。驾驶重机甲向右走跳，空格朝面向连射，连射攒热打出钢轨（穿透）。Shift / Z 冲刺：短无敌，可碾碎爬机 / 浮雷 / 炮手 / 滚刺；落地砸到小机也可碾。撞敌、吃弹、被钢轨扫到、坠井丢一条命。点顶栏「重开」或按 R：标题页进钢魂；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-gunhed-mute。弹层打开时方向键不走路、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 80 高，能上一层，不能从地面直上高层。镜头跟在机甲右前方，Boss 战时锁在关底。地面有缺口（井，约 60–80 宽，起跳可过），掉出屏幕底丢命。中高层平台可落上。机甲宽约 26、高 36。走约 180，空中约 0.92。冲刺约 0.14s、520 速，约 0.22s 无敌，冷却约 0.7s。标题页背后演示右进开火、跳井、冲刺碾压，不算分、不掉命。

钢魂三关：废岛（掘甲 24 血，地面拍震）/ 钢廊（塔卫 32 血，竖扫钢轨）/ 核芯（气门 44 血，对射 + 横扫钢轨）。过关保留命、分、连击窗口。巷战同三关，约每三只补一只，速度 ×1.28 并随关递增，Boss 血约 ×1.24。

射击：空格连射机炮，冷却约 0.088s，弹速 600，场上最多 7 发。持续开火攒热（约 1.08s 满），满了进入约 0.82s 钢轨：穿透弹、3 伤、弹速 820。顶栏「轨」条显示热量 / 钢轨窗口。击中粒子 + 约 34–74ms 顿帧。

冲刺：Shift / Z 或触屏「冲」。约 0.14s 以 520 速度突进，约 0.22s 无敌闪烁（可穿弹）。冲进爬机 / 浮雷 / 炮手 / 滚刺直接碾碎，基础分 ×2 再乘倍率，蹦「碾」。落地砸到小机同样碾。炮座 / 吊炮 / Boss 不能碾，冲刺无敌时可穿过。顶栏「冲」冷却时变暗。残影。

敌人：爬机 80 / 1 血巡逻点射；浮雷 100 / 1 血抛弹；炮手 140 / 2 血站射；滚刺 120 / 1 血见人就滚；炮座 160 / 3 血不能碾；吊炮 180 / 2 血不能碾。巷战射速间隔更短。

Boss：掘甲在关底左右走，三向点射，偶发跳起重砸（贴地范围砸死）；塔卫钉在右侧，点射或竖扫钢轨（要走位 / 冲刺穿过去）；气门走射双高炮，偶发贴地横扫钢轨。击破 Boss +3500×倍率，过关 +1500×关次×倍率。钢魂打穿再加 8000，巷战 +10000，弹「核芯捣毁了」/「巷战得手」。

得分：击杀基础分 × 连击倍率；碾压再 ×2。连击为连续命中/击杀，约 1.4 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「×N」。每 15000 分 1UP，命上限 6。最高分写入 playbox-gunhed-best，不存盘面；本局超过即更新。

失败：三命（顶栏青点）扣完弹出「撞上了 / 中弹了 / 被钢轨扫到了 / 坠入井里了 / 机甲碎了」。约 0.86s 爆炸后在最近扎实地面重生，1.18s 闪烁无敌。弹层打开时方向键不再走路；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳，空格射击，Shift / Z 冲刺。点按画布同空格按住。触屏 左 / 跳 / 射 / 右 / 冲。标题页 钢魂 / 巷战，Enter/空格/1 钢魂，2 巷战。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波。打热钢轨金青束 + 更长顿帧。击中粒子爆开 + 短顿帧（约 34–74ms）+ 镜头微震 + 连击数字往上窜。冲刺残影 + 噪声 whoosh，碾碎金爆、对半粒子、双倍分。爆炸粒子、连击 pop。失败与重开都是一键 R。

跟邻作的差：不是机甲（独立转炮 + 装甲条），不是机战（八向飞场 + 光剑），不是合金（救人开车丢雷）。钢魂是重机甲贴地推进，朝面向开火，冲刺碾压，打热出钢轨，撞击丢命。
