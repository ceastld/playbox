玩法：标题页「烈空」。选「烈空」打三关（云燃 → 炎峡 → 烈空），每关密编之后出关底王；选「炎雨」同三关但卷轴更快、编队更密、敌弹更勤、天上慢慢落炎滴弹、Boss 多约 22% 血。点顶栏「重开」或按 R：标题页直接开烈空；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-liekong-mute。←↑↓→ / WASD 八向飞，空格射击（可按住连发，击中积炎条），Shift / Z 或顶栏「桶」扔炎桶。画布拖动跟舰，按下开火。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 烈空、2 炎雨。

场地：虚拟场 480×720。舰开局 y=640、x=240，夹在 22–458 / 40–692。烈空巡航约 88（炎雨 124）；关底王在屏时降到 24。移速约 274（炎雨 318）。点射连发。未解锁音频前无声。三关名：云燃、炎峡、烈空；顶栏在 Boss 时改成「云兽 / 峡核 / 空核」。

三武：开局铳 0。运炎掉一枚循环炎核，约 0.62 秒轮一格：铳 → 翼 → 凤 → 桶。同种升到 MAX（3）；换种保留最多 2 级且至少 1 级。满级再吃同种 +500×倍率。坠机掉一枚当前武装核且火力降 1，武装种类保留。
- 铳：2/3/5/7 向扇刃，弹速 750，冷却约 0.092–0.074s
- 翼：3/3/5/7 向阔焰（可穿 2），弹速 680，冷却约 0.108–0.084s
- 凤：1–4 枚寻敌火鸟，弹速约 410，冷却约 0.142–0.106s
炎雨冷却再 ×0.88。顶栏炎条是击中积热，不是火力。

炎条 / 烈柱：击中积炎（普通约 0.046 / 关底削血约 0.018）。满则自动放出烈柱：金红火柱从舰前烧到屏顶，宽约 18+火力×4，伤约 36+火力×8/秒，顺路消敌弹，约 0.58s。柱跟舰左右缓扫。放出时炎条清空、约 50ms 顿帧、蹦「烈柱」。顶栏满核爆亮。

炎桶：开局 3 枚，上限 6。Shift / Z 清掉全部敌弹、全体扣血（普通 12 / 关底 16），并在舰前三处落下燃痕。全屏闪、金火椭圆环向上拉、约 78ms 顿帧，自身约 0.62s 无敌。过关补 1 枚。用尽再按提示「爆弹用尽」。

燃痕：击坠（非炎桶直杀关底王）在原地留一滩火，约 1.15s，半径约 26–34。每 0.08s 刮周围机体（普通约 3.4、关底 2.2，随寿命衰减）。燃杀额外 +12×倍率并蹦「燃」，再留新痕，可连锁。炎桶也会在舰前种三滩。

敌人：炎蝠 50 / 2 血、俯炎 80 / 2、云台 150 / 6（地面，可飞越只吃对空弹）、炎卫 240 / 10、运炎 280 / 8（死时掉循环炎核）、火滴 90 / 3（死时炸三发散并多留一滩）、侍翼 220 / 14（炎雨 18）。血量再乘炎雨 1.22（关底王/侍翼按上表）。炎雨 V 字 +2、俯炎 +1、火滴 +2、额外一只炎卫；射速约 0.74 倍间隔、弹速约 184（烈空 144）。炎雨另有慢落炎滴弹，约 0.55s 一发（王在屏时 0.38s）。

Boss：云兽 108 血 / r46，峡核 146 / r60，空核 214 / r86（炎雨 ×1.22 → 132 / 178 / 261）。入场约 1.45s 后缓荡。高血扇瞄+偶发环，半血密环兼瞄准，残血双环+扇瞄并吐炎蝠。两侧侍翼绕核瞄准；空核多一枚侍翼。判定约为半径 ×0.52，可从侧翼擦过。打爆后约 1.4s：前两关进下一关，烈空结算。

得分：击杀基础分 × 连击倍率。关底再加 3500+1500×关。连击为连续击杀/吃炎，约 1.4 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。过关 +1600×倍率。烈空打穿再 +8000，炎雨 +10000。每 18000 分 1UP，命上限 6。最高分写入 playbox-liekong-best，不存盘面；本局超过即更新。

胜利：烈空/炎雨打爆第 3 关空核后约 1.4s 结算「烈空尽碎」/「炎雨通关」。
失败：三命（顶栏朱红翼点）扣完弹出「舰毁了」。敌弹（判定约 4.4）或撞空中机体/关底王扣一命；云台可飞越。约 0.92s 爆炸后底部重生，1.5s 闪烁无敌，场上敌弹清空。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格射击（击中积炎），Shift / Z 炎桶。点按画布开火并跟舰。标题页 Enter/空格/1 烈空，2 炎雨。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 三武各异音色（铳升频方波 / 翼方波重拍+噪声 / 凤三角上滑）。击中粒子爆 + 短顿帧（约 34–50ms）+ 镜头微震 + 连击数字往上窜。烈柱三层：听（锯齿上冲 + 方波 + 正弦 + 噪声）、看（金红火柱、炎条爆亮、蹦「烈柱」）、触（约 50ms 顿帧 + 微震）。炎桶三层：听（噪声 rumble + 锯齿下滑）、看（金火椭圆环上拉、全屏闪、舰前三滩燃痕）、触（约 78ms 顿帧 + 强震）。燃痕连锁：听（噪声+锯齿）、看（火滩、「燃」字、新痕）、触（约 30ms 顿帧）。吃炎换武色闪。坠机洋红大爆、约 72ms 顿帧。失败与重开都是一键 R。
