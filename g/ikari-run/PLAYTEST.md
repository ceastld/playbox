玩法：标题页「怒火」。选「丛林」打三关（密林→河谷→要塞，关底 Boss）；选「强攻」敌更密、路更窄，约每 2100 世界单位一 Boss，无终局胜利。八向走，瞄准可转（指针优先，否则朝移动方向转；Q / E 空转枪口）。空格按住连射，G / Shift / F / 右键 / 触屏「弹」丢手雷。走进空坦克上车，坦克有装甲、开炮更重。徒步中弹扣一命；坦克替你扛打，甲尽坦克炸、人弹出并短暂无敌。点顶栏「重开」或按 R：标题页进丛林；对局中或结束层重开同一模式。结束层「再来」同模式；失败「换模式」回标题；通关「强攻」开强攻。M 静音，写入 playbox-ikari-run-mute。弹层打开时方向键不走路、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 480×720。世界 Y 向北增加，镜头钉在人下方约 310，可略回退。左右密林是墙，噪声生成河道式通路；强攻更窄更扭。开局路更宽。石头挡人挡弹，水洼减速约 0.58。人半径约 11（坦克 16）。徒步约 176、坦克约 118。镜头不自动滚，人往北走才推图。标题页背后演示北进，不算分、不掉血。

丛林：密林（装甲车 78 血）/ 河谷（武装直升机 108）/ 要塞（要塞司令 148）。通路上刷步兵、碉堡、敌坦克、直升机、空坦克和手雷箱。过关保留命、分、手雷、是否在车上。强攻刷距约 72（丛林约 108），碉堡和坦克更厚，开局 3 枚手雷。

坦克：空坦克走上去即上车（已在车上则补满甲）。丛林 5 甲、强攻 4 甲。炮冷却 0.28s、伤害 3、弹更大；开火镜头抖、履带嗡。甲被打光：坦克爆炸，人落地约 1.15s 无敌。

手雷：开局丛林 4 / 强攻 3，上限 9，箱 +3。出手约 0.55s 引爆或撞敌即炸，范围伤 5，适合清碉堡。碉堡约 6–8 血，步枪要打多发。

敌人：步兵追人点射 50；碉堡固守连射 160；敌坦克慢速开炮 320；直升机左右扫射 420。Boss 装甲车三向炮、直升机扫射、要塞扇弹并补兵。击坠 Boss 再加 1500×关×倍率。

得分：击杀基础分 × 连击倍率。连击为连续击杀，约 1.45 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 18000 分 1UP，命上限 6。最高分写入 playbox-ikari-run-best，不存盘面；本局超过即更新。

胜利：丛林打掉第 3 关要塞司令后约 2.15s 结算「要塞打穿了」，再加 8000。强攻无终局，Boss 炸完下一波。
失败：徒步挨弹 / 撞步兵 / 撞直升机扣一命（坦克扛打、无敌除外）。约 0.92s 爆炸后在镜头下方重生，1.45s 闪烁无敌。三命（顶栏红点）扣完弹出「被击中了 / 撞上了 / 直升机压下来了」等。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：WASD / 方向键八向走，指针瞄准（按住画布开火；没按方向键时才朝指针走），Q / E 转枪口，空格开火，G / Shift / F / 右键手雷。触屏十字键 +「射」+「弹」。标题页 丛林 / 强攻。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、坦克不履带抖、子弹不拖尾。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：开火枪口闪 + 粒子 + 音效；击中/爆炸粒子 + 30–80ms 顿帧 + 镜头微震 + 连击数字往上窜；坦克移动低频嗡、开炮顿一下并 rumble；上车金闪；手雷金爆清碉堡。
