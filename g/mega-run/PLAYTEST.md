玩法：标题页「洛克」。选「选关」挑机器人首领（电弧 / 炎心 / 霜刺，任意顺序）；全灭后自动进要塞芯核。选「要塞」直线打外廊→闸心→芯核，速度约 ×1.28 并随关递增。侧向跑跳，空格射击，按住充能（约 0.4s 中充、0.95s 满充）。血格 28，挨打扣血，扣完丢一条命。击败首领解锁对应武器（1 标准 2 电弧 3 炎心 4 霜刺）。点顶栏「重开」或按 R：标题页进选关；对局中或结束层重开同一模式。结束层「再来」同模式；失败「换模式」回标题；通关「要塞」开要塞。M 静音，写入 playbox-mega-run-mute。弹层打开时方向键不走路、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 86 高，能上一层，不能从地面直上高层。镜头跟在人右前方，Boss 战时锁在关底。地面有缺口，掉出屏幕底丢命。中高层平台可落上。↓ / S 在地面滑铲（约 0.36s、更快、Hurtbox 更矮）。人宽约 16、立高 24、滑高 12。走约 188。标题页背后演示右进开火充能，不算分、不掉血。

选关三首领：电弧（传送、横雷、三向落雷、落地冲击波）/ 炎心（弧线火弹、火焰冲刺、空中落火、地面火浪）/ 霜刺（冰滑铲、三向冰棱、落冰、慢速冰墙）。弱点三角：霜克电、电克炎、炎克霜。过关保留命、分、已夺武器与武器能量。三名全灭后进芯核。要塞三关：外廊（无 Boss，捡电弧/炎心胶囊，到尽头开闸）/ 闸心（无 Boss，捡霜刺，刺与喷火更密）/ 芯核（40 血，开闭核心、散射、横波、元素弹；要塞血约 ×1.22）。开局仍是标准弹。

武器：1 标准弹屏上约 3 发，点按即射，按住充能；中充 2 伤可穿 1，满充 4 伤可穿 2 并闪光顿帧。2 电弧落地弹跳。3 炎心抛弧火弹。4 霜刺可冻结杂兵。特殊武器耗能量（28 格），不足提示「能量不足」。5–9 提示尚未夺取。触屏「武」循环已解锁武器。

敌人：帽机开盖才受伤并点射 100；飞蝇正弦 150；炮台瞄准 200；行者巡逻 120；地刺与喷火柱伤人。Boss 5000×倍率，过关 +2500×关，夺取武器 +1200，芯核 +8000。选关打掉芯核后再加 10000，弹「芯核瓦解了」；要塞弹「要塞捣毁了」。

得分：击杀基础分 × 连击倍率。连击为连续命中或击杀，约 1.25 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))。每 20000 分 1UP，命上限 6。最高分写入 playbox-mega-run-best，不存盘面；本局超过即更新。

失败：挨弹 / 撞兵 / 喷火扣血（无敌除外）；血格打空、坠崖丢一条命。约 0.85s 爆炸后在最近扎实地面重生，1.4s 闪烁无敌，血格回满。三命扣完弹出「被击中了 / 坠入深渊了 / 触上刺了 / 被烧到了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳，↓ / S 滑铲，空格射击（按住充能）。1–4 换武器。点按画布同空格按住。触屏 左 / 跳 / 射 / 右 / 滑 / 武。标题页 选关 / 要塞，Enter/空格/1 选关，2 要塞。选关页 ← → 挑首领，空格进入，也可点肖像。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：射击枪口闪 + 粒子 + 各枪不同音色。充能身上光晕、嘀声爬升、满充闪光「充能完毕」。命中/爆炸粒子 + 30–80ms 顿帧 + 镜头微震 + 连击数字往上窜。弱点命中跳出「弱点!」。滑铲尘、落地顿。失败与重开都是一键 R。
