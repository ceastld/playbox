玩法：标题页「月巡」。选「经典」分段赛道 A–F，检查点补给，跑到 Z 巡成；选「疾驰」更快更密、无终点，距离即分。点「重开」或 R：标题页直接开经典；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-moon-run-mute。空格 / 上 / W / 触屏「跳」起跳。Z / J / X / 点按画布双炮（对空+对地，可按住连射）。触屏「射」。

场地：虚拟场 640×360。月面车钉在屏幕 x=126，地面 y=278。世界自动右滚：经典 168px/s，疾驰 248px/s 并随时间最高再加 72。跳跃初速 318、重力 920，滞空约 0.69s；经典一跳约 116px，足够过中坑，大坑要早跳。短按早放可切高重力收跳。土狼时 0.09s、跳跃缓冲 0.12s。

陨坑与石头：坑有 8px  Rim 可站，轮子掉进开口即栽坑。石头接地碰撞即炸，跳过去或对地炮打碎（高石 2 下）。植物碾过 +25，打掉更高。飞碟丢炸弹，落地会炸出新坑（避开已有坑和基地）。飞碟三种：侦察 / 轰炸机 / 俯冲，击落 200/300/400 × 连击。

得分：距离持续加分。跳过坑 +60×倍率、跳过石 +40×倍率。打碎石/植物、打飞碟、打炸弹另加。检查点 +400+150×路段，终点 +2000。连击 1.55s 无跳过/击杀则断，顶栏显示连击次数。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。最高分按模式分记，写入 localStorage 键 playbox-moon-run-best，JSON `{c,d}`。本局超过即更新。

胜利：经典通过终点基地 Z 弹出「巡成」。疾驰无终局胜利。
失败：三命（顶栏青点）扣完弹出「炸车」。栽坑、撞岩、中弹、擦机都会扣命。约 0.68s 爆炸后在最近检查点前方的实地上重生，1.35s 闪烁无敌。弹层打开时顶栏重开与 R 随时可用。

操作：空格 / ↑ / W 跳，Z 双炮。点按画布开火。触屏跳 / 射。标题页 Enter/空格/1 经典，2 疾驰。A 自动，R 重开，M 静音。无手柄。

自动（AUTOPLAY）：点「自动」或按 A 开关托管（开着时按钮呈按下态并显示「停下」）。默认关闭，开关不写入存储，刷新后关闭；重开不会关掉自动。开着时忽略空格 / 上 / W 跳、Z / J / X 射击、点按画布和触屏跳/射；A / R / M / 重开 / 速度滑条仍可用。标题页开自动会进经典；疾驰也可托管（先点「疾驰」再开自动，或托管中点「疾驰」）。炸车 / 巡成弹层时自动停手；重开且自动仍开着则新局接着托管。速度滑条 1–4 为 慢 / 中 / 快 / 极快（默认快），写入 playbox-moon-run-auto-speed。慢/中放慢时间便于看清起跳，快为实时，极快约 2.6 倍步进并跳过顿帧。AI 预扫前方陨坑与石头，在能清过的最早点起跳并按住至落地，不乱跳；双炮打飞碟、炸弹和来得及打碎的石头，能轰掉的石头就地打掉。经典和疾驰都能托管。不是完美求解，坑密或炸弹贴身时仍可能炸车。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏。触控棋盘 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开。

爽感：每次起跳都有跳声 + 尘 + 约 28ms 顿帧 + 挤压拉伸。跳过陨坑必有三层：听（音高随连击往上爬）、看（青环、金屑、分数蹦出）、触（约 50ms 顿帧 + 镜头微踢）。双炮开火有炮口闪、金/青粒子和屏幕闪一下。打飞碟约 62ms 顿帧、爆炸粒子。栽坑洋红闪、约 80ms 顿帧并震一下。连击数字往上叠。失败与重开都是一键 R。
