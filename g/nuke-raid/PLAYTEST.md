玩法：标题页「核袭」。选「核袭」打三关（废原 → 堡群 → 堆芯），关底分别是锈堡、核门、核芯；选「核雨」同三关但卷轴更快、编队更密、敌弹更勤、地上多一座堡，Boss 多约 22% 血。点顶栏「重开」或按 R：标题页直接开核袭；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题（通关核袭时该钮变成「核雨」）。M 静音，写入 playbox-nuke-raid-mute。←↑↓→ / WASD 八向飞，空格射击（可按住连发，9 链起加一路中弹），Shift / Z 或顶栏「核」丢核弹。画布拖动跟舰，按下开火。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 核袭、2 核雨。

场地：虚拟场 480×720。舰开局 y=640、x=240，夹在 22–458 / 40–692。核袭巡航约 88（核雨 124）；堡/芯在屏时降到 22。移速约 276（核雨 318）。点射连发，弹速 740，冷却约 0.095s（核雨 0.078）。未解锁音频前无声。三关名：废原、堡群、堆芯；顶栏在 Boss 时改成「锈堡 / 核门 / 核芯」。舰前约 118 像素有菱形落点，核弹飞向按下时的锁定点。

双层目标：空中（拦截、俯冲、精锐、运械、导弹）吃满伤；地上（井、堡、炮台、关底堡）对机炮有约 0.4 装甲，核弹打满。砸地和拆炮给核压。核压满条（顶栏「压」爆亮）下一发是超核：半径约 118（普核 72），地伤 28 / 空伤 12（普核 16 / 5），蘑菇云更大，残留辐射坑更久。

核弹：开局 3 枚，上限 6。Shift / Z 从舰头丢出，约 0.46s（超核 0.38s）落到菱点，蘑菇云清半径内敌弹、砸地堡、伤空中，自身约 0.28s 无敌。过关补 1 枚。运械掉「核」。用尽再按提示「核弹用尽」。辐射坑约 0.18s 跳 1 伤。一次核爆击坠 ≥3 蹦「核爆 N」。

敌人：拦截 50 / 2 血、俯冲 80 / 2、导弹 90 / 2、炮台 150 / 6、井 180 / 8、堡垒 200 / 10、精锐 240 / 10、运械 280 / 8、炮口 120、冷却棒 160、锈堡/核门 2800、核芯 4800。血量再乘核雨 1.22。核雨 V 字 +2、俯冲 +1、额外一只精锐与一座中堡。射速约 0.74 倍间隔、弹速约 188（核袭 148）。

Boss：锈堡/核门入场约 1.15s 后左右游荡。四门炮可单独打爆；打爆一门堡会顿约 0.85s 停火。打光四炮堡体血被削到约 35% 并提示「全炮」。半血起环弹，残血吐拦截。核芯四根冷却棒；棒在时芯只吃约 0.45 机炮伤。打光四棒「过热」，核弹约 1.6 倍。高血瞄准 + 偶发八环，半血十环兼瞄准，残血双环+五发散并吐机。打爆后约 1.35s 进下一关或结算。

得分：击杀基础分 × 连击倍率。连击为连续击杀/打炮/打棒/吃核，约 1.4 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。过关 +1600×倍率。核袭打穿再 +8000，核雨 +10000。每 18000 分 1UP，命上限 6。最高分写入 playbox-nuke-raid-best，不存盘面；本局超过即更新。

胜利：核袭/核雨打爆核芯后约 1.35s 结算「堆芯尽碎」/「核雨通关」。
失败：三命（顶栏朱红堡形点）扣完弹出「舰毁了」。敌弹（判定约 4.4）或撞空中机体/堡体/井/芯扣一命。约 0.92s 爆炸后底部重生，1.5s 闪烁无敌，场上敌弹清空。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格射击，Shift / Z 核弹。点按画布开火并跟舰。标题页 Enter/空格/1 核袭，2 核雨。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 双管短音。击中粒子爆 + 短顿帧（约 32–50ms）+ 镜头微震 + 连击数字往上窜。砸地另有低噪声。核弹三层：听（噪声 + 锯齿下滑 + 上滑正弦）、看（蘑菇云、辐射坑、边框闪、超核蹦字）、触（约 70–82ms 顿帧 + 强震）。核压满条爆亮。坠机洋红大爆、约 72ms 顿帧。失败与重开都是一键 R。
