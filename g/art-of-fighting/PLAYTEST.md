玩法：标题页「拳道」。选「拳道」对白隼，先赢两局（三局两胜，99 秒）；选「连打」对铁面，同样先赢两局但更快更密（70 秒、三连拳、气焰更密）。点顶栏「重开」或按 R：标题页进拳道；对局中或结束层重开同一模式第 1 局。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-art-of-fighting-mute。弹层打开时方向键不走路、空格不打（标题空格/Enter/1 开拳道，2 开连打）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 720×400。地面 Y=338。南镇夜道馆，窗透橙霓虹，气焰从地板升。人开局 x=168 对 x=552，夹在 42–678。拳道走速约 170，连打约 ×1.3。起跳约 84 高，可跃过吼拳。点按画布轻点拳，上滑跳，下滑蓄气，左右滑走。触屏底栏 左 / 跳 / 右 / 蓄 / 拳 / 踢 / 气。未解锁音频前无声。近身镜头略拉近，远离拉远。连打气焰更密更红。

对决：橙龙 100 血（连打 86）。白隼 100 血、爱放吼拳、更会蹲蓄；铁面 86 血、更快更凶、更爱踢。气槽开局即满（100），出必杀扣气，挨打再扣 8 点；打中不加气。下蹲站住蓄气（约 46/秒，连打 62/秒），蓄满金闪。空格点拳，命中后可取消成二拳；连打模式二拳命中后再取消三拳（击倒）。下+拳为扫腿（低、击倒，可跳过）。X / C / 触屏踢为踢。跳中拳或踢一次。Shift / Z 花 40 放吼拳（胸口气拳，贴胸飞，可蹲下穿过，可高跳越过）；近身花 45 放虎炮（上拳击飞，起手短暂无敌）；气满花 100 放超吼（更大更痛）。血低于 28% 时必杀气耗七折，且气 ≥50 即可超吼（绝境）。气不足出招提示「气不足」。无格挡，无换线，靠蹲过吼拳 / 跳过扫腿。踢或虎炮可把迎面吼拳踢破。

回合：体力 0 即该局负，KO 后约 1.85 秒进下一局或结算。时间到比谁血多，平局重打该局不记分。先赢 2 局赢场。同归于尽重打该局。

得分：拳 70、二拳 110、三拳 150、踢 90、跳拳 80、跳踢 100、扫腿 85、吼拳 220、虎炮 240、超吼 380，乘连打倍率。对打 50。踢破吼拳 +80。连打约 1.18 秒不断（连打模式约 1.52），倍率 = 1 + min(4, floor((连打-1)/2))，即 1–2 连 1 倍、3–4 连 2 倍，最高 5 倍。KO +1000，完美（自己满血）+2000，赢局 +400，时间胜 +600，拳道赢场 +2000，连打赢场 +2500。最高分按模式分记，写入 playbox-art-of-fighting-best，JSON `{v,l}`（拳道 / 连打）。本局超过即更新。不存盘面。

胜利：先拿 2 局后约 1.85s 结算「道胜」（连打「连尽」）。
失败：己方先被拿下 2 局弹出「道败」。弹层打开时方向键不再走；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳，↓ / S 蹲蓄，空格拳，X / C 踢，Shift / Z 吼拳。点画布拳，上滑跳，下滑蓄。标题 Enter/空格/1 拳道，2 连打。R 重开，M 静音。无手柄。与拳皇不同：不是三人队、气不是靠打涨，是开局满气、蹲蓄回气，没有 MAX。与饿狼不同：不是南镇双街换线，没有贴地波，是单层道馆 + 胸口吼拳（蹲过）+ 近身镜头。与末刃 / 侍魂不同：不是对剑，是拳踢 + 气槽蓄气。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、少气焰、不拉近镜头。触控画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：出拳必有三层——听（拳风噪声 / 踢更闷 / 命中方波随连打往上爬 / 对打金属高音 / 吼拳低啸 / 虎炮上冲 / 蓄气上行音各不一样）、看（拳光弧、火星、胸口气拳、蓄气金圈、分数蹦出、HIT 字、大字 N 打、近身拉镜）、触（拳约 38ms / 踢约 54ms / 吼拳约 64ms / 超吼约 78ms 顿帧 + 镜头微震）。蓄气金闪。KO 大字 + 倒地砸屏 + 重低音。失败与重开都是一键 R。
