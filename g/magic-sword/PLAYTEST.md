玩法：标题页「魔剑」。选「闯塔」打四层（底层→回廊→祭坛→塔巅，关底石魔 / 双首 / 骨王 / 魔龙）；选「魔潮」一潮接一潮更密，每 3 潮刷囚笼、每 4 潮出头目，无终局胜利。往右走、竖梯往上爬。空格挥长剑。劈开囚笼救出女猎或法师，同伴会自动射击直到体力打空。体力打空扣一命。点顶栏「重开」或按 R：标题页进闯塔；对局中或结束层重开同一模式第 1 层 / 第 1 潮。结束层「再来」同模式；失败「换模式」回标题；闯塔通关「魔潮」开魔潮。M 静音，写入 playbox-magic-sword-mute。A 或「自动」开关托管。弹层打开时方向键不走路、空格不斩（标题空格/Enter 开闯塔）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=320，中层 248，高层 176，间距 72；起跳约 76 高，能上一层，不能从地面直上高层。竖梯连接层：脚下踩梯口按上攀登，梯顶按下离开，梯上可左右跳下。镜头跟在人右前方，头目战时锁在关底。地面有缺口，掉出屏幕底丢命。人宽约 14、高 26。走约 152，挥剑时地面走速约 ×0.52，空中仍可改向。标题页背后演示右进挥剑爬梯，不算分、不掉血。

闯塔四层：底层（石魔 16 血，囚笼女猎，铁剑→焰剑）/ 回廊（双首 22 血，囚笼法师）/ 祭坛（骨王 26 血，召小鬼/骷髅）/ 塔巅（魔龙 32 血，飞喷火）。过关保留命、体、分、剑和同伴，补 3 点体力。头目未倒走进出口 toast「先击败头目」。魔潮同底层廊，场地宽 2000，第 n 潮人数 min(16, 5+⌊0.85n⌋)，速度约 ×(1.22×(1+0.06×(关−1)))，血量 ×(1+0.08×(n−1))。

长剑：铁剑射程 48 伤 1；焰剑 64 伤 2；魔剑 80 伤 3。捡剑升一级，已满回 3 体。挥一次约 0.20–0.24s，可边走边斩。三连第三下更远更沉（射程 +14、伤 +1、顿帧更长）。与圆桌不同：没有坐骑、没有打下马。与柳巫不同：没有法力条、没有短剑+远程魔法，是长剑横扫闯塔。

同伴：女猎 6 体射箭（伤 1）；法师 5 体射魔矢（伤 2）。自动锁近敌，约 0.70 / 0.84s 一发。挨打有约 0.85s 无敌。倒下 toast，可再劈笼换人。同时只有一名同伴。

敌人：小鬼 hop 2 血；骷髅走砍 3 血；黑骑（步行）5 血伤 2；魔蝠正弦飞 1 血；魔眼浮射 3 血。石魔砸地震波；双首双头喷火；骨王召兵；魔龙盘旋喷火。体力 12 格，顶栏条显示。挨打扣 1（骑士/魔眼/头目 2–3），0 体力丢一条命。药包回 5 体。三命（顶栏橙点）扣完弹出「倒下了 / 坠入魔塔深渊了」。约 0.80s 后在最近扎实地面重生，满体力，1.22s 闪烁无敌。每 18000 分 1UP，命上限 6。最高分写入 playbox-magic-sword-best，不存盘面；本局超过即更新。

得分：命中 40×连击倍率，击杀小鬼 120 / 骷髅 180 / 黑骑 280 / 魔蝠 140 / 魔眼 200，头目 3600 / 4200 / 4800 / 6400×倍率，过层 2000×层，清潮 500×潮，闯塔通关再加 8000，劈笼 200，药 80，剑 100，金 60。连击为连续命中，约 1.4 秒无命中则断；挨打立刻断。倍率 = 1 + min(4, floor((连击-1)/2))。

失败：体力打空 / 坠崖扣一命（无敌除外）。弹层打开时方向键不再斩；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / D 走，↑ / W 跳（梯口上楼），↓ / S 下梯，空格 / 点画布挥剑。A 为自动（不再当左移）。触屏 左 / 跳 / 右 / 斩 / 下。标题 Enter/空格闯塔，1 闯塔，2 魔潮。R 重开，M 静音。无手柄。

自动：点「自动」或按 A 开关托管（开着时按钮呈按下态并显示「停下」）。标题页开启则自动开闯塔；倒下/通关弹层仍开着则自动再开同一模式。开着时忽略方向键、W/S/D、触屏和底栏；A / R / M / 重开仍可用。开关不写入存储，刷新后关闭；重开不会关掉自动。速度滑条 1–4 为 慢 / 中 / 快 / 极快（默认快），写入 playbox-magic-sword-auto-speed，改速立刻生效。托管会往右走、跳过缺口、挥剑斩敌/头目/囚笼、爬梯换层，闯塔与魔潮都会真打，不是原地晃。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不顿帧、不抖屏、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：斩必有三层——听（铁剑脆钢 / 焰剑火啸 / 魔剑金鸣各不一样）、看（火屑、十字星芒、长剑弧光、分数蹦出）、触（约 36–78ms 顿帧 + 镜头踢）。三连第三下更沉。救出同伴金鸣。连击升档金闪、大字 ×N。失败与重开都是一键 R。
