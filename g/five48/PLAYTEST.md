玩法：点开即开局，棋盘 5×5，先出现两枚 2 或 4。用方向键 / W S D 或在棋盘上滑动，格子会滑向该方向；相同数字撞上合并成两倍。只有棋盘真的变了才会再生成一枚新砖（90% 是 2，10% 是 4）。点「重开」或 R 开新局。M 静音。A 为自动（不再当左移）。顶栏可切「经典」与「限时」，切换即重开。
胜利：任意一枚砖达到 8192，弹出「合到 8192」。点「继续」可接着合成 16384 及以上，本局不再弹出胜利层；点「重开」则新开一局。限时局里合到 8192 同样可继续冲分。自动开启时不弹胜利层，记下已到过 8192 后继续下合成。
失败：没有空格，且上下左右都没有两枚相同数字可以合并（没有合法滑动）时弹出「没有空位了」，只能「重开」。自动在失败弹层上暂停，重开后若仍开着自动会接着下新局。
限时：点「限时」为 90 秒冲分。倒计时在第一次有效滑动后开始，弹层与切走页面会暂停。时间耗尽弹出「时间到」，记下本局分数；滑动中途到点会先走完再结算。空滑不扣时。自动在「时间到」弹层上同样暂停。
合并一次：同一回合里新合成的砖不能再跟别的砖合并。例如五行 [2,2,2,2,2] 向左是 [4,4,2,0,0] 不是 [8,2,0,0,0]；[2,2,4,4,8] 向左是 [4,8,8,0,0]；[2,2,2,0,0] 向左是 [4,2,0,0,0]。分数加上新砖的面值（两枚 8 合成加 16）。空滑（棋盘不变）不生成、不计分。
限制：最高分写入 localStorage 键 playbox-five48-best，模式写入 playbox-five48-mode；不保存棋盘，刷新只保留最高分和上次模式。没有悔棋。滑动动画约 110ms，其间最多排队一次方向。系统开了减少动态时砖块直接到位，仍会短暂弹出。声音要在一次按键或滑动之后才有。触控滑动小于 24px 会忽略，避免误触。
弹层打开时方向键不移动棋盘，避免挡住「继续」「重开」；顶栏「重开」随时可用。按住方向键会按动画节奏连滑。失败 / 时间到弹层沉在棋盘下方，不遮砖。点弹层外面可收起看盘面，之后只能重开。

AUTOPLAY
自动：点「自动」或按 A 开关（开启时按钮呈按下态并显示「停下」）。开局默认关闭。AI 用五行表加速的 expectimax，按当前最大砖所在角走蛇形，朝 8192 合并，仍不是完美求解。开着时忽略玩家滑动和方向键，A / R / M / 重开与模式切换仍可用。速度滑条 1–4 为慢/中/快/极快（约 420 / 200 / 70 / 0 ms，默认快），写入 playbox-five48-auto-speed。极快时砖块直接到位、搜索更浅；慢与快搜索更深。经典 5×5 与限时 90 秒都可自动，规则不变（合一次、胜 8192）。
