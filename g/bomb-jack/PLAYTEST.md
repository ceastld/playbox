玩法：标题页选「排弹」或「连收」。单屏平台，收齐 20 枚炸弹过关。亮着的那枚按预定顺序轮转，专收亮弹才叠连收；收暗弹只得 100 分并断连。点「重开」或 R 开新局（标题页 R 进排弹；局中或结算重开回当前模式第 1 关）。M 静音，写入 playbox-bomb-jack-mute。

跳与悬停：空格 / 上 / W / 触屏「跳」起跳。起跳时按住上会更高跳。空中再按或按住跳会拍翅悬停（再跳币期间拍翅更猛）。下 / S 空中快落。碰到鸟或木乃伊丢一条命。

炸弹：每关 20 枚，顺序固定，未收的第一枚永远是亮的。亮弹 200 起跳，连收越高越贵（封顶 900）。暗弹 100 并清连。收齐过关；连收 16/17/18/19/20 枚有 5千 / 1万 / 2万 / 3万 / 5万 清关奖。最高分按模式分记，写入 localStorage 键 playbox-bomb-jack-best，JSON `{s,r}`。本局超过即更新。

能力币：每收 8 枚出现一枚，冻 / 跳轮流。冻：敌人约 5.2 秒不能伤人。跳：约 7.4 秒拍翅更强。碰到敌人（非冻结、非无敌）扣命，约 0.7 秒后在出生点重生并短暂无敌；三命用尽弹出「命尽」。

模式：排弹按关卡换六种平台（殿、柱、阶、环、塔、空）循环，敌人随关加快。连收鸟更多更快，木乃伊也略快。两套最高分不共用。

操作：← → / D 走（A 为自动，不再当左移），↑ / W / 空格跳（空中再按悬停），↓ / S 快落。触屏左 / 下 / 跳 / 右。标题页 Enter/空格/1 排弹，2 连收。R 重开，M 静音。无手柄。

自动（AUTOPLAY）：点「自动」或按 A 开关托管（开着时按钮呈按下态并显示「停下」）。默认关闭，开关不写入存储，刷新后关闭；重开不会关掉自动。开着时忽略方向键、W/S/D、空格和触屏底栏；A / R / M / 重开仍可用。标题页开自动会进排弹；连收也可托管（先点「连收」再开自动，或托管中点「连收」）。命尽弹层「命尽」时自动停手；重开且自动仍开着则新局接着托管。速度滑条 1–4 为 慢 / 中 / 快 / 极快（默认快），写入 playbox-bomb-jack-auto-speed。慢/中放慢时间便于看清路线，快为实时，极快约 3 倍步进并跳过顿帧。AI 朝当前亮弹飞，近处能力币会顺手捡，敌人贴身就跳开或拍翅。不是完美求解，鸟密时仍可能撞上。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏。触控棋盘 `touch-action: none`，避免页面跟着滚。弹层打开时顶栏重开与 R 随时可用。

爽感：每次起跳都有跳声 + 尘 + 约 28ms 顿帧。收亮弹必有三层：听（音高随连收往上爬）、看（金屑、火环、分数蹦出、连收闪屏）、触（约 45–60ms 顿帧 + 镜头微踢）。收暗弹闷响。能力币约 70ms 顿帧并爆青/金屑。撞敌洋红闪、约 75ms 顿帧并震一下。连收 5/10/15/20 数字往上叠。失败与重开都是一键 R。
