玩法：标题页「魂斗2」。选「魂斗2」打两段侧向钢巷 / 坠廊，第三关锁镜打核门；选「魂核」敌更密更快，坠物更密，核门更厚，速度约 ×1.28。侧向跑跳，八向瞄准开火（空格按住连射）。中弹、撞兵、坠井或被坠物砸中立刻丢一命。点顶栏「重开」或按 R：标题页进魂斗2；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「魂核」开魂核。M 静音，写入 playbox-contra2-mute。弹层打开时方向键不走路、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 86 高，能上一层，不能从地面直上高层。镜头跟人右前方，核门战时锁在关底。地面有缺口（井），掉出屏幕底丢命。中高层平台可落上，蹲下不掉穿。人宽约 14、立高 26、蹲高 14。走约 224，空中约 0.9。标题页背后演示右进开火，不算分、不掉血。

魂斗2 三关：钢巷（巷战坠板 + 散弹荚）/ 坠廊（钢梁坠砸 + 激光荚，透视廊）/ 核门（短突进后锁镜，核门 44 血，关底坠板）。过关保留命、分、当前枪。魂核同三关，速度 ×1.28 并随关递增，额外补兵与坠物，核门血约 ×1.24，开局仍是步枪。

武器：默认步枪 0.15s 一发、屏上约 4 发。S 散弹五向扇。L 激光穿敌。空中八向；落地按住空格+上可立定上射（跳是独立键，不上跳）；蹲下只打左右。死亡重生变回步枪。

敌人 / 机关：巷卫巡逻点射 100；冲兵冲脸 150；窗狙三向 200；坠翼抛弹 200；钢巢转向连射 250；荚 300，击破掉 S/L。坠板 / 钢梁 / 坠机从顶砸下，砸中即撞击丢命。核门三向炮 + 关底坠板，残血加环弹；魂核再加扇面。击破核门再加 5000×倍率，过关 +2000×关。魂斗2 打掉核门后再加 8000，弹「核门拆了」；魂核弹「魂核清场」。

得分：击杀基础分 × 连击倍率。连击为连续击杀，约 1.32 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 16000 分 1UP，命上限 6。最高分写入 playbox-contra2-best，不存盘面；本局超过即更新。

失败：挨弹 / 撞兵 / 坠井 / 被坠物砸扁立刻丢一命（无敌除外，坠井强制）。约 0.82s 爆炸后在最近扎实地面重生，1.2s 闪烁无敌，枪变回步枪。三命（顶栏橙点）扣完弹出「被击中了 / 中弹了 / 坠入井里了 / 撞上了 / 被砸扁了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 上瞄，↓ / S 蹲，Shift / Z 跳，空格开火。点按画布同空格按住。触屏 左 / 跳 / 射 / 右 / 蹲。标题页 魂斗2 / 魂核，Enter/空格/1 魂斗2，2 魂核。R 重开，M 静音。无手柄。

与魂斗不同：不是密林捡 M/S/L/F，跳不是上键，是独立 Shift/Z，场地是钢巷坠廊核门，有坠物砸扁。与超魂不同：不是体力条、不是坞廊压机/刺带/连装炮。与合金不同：没有坦克、手雷、人质。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：开火枪口闪 + 粒子 + 步枪/散弹/激光各一音色。击杀/爆炸粒子 + 30–80ms 顿帧 + 镜头微震 + 连击数字往上窜。坠物砸地重震。核门崩开金爆。失败与重开都是一键 R。
