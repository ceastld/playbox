玩法：空格 / J / F / K / 点击 / 触屏在拍点出刀。粉菱必须砍，青色空圈必须收刃；砍在空拍或漏掉粉点都会折刃。
胜利：撑完整段 128 拍、八段一曲（听拍 88 → 连斩 96 → 起式 104 → 交错 112 → 收刃 122 → 密斩 132 → 空陷 140 → 终式 152），刃未折尽即胜。
失败：刃裂三次（空拍出刀、失拍）。拍外挥刀只断连击。R 或「重开」再来。
操作：空格/回车开局与出刀，M 静音，R 重开。听前奏四拍再下手。
限制：无手柄；切走页面会暂停拍钟；点到顶栏按钮不会出刀。声音需一次手势后才有。后段判定窗从 138ms 收到 68ms。空陷段连续空拍最容易误斩；终式收四连斩。
什么变难：前两段教交替与连斩收刃；中段保留原曲三种节奏；密斩几乎全是粉菱，空陷突然连空，终式又快又窄。三命要撑过 128 拍。
