玩法：标题页「阿历」。选「阿历」打三关（圣山→碧湖→王岛，尽头猜拳头目）；选「历核」敌人更密更快、猜拳窗更短、头目血更多，开局带一段星拳。侧向走跳，空格出拳砸星砖。撞敌即丢命。点顶栏「重开」或按 R：标题页进阿历；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「历核」开历核。M 静音，写入 playbox-alex-kidd-mute。弹层打开时方向键不走路、空格不出拳（空格/Enter 在标题开阿历、结束层再来）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=320，中层 248，高层 176，间距 72；起跳约 86 高，能上一层，不能从地面直上高层。镜头跟在人右前方，高层略上抬。地面有缺口，掉出屏幕底丢命。中高层平台可单向落（↓ / S 掉落），地面不能掉穿。头目激活后镜头锁在关尾，人被关在约 520 宽的擂台。

三关：圣山（石灵 8 血）/ 碧湖（剪灵 12 血）/ 王岛（猜拳王 16 血）。过关保留命、分、金、星拳剩余。历核同三关，移速约 ×1.28，额外补兵，头目血约 ×1.28，猜拳窗 0.95 秒（阿历 1.4 秒），开局星拳约 4.4 秒。

出拳：空格 / 点画布 / 触屏「拳」。持续约 0.15 秒，冷却约 0.22 秒（星拳略快）。拳距 32。出拳期间身体不挨打。拳中星砖爆金袋 / 饭团 1UP / 星拳 / 空砖加分，或钻出灵。星拳开启后每次出拳再飞出拳星，可砸砖、打敌、打头目。

星砖：金=1 金+280×倍率；饭=1UP+800×；星=星拳 8 秒+400×；灵=放出追人灵；空=60×。砸砖把检查点记在砖处。

敌人：刺球巡逻；海鸟正弦飞；跳鱼从水坑跃出；灵会追人。一律一拳打死。身体碰上（无出拳、无无敌）丢命。没有踩头，没有商店，没有滑板/摩托，体力不饿。

头目：进入擂台后猜拳对打。石灵冲拳（跳过）；剪灵丢剪弹（出拳弹回可打头目）；猜拳王冲拳、剪弹、落地布浪（跳过）。每隔数次攻击进入猜拳：左/1 石，下/空格/2 剪，右/3 布；触屏左石 / 拳剪 / 右布，点画布左中右三等分。赢则头目眩晕约 2.05 秒并扣 2 血，可连殴；平手重猜；输或超时丢命。眩晕中出拳每次 1 血。击破再加 5000×倍率，过关 +1800×层。打完王岛再加 8000（历核 16000），弹「圣山打通」或「历核打穿」。

得分：砸砖/击杀/弹回/猜拳胜基础分 × 连击倍率。连击为连续砸砖、击杀、弹回或猜拳胜，约 1.32 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))。每 12000 分 1UP，命上限 6。最高分写入 playbox-alex-kidd-best，不存盘面；本局超过即更新。

失败：挨打 / 中弹或布浪 / 坠崖 / 猜拳输或超时扣一命（无敌与出拳帧除外）。约 0.82s 后在最近砸砖处（或关首）重生，1.4s 闪烁无敌。三命扣完弹出「被揍到了 / 掉下去了 / 猜拳输了」。弹层打开时方向键不再出拳；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W / Z 跳（空格不跳），↓ / S 从平台掉落，空格出拳。点按画布同出拳。触屏左 / 跳 / 拳 / 右。标题页 阿历 / 历核，Enter/空格/1 阿历，2 历核。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：出拳必有挥拳音 + 拳风。砸砖/打中必有三层——听（噪声+方波下扫，连击升调）、看（金屑爆开、分数蹦出、星砖挤扁）、触（砸砖约 55ms / 出拳约 32ms / 飞拳约 50ms / 猜拳胜约 75ms 顿帧 + 镜头微踢）。星拳周身金环、飞拳爆星。猜拳倒计时环、三手印弹出。头目倒下全屏金闪。连击数字往上叠。失败与重开都是一键 R。
