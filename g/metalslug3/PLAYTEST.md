玩法：标题页「金弹3」。选「金弹3」打两段侧向沙墓 / 沼岸（各有分路），第三关雪谷锁镜打木星坦；选「弹核」敌更密更快，铁蛞更挤，木星坦更厚，速度约 ×1.26。侧向跑跳，空格开火，Shift / Z 丢手雷。撞兵、中弹、坠坑或载具撞毁立刻丢一命。点顶栏「重开」或按 R：标题页进金弹3；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「弹核」开弹核。M 静音，写入 playbox-metalslug3-mute。弹层打开时方向键不走路、空格不开火、Shift 不丢雷；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；陵道 / 潜道地板 y=400。起跳约 86 高，能上一层，不能从地面直上高层；从陵道可跳回地面汇合。镜头跟人右前方，并随下路下移；木星坦战时锁在关底。地面有缺口，掉出下层底丢命。走过缺口上方平台走沙道 / 沼岸，掉进缺口走陵道 / 潜道。人宽约 14、立高 26、蹲高 14；铁蛞更宽约 44。走约 224，铁蛞约 168，空中约 0.9，潜道游约 138。标题页背后演示右进开火，不算分、不掉血。

金弹3 三关：沙墓（金字塔分沙道 / 陵道 + 铁蛞，捡机枪 / 散弹）/ 沼岸（沼泽分沼岸 / 潜道，潜道可游，捡散弹 / 机枪）/ 雪谷（短突进后锁镜，木星坦 56 血）。过关保留命、分、手雷、当前枪；载具不带过关。弹核同三关，速度 ×1.26 并随关递增，额外补兵，木星坦血约 ×1.24，开局仍是手枪、手雷 6 枚（金弹3 8 枚）。

武器：默认手枪 0.15s 一发、屏上约 4 发。H 机枪更快更密。S 散弹三向近距，伤 2。手雷弧线，落地或碰敌约 0.62s 内引爆，范围伤 3，上限 20。铁蛞双炮，伤 2 可穿。死亡重生变回手枪，掉下载具。

载具：走过空铁蛞即上车。铁蛞跳更沉、炮管双伤可穿。载具没有装甲：中弹、撞兵立刻撞毁丢一命（无敌除外）。潜道里铁蛞更沉，↑↓ 仍可游。

分路：沙墓在叉口（约 x=820）走上方平台是沙道（沙兵），掉进缺口是陵道（木乃伊）。沼岸走上方是沼岸（尸兵 / 蛙），掉进水是潜道（蟹，↑↓ 游）。HUD 显示当前路名。两条路在关尾汇合。雪谷不分路。

敌人：沙兵巡逻点射 100；刀兵冲脸 150；沙炮转向 250；迫击抛弹 200；飞翼俯冲弹 200；蛙兵跳砸 150；卡车横撞 250（撞上丢命）；木箱 80，打破掉手雷 / H / S。木乃伊抛绷带 180；尸兵扑脸 160；蟹兵水里夹射 140；雪人冲脸抛冰 220。木星坦高低炮 + 履带弹，残血放环弹与地雷；弹核更密。击破木星坦再加 5000×倍率，过关 +2000×关。金弹3 打掉木星坦后再加 8000，弹「木星坦拆了」；弹核弹「弹核清场」。

得分：击杀基础分 × 连击倍率。连击为连续击杀，约 1.35 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 15000 分 1UP，命上限 6。最高分写入 playbox-metalslug3-best，不存盘面；本局超过即更新。

失败：挨弹 / 撞兵 / 撞卡车 / 载具撞毁 / 坠坑立刻丢一命（无敌除外，坠坑强制）。约 0.82s 爆炸后在最近扎实地面重生，1.2s 闪烁无敌，枪变回手枪，掉下载具。三命（顶栏橙点）扣完弹出「被击中了 / 中弹了 / 坠入坑里了 / 撞上了 / 载具撞毁了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳（潜道则升），↓ / S 蹲（潜道则潜），空格开火，Shift / Z 手雷。点按画布同空格按住。触屏 左 / 跳 / 射 / 右 / 蹲 / 雷。标题页 金弹3 / 弹核，Enter/空格/1 金弹3，2 弹核。R 重开，M 静音。无手柄。

与金弹不同：没有骆驼 / 飞艇，载具是铁蛞；关卡是沙墓 / 沼岸 / 雪谷，有分路和潜道游泳；枪是机枪 / 散弹不是喷火 / 铁蜥；头目是木星坦不是铁甲。与合金不同：没有体力条，坦克不会弹出保命；载具撞毁直接丢命；手雷是 Shift/Z 不是 C；没有人质。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 手枪 / 机枪 / 散弹 / 铁蛞炮各一音色。击杀 / 爆炸粒子 + 30–80ms 顿帧 + 镜头微震 + 连击数字往上窜。入水溅起。载具撞毁大爆。木星坦崩开金爆。失败与重开都是一键 R。
