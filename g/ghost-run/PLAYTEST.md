玩法：标题页「魔界」。选「墓地」打三关（墓地→沼泽→魔城，关底 Boss）；选「赤月」敌更快更密，开局没有铠甲，重生也不给甲。侧向跑跳（跳弧在空中锁死方向），空格丢枪。铠甲第一下打碎，内裤再挨一下丢命。点顶栏「重开」或按 R：标题页进墓地；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「赤月」开赤月。M 静音，写入 playbox-ghost-run-mute。弹层打开时方向键不走路、空格不丢枪；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 86 高，能上一层，不能从地面直上高层。跳弧锁定：起跳瞬间记下左右，空中不能改方向。镜头跟在人右前方，Boss 战时锁在关底。地面有缺口，掉出屏幕底丢命。中高层平台可单向落（↓ / S 掉落）。人宽约 14、立高 26、蹲高 14。走约 210。标题页背后演示右进丢枪，不算分、不掉血。

墓地三关：墓地（墓王 28 血，墓碑刷尸、蝙蝠、赤弓）/ 沼泽（赤翼 36 血，喷火藤、两只赤弓）/ 魔城（魔神 48 血，赤弓更勤，残血召蝠）。过关保留命、分、当前枪与铠甲状态。赤月同三关，速度 ×1.32 并随关递增，额外补兵（墓碑与赤弓不加倍），Boss 血约 ×1.22，开局内裤，第一件铠甲箱跳过。

武器：默认长枪 0.20s、屏上 2 发、直线。短匕 0.11s、屏上 3 发、更快。火焰抛弧，落地燃池约 1.35s、单发 2 伤。战斧抛弧、穿敌约 3 次、2 伤。空中仍按面朝方向丢；蹲下枪口更低。死亡重生保留当前枪。

敌人：墓碑定时刷尸（可砸，80）；僵尸走脸 100；蝙蝠正弦飞 150；喷火藤吐弹 200；赤弓飞扑吐火 500。Boss 墓王三向骨、赤翼洒火、魔神三向焰（残血召蝠）。击破 Boss 再加 4000×倍率，过关 +2000×关。墓地打掉魔神后再加 8000，弹「魔城已破」；赤月弹「赤月熄了」。

铠甲：墓地开局有甲，第一下碎甲（银屑、约 72ms 顿帧、镜头踢、提示「铠甲碎了」），内裤再挨一下丢命。可捡「甲」重新着装。墓地重生给回铠甲；赤月重生仍是内裤。无敌闪约 1.45s（赤月 1.05s）。

得分：击杀基础分 × 连击倍率。连击为连续击杀，约 1.4 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 15000 分 1UP，命上限 6。最高分写入 playbox-ghost-run-best，不存盘面；本局超过即更新。

失败：挨弹 / 撞兵 / 坠渊扣一命（无敌除外；有甲时先碎甲）。约 0.82s 后在最近扎实地面重生。三命（顶栏红点）扣完弹出「被击中了 / 坠入深渊了 / 撞上了」。弹层打开时方向键不再丢枪；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳（空格不跳），↓ / S 蹲或从平台掉落，空格丢枪。点按画布同空格。触屏 左 / 跳 / 投 / 右 / 蹲。标题页 墓地 / 赤月，Enter/空格/1 墓地，2 赤月。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：丢枪枪口闪 + 各枪不同音色。碎甲必有三层——听（金属噪+下扫）、看（银甲碎片飞散、全屏闪、toast）、触（约 72ms 顿帧 + 镜头踢）。换枪金鸣三音、全屏闪、HUD 闪。击杀粒子 + 30–80ms 顿帧 + 连击数字往上窜。失败与重开都是一键 R。
