玩法：标题页「突袭」。选「突袭」打三关短推进（雪营 → 港闸 → 核库，关底 Boss）；选「夜袭营」同三关但更密更快，Boss 更厚，速度约 ×1.26。徒步向右跑跳刺刀，贴身近处优先军刀。地上捡喷火 / 火箭 / 霰弹，各 3 发打完回军刀。撞敌、中弹、被喷、坠缺口都丢一条命。点顶栏「重开」或按 R：标题页进突袭；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-rush-n-attack-mute。弹层打开时方向键不走路、空格不刺；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 80 高，能上一层，不能从地面直上高层。镜头跟在人朝向一侧，Boss 战时锁在关底。地面有缺口（约 70 宽，起跳可过），掉出屏幕底丢命。中高层平台可落上，不能按下降落穿台。人宽约 14、立高 26、蹲高 16。走约 218，蹲走约 0.62，空中约 0.9。标题页背后演示右进刺刀、跳缺口，不算分、不掉命。

突袭三关：雪营（营门 24 血，钉右侧三向点射，蹲可过平弹，残血抛弹）/ 港闸（趸闸 34 血，走射双弹，偶发起跳）/ 核库（库司 46 血，扇射三弹，残血抛弹并招跳兵）。过关保留命、分、连击窗口、当前枪和弹药。夜袭营同三关，约每三只补一只（机枪巢 / 枪械不补），速度 ×1.26 并随关递增，Boss 血约 ×1.22，侧翼刷新更快。

攻击：空格近处优先军刀一击，远处有弹药才开火。方向 / WASD 走；↓ / S 蹲（迫击抛弹和部分平射可蹲过）。跳是 Shift / Z，和走分开，可立定起跳。军刀约 0.2s 一刀，弧长约 46。喷火 3 发短柱、可穿 1，约 0.2s；火箭 3 发爆炸范围伤，约 0.36s；霰弹 3 发、一次三粒。点按画布同空格。击中粒子 + 约 36–70ms 顿帧。军刀还能削掉迎面敌弹。

武器：开局军刀无限近斩。地上捡喷火 3 / 火箭 3 / 霰弹 3。换种替换。打空变回军刀，弹「军刀」。过关带着枪走，死亡重生变回军刀。

敌人：步兵 80 / 1 血巡逻；冲兵 120 / 1 血见人冲脸；跳兵 110 / 1 血近处起跳扑；军犬 150 / 1 血贴地冲（蹲也躲不过）；迫击 200 / 1 血抛弧（蹲可过）；机枪巢 180 / 2 血站射；喷火兵 160 / 2 血近距喷柱。夜袭营射速间隔更短，背后会补跳兵 / 军犬。

Boss：营门钉在关底右侧三向点射，平弹可蹲过，残血抛弧弹；趸闸左右走双弹，偶发起跳；库司扇射，半血抛弹并招跳兵。击破 Boss +3600×倍率，过关 +1400×关次×倍率。突袭打穿再加 8000，夜袭营 +10000，弹「核库捣毁了」/「夜袭营得手」。

得分：击杀基础分 × 连击倍率。连击为连续命中/击杀，约 1.4 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。2 连起蹦「×N」，升档时再顿一帧。每 15000 分 1UP，命上限 6。最高分写入 playbox-rush-n-attack-best，不存盘面；本局超过即更新。

失败：三命（顶栏绿点）扣完弹出「撞上了 / 中弹了 / 被喷到了 / 坠入缺口了」。约 0.86s 爆炸后在最近扎实地面重生，1.2s 闪烁无敌，枪变回军刀。弹层打开时方向键不再走路；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↓ / S 蹲，空格刺或射，Shift / Z 跳。点按画布同空格。触屏 左 / 跳 / 刺 / 右 / 蹲。标题页 突袭 / 夜袭营，Enter/空格/1 突袭，2 夜袭营。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：军刀金弧 + 刀风噪声 + 下扫锯齿 + 约 56ms 顿帧。喷火橙柱咆哮。火箭爆开全屏闪、约 70ms 顿帧。霰弹三粒枪口闪。击中粒子爆开 + 镜头微震 + 连击数字往上窜。捡枪金鸣三音。失败与重开都是一键 R。

跟邻作的差：不是绿兵（正面两格体力、背后偷袭、↑ 跳、Z 刺、四营只有狱长）。不是雷狐（空翻碾、玻璃、贴身没翻就撞死）。不是佣兵（纵版、手雷越碉、救人补雷）。不是枪力（夺空机甲、机甲碾兵、装甲打空撞毁）。突袭是军刀为本、三发枪、独立跳键、蹲过抛弹，撞上就丢命，三关各有关底。
