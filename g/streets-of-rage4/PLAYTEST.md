玩法：标题页「怒四」。选「怒四」打三关（画廊→夜港→罪殿，罪殿尽头是罪主）；选「怒核」同三关但每包更密、更快、更肉。沿街带状走（左右推进、上下换深度），空格出拳三连，末击把人打浮空，空中再打可连浮；双击左/右星冲打飞，Shift / Z 星砸（耗星能，跃起砸地，浮空的人会被砸落并溅射）。没有跳、不捡铁管飞刀、没有抓投。体力打空扣一命。点顶栏「重开」或按 R：标题页进怒四；对局中或结束层重开同一模式。结束层「再来」同模式；失败「换模式」回标题；通关「怒核」开怒核。M 静音，写入 playbox-streets-of-rage4-mute。弹层打开时方向键不走路、空格不出拳；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。可走带宽 y=222–322。镜头跟在人右前方，遇兵和 Boss 锁在当前段。人约 16 宽 30 高，走约 192，纵深约 122。标题页背后演示右进出拳、星冲打飞和星砸，不算分、不掉血。

怒四三关：画廊（画鬼 180 血，街痞/星刃，烤鸡与星能）/ 夜港（夜鲨 240 血，摩托/铁臂更多）/ 罪殿（罪主 330 血，会开枪并叫打手）。过关保留命、分、星能和体力。怒核同街景，每包多 1～2 人，敌速约 ×1.12，血量约 ×1.16。

出拳：空格三连（直→直→上勾），第 3 击打浮空。浮空的人还能再打，每次上抛衰减，墙会弹回来加连击。星冲：0.24 秒内同向连点左或右（触屏「冲」），约 0.22 秒冲刺、无敌、打飞路径上的人、打掉星镖，冷却约 0.72 秒。星砸耗 1 星（上限 3，开局 2，打中回星），跃起砸地半径清场，浮空的人被砸落并溅射近邻，星砸中无敌。星刃星镖用上下换深度躲开，星冲/星砸也可拆镖。

敌人：街痞近打；星刃远掷星镖；铁臂重拳、较难打飞；摩托冲撞。Boss 画鬼掷星压场、夜鲨冲撞、罪主开枪并叫打手。击破 Boss 再加 4400/5600/9600×倍率，过关 +2000×关。怒四打掉罪主后再加 8000，弹「罪殿清了」。

得分：击杀基础分 × 连击倍率。连击为连续打中，约 1.55 秒无打中则断。倍率 = 1 + min(4, floor(连击/3))，即 1–2 连 1 倍、3–5 连 2 倍，最高 5 倍。每 20000 分 1UP，命上限 6。最高分写入 playbox-streets-of-rage4-best，不存盘面；本局超过即更新。

失败：挨打扣体力（无敌、星冲与星砸除外）。体力 0 扣一命。约 0.8s 倒地后原地满血重生，1.35s 闪烁无敌。三命（顶栏红点）扣完弹出「被打倒了 / 血空了 / 被摩托撞了 / 被街痞打中了 / 中星镖了 / 中弹了」等。弹层打开时方向键不再出拳；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → ↑ ↓ / WASD 走（上下换深度），空格 / J 出拳，Shift / Z / K 星砸，同向连点方向或 X / C / 触屏「冲」星冲。点画布同出拳。触屏 上 / 下 / 左 / 右 / 拳 / 砸 / 冲。标题页 怒四 / 怒核，Enter/空格/1 怒四，2 怒核。R 重开，M 静音。无手柄。与怒二不同：没有升龙、没有抓投甩人，核心是浮空连打和星砸砸地，关卡是画廊/夜港/罪殿不是闹市/铁桥/罪巢。与怒三不同：没有电旋，星冲是打飞不是穿场无敌拆等离子，机兵换成星刃。与终斗不同：没有抱住膝撞砸地、没有旋扫，不是香港/巴黎/罗马。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：出拳挥拳风声。打中：撞击音 + 粒子/火花 + 分数蹦出 + 约 40–72ms 顿帧（上勾/浮空更长，星砸约 80ms，星冲约 56ms）+ 镜头微震。连击数字往上窜，倍率跳时全屏 ×N。星冲：金青残影、打飞、拆镖。星砸：跃起金星爆光、砸地爆屑、溅射、全屏闪、震。浮空撞墙爆屑再弹。击破金星爆。失败与重开都是一键 R。
