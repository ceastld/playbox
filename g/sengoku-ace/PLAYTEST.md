玩法：标题页「战国」。选「空战」打三关（秋野 → 云寺 → 鬼门），每关中 Boss 与关底 Boss；选「乱世」同三关但卷轴更快、编队更密、敌弹更勤、Boss 多约 22% 血、额外补波。点顶栏「重开」或按 R：标题页直接开空战；对局中或结束层重开同一模式。结束层「再来」同模式；舰毁「换模式」回标题；通关「乱世」开乱世（乱世通关则「换模式」回标题）。M 静音，写入 playbox-sengoku-ace-mute。方向键 / WASD 八向飞，空格机炮（可按住连射），Shift / Z 或顶栏「斩」放天斩爆弹。画布拖动跟机，按下开火。触屏右下「斩」放天斩。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 空战、2 乱世。

场地：虚拟场 480×720。机开局 y=630、x=240，夹在 22–458 / 40–692。空战巡航约 86（关卡与连击再加），乱世约 118；中/关底 Boss 在屏时降到约 26–34。移速约 276（乱世 318）再加火力等级。点按或按住空格开火。未解锁音频前无声。双翼机螺旋桨自转。

火力：开局 0 级双发金刃，冷却约 0.112s。吃菱形「刃」胶囊升到 MAX（3）：1 三向 0.098s、2 五向 0.084s、MAX 七向 0.070s。满级再吃 +500×倍率。运刃循环掉 刃/刃/斩。坠机掉一枚「刃」且火力归零，天斩保留。顶栏刃条跟等级走，MAX 时爆亮。

天斩：开局 3 枚，上限 6。Shift / Z 清掉全部敌弹、全体扣血，金刃从顶劈下约 0.72s 继续刮伤，全屏闪、金环、约 78ms 顿帧，自身约 0.52s 无敌。过关补 1 枚。用尽再按提示「天斩用尽」。

关卡：第 1 关秋野中 Boss「石犬」40 血、关底「秋城」96；第 2 关云寺「殿舆」54 / 「云殿」128；第 3 关鬼门「鬼鼓」68 / 「天狗王」172。乱世血量 ×1.22。中 Boss 在场时波次计时暂停。编队纸鹤、侧翼切入、俯冲忍鸢、天狗、鬼机、鸟居（地面可飞越只吃对空弹）、灯笼、运刃。秋城扇扫；云殿旋转弹幕；天狗王双环弹+瞄准。空中机体相撞扣命。

得分：击杀基础分 × 连击倍率。鹤 50、鸢 100、天狗 120、鬼机 200、鸟居 150、灯笼 80、运刃 300、中 Boss 2000、关底 4000+1500×关。连击为连续击杀，约 1.42 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。击坠关底再加 1500×关。三关打穿 +8000（乱世 +10000）并「乱世尽破」。每 20000 分 1UP，命上限 6。最高分写入 playbox-sengoku-ace-best，不存盘面；本局超过即更新。

胜利：空战/乱世打掉第 3 关天狗王后约 2.05s 结算胜利。
失败：敌弹碰到自己，或空中机体相撞，扣一命（重生无敌与天斩期间除外）。约 0.95s 爆炸后重生，1.55s 闪烁无敌，场上敌弹清空。三命（顶栏橙菱点）扣完弹出「机毁了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格机炮，Shift / Z 天斩。点按画布开火并跟机。标题页 Enter/空格/1 空战，2 乱世。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾、螺旋桨不夸张。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波（火力越高越厚）。击中粒子爆开 + 短顿帧（约 34–72ms）+ 镜头微震 + 连击数字往上窜。天斩三层：听（噪声 + 低锯齿 rumble + 上滑正弦）、看（金刃劈下、金环、边框闪）、触（约 78ms 顿帧 + 强震）。吃刃金闪。满级「MAX」蹦字。坠机洋红大爆、约 72ms 顿帧。失败与重开都是一键 R。
