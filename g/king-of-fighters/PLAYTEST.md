玩法：标题页「拳皇」。选「拳皇」对紫牙，先赢两局（三局两胜，99 秒）；选「连打」对迅风，同样先赢两局但更快更密（70 秒、三连拳、金紫屑更密）。点顶栏「重开」或按 R：标题页进拳皇；对局中或结束层重开同一模式第 1 局。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-king-of-fighters-mute。弹层打开时方向键不走路、空格不打（标题空格/Enter/1 开拳皇，2 开连打）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 720×400。地面 Y=338。夜擂台金绳，观众席在后。人开局 x=168 对 x=552，夹在 42–678。拳皇走速约 172，连打约 ×1.28。轻点上为小跳约 46 高（躲不过气功弹），按住上为高跳约 85 高（跃过气功弹）。点按画布轻点拳，上滑跳（短按小跳），下滑蹲，左右滑走，连点同向突进。触屏底栏 左 / 跳 / 右 / 蹲 / 拳 / 踢 / MAX。未解锁音频前无声。连打金紫屑更密。

对决：炎王 100 血（连打 86）。紫牙 100 血、爱放气功、更会开 MAX；迅风 86 血、更快更凶、更爱突进踢。空格点拳，命中后可取消成二拳；连打模式二拳命中后再取消三拳（击倒）。Shift / Z 踢。下+踢为突进踢（前冲中段、击倒，气功弹会被突进踢撞碎）。跳中拳或踢一次。双击左右短突进。气 0–100，下+拳花 35 放气功弹（贴胸口飞，不贴地；可蹲下穿过，可高跳越过，小跳会被打中）。气满花 100 放三连炎（近身三段，末段击倒）。气 ≥50 时拳+踢（或触屏 MAX / X）开 MAX 约 3.6 秒：金气、走得更快、命中后可取消成气功/突进/超炎；MAX 中下+拳直接三连炎并结束 MAX。气不足出招提示「气不足」。无格挡，无换线，靠小跳 / 高跳 / 蹲过气功。

回合：体力 0 即该局负，KO 后约 1.85 秒进下一局或结算。时间到比谁血多，平局重打该局不记分。先赢 2 局赢场。同归于尽重打该局。

得分：拳 70、二拳 110、三拳 150、踢 95、跳拳 80、跳踢 100、下拳 60、突进 120、气功 180、三连炎每段 140，乘连打倍率。对打 50。蹲过对手气功弹 +80。连打约 1.18 秒不断（连打模式约 1.52），倍率 = 1 + min(4, floor((连打-1)/2))，即 1–2 连 1 倍、3–4 连 2 倍，最高 5 倍。KO +1000，完美（自己满血）+2000，赢局 +400，时间胜 +600，拳皇赢场 +2000，连打赢场 +2500。最高分按模式分记，写入 playbox-king-of-fighters-best，JSON `{v,l}`（拳皇 / 连打）。本局超过即更新。不存盘面。

胜利：先拿 2 局后约 1.85s 结算「皇胜」（连打「连尽」）。
失败：己方先被拿下 2 局弹出「皇败」。弹层打开时方向键不再走；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走（连点同向突进），↑ / W 跳（轻点小跳、按住高跳），↓ / S 蹲，空格拳，Shift / Z 踢，拳+踢 / X / 触屏 MAX 开 MAX。点画布拳，上滑跳，下滑蹲。标题 Enter/空格/1 拳皇，2 连打。R 重开，M 静音。无手柄。与饿狼不同：不是南镇双街换线，没有贴地波，是单层擂台 + 胸口气功弹（蹲过 / 高跳过）+ 小跳 + MAX 模式。与末刃 / 侍魂不同：不是对剑，是拳踢。与红侠不同：不是清街慢镜，是一对一擂台。与街霸不同：没有站防蹲防、没有升龙，气功弹飞胸口可蹲过，小跳会被打中，超必杀是三连炎不是升龙。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、少金屑。触控画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：出拳必有三层——听（拳风噪声 / 踢更闷 / 命中方波随连打往上爬 / 对打金属高音 / 气功嗡鸣 / MAX 上行琶音 / 三连炎低啸各不一样）、看（拳光弧、火星、胸口气功球、MAX 金气、分数蹦出、HIT 字、大字 N 打、蹲过青字）、触（拳约 38ms / 踢约 54ms / 气功约 60ms / 三连炎每段约 48ms / KO 约 80ms 顿帧 + 镜头微震）。MAX 金闪。KO 大字 + 倒地砸屏 + 重低音。失败与重开都是一键 R。
