玩法：标题页选「城堡」打八座（庭院→王座），选「无尽」一座接一座、敌人更快更多。八向跑，踩齐场上全部水晶即过关。跳起从怪头上掠过可短暂晕住它们；魔帽戴上后接触即晕。传送门成对折路。还剩最后一颗时全体扑过来。点「重开」或 R：标题页进城堡；对局中或结束层重开同一模式。M 静音，写入 playbox-crystal-run-mute。弹层打开时方向键不跑、空格不跳（改作确认）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：13×13 等距城堡。外圈是深坑，内里有地板、抬高台、立柱墙和坑。相邻格高度差大于 1 不能走。人半径约 0.28 格，速度约 4.92 格/秒。WASD / 方向键按屏幕八向（W 往画面上方），不是网格北。踩到坑中心会坠落。

城堡：庭院（开阔抬台、两棵树）/ 回廊（中空一圈，对角传送）/ 蜂巢（蜂）/ 螺旋（幽灵）/ 双塔（一层接二层，魔帽）/ 地道（房间只靠传送门连通）/ 密林（柱子+树吞水晶）/ 王座（三层台、全员）。过关保留分数和命。无尽：第 1 座起就加速加人，之后每座再加快（上限约 1.85 倍），场上树/蜂/幽灵往上加。

水晶：走上去即收。连收约 1.38 秒内不断档。树会把踩到的水晶吞掉（最后一颗吞不了）。顶栏「晶」条是剩余 / 开局。收光清关，约 1 秒后进下一座。

跳跃与帽：空格 / 点画布 / 触屏「跳」。腾空约 0.32 秒，这段碰到怪会晕约 2.1 秒。魔帽约 4.55 秒无敌并接触即晕（约 2.9 秒）。跳跃不能飞过深坑，只能晕怪。

敌人：树（绿，沿地面追，吞水晶）；蜂（黄，飞，可越坑越墙）；幽灵（紫，穿墙穿坑）。晕住时发白、停步，可从身上跑过。最后一颗时全体约 1.82 倍速，并补蜂。

传送：成对青/洋红涡。踩上瞬移到另一端，约 0.52 秒内不会来回弹。

得分：水晶 18×倍率（最后一颗 420×）。晕怪 80×。帽 280。清关 520+层/波加成。连击每 3 颗升一档，最高 ×5。最高分按模式分记，写入 localStorage 键 playbox-crystal-run-best，JSON `{c,e}`（城堡 / 无尽）。本局超过即更新。不存盘面。

生命：3 条，顶栏青块。撞树「树撞上了」，撞蜂「蜂群撞上了」，撞幽灵「幽灵贴上来了」，掉坑「掉下去了」。扣命后约 1.12 秒无敌，出生点重生，敌人重置，已收/被吞的水晶不回来。三命用尽弹出「命尽」。

模式：城堡打完王座弹出「城堡收复」。无尽没有清盘，命尽为止。两套最高分不共用。

操作：WASD / 方向键八向跑 · 空格跳跃。标题页 Enter/空格/1 城堡，2 无尽。R 重开，M 静音。点按画布跳，拖过约 18px 按屏幕八向跑。触屏左下十字加「跳」。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、跳跃无弧。触控棋盘 `touch-action: none`，避免页面跟着滚。第一稿没有自动玩。

爽感：每收一颗都有三层——听（水晶叮，音高随连击往上爬）、看（爆屑、环、分数蹦出、方块微亮）、触（约 32ms 顿帧 + 镜头微挤）。晕怪白闪 + 约 55ms 顿帧 + 震一下。最后一颗警报、洋红脉冲、全员加速。坠落实线、重开一键 R。
