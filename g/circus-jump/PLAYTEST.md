玩法：标题页「杂技」。选「马戏」打五场气球，选「连弹」越弹越快直到漏接。侧视马戏篷，底边蹦床左右滑，接住落下的小丑弹上去戳破三排气球。点「重开」或 R 开新局（标题页 R 进马戏；局中重开保留当前模式）。M 静音，写入 playbox-circus-jump-mute。弹层 `pointer-events: none`（面板可点），不挡住顶栏重开；R 在弹层打开时同样立刻重开。
蹦床：虚拟场 960×540。小丑半径 15。蹦床顶边 y=492，高 15，宽马戏 156→122（第五场），连弹 150 起每波 -6 至最窄 110。← → / A D 或在场上拖/划（鼠标移上去也会跟，按着方向键时键优先）移动，速度马戏 560、连弹 680。落下穿过蹦床顶边且相对中心偏移 |off|≤1.08 算接住；超出或落到 y>512 算漏接，扣一命。接住时按落点改弹力：正中最高，两端只够到底排。|off|<0.22 为「正中」，再加 7% 弹速，顿帧约 55ms。蹦床被接住时会压扁回弹并微倾。
气球：三排，金 y≈58 / 100 分、粉 y≈108 / 50 分、青 y≈158 / 20 分。同色最后一个分别 400 / 200 / 80，再乘连弹倍率。小丑穿过即破，不反弹，一弧可连破多颗。破球顿帧约 42ms，同色清 75ms。清完所有气球进下一场/下一波（等小丑落到 y>240 或最多约 0.85 秒再刷，避免刷在脸上）。清场加 300（马戏）或 150+波×40（连弹）。
连击：漏接清零。每破一颗 combo+1，分×(1+(combo-1)×0.08)，连弹模式改为 ×0.2。顶栏「连弹」显示倍数。
火圈 / 飞板：马戏第 2 场起 1 个火圈，第 3 场加飞板，第 4–5 场双圈（第 5 场再加一块板）。连弹第 2 波起圈、第 3 波起板。穿圈（圆心距 < 内径）+80×(1+0.08combo)，擦圈边会弹开。飞板可垫一下，弹力较弱。
马戏五场：开幕 / 火圈 / 飞板 / 双圈 / 谢幕。重力 980→1160，气球略增并开始左右漂。五场全清弹出「谢幕」。
连弹：重力 1180 起每波 +36（上限约 1440），弹速、圈板随波增加。没有谢幕，三命扣完「没接住」。
得分：破球分见上；穿圈；清场奖。最高分按模式分记，写入 localStorage 键 playbox-circus-jump-best，JSON `{c,r}`（马戏 / 连弹）；本局超过即更新。标题页最高显示马戏。
胜利：马戏第五场气球清完弹出「谢幕」（刷新最高分则正文带「新纪录」），可再来或改连弹。
失败：三命（顶栏金点）扣完弹出「没接住」，只能重开或换模式。弹层打开时顶栏重开和 R 随时可用。
操作：← → / A D 或拖动画布。标题页 1 马戏、2 连弹，Enter / 空格进马戏。R 重开，M 静音。无手柄、无暂停。
限制：声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不顿帧。触控画布 `touch-action: none`，避免页面跟着滚。标题页会自行演示弹跳戳球，不算分。
爽感：正中低音 thump + 金闪 + 粒子 + 短顿帧；破球噪声+音高随 combo 往上爬；同色清和弦。漏接干一声，一键 R 立刻再来。
什么变难：后场蹦床变窄、重力变大、火圈挡路、气球左右漂。正中窗口比擦边窄，顶排要正中才稳。
