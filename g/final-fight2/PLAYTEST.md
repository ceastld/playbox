玩法：标题页「终斗」。选「终斗」打三关（香港→巴黎→罗马，罗马尽头是雷图）；选「斗核」同三关但每包更密、更快、更肉。沿街带状走（左右推进、上下换深度），空格出拳三连，贴近晕住的人抱住，空格膝撞两下再砸地抱摔，Shift / Z 旋扫（耗忍气，原地两侧清场）。没有跳、不捡铁管飞刀。砸木桶掉烤鸡。体力打空扣一命。点顶栏「重开」或按 R：标题页进终斗；对局中或结束层重开同一模式。结束层「再来」同模式；失败「换模式」回标题；通关「斗核」开斗核。M 静音，写入 playbox-final-fight2-mute。弹层打开时方向键不走路、空格不出拳；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。可走带宽 y=222–322。镜头跟在人右前方，遇兵和 Boss 锁在当前段。人约 16 宽 30 高，走约 186，纵深约 118。标题页背后演示右进出拳抱摔旋扫，不算分、不掉血。

终斗三关：香港（旺旺 170 血，痞子/苦无，木桶烤鸡）/ 巴黎（弗雷迪 230 血，飞车/安多更多）/ 罗马（雷图 310 血，会开枪并叫安多）。过关保留命、分、忍气和体力。斗核同街景，每包多 1～2 人，敌速约 ×1.12，血量约 ×1.16。

出拳：空格三连（直→直→勾），第 3 击击晕。贴近晕住的非头目即抱住，抓住可走动；空格膝撞（两次），第三次或旋扫改砸地抱摔。抱摔砸地有冲击波，近的人也挨打。旋扫耗 1 忍（上限 3，开局 2，打中回忍），原地转一圈两侧都打，旋扫中无敌。苦无飞镖用上下换深度躲开。

敌人：痞子近打；苦无远掷；安多重拳；飞车冲撞。Boss 旺旺重拍、弗雷迪冲踢、雷图开枪压场。击破 Boss 再加 4200/5400/9200×倍率，过关 +2000×关。终斗打掉雷图后再加 8000，弹「罗马清了」。

得分：击杀基础分 × 连击倍率。连击为连续打中，约 1.4 秒无打中则断。倍率 = 1 + min(4, floor((连击-1)/2))，即 1–2 连 1 倍、3–4 连 2 倍，最高 5 倍。每 20000 分 1UP，命上限 6。最高分写入 playbox-final-fight2-best，不存盘面；本局超过即更新。

失败：挨打扣体力（无敌与旋扫除外）。体力 0 扣一命。约 0.8s 倒地后原地满血重生，1.35s 闪烁无敌。三命（顶栏红点）扣完弹出「被打倒了 / 血空了 / 被飞车撞了 / 被痞子打中了 / 中镖了 / 中弹了」等。弹层打开时方向键不再出拳；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → ↑ ↓ / WASD 走（上下换深度），空格 / J 出拳，Shift / Z / K 旋扫。点画布同出拳。触屏 上 / 下 / 左 / 右 / 拳 / 旋。标题页 终斗 / 斗核，Enter/空格/1 终斗，2 斗核。R 重开，M 静音。无手柄。与怒街不同：没有跳、没有铁管飞刀，爆发不耗血。与怒二不同：没有升龙，核心是抱住膝撞再砸地、原地两侧旋扫，关卡是香港/巴黎/罗马不是闹市/铁桥/罪巢。与怒三不同：没有暴冲电旋。与终斗街机不同：人是紫衣忍，跨国走，不是只打大城一地。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：出拳挥拳风声。打中：撞击音 + 粒子/火花 + 分数蹦出 + 约 40–76ms 顿帧（勾拳/抱摔更长，旋扫约 80ms）+ 镜头微震。连击数字往上窜，倍率跳时全屏 ×N。旋扫：紫金爆光、残影、全屏闪、震。抱摔砸地爆屑冲击波。砸桶金鸣。失败与重开都是一键 R。
