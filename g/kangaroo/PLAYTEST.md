玩法：标题页选「救子」或「群猴」。横版平台，拳打猴子、砸飞苹果，沿藤蔓或跳跃爬到顶层笼子救出小袋鼠。碰到猴子或苹果、掉出屏幕都会丢命。点「重开」或 R 开新局（标题页 R 进救子；局中或结算重开回当前模式第 1 关）。M 静音，写入 playbox-kangaroo-mute。

平台与藤蔓：每关一张树穴地图，多层木台，青色藤蔓连通上下。可跳上邻层，藤蔓能更快上下；在藤底按左右可走下藤。走出平台边缘会掉下去，可落到下层。蹲下（↓ / S）缩短受击高度，能躲过弧线偏高的苹果，贴地苹果仍会砸中。

出拳：Z 或触屏「拳」。出拳窗口内打中猴子会把猴打飞（约 55ms 顿帧，拳套约 70ms），打中苹果会溅汁。拳优先于身体碰撞：同一拳打中的猴子/苹果不会因此丢命。拳套拾取后约 8.2 秒，出拳更长，HUD「拳」槽亮起。

过关：站上顶层笼子前即清关，进入下一关（三张地图循环，猴子与苹果加快）。摔下、撞猴或中苹果扣一条命，约 0.88 秒无敌后在本关出生点重生；三命用尽弹出「命尽」。

得分：打飞猴子 +200×连击，砸苹果 +50×连击，水果 樱桃 100 / 草莓 200 / 香蕉 300 / 菠萝 500，拳套 +400，过关 +1000+250×关卡。连击约 1.38 秒内不打中会断。最高分按模式分记，写入 localStorage 键 playbox-kangaroo-best，JSON `{j,q}`（救子 / 群猴）。本局超过即更新。

模式：救子为三关循环的正常密度。群猴同地图，额外猴子、投掷更勤、场上苹果上限更高，并会从顶上落苹果。两套最高分不共用。

操作：← → / A D 走，↑ / W / 空格跳（藤上：上爬，左右+跳跃下），↓ / S 蹲或下藤，Z 出拳。触屏左 / 下 / 跳 / 右 / 拳。标题页 Enter/空格/1 救子，2 群猴。R 重开，M 静音。无手柄。无自动。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏。触控棋盘 `touch-action: none`，避免页面跟着滚。弹层打开时顶栏重开与 R 随时可用。

爽感：每次出拳都有挥拳声。打中猴子必有三层：听（冲击随连击往上爬）、看（洋红屑、金火花、POW 字、分数蹦出）、触（约 55–70ms 顿帧 + 镜头踢）。苹果溅汁约 38ms 顿帧。救出有钟声琶音、金屑与青环。连击数字往上叠。失败与重开都是一键 R。
