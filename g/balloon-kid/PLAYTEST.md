玩法：标题页「气斗」。选「对空」打关卡清鸟；选「漂流」顶爆三只大球（电花会扎你的气球）。点顶栏「重开」或按 R：标题页直接开对空；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-balloon-kid-mute。弹层 `pointer-events: none`，只有面板按钮可点；顶栏重开与 R 随时可用，不被 overlay 挡住。
场地：虚拟场 640×400。左右穿屏。底边海水约 y=366，身体没入即死。对空五套岛云循环（港湾 / 双岛 / 云桥 / 断崖 / 密云），部分云台会平移。漂流三朵云台缓慢横移，并有轻风。
飞行：重力随气球数变（两球最轻，一球明显坠，零球直落）。空格 / ↑ / W / 点画布 / 触屏「扇」扇翅；按住会连扇。← → / A D 左右。落地可走，再扇起飞。丢光气球不能扇，会穿透台子掉进水。
对撞：比身体高度。高出约 6px 以上才算从气球下方顶爆（你在上头往下撞）；同高弹开；更低你被爆。每顶爆一只气球：顿帧约 55ms、镜头踢、粒子、爆音。鸟没球后撑伞缓降，再撞一下打落，掉进水才算击沉。伞兵若落到台上会补一球再飞。漂流大球同样：你在上方或同高顶爆，你在下方会被反弹并掉一球。
对空：第 1 关 2 绿 + 1 粉（粉一球，绿/金两球）。之后加金鸟、加快加密，场上最多约 7 只。清光（含伞兵必须沉水）才进下一关。关内会从水里冒分值泡，捡到加分。
漂流：每轮 3 只彩球弹跳，电花正弦游走，碰到掉一球并短暂无敌。三球都顶爆立刻「清漂」进下一漂，电花变多、球变快。
大鱼：在水面上方约 48px 逗留超过约 1.12 秒会扑上来（提示「大鱼」），咬中即死；也会吞掉水边的鸟。落水无论有没有气球都是即死。
得分：顶爆气球 500×连爆倍率；打落伞兵 300×；击沉粉 500 / 绿 750 / 金 1000（再乘倍率）；泡 300–800×；漂流三球 1000 / 2000 / 3000×。清关 +1500+250×关。连爆窗口约 2.05 秒，倍率 1 + min(4, 连爆-1)，最高 5 倍。每 20000 分 1UP，命上限 6。最高分写入 playbox-balloon-kid-best，不存盘面；本局超过即更新。扣命或超时未动作会断连。
生命：3 条（顶栏气球点）。两球都爆、落水或被鱼吞都扣一条。约 0.82 秒后在台上重生，约 1.55 秒闪烁无敌（落水 / 鱼不受无敌保护）。三命用尽「落海了」。弹层打开时方向键不再飞；顶栏重开与 R 随时可用。
操作：← → / A D 移动，空格 / ↑ / W 扇翅。触屏左 / 扇 / 右；点画布一下扇翅，按在左右侧同时转向。标题 Enter/空格/1 对空，2 漂流。结束层 Enter/空格/1 再来，2 换模式。
限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不顿帧、不抖屏。触控画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。
爽感：每次有效扇翅有翅声+翅下尘。顶爆：爆音+气球碎+约 55ms 顿帧+镜头踢+闪光。打落伞兵另有闷响。击沉/落水有水花圈和溅射。捡泡 ping。连爆数字往上叠。失败与重开都是一键 R。
