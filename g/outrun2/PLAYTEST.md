玩法：标题页选「海岸」或「夜奔」。黄色超跑停在画面底部，公路向消失点卷去。← → / A D 转向，↑ / W / 按住画布加油门，↓ / S / 画布底部刹车，空格 / 触屏「漂」甩尾过弯。点「重开」或 R 开新局（标题页 R 进海岸；局中或结算重开回当前模式）。M 静音，写入 playbox-outrun2-mute。
场地与碰撞：虚拟场 800×450，伪 3D 路段。玩家横向约 ±1 为路面，超过即冲出（减速、扬尘，不出局）。来车偏移与玩家横向差小于 0.3 且纵向约 210 内即撞击：时速约剩 34%、弹开、70ms 顿帧。撞击只减速，不扣时，也不会直接出局。
分叉与风景：五段三角分叉。椰滩（海滨）起，靠左/靠右驶过检查门进入下一段：云岭、棕湾、城垣、深湖、砂海、雪廊、瀑谷、王道、遗墟。门上 CHECK / GOAL，路牌标下一段名。第五段冲 GOAL 胜利。可能终点：雪峰 / 飞瀑 / 王城 / 遗塔 / 落日。
时间与分数：海岸开局 52 秒，过门 +16；夜奔 38 秒、+12，且顶速更高、车更快更密、弯更急。超时才结束（车会滑停再弹层）。距离一直加分；超车 88×连超；弯中甩尾每 0.28 秒一层连漂；过门 820+；终点 3000+剩余时间。最高分按模式写入 playbox-outrun2-best，JSON `{h,n}`（海岸 / 夜奔）。
胜利：第五段冲过 GOAL。失败：时间到 0。弹层 `pointer-events: none`，不挡 R 与顶栏重开。
操作：方向键 / WASD 转向+油门+刹车；空格漂移。点按画布加速并按左右位置转向，靠底部刹车。触屏也可用底栏 左/油/刹/漂/右。标题页 Enter/空格/1 海岸，2 夜奔。结算 Enter 再开。无手柄。无自动。
限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏。触控画布 `touch-action: none`。标题页背后是演示驶，到门会重置，不算分。
爽感：入漂顿帧+火花粒子+轮胎尖叫；连漂/超车数字往上窜；过门金闪加时；撞击火花+顿帧+引擎闷一下。失败与重开都是一键 R。
什么变难：弯道离心力把车往外甩，必须空格漂移压住。夜奔车流更快更密、弯更急、时间更紧。冲出路面掉速。检查门前必须选边。城垣弯急墙近，砂海视距热浪。
