玩法：标题页「四二」。选「四二」打三关（中途岛 → 威克环礁 → 拉包尔），每关中 Boss 与关底飞空要塞机；选「云核」同三关但卷轴更快、编队更密、云层更厚、Boss 多约 22% 血、额外补波。点顶栏「重开」或按 R：标题页直接开四二；对局中或结束层重开同一模式。结束层「再来」同模式；机毁「换模式」回标题；通关「云核」开云核（云核通关则「换模式」回标题）。M 静音，写入 playbox-n1942-mute。方向键 / WASD 八向飞，空格开火（可按住连射），Shift / Z 翻环。画布拖动跟机，按下开火。触屏右下「环」翻环。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 四二、2 云核。

场地：虚拟场 480×720。超级王牌（双尾）开局 y=630、x=240，夹在 22–458 / 40–692。四二巡航约 82（关卡与连击再加），云核约 114；中/关底 Boss 在屏时降到约 26–34。移速约 278（云核 312）再加火力等级。子弹相对机向上 700。点按或按住空格开火。未解锁音频前无声。双发螺旋桨约 88ms 一拍低频 rumble。云团只做氛围，不挡弹不藏机。

两层：空中单位（零战、俯冲金侦、双发中爆、运力机、中/关底要塞机）撞机扣命；地面单位（炮艇、军舰、环礁高炮、航母甲板）可飞越，只吃它们的对空弹。玩家弹打空打地都结算。翻环期间无敌，可穿阵 ram 空中单位，擦掉近身敌弹。

火力：默认力 0 双发（双尾各一），冷却约 0.110s。吃菱形「力」胶囊加宽：1 四发 0.099s、2 五向 0.088s、3 六向 0.077s、4 七向+翼机枪 MAX 0.066s。满级再吃若环未满则环 +1（上限 5），否则 +500×倍率。运力机必掉力。航母甲板常掉「环」。被弹若有火力会掉一枚力可再捡，火力归零。

翻环：Shift / Z / 顶栏「环」/ 触屏「环」，0.82s 无敌翻筋斗。机体旋转放大、残影、青金环、微轨圆。期间擦掉约 36 半径内敌弹（每发 +10×倍率，「擦」字蹦出，每 3 擦加一连），并 ram 空中单位（小机 3 伤、要塞机每 0.16s 2 伤）。结束时若擦 ≥3 结算「擦弹 ×N」。每关 3 次，过关补满；未用余环每枚 +400。用尽再按提示「环用尽」。翻环不落雷、不清全屏弹（只擦近身）。

关卡：第 1 关中途岛中 Boss「舰攻队」42 血、关底「要塞机」100；第 2 关威克环礁「陆攻机」54 / 「巨翼机」128；第 3 关拉包尔「银河爆击」68 / 「司令机」176。云核血量 ×1.22。中 Boss 在场时波次计时暂停。编队 V 字、侧翼切入、俯冲金侦、双发中爆、海面炮艇/军舰、环礁高炮、航母、运力机。要塞机半血后扇扫；巨翼旋转弹幕；司令机双环弹+瞄准。中/关底 Boss 都是飞空单位，可撞可 ram。

得分：击杀基础分 × 连击倍率。战斗机 50、俯冲 80、中爆 140、炮艇 100、军舰 200、高炮 160、航母 220、运力 300、中 Boss 2000、关底 4000+1500×关。连击为连续击杀（擦弹每 3 发也加一连），约 1.42 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。击坠关底再加 1500×关。三关打穿 +8000（云核 +10000）并「太平洋肃清 / 云核尽破」。每 20000 分 1UP，命上限 6。最高分写入 playbox-n1942-best，不存盘面；本局超过即更新。

胜利：四二/云核打掉第 3 关司令机后约 2.1s 结算胜利。
失败：敌弹碰到自己，或空中机体相撞，扣一命（翻环与重生无敌除外）。约 0.95s 爆炸后重生，1.55s 闪烁无敌，场上敌弹清空。三命（顶栏青点）扣完弹出「机毁了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格射击。Shift / Z 翻环擦弹。点按画布开火并跟机。标题页 Enter/空格/1 四二，2 云核。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾、翻环不夸张放大。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波。击中粒子爆开 + 短顿帧（约 34–72ms）+ 镜头微震 + 连击数字往上窜。翻环三层：听（噪声 rumble + 上滑锯齿）、看（青金环、残影、机体旋转）、触（约 50ms 顿帧 + 微震）。擦弹升频叮一声 + 「擦」字。吃力金闪。坠机洋红大爆。失败与重开都是一键 R。
