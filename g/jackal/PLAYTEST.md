玩法：标题页「豺狼」。选「豺狼」打三关往上开（峡谷 → 河岸 → 狼穴，关底 Boss）；选「狼林」同三关但卷轴更快、敌更密、弹更勤、Boss 更厚，速度约 ×1.26。头顶开吉普，八向带惯性，机枪跟车头连射。手雷沿车头地面飞出去，撞敌即炸（不抛弧越营）。碾步兵 / 突兵加分，撞坦克 / 直升机 / 炮艇 / 关底丢一条命。炸营房出人质，人质跑向吉普，上车补雷并升雷种。点顶栏「重开」或按 R：标题页进豺狼；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-jackal-mute。弹层打开时方向键不开车、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 480×720。岩壁约 x=38 与 x=442。吉普开局约 (240, 572)，夹在壁内 18px、y 约 86–664。豺狼巡航约 76（狼林 108）；Boss 在场时降到 18 / 28。驾驶约 248（狼林 ×1.08），有惯性滑动。点射冷却约 0.07s（狼林 0.058），弹速 680，场上最多 10 发机枪。标题页背后演示上开、碾兵、对营丢雷，不算分、不掉命。河岸正中有蜿蜒水面（宽约 26），开进去丢命。

豺狼三关：峡谷（装甲狼 60 血，左右走，三向点射，残血加瞄准）/ 河岸（河炮艇 78 血，贴河瞄准弹，残血加两翼）/ 狼穴（狼堡 98 血，绕场扇弹，残血补坦克）。过关保留命、分、连击窗口、手雷、车上人质。狼林同三关，波次 +2 只、营房多一座，速度 ×1.26 并随关递增，Boss 血约 ×1.22，敌射间隔约 0.74 倍，开局 4 枚手雷（豺狼 6 枚）。

射击：空格朝车头连射。点按画布跟人并开火。击中粒子 + 约 34–58ms 顿帧。

手雷：Shift / Z / 右键 / 触屏「雷」。沿车头地面飞，撞敌或到时即炸，不越营。出手约 0.46s 冷却。人质 0–1：手雷，速 360，范围约 48，伤 3。人质 2–3：火箭，速 500，范围约 58，伤 5。人质 4+：导弹，跟踪坦克 / 营 / 机 / 艇 / Boss，范围约 64，伤 6。对人质爆炸会救人。没雷时弹「没雷了」。上限 9。

救人：炸开营房弹出 2 人（狼林 3），标「救」，跑向吉普，开上去即上车。+1 雷、+400×倍率，车上人数上限 6。升到火箭 / 导弹时弹「上车 · 火箭/导弹」。丢命清空车上人质，雷种掉回手雷，手雷数量保留。

碾压：吉普撞步兵 / 突兵即碾，基础 160×倍率，蹦「碾」，约 46ms 顿帧。坦克 / 营房 / 直升机 / 炮艇 / Boss 不能碾，撞上去丢命。营房可推开绕行。

敌人：步兵 80 / 1 血下行点射可碾；突兵 120 / 1 血冲脸可碾；营房 200 / 6 血挡机枪、可推开不可碾，炸开出人质；坦克 240 / 4 血横跑双管，撞上丢命；直升机 180 / 3 血正弦飞俯射；炮艇 160 / 3 血贴河瞄准重弹（河岸）。狼林射速间隔更短。

Boss：装甲狼关顶左右走三向弹，残血加瞄准；河炮艇贴河瞄准弹，残血加两翼；狼堡绕场扇弹，残血补坦克。击破 Boss +3600×倍率，过关 +1400×关次×倍率。豺狼打穿再加 8000，狼林 +10000，弹「狼穴捣毁了」/「狼林通关」。

得分：击杀基础分 × 连击倍率。连击为连续命中/击杀/碾/救人，约 1.44 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。每 15000 分 1UP，命上限 6。最高分写入 playbox-jackal-best，不存盘面；本局超过即更新。

失败：三命（顶栏橙点）扣完弹出「撞车了 / 中弹了 / 碾上了 / 掉进水里了」。约 0.86s 爆炸后底部重生，1.22s 闪烁无敌，场上敌弹清空。弹层打开时方向键不再开车；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 八向开，空格射击，Shift / Z 手雷。点按画布跟车并开火，右键丢雷。触屏 上 / 左 / 雷 / 右 / 下 / 射。标题页 豺狼 / 狼林，Enter/空格/1 豺狼，2 狼林。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波。手雷金尾、火箭更快、导弹青光跟踪。击中粒子爆开 + 短顿帧（约 34–58ms）+ 镜头微震 + 连击数字往上窜。碾兵金爆、对半粒子、「碾」字。救人金鸣、全屏闪、上车补雷。营房挡弹砂石碎屑。爆炸粒子、连击 pop。失败与重开都是一键 R。

跟邻作的差：不是佣兵（徒步八向、手雷抛弧越碉、救人只补雷）。不是武警（摩托纵版弹幕、边车翼力）。不是雷狐（横版空翻碾）。不是枪力（横版夺甲）。豺狼是头顶开吉普往上突，车头机枪、地面手雷、碾步兵、撞甲丢命、炸营上车升雷种。
