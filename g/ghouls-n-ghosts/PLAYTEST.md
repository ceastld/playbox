玩法：标题页「鬼铠」。选「鬼铠」打三关（刑场→腐村→魔殿，关底盾魔 / 三首 / 魔王，击破后走进魔门过关）；选「铠核」敌更快更密，额外补尸与秃鹫（盾兵与火灵不加倍），头目血约 ×1.22。侧向走跳，空中可改向。空格丢枪，按住↑朝上丢、按住↓朝下丢。铠甲第一下打碎，内裤再挨一下丢命；金甲再多一层，并可按住空格蓄魔法。点顶栏「重开」或按 R：标题页进鬼铠；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「铠核」开铠核。M 静音，写入 playbox-ghouls-n-ghosts-mute。弹层打开时方向键不走路、空格不丢枪；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 84 高，能上一层，不能从地面直上高层。空中可改向（约 ×0.88 走速）。镜头跟在人右前方，头目与魔门时锁在关底。地面有缺口，掉出屏幕底丢命。中高层平台可单向落（↓ / S 掉落）。人宽约 14、立高 26、蹲高 14。走约 200。标题页背后演示右进丢枪跳坑，不算分、不掉血。

鬼铠三关：刑场（盾魔 26 血，尸从土里冒、秃鹫俯冲、盾兵挡平射、火灵，盾魔正面有盾须向上丢）/ 腐村（三首 36 血，三向喷火，盾兵与鹫更多）/ 魔殿（魔王 48 血，洒弹并可残血召火灵）。过关保留命、分、当前枪与铠甲状态。铠核同三关，速度 ×1.30 并随关递增。击破头目不立刻过关，魔门打开后要走进去（刑场 / 腐村 / 魔殿皆然），走进再 +800×倍率，过关 +2200×关。鬼铠走进第三扇门后再加 9000，弹「魔殿已破」；铠核弹「铠核平了」。

武器：默认长枪 0.20s、屏上 2 发、直线。圆盘 0.28s、屏上 1 发、飞出后折返可再打。魔火抛弧，落地燃池约 1.32s、单发 2 伤。空中仍可按面朝、朝上或朝下丢。死亡重生保留当前枪，并给回铠甲。

敌人：尸贴脸走，靠近才出土 100；秃鹫正弦飞再俯冲 160；盾兵走砍、盾举起时挡平射（上丢或下丢可绕）220；火灵浮射 180。头目盾魔单发并周期性收盾；三首三向焰；魔王洒火、残血召灵。击破头目 +4200×倍率；走进魔门再 +800×倍率，过关 +2200×关。

铠甲：开局钢甲，第一下碎甲（银屑、约 74ms 顿帧、镜头踢、提示「铠甲碎了」），内裤再挨一下丢命。可捡「甲」重新着装；捡「金」升金甲（金屑、金闪）。金甲再挨一下退回钢甲（「金甲碎了」）。金甲按住空格约 0.55s 蓄满，松手施魔法：长枪雷击、圆盘追盘、魔火炎浪。重生给回铠甲。无敌闪约 1.38s（铠核 1.04s）。

得分：击杀基础分 × 连击倍率。连击为连续击杀，约 1.32 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 15000 分 1UP，命上限 6。最高分写入 playbox-ghouls-n-ghosts-best，不存盘面；本局超过即更新。

失败：挨弹 / 撞兵 / 坠渊扣一命（无敌除外；有甲时先碎甲，金甲先退钢甲）。约 0.80s 后在最近扎实地面重生。三命（顶栏红点）扣完弹出「被击中了 / 坠入深渊了 / 撞上了」。弹层打开时方向键不再走路；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W / Z 跳（空格不跳），↓ / S 蹲或从平台掉落，空格丢枪（按住↑朝上、按住↓朝下；金甲按住蓄魔法）。点按画布同空格。触屏 上 / 跳 / 投 / 左 / 蹲 / 右。标题页 鬼铠 / 铠核，Enter/空格/1 鬼铠，2 铠核。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：丢枪必有三层——听（枪种音色：枪脆钢、盘回旋、火啸）、看（枪口闪、火花）、触（约 34ms 顿帧 + 画面挤压）。碎甲必有三层——听（金属噪+下扫）、看（银/金碎片飞散、全屏闪、toast）、触（约 74ms 顿帧 + 镜头踢）。金甲魔法雷鸣/追盘/炎浪 + 更长顿帧 + 全屏金闪。击杀粒子 + 30–80ms 顿帧 + 连击数字往上窜。盾挡当一声金属撞。失败与重开都是一键 R。
