# 弹堂 · TAN HALL

回合制 2D 弹道对决。调角度、蓄力度、读风向，打穿可毁地形。原创 IP，不抄 TNT / 弹弹堂 / 弹弹星球的名字、地图、角色。

一句话：看风，拉满或点射，把对面从石殿上轰下去。

## 世界

云海石殿「弹堂」。弹师以灵弹对决，风是殿息。

- 玩家 **岚丸**（青焰狸灵，左台）
- AI **烬丸**（赤砂狸灵，右台）

无第三方角色、无现成商店素材。深色霓虹，跟游廊一家。中文 UI，英文短副标题 `TAN HALL`。

## 核心循环

1. 回合开始：风向、风力重掷，顶栏箭头 + 数字立刻更新。
2. 行动方：有限步数左右走 → 调角度 → 选武器 → 长按蓄力松手发射。
3. 灵弹带重力 + 风偏飞行；拖尾被风明显吹弯。
4. 落地：挖坑、直击 / 溅射扣血；脚下被挖空则坠落，落差够大再吃摔伤。
5. 换手。一方 HP ≤ 0 结束。

30 秒内能懂。标题页一句话 + 操作提示，无长教程。

## 模式

| 模式 | 说明 |
|------|------|
| **弹堂** | 标准 1v1 vs AI。HP 100。风 -8～+8，每回合重掷。 |
| **堂核** | 快风低血。HP 60。风 -14～+14 且更易大变。伤害约 ×1.15。局更快。 |

标题页点模式开局。Enter / 空格 / 1 进弹堂，2 进堂核。对局中途不换模式。R 重开同一模式同一图。

地图三选一（标题页点选，默认平原）：

| 图 | 地形 | 教学点 |
|----|------|--------|
| **平原** | 缓丘开阔，两侧落点近。 | 65° 远射、读风。 |
| **峡谷** | 中央深 V，壁陡。 | 高抛或 **穿透** 穿壁。 |
| **双台** | 左右高台，中间断层。 | 90° 近打台沿；过缝要对风。 |

三图宽度相同、轮廓不同。地面可挖穿；掉出画布底 = 坠亡（HP 清零）。

## 操作

键盘为主。方向键与 WASD 等价。

| 键 | 作用 |
|----|------|
| ← → / A D | 左右走。本回合步数有限（约 96px），走完条空即停。贴地，不跳。 |
| ↑ ↓ / W S | 调炮口角度，1° 一步，按住连调。范围 0°～180°（90° 朝天，0° 朝右，180° 朝左）。 |
| 空格 / Z | **按住蓄力，松开发射**。蓄力 0.8s 走满 100，满档闪一下仍可松。未蓄松手 = 点射（约 12%）。 |
| 1 / 2 / 3 | 切 普通弹 / 高爆 / 穿透。顶栏也可点。 |
| R | 随时重开。 |
| M | 静音，写入存储。 |

触屏 / 指针（第二种操作）：画布下虚拟键「左 / 右 / 仰 / 俯 / 蓄」，按住蓄、松开发射；点顶栏切武器。`touch-action: none`，方向键与空格 `preventDefault`，避免页面跟着滚。无手柄。

HUD 常显：双方 HP、当前风（箭头+数字）、角度 °、蓄力 %、剩余步数、当前武器。

## 战斗

- **场地**：横版 960×540。重力恒定。风只改水平加速度，每回合一次，飞行中不变。
- **HP**：见模式。顶栏双方血条，数字同步。
- **直击**：弹心碰到对方身体（约 14px 半径）。
- **溅射**：爆心到对方中心距离衰减；半径内都算。直击与溅射不叠满，取高。
- **挖坑**：圆形刨地形。人站坑沿则滑落贴新地面。
- **摔伤**：本回合因挖坑或滑落，落差 ≥ 36px 才算。伤 ≈ `min(28, floor((落差-36) × 0.35))`。堂核 ×1.15。落地粒子 + 闷响。
- **自杀 / 误伤**：打到自己算。摔伤、坠出底边同理。
- **回合超时**：约 20s 未发射则强制 50% 力、当前角度打出，防挂机。

### 瞄准手感（必须可学）

同一力度，**65° 接近最远**，**90° 几乎落回脚下**。玩家要靠「角度定远近、力度微调、风改落点」学会，不要随机飘。

- 65°、力度 70：平原无风大约打到对方开局位（约 520–620px 水平）。
- 90°、任意力度：升天后原路落下，落点就在炮口附近（风只会左右偏一点点）。
- 45° 与 65° 同力比，45° 更「平、快、略近」，65° 更「高、远」。
- HUD 实时写角度与蓄力。炮口只画 **约 80px 初速虚线**（不含风、不含重力），让人看见朝向，不替玩家算弹道。
- 飞行拖尾每帧画点；风非零时弧线肉眼能看出被吹弯（顶栏风标同时动）。
- 蓄力条跟手，松开即按当前 % 出膛，无延迟、无粘键。

## 武器（3）

开局三把都有，无限弹药，每回合只能打一发。

| 武器 | 直击 | 溅射半径 | 坑半径 | 弹速系数 | 特效 |
|------|------|----------|--------|----------|------|
| **普通弹** | 32 | 36 | 30 | 1.0 | 基准。青焰小爆。 |
| **高爆** | 24 | 56 | 48 | 0.88 | 坑大、溅射远、直击略低。改地形、砸台沿、逼摔。 |
| **穿透** | 30 | 32 | 26 | 1.06 | 弹体第一次碰到地形不爆，开一条短隧道（约 46px）再穿出；第二次碰地形或穿出后超时（约 0.18s）才爆。穿峡谷壁、打掩体后的人。只穿一次。 |

堂核伤害 ×1.15。打中必有粒子 + 顿帧；打空只有挖坑音和土屑。

## AI（烬丸）

必须真会打，不乱抖。

- 读当前风、己方位置、对方位置、地形轮廓。
- 枚举角度 15°–165°、力度 20–100，模拟弹道（含风、含当前武器），打分：直击 > 近溅射 > 挖对方脚下（逼摔）> 拆掩体。
- 堂核：误差小（角度 ±3°、力度 ±4）。弹堂：略松（±6° / ±8），偶尔打偏让玩家有机会。
- 峡谷优先 **穿透**；对方贴边或站薄台优先 **高爆**；开阔地对射 **普通弹**。
- 先走几步找更好的射击角（仍受步数限制），再蓄力发射。蓄力条可见，不要瞬发。
- 第一稿可不做「自动」托管；对局 AI 必须在。

## 胜负与存储

- 对方 HP ≤ 0：「堂破了」。己方清零：「落堂了」。同时清零算平「对坠」。
- 结束层：胜 / 负 / 平 + 本局回合数。按钮「再来」（同模式同图）「换一局」（回标题）。
- 失败、结束都快。R 一键重开。结束层不挡顶栏。
- 不存盘面。刷新只留最高连胜 / 最快获胜回合、上次模式与地图、静音。
- 键：`playbox-tan-tang-best`（JSON：`winStreak`, `bestTurns`, `mode`, `map`）、`playbox-tan-tang-mute`。

## 爽感

每次有效命中必须三层，缺一不可：

- **听**：Web Audio。蓄力升调、出膛呼、飞行风哨、直击爆、溅射闷、挖土、摔落、击破。各武器音色不同。可 M 静音。第一次按键 / 点击后才开音频上下文。
- **看**：爆心粒子、土屑、HP 数字蹦出、血条闪、弹道拖尾。击破全屏一闪。
- **触**：命中 hit-stop 40–70ms + 镜头微震。打空不顿帧。

连击：连续两回合打出直击或有效溅射，蹦「连堂 ×N」，音阶上行。断手或打空清零。

`prefers-reduced-motion`：缩短顿帧、少粒子、不抖屏。切走页面暂停步进。

- `node --check js/game.js` 须通过。

## 验收

- 平原无风，65° + 中高力能打到对岸；90° 同力落在自己附近。换风后弧线肉眼偏。
- 高爆坑明显大于普通弹；穿透能穿峡谷薄壁再爆。
- 挖掉脚下会掉下去，落差够则扣摔伤。
- 堂核风更大、血更薄，一局明显更快。
- R 在对局、结束层、标题层都能重开；结束层不挡重开。
- 命中有声、有粒子、有顿帧；M 能静音。
