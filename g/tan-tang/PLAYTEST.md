玩法：标题页「弹堂」+ TAN HALL。点地图选平原 / 峡谷 / 双台（默认平原，写入 playbox-tan-tang-best.map）。点「弹堂」或按 1 / 回车 / 空格开标准局；点「堂核」或按 2 开快风低血。对局中途不换模式。点顶栏「重开」或按 R：标题页直接开弹堂（当前图）；对局中或结束层重开同一模式同一图。结束层「再来」同模式同图；「换一局」回标题。M 静音，写入 playbox-tan-tang-mute。弹层 `.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`，只有面板按钮可点，绝不挡顶栏重开。R 随时可用。

场地：虚拟场 960×540 横版。列高度图，挖坑即时写回。人每帧贴地；脚下被挖空则坠落，掉出画布底 = 坠亡（HP 清零）。三图同宽不同轮廓：平原缓丘开阔；峡谷中央深 V、两侧有台；双台左右高台中间断层。岚丸（青焰）左台，烬丸（赤砂 AI）右台。封面用 preview.png 铺在标题天空后。

模式：弹堂 HP 100，风 -8～+8，每回合重掷。堂核 HP 60，风 -14～+14 且更易刮大风，伤害 ×1.15，局更快。风只改水平加速度，飞行中不变。顶栏箭头 + 数字立刻更新；拖尾能看出被吹弯。

操作：键盘为主。← → / A D 走，本回合步数约 96px，走完即停，贴地不跳。↑ ↓ / W S 调角，0°～180°（90° 朝天，0° 朝右，180° 朝左），按住连调。空格 / Z 按住蓄力、松开发射；0.8s 走满 100，未蓄松手 = 点射约 12%。满档金闪仍可松。1 / 2 / 3 切普通弹 / 高爆 / 穿透，顶栏也可点。触屏用画布下「左 / 右 / 仰 / 俯 / 蓄」，按住蓄、松开发射。鼠标点画布拉角并按住蓄力。方向键与空格 preventDefault。无手柄。无暂停、无悔弹。

瞄准：同一力度，65° 接近最远，90° 几乎落回脚下。平原无风 65° + 力度 70 大约打到对岸开局位（约 520–620px 水平）。45° 同力更平、更快、略近。炮口只画约 80px 初速虚线（不含风、不含重力）。HUD 实时写角度、蓄力、剩余步数、风、双方 HP。回合约 20s 未发射则强制 50% 力打出。

武器：开局三把都有，无限弹药，每回合一发。普通弹直击 32 / 溅射 36 / 坑 30 / 弹速 1.0。高爆直击 24 / 溅射 56 / 坑 48 / 弹速 0.88，改地形、砸台沿、逼摔。穿透直击 30 / 溅射 32 / 坑 26 / 弹速 1.06：第一次碰地形不爆，开约 46px 短隧道再穿出；第二次碰地形或穿出后约 0.18s 才爆。只穿一次。直击与溅射取高不叠满。堂核伤害 ×1.15。打中必有粒子 + 顿帧；打空只有挖坑音和土屑。

摔伤：本回合因挖坑或滑落，落差 ≥ 36px 才算。伤 ≈ min(28, floor((落差-36)×0.35))，堂核 ×1.15。落地粒子 + 闷响。打到自己、摔伤、坠底都算。

AI 烬丸：读风、双方位置、地形。枚举角度 15°–165°、力度 18–100 模拟弹道（含风、含当前武器），打分直击 > 近溅射 > 挖脚下 > 拆掩体。先走几步找更好射击角（仍受步数限制），再可见蓄力发射，不瞬发。堂核误差小（约 ±3° / ±4），弹堂略松（约 ±6° / ±8）。峡谷优先穿透；对方贴边或站薄台优先高爆；开阔普通弹。第一稿无「自动」托管按钮。

胜负：对方 HP ≤ 0「堂破了」。己方清零「落堂了」。同时清零「对坠」。结束层写本局回合数。最高连胜 / 最快获胜回合写入 playbox-tan-tang-best（JSON：winStreak, bestTurns, mode, map）。刷新只留这些和静音。不存盘面。

爽感：蓄力升调、出膛呼、飞行风哨、直击爆、溅射闷、挖土、摔落、击破。各武器音色不同。第一次按键 / 点击后才开 AudioContext。命中粒子 + HP 数字蹦出 + 血条闪 + 40–70ms 顿帧 + 镜头微震。打空不顿帧。连续两回合有效直击 / 溅射蹦「连堂 ×N」，音阶上行；打空清零。击破全屏一闪。`prefers-reduced-motion` 缩短顿帧、少粒子、不抖。切走页面暂停步进。失败和重开都是一键 R。
