玩法：标题页「引力」。选「巡星」燃料 160、恒星与井内重力较轻、碉堡较慢；选「深井」燃料 100、重力约 ×1.55、碉堡更快更厚、降落更严、得分 ×1.45。点顶栏「重开」或按 R：标题页直接开巡星；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-gravitar-mute。A / D 与 ← → 转向，W / ↑ 推进，空格开火（可按住）。触屏：左下 ↺ ▲ ↻，右下 火。点按画布也可开火。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 巡星、2 深井。
场地：虚拟场 800×480。星系层恒星在场心，半径约 26，行星沿轨道公转；船出边绕回。井内为侧视岩腔，无绕回，左右夹住。巡星第 1 系 3 颗行星，深井 4 颗，之后每系 +1 最多 5。行星名：朱砂 / 靛井 / 霜环 / 赤核 / 玄渊。
降落：靠近行星外缘发光坪，速度 ≤ 巡星 88 / 深井 64 即潜入井内；撞上太快扣命「降落太快」。坠入恒星扣命。死于井内约 1.18s 后回到星系重生（行星仍在），1.85s 闪烁无敌，燃料至少补到上限 42%。
井内：向下重力（巡星 58、深井 98），推进对抗。打碉堡、打或碰燃料罐 +32 油、打反应堆。反应堆打爆后入口亮金，须在倒计时内飞回顶部门框逃出（巡星约 12.4s、深井约 8.2s，每系 −0.55s，最少 6.2s）。超时「没能逃出」。逃出后该行星成残骸，加分并补油 24；全清进下一系并加满油。
船：半径约 9，转向 3.2 rad/s。星系推进 242、最快约 348、极轻阻尼 0.04；井内推进 196、最快约 286、阻尼 0.018。子弹速度 430，寿命约 0.74s，最多 4 发、冷却 0.14s。推进耗油 11/s，转向与开火不耗油。油尽仍可转向开火，只能坠落。
得分：碉堡命中 / 击毁 / 反应堆 / 燃料 / 弹碰弹 均 × 连击 ×（深井 1.45）。逃出 `(600 + 剩余燃料×2) × 模式 × (1+(倍率-1)×0.15)`。肃清星系 `1500 × 系 × 模式`。连击 1.35 秒无命中断开。倍率 = 1 + min(4, floor((连击-1)/2))，最高 5 倍。每 10000 分额外一命（可超过三命）。最高分写入 playbox-gravitar-best，不存盘面；本局超过即更新。
胜利：没有终局胜利，一系接一系直到船尽。
失败：中弹、撞岩/碉堡/反应堆、坠入恒星、降落太快、没能逃出均扣一命。三命（顶栏紫点）扣完弹出「船碎了」，导语带死因。若本局刷新最高分弹层写「新纪录」。弹层打开时转向不再开打；顶栏重开与 R 随时可用。
限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、子弹不拖尾。触控时画布与虚拟键 `touch-action: none` 并 preventDefault，避免页面跟着滚。
爽感：推进双色火焰 + 喷气噪声；命中碉堡/反应堆短顿帧（约 34–80ms）+ 粒子爆 + 镜头微震 + 连击数字往上窜；反应堆引爆大爆、金洋红环、碎片、逃出门框闪金；燃料罐青钻拾取音。
