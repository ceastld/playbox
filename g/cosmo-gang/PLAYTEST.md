玩法：标题页「星帮」。选「星帮」打三关（霓虹巷 → 货仓港 → 帮核城），每关中 Boss 与关底 Boss；选「帮核」同三关但卷轴更快、编队更密、敌弹更勤、Boss 多约 22% 血、额外补波。点顶栏「重开」或按 R：标题页直接开星帮；对局中或结束层重开同一模式。结束层「再来」同模式；机毁「换模式」回标题；通关「帮核」开帮核（帮核通关则「换模式」回标题）。M 静音，写入 playbox-cosmo-gang-mute。方向键 / WASD 八向飞，空格开火（可按住连射），Shift / Z 或顶栏「洞」放黑洞。画布拖动跟机，按下开火。触屏右下「洞」放黑洞。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 星帮、2 帮核。

场地：虚拟场 480×720。超拍战机开局 y=630、x=240，夹在 22–458 / 40–692。星帮巡航约 84（关卡与连击再加），帮核约 116；中/关底 Boss 在屏时降到约 28–36。移速约 272（帮核 310）再加火力等级，8 连再加 12。超拍针相对机向上 700。点按或按住空格开火。未解锁音频前无声。机心紫脉约 90ms 一拍低频 pulse。移动留紫残影。这不是点射切激束（弹蜂），不是闪痕爆链（闪击），不是纵/冲切视（加加），不是翻环擦弹（四二）。

帮阵：帮众从左右入场，落入上半场槽位后左右摆，再逐个俯冲追机。同一帮（≥4）打光立刻蹦「帮灭」，+500×倍率、紫环、约 55ms 顿帧。俯冲中的帮众分更高。这是星帮本命，不是编队俘舰（加普）。

火力：开局 0 级双针，冷却约 0.108s。吃菱形「拍」胶囊加宽：1 三叉 0.097s、2 五向 0.086s、MAX 五向 + 双金核（伤 2）0.075s。满级再吃若洞未满则洞 +1（上限 6），否则若无护罩给罩，再否则 +500×倍率。被弹若有火力会掉一枚拍可再捡，火力归零，黑洞库存重置为 3，护罩清掉。顶栏拍条跟等级走，MAX 时爆亮。

黑洞：Shift / Z / 顶栏「洞」/ 触屏「洞」，库存 3 枚（上限 6），冷却约 0.52s。机前落下半径长到约 196 的紫黑洞，持续约 0.92s：吸附近敌弹（近心化星屑）、拉空中帮众，约 0.12s 扣 1 血；收口再爆 4 伤（地匣 5）。自身约 0.5s 无敌。全屏紫闪 + 漩涡星点 + 约 68ms 顿帧。过关补 1 枚。用尽再按提示「黑洞用尽」。不是全屏金弹雨，不是径向闪光眩敌。

惊吓匣：吃「匣」胶囊，场上帮众定身约 1.12s（中/关底约 0.55s），头上蹦「!」，停射停俯冲。金闪 + 约 50ms 顿帧。金盾币挡弹不撞机；货箱被小偷拖向两侧，击落小偷「货救」+400×倍率，拖出边则「货被抢」。匣炮是地台，可飞越，只吃对空弹与黑洞。龙帮横穿并吐帮众。护罩「罩」可挡一次。

关卡：第 1 关霓虹巷中 Boss「巷霸」42 血、关底「巷门」100；第 2 关货仓港「仓卫」54 / 「货舰」128；第 3 关帮核城「龙帮」68 / 「堂主」180。帮核血量 ×1.22。中 Boss 在场时波次计时暂停。编队 V 字帮众、侧翼切入、金影俯冲、重帮、金盾币、匣炮、货箱、运拍（爆斗）、龙帮。巷门半血后扇扫；货舰旋转弹幕；堂主双环弹+瞄准并吐帮众，残血更密。空中机体相撞扣命。

得分：击杀基础分 × 连击倍率。帮众 50、俯冲 90、重帮 140、金盾币 80、匣炮 150、货箱 200、货救 400、小偷 120、爆斗 300、龙帮 280、星屑 15、帮灭 500、中 Boss 2000、关底 4000+1500×关。连击为连续击杀，约 1.4 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。击坠关底再加 1500×关。三关打穿 +8000（帮核 +10000）并「星帮尽破 / 帮核尽破」。每 20000 分 1UP，命上限 6。最高分写入 playbox-cosmo-gang-best，不存盘面；本局超过即更新。

胜利：星帮/帮核打掉第 3 关堂主后约 2.05s 结算胜利。
失败：敌弹碰到自己（判定约 4.8），或空中机体相撞，扣一命（重生无敌、黑洞期间、护罩除外）。有护罩则先碎罩约 0.62s 无敌。约 0.95s 爆炸后重生，1.55s 闪烁无敌，场上敌弹清空。三命（顶栏紫点）扣完弹出「机毁了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格射击，Shift / Z 黑洞。点按画布开火并跟机。标题页 Enter/空格/1 星帮，2 帮核。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾、残影不跟。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波。击中粒子爆开 + 短顿帧（弹中约 18ms，击杀约 34–72ms）+ 镜头微震 + 连击数字往上窜。帮灭三层：听（上行和弦）、看（紫环「帮灭」蹦字）、触（约 55ms 顿帧）。黑洞三层：听（噪声 rumble + 下滑正弦）、看（紫黑洞吸弹漩涡、星屑）、触（约 68ms 顿帧 + 强震）。惊吓匣弹簧音 + 定身感叹号。吃拍金闪。满级「MAX」蹦字。堂主碎裂金环大爆。坠机洋红大爆、约 78ms 顿帧。失败与重开都是一键 R。
