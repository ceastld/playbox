玩法：标题页「穿球」。选「穿球」打五个固定房间，选「连爆」一波接一波、球更快更密且可同时两支叉。左右方向键或 A D 走，空格向上射叉（可按住连射，叉未消失前房间模式只能有 1 支）。点顶栏「重开」或 R 开新局（标题页 R 进穿球；局中或结算重开回当前模式）。M 静音，写入 playbox-pang-mute。

场地：虚拟场 420×540。左右墙 x=16 / 404，顶 y=30，地面 y=510。人只在地面走，移速 208，身子约 16×26。叉从胸口竖直往上 560，碰到顶或平台底就消失。平台挡叉、也给球当弹面。没有梯子，人不能上台。

气球：四档（半径约 34 / 24 / 16 / 9）。重力 380，落地按档位弹回固定高度（不是按入射原样弹）。撞墙只翻左右速。叉中：3→两只 2，2→两只 1，1→两只 0，0 直接爆。裂开的两只左右飞、略上抛。身子碰到球扣一命（受击盒略小于球，约 0.82 半径）。

房间（穿球）：
1. 空厅 — 一只最大球，无平台，78 秒。
2. 双月 — 两只中球，中央一条平台，74 秒。
3. 檐下 — 一只最大 + 两只小，左右檐，70 秒。
4. 夹缝 — 最大 + 中，顶棚中间留缝，叉必须从缝里穿，66 秒。
5. 满月 — 最大 + 中 + 小，三层台，62 秒。

连爆：无时限。第 1 波两只中球；之后加球、加台、加速（约每波 +8% 水平速，封顶约 1.55 倍）。可同时 2 支叉。

得分：裂/爆 50 / 100 / 200 / 400 × 连爆倍率。倍率 = min(6, 连击数)，约 1.42 秒内不叉会断。清房 +800×房号；五房打穿再 +1800。连爆清波 +300×波次。每 10000 分 1UP，命上限 6。最高分按模式分记，写入 localStorage 键 playbox-pang-best，JSON `{r,c}`（穿球 / 连爆）。本局超过即更新。

胜利：穿球打完第 5 房结算「穿尽」。连爆无终局。

失败：球撞人或穿球时限到 0 扣一命。约 0.72 秒爆炸后重生，1.42 秒闪烁无敌。撞球保留场上剩余球；时限耗尽则重置本房布局和时钟。三命（顶栏青点）扣完弹出「命尽」，只能重开。弹层打开时方向键不再走动或开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。

操作：← → / A D 走，空格射叉。触屏拖画布跟人并点射，底栏左 / 射 / 右。标题页 Enter/空格/1 穿球，2 连爆。R 重开，M 静音。无手柄。无自动。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、叉不拖尾。触控棋盘 `touch-action: none`，避免页面跟着滚。

爽感：每次射叉枪口青闪 + 嗖声。裂球必有三层：听（音高随连爆往上爬，裂和爆音色不同）、看（色屑、光环、分数和「连×n」蹦出）、触（约 32–70ms 顿帧 + 镜头微踢，越大越长）。最小球爆掉金屑更密。撞人/时限洋红闪、约 80ms 顿帧并震一下。连爆数字往上叠到 ×6。失败与重开都是一键 R。
