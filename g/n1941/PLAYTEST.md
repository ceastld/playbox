玩法：标题页「四一」。选「四一」打三关（吉尔伯特 → 马绍尔 → 特鲁克），每关中 Boss 舰与关底舰；选「海核」同三关但卷轴更快、编队更密、海面单位更厚、Boss 多约 22% 血、额外补波。点顶栏「重开」或按 R：标题页直接开四一；对局中或结束层重开同一模式。结束层「再来」同模式；机毁「换模式」回标题；通关「海核」开海核（海核通关则「换模式」回标题）。M 静音，写入 playbox-n1941-mute。方向键 / WASD 八向飞，空格开火（可按住连射），Shift / Z 落雷。画布拖动跟机，按下开火。触屏右下「闪」落雷。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 四一、2 海核。

场地：虚拟场 480×720。双尾闪电开局 y=630、x=240，夹在 22–458 / 40–692。四一巡航约 78（关卡与连击再加），海核约 110；中/关底舰在屏时降到约 28–36。移速约 274（海核 308）再加火力等级。子弹相对机向上 700。点按或按住空格开火。未解锁音频前无声。双发螺旋桨约 90ms 一拍低频 rumble。日落海面与礁岛只做氛围，不挡弹不藏机。这不是翻环擦弹（四二），不是空陆变形（陆力）。

两层：空中单位（战斗机、俯冲机、双发中爆、运雷机）撞机扣命；海面单位（鱼雷艇、军舰、礁上高炮、护航母、中/关底舰）可飞越，只吃它们的对空弹。玩家弹打空打舰都结算。落雷期间约 0.42s 无敌，清场上全部敌弹，并对在屏单位劈伤。

火力：默认雷 0 双发（双尾各一），冷却约 0.110s。吃菱形「雷」胶囊加宽：1 四发 0.099s、2 五向 0.088s、3 六向 0.077s、4 七向+翼迹 MAX 0.066s。满级再吃若闪未满则闪 +1（上限 5），否则 +500×倍率。运雷机必掉雷。护航母与第 3 关旗舰航母常掉「闪」。被弹若有火力会掉一枚雷可再捡，火力归零。

落雷：Shift / Z / 顶栏「闪」/ 触屏「闪」，金白折线从天劈向在场单位并在近距单位间连环。空中扣 4、海面扣 6、中/关底扣 8，并清场上敌弹。全屏金闪、粒子雨、约 56ms 顿帧、镜头微震。每关 3 次，过关补满；未用余闪每枚 +500。用尽再按提示「闪用尽」。落雷不是翻环，机体不旋转不 ram。

关卡：第 1 关吉尔伯特中 Boss「鱼雷艇」38 血、关底「轻巡舰」92；第 2 关马绍尔「重巡舰」50 / 「战列舰」122；第 3 关特鲁克「补给舰」64 / 「旗舰航母」168。海核血量 ×1.22。中 Boss 在场时波次计时暂停。编队 V 字、侧翼切入、俯冲金侦、双发中爆、海面鱼雷艇/军舰、礁上高炮、护航母、运雷机。轻巡半血后扇扫；战列旋转弹幕；旗舰航母双环弹+瞄准，停泊后从甲板放飞战斗机。中/关底都是海面单位，可飞越，不可撞毁。

得分：击杀基础分 × 连击倍率。战斗机 50、俯冲 80、中爆 140、鱼雷艇 100、军舰 200、高炮 160、护航母 220、运雷 300、中 Boss 2000、关底 4000+1500×关。连击为连续击杀，约 1.4 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。击沉关底再加 1500×关。三关打穿 +8000（海核 +10000）并「航母击沉 / 海核尽破」。每 20000 分 1UP，命上限 6。最高分写入 playbox-n1941-best，不存盘面；本局超过即更新。

胜利：四一/海核打掉第 3 关旗舰航母后约 2.05s 结算胜利。
失败：敌弹碰到自己，或空中机体相撞，扣一命（落雷与重生无敌除外）。约 0.95s 爆炸后重生，1.55s 闪烁无敌，场上敌弹清空。三命（顶栏橙点）扣完弹出「机毁了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格射击。Shift / Z 落雷清弹。点按画布开火并跟机。标题页 Enter/空格/1 四一，2 海核。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾、落雷不画折线。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波。击中粒子爆开 + 短顿帧（约 34–72ms）+ 镜头微震 + 连击数字往上窜。落雷三层：听（噪声雷鸣 + 下滑锯齿）、看（金白折线劈海、全屏闪、连环）、触（约 56ms 顿帧 + 微震）。吃雷金闪。坠机洋红大爆。失败与重开都是一键 R。
