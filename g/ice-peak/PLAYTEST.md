玩法：标题页选「登顶」或「无尽」。侧视冰砖山，左右环绕。跳起来空格挥锤砸头顶/身侧的冰，从碎洞钻上更高一层。平台上有走兽会补洞，飞鸟横掠。掉出画面或撞怪丢一条命。点「重开」或 R 开新局（标题页 R 进登顶；局中或结算重开回当前模式）。M 静音，写入 playbox-ice-peak-mute。

冰砖：14 列，层距约 46。第 0、1 层全实心，开局必须跳+锤砸出洞。冰砖一锤碎；洋红石砖砸不破，只迸火星。部分层有横向漂的白云可站。左右走出画面会从另一侧出来。

跳跃与锤：↑ / W / 触屏「跳」起跳（土狼跳约 0.09 秒，缓冲 0.12 秒）。空格 / 触屏「锤」挥锤。跳中锤中碎头顶冰可借同一跳钻上去。落地锤可砸身侧同层冰，或够到斜上方的砖。S / ↓ 加速下落。

敌人：走兽沿层巡逻，踩到空洞会停下来补一块冰。飞鸟正弦掠过。锤子打中都碎。碰身（无敌时除外）丢命。约 1.05 秒无敌后在最近安全砖重生；三命用尽弹出「命尽」。

蔬菜：同一层砸碎 3 块冰后，该层冒出茄子/萝卜/白菜/玉米/西瓜，跳过去吃。

过关：登顶到第 16 层平台，跳上左右巡航的神鹰即清关。无尽没有神鹰，山继续往上长，风随高度变急，走兽飞鸟更快，按高度加分。

得分：碎冰 +20×连碎，打怪 +120×连碎，蔬菜 400–1000，无尽每新一层 +10，抓住神鹰 +2000+200×剩余命。连碎约 1.15 秒内不再碎/打/吃会断。最高分按模式分记，写入 localStorage 键 playbox-ice-peak-best，JSON `{s,e}`。本局超过即更新。

模式：登顶固定种子山，16 层神鹰。无尽风更大更频，层数随爬升生成。两套最高分不共用。

操作：← → / D 走（A 为自动，不再当左移），↑ / W 跳，空格锤，↓ / S 快坠。触屏左 / 跳 / 锤 / 右。标题页 Enter/空格/1 登顶，2 无尽。R 重开，M 静音。无手柄。

自动（AUTOPLAY）：点「自动」或按 A 开关托管（开着时按钮呈按下态并显示「停下」）。默认关闭，开关不写入存储，刷新后关闭；重开不会关掉自动。开着时忽略方向键、W/S/D、空格和触屏底栏；A / R / M / 重开仍可用。标题页开自动会进登顶；无尽也可托管（先点「无尽」再开自动，或托管中点「无尽」）。命尽 / 登顶弹层时自动停手；重开且自动仍开着则新局接着托管。速度滑条 1–4 为 慢 / 中 / 快 / 极快（默认快），写入 playbox-ice-peak-auto-speed。慢/中放慢时间便于看清爬层，快为实时，极快约 3 倍步进并跳过顿帧。AI 朝可砸/已开的碎洞走，跳起来挥锤砸头顶冰，从洞钻上更高一层，避开走兽飞鸟和脚下空洞，登顶模式到顶跳抓神鹰；不在层上左右晃。登顶和无尽都能托管。不是完美求解，风急或怪密时仍可能坠崖或撞怪。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏。触控棋盘 `touch-action: none`，避免页面跟着滚。弹层 `pointer-events: none`（面板按钮除外），顶栏重开与 R 随时可用。

爽感：每次起跳都有跳声 + 尘 + 约 28ms 顿帧。碎冰必有三层：听（水晶碎裂+音高随连碎往上爬）、看（冰片炸开、青环、分数蹦出）、触（约 50–80ms 顿帧 + 镜头微踢）。砸怪约 70ms 顿帧。撞怪/坠崖洋红闪、约 80ms 顿帧并震一下。连碎数字往上叠。失败与重开都是一键 R。
