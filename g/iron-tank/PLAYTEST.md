玩法：标题页「铁坦」。选「铁坦」打三关往上开（战壕 → 雷区 → 铁堡，关底 Boss）；选「坦林」同三关但卷轴更快、敌更密、弹更勤、Boss 更厚，速度约 ×1.26。头顶开铁坦，八向带更重惯性，炮塔略滞后车头。机枪跟炮口连射。榴弹沿炮口直线飞出，撞敌即炸（不抛弧）。碾步兵 / 突兵加分，撞坦克 / 直升机 / 关底丢一条命。碉堡挡机枪、可推开不可碾，炮弹可砸穿。炸补给箱出「弹」拾取，开上去补弹并升炮种。点顶栏「重开」或按 R：标题页进铁坦；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-iron-tank-mute。弹层打开时方向键不开车、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 480×720。岩壁约 x=40 与 x=440。铁坦开局约 (240, 572)，夹在壁内 20px、y 约 86–664。铁坦巡航约 70（坦林 102）；Boss 在场时降到 16 / 26。驾驶约 220（坦林 ×1.08），惯性比吉普更黏。点射冷却约 0.075s（坦林 0.062），弹速 700，场上最多 10 发机枪。标题页背后演示上开、碾兵、对碉开炮，不算分、不掉命。雷区正中有蜿蜒雷带（宽约 24），轧上去丢命。

铁坦三关：战壕（壕甲 62 血，左右走，三向点射，残血加瞄准）/ 雷区（雷舰 80 血，贴雷带瞄准弹，残血加两翼）/ 铁堡（铁司令 102 血，绕场扇弹，残血补坦克）。过关保留命、分、连击窗口、炮弹、箱货。坦林同三关，波次 +2 只、碉堡/箱多一座，速度 ×1.26 并随关递增，Boss 血约 ×1.22，敌射间隔约 0.74 倍，开局 4 发炮弹（铁坦 5 发）。

射击：空格朝炮口连射。点按画布跟车并开火。击中粒子 + 约 34–54ms 顿帧。

炮弹：Shift / Z / 右键 / 触屏「炮」。沿炮口直线飞，开炮后坐力把车往后推一下。出手约 0.5s 冷却。箱货 0–1：榴弹，速 480，范围约 50，伤 3。箱货 2–3：穿甲，速 640，可穿透（最多打中 3 个），伤 5。箱货 4+：高爆，跟踪坦克 / 碉 / 机 / Boss，范围约 62，伤 6。拾取「弹」会补弹升炮。没弹时弹「没弹了」。上限 9。

补弹：炸开补给箱弹出 1 枚「弹」，标「弹」，吸向铁坦，开上去即收取。+2 弹、+360×倍率，箱货上限 6。升到穿甲 / 高爆时弹「升炮 · 穿甲/高爆」。丢命清空箱货，炮种掉回榴弹，炮弹数量保留。碾箱等同炸开。

碾压：铁坦撞步兵 / 突兵即碾，基础 160×倍率，蹦「碾」，约 46ms 顿帧。坦克 / 碉堡 / 直升机 / 关底不能碾，撞上去丢命。碉堡可推开绕行。补给箱可碾开。

敌人：步兵 80 / 1 血下行点射可碾；突兵 120 / 1 血冲脸可碾；碉堡 220 / 8 血挡机枪、可推开不可碾，炮弹砸穿；坦克 260 / 5 血横跑双管，撞上丢命；直升机 190 / 3 血正弦飞俯射；补给箱 180 / 4 血，炸开出弹。坦林射速间隔更短。

Boss：壕甲关顶左右走三向弹，残血加瞄准；雷舰贴雷带瞄准弹，残血加两翼；铁司令绕场扇弹，残血补坦克。击破 Boss +3800×倍率，过关 +1400×关次×倍率。铁坦打穿再加 8000，坦林 +10000，弹「铁堡捣毁了」/「坦林通关」。

得分：击杀基础分 × 连击倍率。连击为连续命中/击杀/碾/补弹，约 1.44 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。每 15000 分 1UP，命上限 6。最高分写入 playbox-iron-tank-best，不存盘面；本局超过即更新。

失败：三命（顶栏菱形橙点）扣完弹出「撞车了 / 中弹了 / 碾上了 / 轧雷了」。约 0.88s 爆炸后底部重生，1.24s 闪烁无敌，场上敌弹清空。弹层打开时方向键不再开车；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 八向开，空格射击，Shift / Z 开炮。点按画布跟车并开火，右键开炮。触屏 上 / 左 / 炮 / 右 / 下 / 射。标题页 铁坦 / 坦林，Enter/空格/1 铁坦，2 坦林。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波。榴弹金尾后坐、穿甲白光穿透、高爆青光跟踪。击中粒子爆开 + 短顿帧（约 34–54ms）+ 镜头微震 + 连击数字往上窜。碾兵金爆、履带泥点、「碾」字。补弹金鸣、全屏闪、升炮。碉堡挡弹砂石碎屑。爆炸粒子、连击 pop。失败与重开都是一键 R。

跟邻作的差：不是豺狼（吉普、地面手雷、炸营救人上车升雷种）。不是佣兵（徒步八向、手雷抛弧越碉、救人只补雷）。不是武警（摩托纵版弹幕、边车翼力、警笛爆）。铁坦是头顶开铁甲往上突，炮口机枪、直线炮弹、碾步兵、撞甲丢命、炸箱补弹升炮种；穿甲可穿透目标，开炮有后坐。
