玩法：标题页「空孩」。选「空孩」打三关（草原 → 峡谷 → 云堡），低空夺旗、翻跟头躲弹，最后打云堡核心；选「云核」同三关但卷轴更快、敌机更密、对空更勤、云堡约 +22% 血、额外坦克与高炮。点顶栏「重开」或按 R：标题页直接开空孩；对局中或结束层重开同一模式。结束层「再飞」同模式，「换模式」回标题。M 静音，写入 playbox-sky-kid-mute。方向键 / WASD 飞（上爬升、下俯冲），空格开火（可按住连射），Shift / Z 翻跟头。点按画布：机朝指针飞并开火。触屏左簇 ◀ ▲ ▼ ▶，右簇「射」「翻」。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 空孩、2 云核。

场地：虚拟场 800×450 横版，向右卷。地面 y=418，丘陵用余弦鼓包抬高，擦地或擦塔即坠毁。镜头跟卷轴走，机夹在画面左 48 到右 70 之间、高度 24 到接近地面。空孩巡航约 118（关卡与连击再加），云核约 152；云堡在屏时降到约 32–42。移速约 230（云核 268）。子弹沿机头 540。未解锁音频前无声。

不是时飞：不能 360° 环飞，机头默认朝右，世界从左向右卷。不是空霸 / 四二 / 高炮：那些是纵版；空孩是横版双翼机，核心是翻跟头 + 低空夺旗。

翻跟头：冷却约 0.92s，持续约 0.56s，半径 38，先拉升再绕一圈。期间无敌吃弹，空中敌机被机身撞到即炸（弹「撞!」）。擦地、撞塔、撞云堡仍会坠毁。跟头中开火沿机头扫一圈。顶栏「翻」亮着表示就绪。

旗帜：三关共 16 面（草原 6、峡谷 6、云堡 4），挂在地面旗杆上。飞近旗面约 20（跟头中 28）即夺，金闪 +「旗!」。全夺再加 2000×倍率。

敌人：空中侦察机 / 王牌 / 俯冲机 / 双发轰炸机 / 鸟群会撞机；地面坦克、高炮、塔楼、云堡炮台可飞越其上方，只吃它们的对空弹，撞上实体仍坠毁。玩家弹打空打地都结算。俯冲机扎进地面自行炸开。

关卡：第 1 关草原丘陵较矮；第 2 关峡谷山脊更高更密，必须爬升再俯冲夺旗；第 3 关云堡钉在右侧，核心 96 血（云核 ×1.22），四座炮台各 10/12 血。核心在场时卷轴锁住，打爆核心约 2.05s 后胜利。

得分：击杀 / 夺旗基础分 × 连击倍率。鸟 40、侦察 80、俯冲 110、王牌 150、坦克 170、高炮 160、塔楼 90、轰炸 220、旗 280、炮台 380、核心 4000。连击为连续击杀或夺旗，约 1.42 秒无事则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。过关 1200+本关夺旗×50+剩余命×150。打穿云堡再 +6000（云核 +9000）。旗帜全夺 +2000×倍率。每 18000 分 1UP，命上限 6。最高分写入 playbox-sky-kid-best，不存盘面；本局超过即更新。

胜利：空孩 / 云核打掉云堡核心后约 2.05s 结算「旗帜夺回了」或「云核打穿」。
失败：三机（顶栏青点）扣完弹出「坠机了」（撞上地面 / 撞上塔楼 / 撞上云堡 / 撞上敌机 / 撞上鸟群 / 撞上地面火力 / 被击落 / 被航弹击中）。若本局刷新最高分弹层写「新纪录」。坠毁后约 1.28s 在镜头左侧重生，1.65s 闪烁无敌，场上敌弹清空。弹层打开时方向不再飞；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格开火，Shift / Z 翻跟头。点按画布跟机并开火。顶栏或触屏「翻」同跟头。标题页 Enter/空格/1 空孩，2 云核。结算 Enter 再飞。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、跟头粒子更少。触控画布与虚拟键 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波。击中粒子爆开 + 短顿帧（约 34–72ms）+ 镜头微震 + 连击数字往上窜。夺旗金闪 + 48ms 顿帧 +「旗!」蹦出。翻跟头呼啸 + 青轨 + 撞机「撞!」。地面目标加低锯齿。螺旋桨持续低频。坠机洋红大爆。失败与重开都是一键 R。

什么变难：峡谷山脊夹在旗帜之间，必须爬升再俯冲。云核卷更快、弹更密、云堡多血、额外坦克高炮。跟头吃弹不吃地，贴地夺旗要算准拉升。
