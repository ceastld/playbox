玩法：标题页「超魂」。选「突进」打两段侧向坞廊 / 异道，轰开闸门过关，第三关炮巢锁镜打连装炮；选「弹幕」敌弹更密更快，连装炮更厚，速度约 ×1.2。侧向跑跳，八向瞄准开火（空格按住连射）。中弹扣体力；撞兵、压机、刺带或坠井为撞击，立刻丢一命。点顶栏「重开」或按 R：标题页进突进；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「弹幕」开弹幕。M 静音，写入 playbox-super-contra-mute。弹层打开时方向键不走路、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 86 高，能上一层，不能从地面直上高层。镜头跟人右前方，连装炮战时锁在关底。地面有缺口（井），掉出屏幕底丢命。中高层平台可落上，蹲下不掉穿。人宽约 14、立高 26、蹲高 14。走约 224，空中约 0.9。标题页背后演示右进开火，不算分、不掉血。

突进三关：坞廊（工业压机 + 闸门，散弹胶囊）/ 异道（刺带 + 飞碟，激光胶囊）/ 炮巢（短突进后锁镜，连装炮 42 血）。过关保留命、分、当前枪，补满体力。弹幕同三关，速度 ×1.2 并随关递增，步兵改三向弹、壁炮连射，连装炮血约 ×1.28，开局仍是步枪。

武器：默认步枪 0.15s 一发、屏上约 4 发。S 散弹五向扇。L 激光穿敌穿闸。空中八向；落地按住空格+上可立定上射（不跳）；蹲下只打左右。死亡重生变回步枪。H 胶囊回 4 体。

敌人 / 机关：卫兵巡逻点射 100；突兵冲脸 150；飞碟抛弹 200；壁炮转向连射 250；胶囊 300，击破掉 S/L/H。闸门挡路 400/800，打穿才过关。压机上下砸，砸中即撞击丢命。刺带踩上即死。连装炮三管轮射，残血加环弹；弹幕再加扇面。击破连装炮再加 5000×倍率，过关 +2000×关。突进打掉连装炮后再加 8000，弹「连装炮拆了」；弹幕弹「弹幕清场」。

得分：击杀基础分 × 连击倍率。连击为连续击杀，约 1.32 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 16000 分 1UP，命上限 6。最高分写入 playbox-super-contra-best，不存盘面；本局超过即更新。

失败：中弹扣体，体力打空丢一命；撞兵 / 压机 / 刺带 / 坠井立刻丢一命（无敌除外，坠井强制）。约 0.82s 爆炸后在最近扎实地面重生，满体、1.2s 闪烁无敌，枪变回步枪。三命（顶栏绿点）扣完弹出「被击中了 / 体力打空了 / 坠入井里了 / 撞上了 / 被压扁了 / 踩上刺了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳（按住空格且不走时可立定上射），↓ / S 蹲，空格开火。点按画布同空格按住。触屏 左 / 跳 / 射 / 右 / 蹲。标题页 突进 / 弹幕，Enter/空格/1 突进，2 弹幕。R 重开，M 静音。无手柄。

与魂斗不同：不是一打即死、不是密林捡 M/S/L/F，是体力条 + 压机撞击 + 胶囊 S/L + 关底连装炮。与枪星不同：不是三枪循环、没有近斩、没有弱点核。与合金不同：没有坦克、手雷、人质。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：开火枪口闪 + 粒子 + 步枪/散弹/激光各一音色。击杀/爆炸粒子 + 30–80ms 顿帧 + 镜头微震 + 连击数字往上窜。压机砸地重震。闸门崩开金爆。失败与重开都是一键 R。
