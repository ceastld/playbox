玩法：标题页「魔城」。选「魔城」打三关（城门→地窟→伯爵，关底巨蝠 / 死神 / 伯爵，伯爵打空后化蝠再打一形态）；选「城核」敌更快更密，额外补人鱼与蝙蝠（甲骑不加倍），头目血约 ×1.22，美杜莎头从第一关就开始飞。侧向走跳，空中锁方向（硬跳）。空格挥鞭，Shift / Z 丢副武器（耗心）。点顶栏「重开」或按 R：标题页进魔城；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「城核」开城核。M 静音，写入 playbox-castlevania-mute。弹层打开时方向键不走路、空格不挥鞭；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 80 高，能上一层，不能从地面直上高层。楼梯 45° 连接层：脚下踩梯口按上攀登，高层梯口按下或朝下坡方向走进入。梯上左右/上下沿斜线走，挥鞭时停步。镜头跟在人右前方，Boss 战时锁在关底。地面有水坑缺口，人鱼从坑里跃出；掉出屏幕底丢命。人宽约 14、立高 26、蹲高 14。走约 132，空中速度锁定起跳时的水平速度。标题页背后演示右进挥鞭跳坑，不算分、不掉血。

魔城三关：城门（巨蝠 18 血，皮鞭→锁链、飞刀/十字，水坑人鱼）/ 地窟（死神 24 血，晨星、斧、圣水，甲骑抛斧）/ 伯爵（伯爵 32 血，化蝠后再约 18 血，瞬移喷火再俯冲）。过关保留命、心、鞭长、副武器、分。城核同三关，速度 ×1.30 并随关递增，额外补兵，Boss 血约 ×1.22，开局仍是皮鞭。击破头目 +4500×倍率，过关 +2000×关。魔城打掉蝠形伯爵后再加 9000，弹「魔城已破」；城核弹「城核平了」。

鞭：空格挥一次约 0.28s，落地挥鞭时不能走。皮鞭 36 / 锁链 58 / 晨星 86，蜡烛掉「鞭」升级，晨星伤害 2。副武器：飞刀直线、斧抛物线（可穿 1）、十字回旋镖（飞出再折返可再打、穿 2）、圣水落地燃池持续灼烧，均耗 1 心。无副武器或心不够会 toast。蜡烛还掉小心、大心、烤肉（1UP，命满则心 +8）。

敌人：僵尸慢走 100；蝙蝠正弦 150；人鱼从水坑跃出再走 180；甲骑抛斧 250；美杜莎头正弦穿屏 200。Boss 巨蝠洒唾、死神甩镰、伯爵瞬移火球后化蝠俯冲。与魔界不同：不是丢枪碎甲，是鞭与副武器，一碰丢命。与魔剑不同：不是长剑闯塔救同伴。与鬼铠不同：没有铠甲/金甲魔法，空中不能改向。

一碰丢命：没有生命条。挨弹 / 撞兵 / 坠渊立刻扣一条命（无敌除外）。约 0.82s 后在最近扎实地面重生，1.22s 闪烁无敌（城核 0.92s）。三命（顶栏紫点）扣完弹出「被击中了 / 坠入深渊了 / 被伯爵击倒了」。每 15000 分 1UP，命上限 6。最高分写入 playbox-castlevania-best，不存盘面；本局超过即更新。

得分：击杀/打蜡基础分 × 连击倍率。连击为连续击杀或打蜡，约 1.36 秒无动作则断；挨打立刻断。倍率 = 1 + min(4, floor((连击-1)/3))。

失败：一碰 / 坠崖扣一命。弹层打开时方向键不再挥鞭；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳（梯口上楼），↓ / S 蹲或下梯，空格挥鞭，Shift / Z 副武器。点按画布同空格。触屏 跳 / 鞭 / 副 / 左 / 下 / 右。标题页 魔城 / 城核，Enter/空格/1 魔城，2 城核。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：挥鞭必有三层——听（抽响噪声+下扫）、看（青/金鞭梢、蜡火爆开、分数蹦出）、触（约 34–72ms 顿帧 + 镜头踢）。打蜡金鸣+粒子爆。副武器出手全屏闪：飞刀脆钢、斧沉啸、十字金回旋、圣水池紫焰。连击数字往上叠。伯爵化蝠有变身轰鸣与全屏闪。失败与重开都是一键 R。
