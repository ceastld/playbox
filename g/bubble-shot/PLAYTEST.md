玩法：标题页「泡弹」。点「闯关」打八关，点「限时 90s」冲分。盘面六角密铺，偶数行 8 颗、奇数行 7 颗，挂在顶上的齿状天花板上。六色霓虹泡（粉 / 青 / 金 / 紫 / 绿 / 橙）。对准同色打进去，连成三颗或以上就爆。爆完不连天花板的整串坠落加分。点「重开」或 R 立刻新开一局。M 静音。A 或「自动」开关托管。顶栏可切「闯关 / 限时」，点另一模式才切换重开，点当前模式不动。

闯关：八关，清光当前盘进入下一关，压顶间隔更短、颜色更多。第一关每 8 发压一格，终幕每 4 发。八关都清弹出「通关了」，另加 1000。贴到粉虚线地面弹出「贴地了」。最高分写入 localStorage 键 `playbox-bubble-shot-best`（JSON，字段 `campaign`）。不存盘面，刷新只留最高分、上次模式、静音和自动速度。

限时：90 秒冲分。倒计时在第一次发射后开始，弹层与切走页面会暂停。时间耗尽弹出「时间到」。盘面清光会立刻落下一盘（清盘加分并保留连击）。最高分写入同一键的 `timed` 字段。模式写入 `playbox-bubble-shot-mode`。

天花板：每 N 发（本关 `dropEvery`）整盘往下压一格。还剩 3 / 2 / 1 发时顶栏金点变粉并警告「还剩 n 发」/「最后一发！」。压顶后计数重置。贴地判定在落地消完、坠落完、以及压顶动画结束后做：先消再判死，所以贴线的那一串如果爆掉或坠走，可以救回来。

得分：炸掉 n 颗得 `n × 10 × 连击`。坠落第 i 颗（从 0）得 `20 × 2^min(i,6) × 连击`，即 20、40、80… 封顶 1280 再乘连击。连续有效炸掉连击 +1（从 ×1 起跳）；打空（不足三颗）连击回到 ×1。清盘加 `400 + 关卡×120`。空发、墙弹不计分。

操作（指针 / 触屏）：移动瞄准，点按或轻触立刻按该方向射出。画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。轨迹虚线和落点浅影只在可发射时出现。顶栏按钮不会误射。

操作（键盘）：← → 或 D 转炮，空格或回车发射。A 为自动（不再当左转）。结束层空格/回车等于重开；标题层空格开闯关。方向键和空格会 preventDefault，避免页面跟着滚。

手感：有效炸掉必有三层——爆裂音（颗数和连击升调）、粒子/光环/弹出分数、短顿帧（约 34–78ms）加镜头下踢。坠落串会逐颗蹦出加倍数字并有上行音阶。打空是闷响加微震，几乎无粒子。撞墙有短促弹音。压顶有低频轰一声。系统开了减少动态则缩短顿帧、少粒子、不抖屏。

限制：没有悔棋、没有交换下一发。声音要在一次按键或点按之后才有。失败 / 时间到弹层沉在棋盘下方，不挡「重开」。点弹层外面可收起看盘面，之后只能重开。

自动（AUTOPLAY）：点「自动」或按 A 开关托管（开着时按钮呈按下态并显示「停下」）。默认关闭，开关不写入存储，刷新后关闭；重开不会关掉自动。开着时忽略瞄准点按、空格发射和方向键 / D 转炮；A / R / M / 重开 / 切模式 / 速度滑条仍可用。标题页开自动会按当前模式开局并托管。贴地 / 通关 / 时间到弹层上自动停手；重开且自动仍开着则新局接着托管。闯关和限时都可自动，规则不变（限时第一次发射开始计时，清盘接着打）。速度滑条 1–4 为 慢 / 中 / 快 / 极快（约 420 / 200 / 70 / 0 ms，默认快），写入 playbox-bubble-shot-auto-speed。慢/中看得见炮口转到落点再发射；快/极快更快出手，极快选定角度后立刻发射。AI 枚举可到达的落点（含撞墙反弹），在副本盘上模拟落地、三连爆炸和悬空坠落，只打能清的：优先三颗以上同色爆串，坠落串加分更高所以会找连锁掉落，打不出爆则贴到同色做下一手，不随机空打。不是完美求解，颜色不齐或夹缝里仍可能堆高贴地。
