玩法：标题页「异兵」。选「异兵」打三关（锈廊→脉巢→翼核，关底 Boss）；选「兵核」敌更快更密，Boss 更厚，速度约 ×1.30。八向悬浮（地面可跑，空中像喷气一样飞），空格/Z 点射，按住蓄力场，松开发力场弹。Shift 八向冲刺，冲刺中无敌并可撞碎兵、穿弹。撞上即死。蓄满力场时挨打会「反击」而不是丢命。点顶栏「重开」或按 R：标题页进异兵；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「兵核」开兵核。M 静音，写入 playbox-alien-soldier-mute。弹层打开时方向键不走路、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184。地面有缺口（航隙），掉出屏幕底丢命。中高层平台可落下；按住下降会穿过非地面平台。人宽约 13、高 22。地面走约 256。空中八向悬浮，最大约 272，松手会缓降。不是魂斗那种跳弧，也不是枪星的近斩换枪。标题页背后演示右飞开火冲刺蓄力，不算分、不掉血。

异兵三关：锈廊（颚门 48 血，口开才是弱点，合上挡普通弹；有炎波箱）/ 脉巢（核蛛 62 血，贴地贴顶爬，放射弹，会补爬刺；有追踪箱）/ 翼核（异皇 84 血，三段：扇弹 / 扑杀 / 追踪核弹）。过关保留命、分、当前枪。兵核同三关，速度 ×1.30 并额外补兵，Boss 血约 ×1.24，开局仍是凰弹。

武装：默认凰弹 0.07s 一发、屏上约 8 发。炎波较慢、单发 2、略厚可穿。追踪会拐弯咬最近目标。死亡重生变回凰弹。力场与枪无关：按住空格超过约 0.38s 松开打出力场（穿、4–9 伤），蓄满约 0.88s 更大更金。冲刺 0.18s、冷却约 0.56s，八向，撞兵 3 伤。

敌人：巡翼蛇形点射 120；爬刺巡地 100；弹巢三向 180；冲颚见人就撞 160；炮节瞄准 220；卫核厚甲双弹 280，击破掉炎/追。Boss 颚门开合口、核蛛爬顶、异皇三阶段。击破 Boss 再加 4200×倍率，过关 +2000×关。异兵打掉异皇后再加 8000，弹「翼核捣毁了」；兵核弹「兵核清场」。

得分：击杀基础分 × 连击倍率。连击为连续击杀/命中，约 1.32 秒无命中则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 16000 分 1UP，命上限 6。最高分写入 playbox-alien-soldier-best，不存盘面；本局超过即更新。

失败：挨弹 / 撞兵 / 坠航隙扣一命（无敌、冲刺除外）。力场蓄到约一半以上时挨打会反击：清近弹、反弹、短无敌，不丢命。约 0.82s 爆炸后在最近扎实地面重生，1.35s 闪烁无敌，枪变回凰弹。三命（顶栏绿点）扣完弹出「被击中了 / 中弹了 / 坠入航隙了 / 撞上了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 升空（地面弹起进入悬浮；按住空格且不走时可立定上射），↓ / S 俯冲，空格/Z 射击（按住蓄力场），Shift 冲刺。点按画布同空格按住。触屏 左 / 升 / 射 / 右 / 降 / 冲。标题页 异兵 / 兵核，Enter/空格/1 异兵，2 兵核。R 重开，M 静音。无手柄。

与魂斗不同：不是跳蹲捡 M/S/L/F，是喷气悬浮 + 冲刺穿弹 + 蓄力场/反击。与金弹不同：没有载具、手雷、人质。与枪星不同：一打即死，没有近斩和三枪循环，力场与冲刺才是主菜。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：开火枪口闪 + 粒子 + 凰弹/炎波/追踪各一音色。击杀/爆炸粒子 + 30–80ms 顿帧 + 镜头微震 + 连击数字往上窜。冲刺残影青光、力场金爆、反击全屏闪。失败与重开都是一键 R。
