玩法：标题页「雷狐」。选「雷狐」打三关短推进（雨镇 → 空堡 → 王座，关底 Boss）；选「狐巷」同三关但更密更快，Boss 更厚，速度约 ×1.26。徒步向右跑跳射击，跳即空翻：空翻期间无敌、能碾步兵 / 跑兵 / 翼机并碎玻璃。贴身没在空翻会撞死，丢一条命。点顶栏「重开」或按 R：标题页进雷狐；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-thunder-fox-mute。弹层打开时方向键不走路、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；普通跳约 80 高，能上一层，不能从地面直上高层。按住 ↑ / W 再跳为高翻约 104，可从中层上高层。镜头跟在人右前方，Boss 战时锁在关底。地面有缺口（裂隙，约 70 宽，起跳可过），掉出屏幕底丢命。中高层平台可落上。人宽约 14、立高 26、蹲高 16。走约 214，空中约 0.92。标题页背后演示右进开火、跳沟、空翻碎玻璃，不算分、不掉命。

雷狐三关：雨镇（铁兽 24 血，平射可蹲过 + 残血抛弹）/ 空堡（堡心 34 血，浮空弹环，残血加瞄准）/ 王座（雷首 46 血，走射双弹，残血抛弹并招匪）。过关保留命、分、连击窗口、当前枪和弹药。狐巷同三关，约每三只补一只（玻璃 / 机枪巢 / 枪械不补），速度 ×1.26 并随关递增，Boss 血约 ×1.22。

射击：空格朝瞄准方向开火。方向 / WASD 走；↑ / W 上瞄，空中 ↓ / S 下瞄，落地 ↓ 蹲（铁兽平射可蹲过）。跳是 Shift / Z，和上瞄分开。贴身自动改近斩（刃），没弹也是刃。手枪约 0.12s 一发、场上约 5 发；步枪约 0.07s、可穿、场上约 8；雷弹约 0.32s、3 伤并爆，场上约 3。点按画布同空格按住。击中粒子 + 约 34–74ms 顿帧。

空翻：跳即翻。翻的约 0.48s 内无敌，碾碎步兵 / 跑兵 / 翼机 / 玻璃（基础分 ×1.5，蹦「碾」「碎」）。机枪巢 / 厚甲不能整碾，空翻撞上去扣 1 血并弹开。贴上去（没在翻）立刻丢命。雷条满后下一次起跳变「雷翻」：更高更快，带电碾，连巢 / 甲也重创，撞 Boss 约 2 伤。

玻璃：竖在路上挡走。空翻 / 近斩 / 开枪 / 雷弹都能碎，蹦「碎」、青鸣。不碎就顶回去，不会因玻璃丢命。

武器：开局刃无限近斩。地上捡手枪 20 / 步枪 30 / 雷弹 3。同种叠加（有上限），换种替换。打空变回刃。过关带着枪走，死亡重生变回刃。

敌人：步兵 80 / 1 血巡逻点射；跑兵 110 / 1 血见人冲脸；翼机 100 / 1 血正弦飞俯射；机枪巢 160 / 3 血不能整碾；厚甲 200 / 3 血巡逻对射不能整碾。狐巷射速间隔更短。

Boss：铁兽钉在关底右侧平射（蹲可过）+ 斜弹，残血抛弧弹；堡心浮空弹环，残血加瞄准弹；雷首左右走双弹，残血抛弹并招匪。击破 Boss +3600×倍率，过关 +1400×关次×倍率。雷狐打穿再加 8000，狐巷 +10000，弹「王座捣毁了」/「狐巷得手」。

得分：击杀基础分 × 连击倍率；空翻碾再 ×1.5。连击为连续命中/击杀/碎玻璃/捡枪，约 1.42 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。2 连起蹦「×N」，升档时再顿一帧。每 16000 分 1UP，命上限 6。最高分写入 playbox-thunder-fox-best，不存盘面；本局超过即更新。

失败：三命（顶栏橙点）扣完弹出「撞上了 / 中弹了 / 坠入裂隙了」。约 0.86s 爆炸后在最近扎实地面重生，1.22s 闪烁无敌，枪变回刃。弹层打开时方向键不再走路；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 上瞄或高翻，↓ / S 蹲或下瞄，空格射击 / 近斩，Shift / Z 跳（空翻）。点按画布同空格按住。触屏 左 / 跳 / 射 / 右 / 下。标题页 雷狐 / 狐巷，Enter/空格/1 雷狐，2 狐巷。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波（手枪尖、步枪连、雷弹低炸）。近斩青弧。击中粒子爆开 + 短顿帧（约 34–74ms）+ 镜头微震 + 连击数字往上窜。空翻碾金爆、玻璃碎青鸣。雷翻满条金鸣、全屏闪、电弧拖尾。失败与重开都是一键 R。

跟邻作的差：不是枪力（夺空机甲、机甲碾兵、装甲打空撞毁）。不是佣兵 / 恐龙（拳、恐龙、凯迪拉克兜风）。不是外域（纵版飞、360° 炮、店）。不是超魂 / 枪星（八向合成枪、近斩换枪、弱点核）。雷狐是刃 + 有限弹药 + 空翻碾敌，贴身没翻就撞死，玻璃挡路要碎。
