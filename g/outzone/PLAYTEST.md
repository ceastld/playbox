玩法：标题页「外域」。选「外域」打三关往上推进（沙脊 → 锈城 → 外核，关底 Boss）；选「谷雨」同三关但卷轴更快、敌更密、弹更勤、Boss 更厚，速度约 ×1.28。驾驶机甲在纵向峡谷里八向走，空格朝面向连射。连击攒满「球」条打出超球：撞左右壁弹回、可穿一层。Shift / Z 跳起（约 84 高），越过贴地爬虫 / 滚刺 / 炮座以及贴地弹和震圈。撞敌、吃弹、被砸丢一条命。点顶栏「重开」或按 R：标题页进外域；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-outzone-mute。弹层打开时方向键不走路、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 480×720。峡谷壁约 x=38 与 x=442。机甲开局约 (240, 572)，夹在壁内 14px、y 约 86–664。外域巡航约 76（谷雨 108）；Boss 在场时降到 18 / 28。走约 228（谷雨 ×1.08），空中约 0.92。起跳初速 520、重力 1600，跳高约 84，离地 ≥18 即可越过贴地物。点射冷却约 0.086s（谷雨 0.074），弹速 640，场上最多 8 发机炮。标题页背后演示上走开火、跳越爬虫，不算分、不掉命。

外域三关：沙脊（砂颚 52 血，左右走，三向贴地弹 + 震圈，要跳）/ 锈城（闸卫 68 血，顶部门闸，竖道弹幕兼五发散）/ 外核（域心 88 血，绕场，八角弹球会撞墙弹，偶发双震圈）。过关保留命、分、连击窗口、球条。谷雨同三关，波次 +2 只、炮座多两座，速度 ×1.28 并随关递增，Boss 血约 ×1.24，敌射间隔约 0.74 倍。

射击：空格朝最近面向八向连射。击中/击杀掉「球」。满条进入约 2.24s 超球：青绿弹、2 伤、穿 1、撞左右壁与顶边最多弹 4 次。连击 ≥9 时超球变三向金弹。顶栏「球」条显示热量 / 超球窗口。击中粒子 + 约 32–50ms 顿帧。捡场上青「球」补 0.55。

跳跃：Shift / Z 或触屏「跳」。约 84 高，落地有挤压与尘。滞空时贴地爬虫 / 滚刺 / 炮座、贴地弹、震圈从脚底过去；浮雷 / 翼蜂 / 高弹仍打中。落地砸尘。

敌人：爬虫 80 / 1 血贴地走射，可跳过；跳蚤 110 / 2 血自己也会跳；浮雷 90 / 1 血正弦下飘，跳不过；炮座 160 / 3 血钉两边；翼蜂 130 / 2 血侧扑，跳不过；滚刺 100 / 1 血撞壁来回滚，可跳过。谷雨射速间隔更短。

Boss：砂颚在关顶左右走，三向贴地弹兼震圈（跳）；闸卫钉在顶上，竖道弹（走位）或五发散；域心绕场，八角弹球会弹墙，残血双震圈。击破 Boss +3200×倍率，过关 +1400×关次×倍率。外域打穿再加 8000，谷雨 +10000，弹「外核捣毁了」/「谷雨通关」。

得分：击杀基础分 × 连击倍率。连击为连续命中/击杀，约 1.5 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。每 15000 分 1UP，命上限 6。最高分写入 playbox-outzone-best，不存盘面；本局超过即更新。

失败：三命（顶栏青点）扣完弹出「撞上了 / 中弹了 / 被砸中了 / 机甲碎了」。约 0.88s 爆炸后底部重生，1.22s 闪烁无敌，场上敌弹清空。弹层打开时方向键不再走路；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 八向走，空格射击，Shift / Z 跳。点按画布跟机并开火。触屏 上 / 左 / 跳 / 右 / 射。标题页 外域 / 谷雨，Enter/空格/1 外域，2 谷雨。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波。超球弹墙叮一声 + 青绿拖尾。击中粒子爆开 + 短顿帧（约 32–50ms）+ 镜头微震 + 连击数字往上窜。起跳尘、落地挤压。震圈金环。爆炸粒子、连击 pop。失败与重开都是一键 R。

跟邻作的差：不是合金（侧向救人开车丢雷），不是机甲（侧视独立转炮 + 装甲条），不是钢魂（横向贴地冲刺碾压打出钢轨），不是怒火（双摇杆围猎）。外域是机甲往上走的纵向跑打，跳越贴地，超球撞墙弹回，撞击丢命。
