玩法：标题页「大王」。选「大王」打三关（熔脊 → 王垒 → 核殿），每关密编之后出巨大关底王；选「核雨」同三关但卷轴更快、编队更密、敌弹更勤、天上慢慢落核滴弹、Boss 多约 22% 血。点顶栏「重开」或按 R：标题页直接开大王；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-daioh-mute。←↑↓→ / WASD 八向飞，空格射击（可按住连发并蓄王核），Shift / Z 或顶栏「爆」扔王爆。画布拖动跟舰，按下开火。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 大王、2 核雨。

场地：虚拟场 480×720。舰开局 y=640、x=240，夹在 22–458 / 40–692。大王巡航约 86（核雨 122）；关底王在屏时降到 24。移速约 272（核雨 316）。点射连发。未解锁音频前无声。三关名：熔脊、王垒、核殿；顶栏在 Boss 时改成「脊王 / 垒王 / 大王」。

五武：开局散 0。运核掉一枚循环核，约 0.62 秒轮一格：散 → 束 → 追 → 炎 → 阔 → 爆。同种升到 MAX（3）；换种保留最多 2 级且至少 1 级。满级再吃同种 +500×倍率。坠机掉一枚当前武装核且火力降 1，武装种类保留。
- 散：2/3/5/7 向扇刃，弹速 740，冷却约 0.092–0.074s
- 束：1–3 道穿束（穿 4），弹速 920，冷却约 0.118–0.092s
- 追：1–4 枚寻敌雷，弹速约 400，冷却约 0.148–0.110s
- 炎：1–4 枚落炎，触敌或落地溅射（半径约 38），冷却约 0.132–0.100s
- 阔：3/4/5/7 发散近距重弹，寿命约 0.28s，冷却约 0.108–0.086s
核雨冷却再 ×0.88。顶栏核条是王核蓄力，不是火力。

王核 / 王炮：按住空格约 2.5s 蓄满（0.40/s）。满则自动放出寻敌王炮：粗金红柱锁最近敌人，伤约 28+火力×4/秒，顺路消敌弹。放出时核条约 0.36/s 抽空；松手即断、核条 0.16/s 回落。顶栏满核爆亮，蹦「王炮」。

王爆：开局 3 枚，上限 6。Shift / Z 清掉全部敌弹、全体扣血（普通 12 / 关底 16），全屏闪、金核环、约 78ms 顿帧，自身约 0.48s 无敌。过关补 1 枚。用尽再按提示「爆弹用尽」。

敌人：熔蝠 50 / 2 血、俯核 80 / 2、熔台 150 / 6（地面，可飞越只吃对空弹）、核卫 240 / 10、运核 280 / 8（死时掉循环核）、核滴 90 / 3（死时炸三发散）、侍炮 220 / 14（核雨 18）。血量再乘核雨 1.22（关底王/侍炮按上表）。核雨 V 字 +2、俯核 +1、核滴 +2、额外一只核卫；射速约 0.74 倍间隔、弹速约 182（大王 142）。核雨另有慢落核滴弹，约 0.55s 一发（王在屏时 0.38s）。

Boss：脊王 110 血 / r48，垒王 148 / r62，大王 210 / r88（核雨 ×1.22 → 134 / 180 / 256）。入场约 1.45s 后缓荡。高血扇瞄+偶发环，半血密环兼瞄准，残血双环+扇瞄并吐熔蝠。两侧侍炮绕核瞄准；大王多一枚侍炮。判定约为半径 ×0.52，可从侧翼擦过。打爆后约 1.4s：前两关进下一关，核殿结算。

得分：击杀基础分 × 连击倍率。关底再加 3500+1500×关。连击为连续击杀/吃核，约 1.4 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。过关 +1600×倍率。大王打穿再 +8000，核雨 +10000。每 18000 分 1UP，命上限 6。最高分写入 playbox-daioh-best，不存盘面；本局超过即更新。

胜利：大王/核雨打爆第 3 关大王后约 1.4s 结算「核殿尽碎」/「核雨通关」。
失败：三命（顶栏朱红冠点）扣完弹出「舰毁了」。敌弹（判定约 4.5）或撞空中机体/关底王扣一命；熔台可飞越。约 0.92s 爆炸后底部重生，1.5s 闪烁无敌，场上敌弹清空。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格射击（蓄王核），Shift / Z 王爆。点按画布开火并跟舰。标题页 Enter/空格/1 大王，2 核雨。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 五武各异音色（散升频方波 / 束锯齿下滑 / 追三角上滑 / 炎噪声 / 阔方波重拍）。击中粒子爆 + 短顿帧（约 34–50ms）+ 镜头微震 + 连击数字往上窜。王炮三层：听（锯齿上冲 + 方波 + 正弦）、看（金红寻敌柱、核条爆亮、蹦「王炮」）、触（约 50ms 顿帧 + 微震）。王爆三层：听（噪声 rumble + 锯齿下滑）、看（核日环、全屏闪）、触（约 78ms 顿帧 + 强震）。吃核换武色闪。坠机洋红大爆、约 72ms 顿帧。失败与重开都是一键 R。
