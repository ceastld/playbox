玩法：标题页「影忍」。选「夜城」打三关（巷口→塔影→魔殿，关底 Boss）；选「血战」同三关，生命 8 格（夜城 16），敌更快更密，Boss 略厚。侧向走跳，空中可改向。贴上墙壁会抓住并慢滑，再按跳蹬出去。Z 挥刀，C / X 丢忍术（耗忍）。点顶栏「重开」或按 R：标题页进夜城；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「血战」开血战。M 静音，写入 playbox-ninja-gaid-mute。弹层打开时方向键不走路、Z 不斩；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 80 高，能上一层，不能从地面直上高层。墙是细霓虹立面，空中撞上即贴住，滑速约 78。蹬墙水平约 176、垂直约 418，冷却约 0.14s 避免贴回原墙，双墙夹道可左右连蹬爬上高层。镜头跟在人右前方，Boss 战时锁在关底。地面有缺口，掉出屏幕底丢命。中高层平台可落上，蹲下（↓ / S）变矮。人宽约 14、立高 26、蹲高 14。走约 148。标题页背后演示右进斩杀与贴墙，不算分、不掉血。

夜城三关：巷口（蛮将 18 血，手里剑）/ 塔影（铁拳 24 血，风车）/ 魔殿（邪神 32 血，炎轮）。过关保留命、生命、忍、忍术、分。血战同三关，速度约 ×1.18 并随关递增，出兵更勤，Boss 血约 ×1.12，开局生命 8。

刀：Z 挥一次约 0.20s，空中可斩，贴墙可斩。刀可打掉飞刀。忍术：手里剑直线耗 3 忍、风车去回耗 5 忍（可穿）、炎轮绕身两团火耗 8 忍伤 2。无忍或忍不够会 toast。灯笼掉忍、生命、手里剑 / 风车 / 炎轮、偶发 1UP。

敌人：鸟正弦飞 100，会从镜头外补兵；狗贴地猛冲 150，会掉坑；兵慢走 200，会掷飞刀，刀也可被斩掉。关内鸟狗士兵一开始就密，中途继续从两侧补鸟和狗。Boss 蛮将走近挥砍、铁拳起跳砸地、邪神瞬移火球。击破 Boss 再加 3800×关×倍率，过关 +1600×关。夜城打掉邪神后再加 8000，弹「影已散」；血战弹「血战得手」。

生命与忍：夜城生命 16 格，血战 8 格，顶栏条显示。挨打扣 1（兵 / Boss 2），0 生命丢一条命。忍是忍术弹药，灯笼掉，上限 99，开局 20。三命（顶栏红点）扣完弹出「生命耗尽了 / 坠入深渊了 / 被头目击倒了」。约 0.82s 后在最近扎实地面重生，满生命，约 1.12s 闪烁无敌。每 20000 分 1UP，命上限 6。最高分写入 playbox-ninja-gaid-best，不存盘面；本局超过即更新。

得分：击杀 / 打灯基础分 × 连击倍率。连击为连续击杀或打灯，约 1.35 秒无动作则断；挨打立刻断。倍率 = 1 + min(4, floor((连击-1)/3))。

失败：生命归零 / 坠崖扣一命（无敌除外）。弹层打开时方向键不再走路；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W / 空格跳（贴墙再跳即蹬墙），↓ / S 蹲或松墙，Z 斩，C / X 忍术。点按画布同 Z。触屏 左 / 跳 / 斩 / 右 / 忍。标题页 夜城 / 血战，Enter/空格/1 夜城，2 血战。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：挥刀必有三层——听（刀啸噪声+下扫）、看（青白刀弧、灯火爆开、分数蹦出）、触（约 48–62ms 顿帧 + 镜头踢）。蹬墙必有三层——听（蹬墙噪声+上扫）、看（青屑+火花）、触（约 28ms 顿帧 + 镜头侧踢）。忍术出手全屏闪。炎轮绕身赤焰。连击数字往上叠。失败与重开都是一键 R。
