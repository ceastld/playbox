玩法：标题页「沙圈」。选「沙圈」三圈椭圆（直道看台 → 左倾高弯 → 后直椰林 → 再弯回终点）；选「圈核」同椭圆但车更密、弯更甩、喷掉得更快、终段车团更厚。点顶栏「重开」或按 R：标题页直接开沙圈；对局中或结束层重开同一模式。结束层「再冲」同模式，「换模式」回标题。M 静音，写入 playbox-daytona-mute。← → / A D 转向，↑ / W / 空格 / 按住画布加油门，↓ / S 刹车，Shift / Z 或顶栏「喷」或按住画布上半开喷。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。

场地与碰撞：虚拟场 800×450，伪 3D 封闭椭圆，路段循环。玩家横向约 ±1.12 为路面，超过即冲出（减速、扬尘）；时速约 40% 以上冲出或横向 >1.58 即撞出。来车偏移与玩家横向差小于 0.32 且纵向约 210 内即碰上：没开喷且没在高速吸力里则撞车减速；喷着或吸力时速 >62% 且时速 >36% 则顶飞（顿帧、爆粒子）。撞车时速约剩 16%、约 1.48 秒复原、70ms 顿帧，不会出局。超时才结束。

吸力与喷：槽 0–1。贴在前车正后方（纵向约 90–2500、横向差 <0.26）进入吸力：顶速约 ×1.16、加速更快、槽每秒回 0.55（圈核 0.42），画面青线、提示「吸力」。没贴尾时槽每秒只回 0.08。Shift / Z 喷：低于 0.06 点不着；开喷顶速约 ×1.34、加速更快、离心更狠，尾焰+橙色速度线，沙圈每秒耗 0.38、圈核 0.52。空了提示「喷空了」。过线回槽 +0.22。高弯外侧吃坡，离心被削。

终段圈团：末圈约 68% 路程刷一队。沙圈 6 台 / 圈核 9 台，头车是圈王（金框，血量 3 / 圈核 4）。圈王会贴着你的横向堵路。喷（或高速吸力）顶上去扣血，血空才爆。不必清完也能冲线，但堵路。

圈数：封闭椭圆 3 圈。过 START 线加时并进下一圈，第 3 圈过 GOAL 胜利。沙圈看台+落日椰林；圈核同场夜灯。

时间与分数：沙圈开局 42 秒，过线 +13；圈核 32 秒、+10，顶速更高、车更多。超时才结束（车会滑停再弹层）。距离一直加分；超车 80×连击×倍率（吸力/喷中再 ×1.35）；喷顶飞 160×（圈王击破 480×，顶一层 100×）；疾风（时速 >80% 且在路上）每 0.66 秒一层，吸力 0.58、喷时 0.50；过线 800+；终点 2800+剩余时间。连击约 1.9 秒无超车/顶飞则断；自身撞车立刻断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。最高分按模式写入 playbox-daytona-best，JSON `{c,m}`（沙圈 / 圈核），不存盘面；本局超过即更新。

胜利：第 3 圈冲过 GOAL。失败：时间到 0。弹层不挡 R 与顶栏重开。

操作：方向键 / WASD 转向+油门+刹车；空格油门；Shift / Z 喷。点按画布加速并按左右位置转向，按住上半同时喷。标题页 Enter/空格/1 沙圈，2 圈核。结算 Enter 再冲。无手柄。无自动。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、少粒子、无速度残影。触控画布 `touch-action: none`。标题页背后是演示驶，绕圈不算分。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：贴尾吸力青线+谁osh；喷尾焰+橙色速度线+引擎拔高；顶飞顿帧约 38–78ms、爆粒子/环/「爆圈 ×N」蹦字，连击音高往上爬；撞车粒子+顿帧+引擎闷一下；过线金闪、加时数字。失败与重开都是一键 R。

什么变难：左弯离心把车往外甩，外侧高弯能压住。开喷更快更滑。终段圈团堵路，圈王会跟横向。圈核更密、时间更紧、喷掉得快。冲出路面会减速，减速完要加速复原。不贴尾槽涨得慢。
