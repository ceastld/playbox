玩法：标题页「宝洞」。选「寻宝」打八面迷宫，选「追兵」同一套图但卫兵更快、晕得更短、每面多两到三只。四向走，踩金袋得分，空格（或点「踢」、点贴身卫兵）朝面向踢，踢中则晕。金袋攒到本面定额后出口亮起，走进去过关。碰到未晕的卫兵扣一命。点「重开」或 R：标题页进寻宝；局中或结算层随时重开回当前模式第一面。M 静音，写入 playbox-alibaba-mute。弹层打开时方向键不走路、空格不踢；顶栏重开与 R 随时可用，弹层不盖住顶栏，overlay 自身 pointer-events: none。

棋盘：15×13。外圈墙。人不能穿墙。金袋和宝袋可走上去捡。晕着的兵可穿过，未晕贴身即扣命。出口格在开门前只是地面，开门后走进去过关。

寻宝：洞口 → 金巷 → 岔口 → 宝室 → 缩壁 → 追影 → 夹金 → 终窟。金袋、卫兵、步速递增。缩壁 / 夹金 / 终窟会在倒计时后从外圈合拢石壁（金袋被封口仍计定额，出生点若被墙吃掉会内挪）。过关保留命和分。追兵：同八面，兵速约 1.55 倍，晕时约 0.55 倍，每面额外 +2 兵（第五面起再 +1）。

得分：金袋 100×连击，宝袋 400×连击，踢晕 200×连击，再踢击退 350×连击，封口金 50 / 宝 200，出洞 800+200×关+剩余金×20+剩余命×80。连击在 1.9 秒内捡金或踢中叠加。最高分写入 playbox-alibaba-best，不存盘面。

胜利：走进亮起的出口弹出「出洞了」，前七面「下一关」，第八面「宝洞清空 / 再来一轮」。失败：三命（顶栏金点）扣完弹出「被抓住了」，只能再来或换模式。碰兵会顿帧、闪粉、抖屏，还有命则闪回出生点并短暂无敌。

限制：没有暂停、没有穿墙。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、不大字。触控有十字键和「踢」；滑动或点按棋盘时 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：踢中 48–80ms 顿帧、金弧刀光、兵身闪青、连踢大字；捡金爆粒子和加分上窜；宝袋钟声加闪光；出口亮起全屏绿闪；石壁合拢有低鸣和抖。
