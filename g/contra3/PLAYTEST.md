玩法：标题页「魂斗3」。选「魂斗3」先打俯视废路，再侧向残城，第三关锁镜打基核；选「魂核」敌更密更快，车甲更挤，基核更厚，速度约 ×1.26。俯视八向走、朝面向开火；侧向跑跳蹲、八向瞄准。空格按住连射。Shift / Z 丢炸弹清场（开局 3 枚，魂核 2 枚）。中弹、撞兵、撞坦克 / 吉普 / 残骸，或被坠墙砸中立刻丢一命。点顶栏「重开」或按 R：标题页进魂斗3；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「魂核」开魂核。M 静音，写入 playbox-contra3-mute。弹层打开时方向键不走路、空格不开火、Shift 不丢弹；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。废路为俯视大图 1920×1200，镜头跟人，楼块挡路挡弹，坦克 / 吉普 / 残骸撞上即死。残城 / 基核为侧向：地面 y=328，中层 256，高层 184，间距 72；起跳约 86 高，能上一层，不能从地面直上高层。镜头跟人右前方，基核战时锁在关底。地面有缺口，掉出屏幕底丢命。人宽约 14、立高 26、蹲高 14；俯视碰撞半径约 10。走约 224，俯视约 228，空中约 0.9。标题页背后演示俯视推进开火，不算分、不掉血。

魂斗3 三关：废路（俯视，路闸 28 血）/ 残城（侧向坠墙 + 追踪荚 / 炸弹荚，城闸 20 血）/ 基核（短突进后锁镜，基核 52 血，砸臂撞击）。过关保留命、分、当前枪、炸弹数。魂核同三关，速度 ×1.26 并随关递增，额外补兵与坠墙，Boss 血约 ×1.24，开局仍是机枪、炸弹 2 枚。

武器：默认机枪 0.085s 一发、屏上约 6 发（比魂斗步枪更快）。H 追踪弹会拐弯咬最近敌人，单发 2 伤。死亡重生变回机枪，炸弹数保留。炸弹半径约 158，伤 8，清附近敌弹，冷却约 0.72s，上限 9。没弹时弹「没弹了」。

敌人 / 机关：废路步兵点射 100；吉普横跑 200（撞上丢命）；炮塔转向 250（撞上丢命）；坦克慢走点射 300（撞上丢命）；残骸 200（撞上丢命）；荚 300，击破掉 H/B。残城有冲兵、窗狙三向、飞兵抛弹、钢巢、坠墙砸扁。基核三向炮 + 砸臂，残血放环弹；魂核更密。击破 Boss 再加 5000×倍率，过关 +2000×关。魂斗3 打掉基核后再加 8000，弹「基核拆了」；魂核弹「魂核清场」。

得分：击杀基础分 × 连击倍率。连击为连续击杀，约 1.32 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 16000 分 1UP，命上限 6。最高分写入 playbox-contra3-best，不存盘面；本局超过即更新。

失败：挨弹 / 撞兵 / 撞车甲 / 被坠墙砸扁 / 坠缝立刻丢一命（无敌除外，坠缝强制）。约 0.82s 爆炸后在最近检查点重生，1.2s 闪烁无敌，枪变回机枪。三命（顶栏橙点）扣完弹出「被击中了 / 中弹了 / 坠入缝里了 / 撞上车甲了 / 被墙砸扁了 / 撞上了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → ↑ ↓ / WASD 走（俯视八向；侧向 ↑ / W 跳，↓ / S 蹲）。空格开火。Shift / Z 炸弹。点按画布同空格按住，右键丢弹。触屏 上 / 左 / 弹 / 右 / 下 / 射。标题页 魂斗3 / 魂核，Enter/空格/1 魂斗3，2 魂核。R 重开，M 静音。无手柄。

与魂斗不同：不是密林捡 M/S/L/F，有俯视废路和炸弹，默认机枪，捡的是追踪 / 炸弹。与魂斗2不同：Shift/Z 是炸弹不是跳，没有钢巷坠物核门，先俯视再侧向。与超魂不同：不是体力条、不是坞廊压机 / 刺带 / 连装炮，一打即死，有炸弹清场。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 机枪方波 / 追踪下滑音。炸弹金环爆开 + 约 72ms 顿帧 + 重震 + 「轰」。击杀粒子 + 30–80ms 顿帧 + 镜头微震 + 连击数字往上窜。坠墙砸地重震。基核崩开金爆。失败与重开都是一键 R。
