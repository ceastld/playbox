玩法：标题页「枪力」。选「枪力」打三关短推进（河岸 → 街区 → 船坞，关底 Boss）；选「巷战」同三关但更密更快，Boss 更厚，速度约 ×1.26，机甲装甲 3 格（枪力 4 格）。徒步向右跑跳射击，走上空机甲即夺甲。机甲机炮双管、可碾步兵 / 跑兵 / 翼机；装甲打空会撞毁，连人一起丢一条命（不会弹出）。点顶栏「重开」或按 R：标题页进枪力；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-gunforce-mute。弹层打开时方向键不走路、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 80 高，能上一层，不能从地面直上高层。镜头跟在人右前方，Boss 战时锁在关底。地面有缺口（河，约 70 宽，起跳可过；机甲略慢仍跳得过），掉出屏幕底丢命。中高层平台可落上。徒步宽约 14、立高 26、蹲高 16；机甲宽约 28、高 36。走约 208 / 机甲约 150，空中约 0.9。标题页背后演示右进开火、跳河、夺甲，不算分、不掉命。

枪力三关：河岸（趸炮 22 血，三向点射 + 残血抛弹）/ 街区（巷甲 30 血，走射双高炮，偶发起跳）/ 船坞（舰门 42 血，钉在右侧扇射，残血加瞄准弹）。过关保留命、分、连击窗口，以及是否在机甲上和剩余装甲。巷战同三关，约每三只补一只（机枪巢 / 敌甲不补），速度 ×1.26 并随关递增，Boss 血约 ×1.22。

射击：空格朝瞄准方向连射。方向 / WASD 走；↑ / W 上瞄，空中 ↓ / S 下瞄，落地 ↓ 蹲。跳是 Shift / Z，和上瞄分开，可立定上射。徒步手枪约 0.12s 一发、场上约 5 发。机甲机炮双管约 0.078s，场上约 8 发。点按画布同空格按住。击中粒子 + 约 34–74ms 顿帧。

夺甲：空机甲停在地面或中层，走近即上车，弹「夺甲」、金鸣三音、全屏闪。上车 +200×倍率。机甲可碾步兵 / 跑兵 / 翼机（基础分 ×2 再乘倍率，蹦「碾」）；机枪巢 / 敌甲 / 炮手 / Boss 不能碾，撞上去扣一格装甲。装甲打空：撞毁爆炸，丢一条命，重生变回徒步。过关带着机甲走。

敌人：步兵 80 / 1 血巡逻点射；跑兵 120 / 1 血见人冲脸；翼机 100 / 1 血正弦飞俯射；炮手 140 / 2 血站射；机枪巢 160 / 3 血不能碾；敌甲 200 / 3 血巡逻对射不能碾。巷战射速间隔更短。

Boss：趸炮钉在关底右侧三向点射，残血抛弧弹；巷甲左右走双高炮，偶发起跳；舰门钉右侧扇射，半血加瞄准弹。击破 Boss +3600×倍率，过关 +1400×关次×倍率。枪力打穿再加 8000，巷战 +10000，弹「船坞捣毁了」/「巷战得手」。

得分：击杀基础分 × 连击倍率；碾压再 ×2。连击为连续命中/击杀/夺甲，约 1.4 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。2 连起蹦「×N」，升档时再顿一帧。每 15000 分 1UP，命上限 6。最高分写入 playbox-gunforce-best，不存盘面；本局超过即更新。

失败：三命（顶栏橙点）扣完弹出「撞上了 / 中弹了 / 机甲撞毁了 / 坠入河里了」。约 0.86s 爆炸后在最近扎实地面重生，1.2s 闪烁无敌，机甲丢失变回手枪。弹层打开时方向键不再走路；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 上瞄，↓ / S 蹲或下瞄，空格射击，Shift / Z 跳。点按画布同空格按住。触屏 左 / 跳 / 射 / 右 / 下。标题页 枪力 / 巷战，Enter/空格/1 枪力，2 巷战。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波（手枪尖、机炮低锯齿）。击中粒子爆开 + 短顿帧（约 34–74ms）+ 镜头微震 + 连击数字往上窜。夺甲金鸣三音、全屏闪、toast。碾碎金爆、对半粒子、双倍分。装甲挨打砂石碎屑；撞毁大爆。失败与重开都是一键 R。

跟邻作的差：不是枪星（四向合成枪、砸弱点核），不是钢魂（永远开着重机甲、冲刺碾、打热出钢轨），不是外域（纵版），不是合金（救人、手雷、坦克甲尽弹出）。枪力是徒步士兵夺空机甲，跳键独立，机甲撞毁丢命。
