玩法：标题页「忍三」。选「忍三」打三关（潮崖→竹林→魔砦，闯到尽头魔将现身）；选「忍核」同三关但敌更快更密，Boss 血约 ×1.22，开局雷隐 1（忍三 3）。侧向走跳，按住方向约 0.16 秒进入疾跑；同向连点两次或触屏「冲」做冲刺（约 0.24 秒无敌穿身，途中杂兵受伤）。空格永远近斩；疾跑或冲刺中斩变成更长的冲斩。闯到关底结界，族将激活。点顶栏「重开」或按 R：标题页进忍三；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「忍核」开忍核。M 静音，写入 playbox-shinobi3-mute。弹层打开时方向键不走路、空格不斩；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 86 高，能上一层，不能从地面直上高层。镜头跟在人右前方，高层略上抬。地面有缺口，掉出屏幕底丢命。中高层平台可单向落（↓ / S 掉落），地面不能掉穿。闯到关底（约屏宽内）金结界处族将现身，镜头锁在尽头。没有人质，不挡路。

忍三三关：潮崖（浪将 12 血，雷隐勾玉）/ 竹林（竹鬼 16 血，竹海、双拾取）/ 魔砦（魔主 22 血，会瞬移、三向雷、召冲卒）。过关保留命、分、雷。忍核同三关，速度约 ×1.32，铳兵更勤，额外补兵，Boss 血 ×1.22。

雷隐：Shift / Z / 触屏「雷」。绕身放出约 1.08 秒雷罩，自身无敌，约 54 范围内每隔约 0.2 秒削杂兵 1 血、族将 1 血、敌弹粉碎。不是清屏：罩外的人还在。不是穿场火龙，也不是滚场炎轮。耗尽提示「雷隐耗尽」。勾玉 +1，上限 5。

冲刺：同向连点 ← → / A D，或触屏「冲」。约 0.24 秒高速前冲，途中无敌，擦过杂兵削 1 血、族将 1 血。冷却约 0.40 秒。疾跑中空格为冲斩，刀弧约 62（站桩约 46）。没有手里剑。

敌人：徒巡逻 100；铳点射 200；蝠正弦飞 150；冲卒贴地猛冲 150；蛙两跳 300。族将走动抛弹，残血更密，魔主会瞬移并召冲卒。击破族将再加 4500×倍率，过关 +1800×层。忍三打掉魔主后再加 8000，弹「魔砦已破」；忍核弹「忍核得手」。

得分：击杀/拾取基础分 × 连击倍率。连击为连续击杀，约 1.4 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))。每 15000 分 1UP，命上限 6。最高分写入 playbox-shinobi3-best，不存盘面；本局超过即更新。重生点随扎实落地点前移。

失败：挨打 / 中弹 / 坠崖扣一命（斩击打中该敌人的这一下不挨打；无敌、冲刺、雷隐除外）。约 0.78s 后在最近检查点重生，1.35s 闪烁无敌。三命扣完弹出「被击中了 / 中弹了 / 坠入深渊了」。弹层打开时方向键不再斩；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走（按住疾跑，连点冲刺），↑ / W 跳（空格不跳），↓ / S 从平台掉落，空格近斩，Shift / Z 雷隐。点按画布同空格。触屏左 / 跳 / 斩 / 右 / 冲 / 雷。标题页 忍三 / 忍核，Enter/空格/1 忍三，2 忍核。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：斩必有三层——听（刀风噪声+下扫锯齿）、看（金弧、金屑、分数蹦出）、触（约 55ms 顿帧 + 镜头踢）。冲刺三层：听（破风噪声+上扫）、看（残影、青金尘）、触（约 48ms 顿帧 + 镜头踢）。雷隐三层：听（高通噼啪 + 上扫方波）、看（绕身雷弧、金环、罩内电屑）、触（约 70ms 顿帧 + 镜头踢）。连击数字往上叠。失败与重开都是一键 R。

区别：没有人质（不同于「忍」），没有贴墙蹬墙（不同于「影忍」），没有魂分身同斩（不同于「忍魂」），没有近斩远镖与穿场火龙（不同于「忍二」），没有连斩三下与滚场炎轮（不同于「忍影」）。忍术是绕身雷隐，冲刺是本关的走法。
