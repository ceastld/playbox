玩法：标题页「苍穹」。选「苍穹」打三关（苍湾 → 云栅 → 红莲），每关中 Boss 与关底 Boss；选「穹雨」同三关但卷轴更快、敌弹更密、几何编队更多、Boss 多约 22% 血、额外补波。点顶栏「重开」或按 R：标题页直接开苍穹；对局中或结束层重开同一模式。结束层「再来」同模式；舰毁「换模式」回标题；通关「穹雨」开穹雨（穹雨通关则「换模式」回标题）。M 静音，写入 playbox-soukyugurentai-mute。方向键 / WASD 八向飞，点按空格打主炮（可连点）；按住约 0.14 秒张开三维索敌网，网内敌机依次上锁，松开齐射追踪激光。C / X / F / Tab 或顶栏「阵」切换扇 / 锥阵。Shift / Z 或顶栏「爆」扔爆弹。画布拖动跟舰，按下开火，按住张开索敌网，松开齐射。触屏右下「阵」换阵、「爆」爆弹。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 苍穹、2 穹雨。

场地：虚拟场 480×720。舰开局 y=630、x=240，夹在 22–458 / 40–692。苍穹巡航约 88（关卡与连击再加），穹雨约 122；中/关底 Boss 在屏时降到约 26–34。移速约 276（穹雨 312）再加炮等级。点按空格打主炮，按住张开索敌网。未解锁音频前无声。喷气低频 rumble（约 90ms 一拍）。地面炮塔/堡可飞越，只吃它们的对空弹；空中机体相撞扣命。僚机小翼随阵型平移，不占碰撞盒。

索敌网：两种阵。扇：前方约 ±66° 半圆，射程约 208，最多 6 锁，激光伤害 3。锥：前方约 ±21° 长锥，射程约 318，最多 4 锁，激光伤害 6。顶栏「扇 / 锥」。换阵时小翼滑到新槽，出网的锁会掉。淡网始终画在舰前；按住后网格加亮并开始上锁（约 0.082 秒一锁，连击略快）。金框编号 1–n，虚线连回舰。松开把当前锁一次性打出去：青金激光按序飞向目标。满锁提示「满锁 n」，不自动发射。锁分：第 n 锁（从 0）基础 100×2ⁿ，再乘连击倍率。1 锁 100、2 锁 200、…、6 锁 3200。3 锁以上飘「×8」类金字。没打死也按约 18% 记账。叠满再松是本关主要分源。换阵约 0.22s 冷却。

主炮：点按或短按空格。默认双发加两侧小翼。吃菱形「炮」胶囊 双→三→四向→五向 MAX（3）。扇阵小翼外撇，锥阵小翼叠前直射。满级再吃 +500×倍率。「爆」胶囊补爆弹。运兵翼与仓循环掉 炮/爆。坠机炮等级清零并掉一枚炮胶囊。

爆弹：开局 3 枚，上限 6。Shift / Z 清掉全部敌弹、全体扣血（普通 6 / 中 Boss 10 / 关底 14），全屏闪、金环、约 78ms 顿帧，自身约 0.42s 无敌。若索敌网张开且已有锁，改为对锁目标集束（各 10 伤）并提示「集束」。过关补 1 枚。用尽再按提示「爆弹用尽」。

关卡：第 1 关苍湾中 Boss「湾卫」40 血、关底「苍塔」96；第 2 关云栅「栅炮」54 / 「裂穹」128；第 3 关红莲「莲卫」68 / 「红莲核」172。穹雨血量 ×1.22。中 Boss 在场时波次计时暂停。空中：V 字隼、侧翼切入、俯冲楔、3×3 几何编队、运兵翼。地面：炮塔、堡（可飞越）。苍塔扇扫；裂穹旋转弹幕；红莲核双环弹+瞄准。残血后节奏加快。几何编队是本关的锁网诱饵。

得分：空中击杀基础分 × 连击倍率。隼 50、俯冲 100、几何 70、炮塔 150、仓 300、翼 180、堡 280、中 Boss 2000、关底 4000+1500×关。锁定击坠用锁分，不叠基础分。连击为连续击杀，约 1.42 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。击坠关底再加 1500×关。三关打穿 +8000（穹雨 +10000）并「红莲尽破 / 穹雨尽破」。每 20000 分 1UP，命上限 6。最高分写入 playbox-soukyugurentai-best，不存盘面；本局超过即更新。

胜利：苍穹/穹雨打掉第 3 关红莲核后约 2.05s 结算胜利。
失败：敌弹碰到自己或空中机体相撞，扣一命（重生无敌与爆弹期间除外）。地面机体不撞机。约 0.95s 爆炸后重生，1.55s 闪烁无敌，场上敌弹清空。三命（顶栏青点）扣完弹出「舰毁了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格射击（按住索敌，松开齐射），C / X 换阵，Shift / Z 爆弹。点按画布开火并跟舰，按住张开网。标题页 Enter/空格/1 苍穹，2 穹雨。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、不闪爆。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波。张开索敌网：听（低音上滑+高叮）、看（三维网格加亮、金框跳号）、触（短闪）。连锁激光三层：听（锯齿下滑 + 逐发升调）、看（青金缎带、编号框、×2/×4/×8 金字往上窜）、触（34–80ms 顿帧随锁数加长 + 镜头微震）。满锁全屏金闪。换阵三层：听（whoosh）、看（小翼滑槽、阵名弹）、触（约 34ms 顿帧 + 滤镜一闪）。爆弹三层：听（噪声 rumble + 下滑锯齿）、看（全屏白闪、金环、敌弹碎光）、触（约 78ms 顿帧 + 强震）。坠机洋红大爆。失败与重开都是一键 R。
