玩法：标题页「街霸」。选「对战」打青影，先赢两局（三局两胜）；选「无尽」按青影 → 铁腕 → 紫焰 → 金霸循环上场，对手更快更肉，每场仍先赢两局，输一场结束。点顶栏「重开」或按 R：标题页进对战；对局中或结束层重开同一模式第 1 战。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-street-fist-mute。弹层打开时方向键不走路、ZXC 不出招；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=308。两人面对面，不能穿身，左右壁约 36。站立受伤盒约宽 20 高 54，蹲高 34。走约 158，后退约 118，起跳约 79 高，能跳过气波。标题页背后演示对打，不算分、不记局。

对战：固定对手青影，体力 100，计时 99。无尽四位：青影 100 / 铁腕 118 / 紫焰 96 / 金霸 132，第五战起循环并加速（速度与反应约每轮 +12%，封顶约 1.55）。金霸更会防跳攻、更会升龙。

出招：Z 轻拳（可连段、可取消成气波/升龙），X 重拳，C 踢。蹲 Z/X 蹲拳，蹲 C 扫腿（低、击倒，站防会被扫中）。跳攻算高，蹲防会被打中。下→前 + Z/X（或触屏「波」）地面气波；已有气波在场不能再放。向前跳起约 0.32 秒内按 Z 升龙（起跳无敌约 0.13 秒，击倒）。后跳 / 原地跳 Z 是跳轻拳。

防守：背向对手按后（远离键）站防中/高，蹲+后防低/中。气波被防会削 3 血（不会削死）。升龙被防削 4。对打双发气波相撞抵消。

回合：体力 0 即该局负，KO 后约 1.85 秒进下一局或结算。时间到比谁血多，平局重打该局不记分。先赢 2 局赢场。无尽赢场进下一战，局分清零，分数保留。

得分：轻 50、踢 80、重 110、气波 160、升龙 220，乘连击倍率。连击约 1.15 秒不断，倍率 = 1 + min(4, floor((连击-1)/2))，即 1–2 连 1 倍、3–4 连 2 倍，最高 5 倍。KO +1000，完美（自己满血）+2000，赢局 +400，对战赢场 +2000，无尽赢场 +1500×战数。最高分按模式分记，写入 playbox-street-fist-best，JSON `{v,g}`（对战 / 无尽）。本局超过即更新。不存盘面。

操作：← → / A D 走，↑ / W 跳，↓ / S 蹲，Z 轻拳，X 重拳，C 踢。触屏 左 / 跳 / 右 / 蹲 / 轻 / 重 / 踢 / 波。标题页 Enter/空格/1 对战，2 无尽。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不顿帧、不抖屏、少粒子。触控画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

爽感：出拳挥砍音。打中三层：听（音高随连击往上爬）、看（火花、粒子、分数蹦出、HIT 字）、触（轻约 40ms / 重约 70ms / 升龙约 78ms 顿帧 + 镜头踢）。气波/升龙全屏闪 + 专属音色。KO 大字 + 倒地砸屏（约 0.35s 下沉）+ 重低音。连击 ×3/×5/×8 大字蹦出。失败与重开都是一键 R。
