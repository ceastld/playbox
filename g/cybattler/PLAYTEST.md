玩法：标题页「机战」。选「机战」打三场环形竞技（月港 → 钢轨 → 核门），每场三波敌机甲，清波后出 Boss 机；选「核甲」同三场但更密更快，Boss 更厚。驾驶机甲八向走，空格射击（按住会锁朝向侧移），近身自动挥光剑，Shift / Z 冲刺穿弹。撞敌机 / 吃弹 / 被斩丢一条命。点顶栏「重开」或按 R：标题页进机战；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-cybattler-mute。弹层打开时方向键不走路、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。四边墙厚 18，机甲夹在墙内。场上有可打碎的掩体（4 血），挡人挡弹。机甲半径约 13，走速约 162（核甲 176）。标题页背后演示侧移射击、近斩、冲刺，不算分、不掉命。

机战三场：月港（月牙 36 血）/ 钢轨（铁臂 48 血）/ 核门（核甲王 64 血）。过场保留命、分、连击窗口。核甲同三场，敌数约 ×1.42 并多一只翼机，速度约 ×1.22 并随场递增，敌弹略快，Boss 血约 ×1.24。

朝向：八向。按住射击或斩击时锁朝向，移动变成侧移（Cybattler 原作手感）。点按/按住画布朝指针八向开火。松开后朝向跟走路走。

射击：空格或按住画布连射，冷却约 0.085s，弹速 560，场上最多 8 发己弹。击中粒子 + 约 32–74ms 顿帧。

光剑：近身进入扇形（半径 48、点积 >0.32）自动挥斩，X / C 或触屏「斩」也可空挥。冷却约 0.26s，挥击持续约 0.12s。斩击伤害 2，可一次砍死 2 血机体，并可切断扇内敌弹。近斩击杀掉落为基础分 ×2 再乘倍率，机体沿剑向对半飞开。

冲刺：Shift / Z 或触屏「冲」。约 0.14s 以 520 速度突进，约 0.22s 无敌闪烁（可穿弹穿机），冷却约 0.68s。顶栏「冲」在冷却时变暗。残影。

敌人：翼机 80 / 1 血绕场点射；步甲 140 / 2 血追射；刃甲 120 / 1 血前摇后冲斩；炮座 160 / 3 血原地打；重甲 220 / 4 血慢走肥弹。核甲射速间隔更短。

Boss：月牙绕场五发散，偶发突进；铁臂居中挥臂（线段判定），胸炮对射，约 66%/33% 血斩掉左/右臂；核甲王瞬移、八环弹、光环斩波。击破 Boss +4000×倍率，过场 +1500×场次×倍率。机战打穿再加 8000，核甲 +10000，弹「机战清场」/「核甲得手」。

得分：击杀基础分 × 连击倍率；近斩再 ×2。连击为连续命中/击杀，约 1.42 秒无动作则断；挨打立刻断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「×N」。每 15000 分 1UP，命上限 6。最高分写入 playbox-cybattler-best，不存盘面；本局超过即更新。

失败：三命（顶栏青点）扣完弹出「撞上了 / 中弹了 / 被斩了 / 机甲碎了」。约 0.88s 爆炸后场中重生，1.22s 闪烁无敌，场上敌弹清空。弹层打开时方向键不再走路；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 八向走，空格射击，Shift / Z 冲刺，X / C 斩。点按画布瞄准并开火。触屏 上/下/左/右 + 射 / 斩 / 冲。标题页 机战 / 核甲，Enter/空格/1 机战，2 核甲。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波。击中粒子爆开 + 短顿帧（约 32–74ms）+ 镜头微震 + 连击数字往上窜。近斩金绿弧、弹幕被切开、敌机对半飞、更长顿帧。冲刺残影 + 噪声 whoosh。爆炸粒子、连击 pop。失败与重开都是一键 R。
