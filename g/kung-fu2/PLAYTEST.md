玩法：标题页选「功夫2」或「功核」。霓虹塔楼从左打到右，一撞丢命（没有体力条）。空格拳（短、偏高）、Shift/Z 踢（长、偏低，空中变跳踢），上/W 跳。走到右端楼梯自动上楼。四层回廊之后塔顶锁镜，塔尊出场。点顶栏「重开」或按 R：标题页进功夫2；局中或结算重开回当前模式。M 静音，写入 playbox-kung-fu2-mute。弹层打开时方向键不走路、空格不出拳；顶栏重开与 R 随时可用，弹层 `pointer-events` 不挡住重开。

敌人：冲拳手橙衣冲脸，碰到即撞死。暗器手洋红背心，走近抛金色暗器星，拳踢都能打掉（挡星有顿帧、粒子、连击）。飞腿青衣弹跳过来，落地再起跳。夜鸢贴空中正弦飞，靠近会俯冲。功核从一层起暗器/夜鸢更多、更快。

楼层：一层霓虹门、二层金库廊、三层夜宴厅、四层天桥、塔顶塔尊。不必清场，冲到右侧楼梯即可。上楼 +1000+200×层。塔顶靠近尽头锁镜头，清掉杂兵，塔尊出场；打空其体力即通关。

性命：没有体力格。撞敌人 / 中暗器 / 被气波打到 / 撞塔尊立刻丢一条命。约 0.82 秒爆炸后原地重生，约 1.15 秒闪烁无敌。三命（顶栏橙点）扣完弹出失败。每 18000 分加一条命（最多 6）。

塔尊：约 10 血（功核 13）。近身挥拳、放贴地洋红气波、起跳砸地。气波也能拳踢打掉（破波顿帧更重）。打中全身闪白、金屑、约 72ms 顿帧。击破 +5000，再加破塔奖励。

得分：冲拳 100、暗器手 150、飞腿 200、夜鸢 250；拳/踢/跳踢按招式另有基础。挡星 80、破波 120。连击约 1.32 秒内不断则倍率往上叠（最高约 ×2.75）。最高分按模式分记，写入 localStorage 键 playbox-kung-fu2-best，JSON `{f,n}`（功夫2 / 功核）。本局超过即更新。

模式：功夫2 正常节奏。功核敌人更快、出兵更勤、场上更多、暗器与夜鸢比例提高，塔尊多 3 血，速度约 ×1.28。两种最高分不共用。

操作：← → / A D 走，↑ / W 跳，空格拳，Shift / Z 踢。触屏左 / 右 / 跳 / 拳 / 踢。标题页 Enter/空格/1 功夫2，2 功核。R 重开，M 静音。无手柄。

与功夫不同：不是山门回廊擒拿翻滚，不是 Z 拳 X 踢，没有体力格，撞即丢命；场地是霓虹塔楼，敌人是冲拳/暗器/飞腿/夜鸢，终局是塔尊气波。与终斗不同：不是街上连段体力条，是一层一层横版一击必杀。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、粒子更少。触控棋盘 `touch-action: none`，避免页面跟着滚。弹层打开时方向键不走路、空格不出拳；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

爽感：每次出拳/踢都有挥砍音 + 弧光。打中必有三层：听（音高随连击往上爬）、看（敌人被甩出去并炸粒子、分数蹦出）、触（拳约 48ms / 踢约 58ms / 跳踢约 66ms 顿帧 + 镜头微踢）。挡暗器约 52ms 顿帧并炸金屑；破气波约 70ms。塔尊挨打全身闪白、金屑、约 72ms 顿帧。撞死洋红大爆。连击 ×3/×5/×8 大字蹦出。失败与重开都是一键 R。
