玩法：标题页「末刃」。选「末刃」对月影，先赢两局（三局两胜，99 秒）；选「连斩」对赤蝉，同样先赢两局但更快更密（72 秒、三连斩、花瓣更密）。点顶栏「重开」或按 R：标题页进末刃；对局中或结束层重开同一模式第 1 局。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-last-blade-mute。弹层打开时方向键不走路、空格不斩（标题空格/Enter/1 开末刃，2 开连斩）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 720×400。地面 Y=338。人开局 x=168 对 x=552，夹在 40–680。末刃走速约 168，连斩约 ×1.28。起跳约 85 高，可跃过地面中斩。点按画布轻点斩，上滑跳，左右滑走。触屏底栏 左 / 跳 / 右 / 蹲 / 斩 / 月。未解锁音频前无声。月下木场，连斩花瓣更密更红。

对决：末剑 100 血（连斩 88）。月影 100 血、爱绕跳、会放月华；赤蝉 88 血、更快更凶、更会交刃。空格点斩，命中后可取消成二斩；连斩模式二斩命中后再取消三斩（击倒）。下+斩为下斩（低、击倒，可跳过）。跳中斩一次。双方同时出刀且刀光相交则交刃，互不扣血、各加刃气。刃气 0–100，Shift / Z 花 50 放月华（新月波）；气满花 100 放超月华（更大更痛）。气不足出刀提示「气不足」。

回合：体力 0 即该局负，KO 后约 1.85 秒进下一局或结算。时间到比谁血多，平局重打该局不记分。先赢 2 局赢场。同归于尽重打该局。

得分：斩 80、二斩 120、三斩 160、跳斩 100、下斩 90、月华 240、超月华 400，乘连斩倍率。交刃 50。连斩约 1.2 秒不断（连斩模式约 1.55），倍率 = 1 + min(4, floor((连斩-1)/2))，即 1–2 连 1 倍、3–4 连 2 倍，最高 5 倍。KO +1000，完美（自己满血）+2000，赢局 +400，时间胜 +600，末刃赢场 +2000，连斩赢场 +2500。最高分按模式分记，写入 playbox-last-blade-best，JSON `{v,l}`（末刃 / 连斩）。本局超过即更新。不存盘面。

胜利：先拿 2 局后约 1.85s 结算「刃尽」（连斩「连尽」）。
失败：己方先被拿下 2 局弹出「刃折」。弹层打开时方向键不再走；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳，↓ / S 蹲，空格斩，Shift / Z 月华。点画布斩，上滑跳。标题 Enter/空格/1 末刃，2 连斩。R 重开，M 静音。无手柄。与侍秋不同：有跳、无格挡无闪步，是月下对剑而非一维拔刀。与红侠不同：不是清街慢镜，是一对一刀战。与战刃不同：不是圆场顶视蓄斩，是侧视跳斩 + 月华波。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、少花瓣。触控画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：出刀必有三层——听（刀风噪声 / 命中方波随连斩往上爬 / 交刃金属高音 / 月华锯齿各不一样）、看（刀光弧、花瓣、新月波、分数蹦出、HIT 字、大字 N 斩）、触（斩约 46ms / 二斩约 58ms / 月华约 68ms / 超月华约 80ms 顿帧 + 镜头微震）。交刃金闪。KO 大字 + 倒地砸屏 + 重低音。失败与重开都是一键 R。
