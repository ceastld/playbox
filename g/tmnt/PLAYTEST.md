玩法：标题页「神龟」。先点蓝棍 / 橙拳 / 红钗 / 紫叉（或 1–4）选龟，射程不同。选「巷战」打三关（夜街→水道→巢穴，水道出犀甲、巢穴出裂盔）；选「鼠潮」在街上按潮出兵，越往后越密，井盖更勤，每 4 潮出犀甲、每 8 潮出裂盔。侧向走跳，空格劈砍。井盖会掀开冒脚兵，枪兵平射要跳过去。点顶栏「重开」或按 R：标题页进巷战；对局中或结束层重开同一模式第 1 关 / 第 1 潮。结束层「再来」同模式；失败「换模式」回标题；巷战通关「鼠潮」开鼠潮。M 静音，写入 playbox-tmnt-mute。弹层打开时方向键不走路、空格不打（标题空格/Enter 开巷战）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 Y=318，上跳约 62px。左右走、上跳，镜头跟在人右侧。巷战三关长度 2280 / 2480 / 2160。头目未倒走进其约 380 范围内镜头锁成擂台。鼠潮场地宽 2000，潮次在镜头外左右刷出，井盖穿插冒兵。

巷战三关：夜街（脚兵、枪兵、三口井盖、披萨与铁桶）/ 水道（井盖更多，尽头犀甲 22 血会冲撞）/ 巢穴（枪兵更多，尽头裂盔 28 血丢星刃近身砍）。过关保留命、体、分，补 4 点体力。鼠潮同街景，第 n 潮人数 min(12, 3+⌊0.85n⌋)，速度约 ×(1+0.05×(n−1))，血量 ×(1+0.08×(n−1))。

四龟：蓝棍射程 56、挥得慢、击退大；橙拳射程 28、最快，第三下上勾击倒；红钗射程 38；紫叉射程 50。空中劈一次旋身。连击窗口约 1.45 秒。铁桶打爆有时掉披萨，披萨回 5 体。

敌人：脚兵贴脸拳 3 血；枪兵远射 3 血，子弹在胸口高度，跳过去；犀甲冲撞 22 血（鼠潮随潮加血），前摇后直线撞，跳起能躲；裂盔 28 血，三连星刃加近砍。体力条打空扣一命；约 0.82s 后原地满体重生，1.35s 闪烁无敌。三命扣完弹出「倒了」。

得分：命中 40×连击倍率（击倒约 ×1.4），击杀脚兵 160 / 枪兵 240 / 犀甲 3200 / 裂盔 5000×倍率，过关 1500×关，清潮 600×潮，披萨 120，铁桶 80。连击为连续命中，约 1.45 秒无命中则断。倍率 = 1 + min(4, floor((连击-1)/2))。每 20000 分 1UP，命上限 6。最高分写入 playbox-tmnt-best，不存盘面；本局超过即更新。选龟写入 playbox-tmnt-turtle。

失败：体力打空扣一命（无敌除外）。约 0.82s 后原地满体重生，1.35s 闪烁无敌。三命扣完弹出「倒了」。弹层打开时方向键不再打；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳，空格 / 点画布劈砍。触屏 左 / 跳 / 右 / 劈。标题 1–4 选龟，Enter/空格巷战，顶栏或按钮开鼠潮。R 重开，M 静音。无手柄。与双截不同：没有前后走深浅、没有抓投、没有地上捡武器，上键是跳不是进深。与街霸不同：不是 1v1 对波，是侧向清场。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不顿帧、不抖屏、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：劈必有三层——听（棍木裂 / 拳风 / 钗金属，各不一样）、看（龟色屑、闪光、分数蹦出）、触（约 42–70ms 顿帧 + 镜头踢）。击倒更沉，井盖有铁响和尘，枪有火光。连击升档金闪、大字 ×N。失败与重开都是一键 R。
