玩法：标题页「地牢」。选「清廊」打六层短厅（石门→金门），选「尸潮」同六层但发生器更密、吐得更快、生命掉得更狠。四向走，空格射击，贴身自动挥剑斩怪和砸发生器。生命每秒都在掉，捡食物回血；掉到 0 就结束。出口一直开着，可以不砸完发生器就冲出去。点「重开」或 R：标题页进清廊；对局中或结束层重开同一模式。M 静音，写入 playbox-gauntlet-mute。弹层打开时方向键不走路、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：17×11 格。外圈硬墙，内里随机房间加走廊，连通失败会换种子或落到十字底图。出生在西侧房间，出口在离出生最远的空格（青环，清光发生器后变金）。人半径约 0.28 格，速度约 4.48 格/秒，只走四向不斜走。弹打到墙即灭；误射食物/宝藏会毁掉（弹出「毁了」）。影不受弹伤，必须近斩。

清廊：石门 2 发生器 / 骨道 2 / 食窖 3 / 血廊 3 / 影井 4 / 金门 4。骨、尸、影配比递进，生成间隔 2.48s 收到 1.28s，生命流失 3.7/s 收到 4.9/s。过层保留生命和分数。尸潮：同名六层，发生器 +1～2、流失约 +1.5/s、间隔更短，场上怪上限 20。

发生器：石座水晶，按类型吐骨/尸/影，各自最多 4 只活崽。射击每次 1 伤，贴身斩每次 2 伤（3–6 命，随层加）。炸开粒子 + 顿帧。约三分之一掉食物，再少一点掉宝藏。清光该层发生器 +120+24×开局器数。斩发生器不烫人。

怪物：骨（橙，近战追）撞人 -12，1 命；尸（绿，慢）撞人 -16，2 命，近斩一下死；影（紫，只近斩）撞人 -10，弹打上去弹出「穿不透」。接触有约 0.32s 冷却。近斩成功有约 0.14s 免伤。

道具：食物 +32 生命（上限 140）；宝藏 100×倍率。没有药。生命开局 100，一直在掉。低于 26 心跳提示「生命将尽」。

得分：击杀掉落×倍率（骨 50 / 尸 80 / 影 140 / 发生器 180）。连击窗口 1.42s，倍率 = 1 + min(4, floor(连击/2))，最高 5 倍。出门 +50。闯出金门按剩余生命 ×8 加分。最高分写入 playbox-gauntlet-best，不存盘面；本局超过即更新。

胜利：清廊从金门出口弹出「廊清了」。尸潮打穿弹出「尸潮退了」。
失败：生命掉光弹出「命耗光了 / 骨撞上了 / 尸咬上了 / 影贴上来了」。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、不连环大字。触控有十字键和「射」；滑动或点按棋盘时 `touch-action: none` 并 preventDefault，避免页面跟着滚。贴身靠近怪/发生器会自动斩。

爽感：开火枪口闪光与火花；斩击金弧 + 50–80ms 顿帧 + 镜头微震；怪爆粒子；发生器砸开更大一顿；连击倍率上窜并弹出 ×N；捡食用青绿叮、宝藏金琶；弹打影有闷响「穿不透」。
