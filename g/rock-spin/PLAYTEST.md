玩法：标题页「岩旋」。选「经典」四颗大岩、常速；选「碎雨」七颗大岩、更快更密、飞碟更勤、最多五发。点「重开」或 R：标题页直接开经典；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-rock-spin-mute。A / D 与 ← → 转向，W / ↑ 推进，空格开火（可按住），Shift / S / ↓ 跃迁。触屏：左下 ↺ ▲ ↻，右下 跃 / 火。P 或点「自动」托管。
场地：虚拟场 480×720。船、弹、岩全部出边绕回（九宫绘制近边残影）。船半径约 8，转向约 4.55 rad/s（碎雨 ×1.08），推进 268（碎雨 ×1.12），最快约 308（碎雨 ×1.12），极轻阻尼 0.16。子弹速度 448，寿命约 0.94s；经典场上最多 4 发、冷却 0.15s，碎雨最多 5 发、冷却 0.11s。点按或按住空格开火，未解锁音频前无声。
岩石：大 / 中 / 小半径约 38 / 22 / 12。击中大裂成两中、中裂成两小、小消失。大 20、中 50、小 100，再乘连击倍率。碎雨初速 ×1.38，每波再 +5.5%。清波后立刻进下一波：经典 4、5…最多 8 颗大岩；碎雨 7、8…最多 12。清波奖励 150×刚结束的波次。
飞碟：约 12–20 秒后出现（场上至少还有岩）。第 3 波或 4000 分起改小碟。大碟 200、小碟 1000，再乘连击。大碟慢、弹散；小碟快、弹准。飞碟撞岩双方都炸（岩按裂规则，玩家不得分）。飞碟飞出左右场外即离开。
跃迁：冷却约 1.55s，原地散环、随机落点并清速度。基础翻车约 12%，本命每多用一次 +4.5%，封顶 34%；落到岩里也炸。成功有约 0.42s 闪烁无敌。
得分：击碎基础分 × 连击倍率。连击为连续打中（子弹飞完未命中则窗口收到约 0.18s），1.32 秒无击杀也断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 10000 分额外一命（可超过三命）。最高分写入 playbox-rock-spin-best，不存盘面；本局超过即更新。
胜利：没有终局胜利，清波立刻进下一波并提示「第 n 波 · 加速」。
失败：岩、飞碟或飞碟弹打中船扣一命（约 1.35s 爆炸后在场心重生，需周围约 70px 无岩，1.8s 闪烁无敌）。三命（顶栏橙点）扣完弹出「船碎了」。若本局刷新最高分弹层写「新纪录」。弹层打开时转向不再开打；顶栏重开与 R 随时可用。
限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、子弹不拖尾。触控时画布与虚拟键 `touch-action: none` 并 preventDefault，避免页面跟着滚。A 是左转不是自动。
自动：点「自动」或按 P 开关托管（开着时按钮呈按下态并显示「停」）。开着时忽略转向 / 推进 / 开火 / 跃迁；P / R / M / 重开仍可用。开关不写入存储，刷新后关闭；重开不会关掉自动。标题页开自动会进经典；结束层会自动再来且自动仍开着。速度滑条 1–4 为 慢 / 中 / 快 / 极快（默认快），写入 playbox-rock-spin-auto-speed。AI 先躲即将撞上的岩和敌弹，危急时跃迁，否则提前量瞄准飞碟或最近可打的岩。不是完美求解，碎雨里岩密时会撞。
