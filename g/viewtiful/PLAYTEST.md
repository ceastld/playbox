玩法：标题页「红侠」。选「开拍」打三关（街拍棚→古堡棚→火山棚，关底头目）；选「快剪」在街拍棚按潮出兵，群演/镜手/航拍更密，每 4 潮出导播机、每 6 潮出重锤王、每 8 潮出红帽魔。侧向走跳，空格出拳，下/X/K 踢。按住 V 开慢镜：世界约 ×0.26、自己约 ×0.62，拳伤 ×2.2，子弹爬行可打回；按住 C 拉近：镜头约 ×1.42，拳踢更重更远。两键同按进入「红侠」状态，伤再叠 ×1.25 分。特效槽耗尽自动关掉。体力打空扣一命。点顶栏「重开」或按 R：标题页进开拍；对局中或结束层重开同一模式第 1 关 / 第 1 潮。结束层「再来」同模式；失败「换模式」回标题；开拍通关「快剪」开快剪。M 静音，写入 playbox-viewtiful-mute。弹层打开时方向键不走路、空格不打（标题空格/Enter/1 开拍，2 开快剪）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 Y=318，上跳约 62px。左右走、上跳，镜头跟在人右侧；拉近时人更靠画面中。开拍三关长度 1980 / 2080 / 1920。头目未倒走进其约 380 范围内镜头锁成擂台。快剪场地宽 1900，潮次在镜头外左右刷出。

开拍三关：街拍棚（群演、镜手、航拍，片箱与胶片，尽头导播机 22 血会拍板震地、三路镜头弹）/ 古堡棚（甲士与航拍更多，尽头重锤王 26 血跳砸震地）/ 火山棚（爆破与镜手，尽头红帽魔 32 血冲刺、喷火）。过关保留命、体、分、特效槽，补 4 点体力、20 点槽。快剪同街拍景，第 n 潮人数 min(14, 4+⌊1.05n⌋)，速度约 ×(1+0.05×(n−1))，血量 ×(1+0.08×(n−1))。

红侠：拳三段（刺 / 横 / 上勾击倒），空中一拳。踢更宽、击倒，空中踢也可。慢镜打中子弹则反射成青弹，伤害随特效。片箱打碎有时掉胶片，胶片回 5 体、12 槽。连击窗口约 1.42 秒。特效槽 100，开局 70；慢镜每秒耗 22、拉近 18、同按 34；空闲每秒回 9，命中 +7，击杀 +14。槽低于 8 不能新开，耗尽即关。

敌人：群演贴脸拳 3 血；镜手远射 3 血，子弹胸口高度，跳过去或慢镜打回；航拍 3 血空中点射；甲士 4 血挥砍前摇更长；爆破 3 血抛弧弹。导播机 22 血近拍板震地、远三弹；重锤王 26 血跳砸（站地吃震波）；红帽魔 32 血冲刺与喷火。震波贴地，跳起能躲。体力条打空扣一命；约 0.82s 后原地满体重生，1.35s 闪烁无敌。三命扣完弹出「CUT」。

得分：拳命中 40×连击倍率（击倒约 ×1.4），踢命中 55×倍率，打回子弹 80×倍率。红侠状态再 ×1.25。击杀群演 160 / 镜手 220 / 航拍 240 / 甲士 280 / 爆破 260 / 导播机 3600 / 重锤王 4200 / 红帽魔 6000×倍率，过关 1500×关，清潮 600×潮，胶片 120，片箱 80。连击为连续命中，约 1.42 秒无命中则断。倍率 = 1 + min(4, floor((连击-1)/2))。每 20000 分 1UP，命上限 6。最高分写入 playbox-viewtiful-best，不存盘面；本局超过即更新。

失败：体力打空扣一命（无敌除外）。约 0.82s 后原地满体重生，1.35s 闪烁无敌。三命扣完弹出「CUT」。弹层打开时方向键不再打；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳，空格出拳，↓ / S / X / K 踢，按住 V 慢镜，按住 C 拉近。触屏 左 / 跳 / 右 / 拳 / 踢，右下 慢 / 镜。点画布出拳。标题 Enter/空格/1 开拍，2 快剪。R 重开，M 静音。无手柄。与街霸不同：不是对打选角波升龙，是片场清场。与神龟不同：没有四龟、井盖、披萨下水道。与制裁不同：不以枪为主，靠慢镜打回子弹和拉近大招。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不顿帧、不抖屏、少粒子、不拉近镜头。触控画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

爽感：出拳挥砍音，踢更闷。打中三层：听（拳风、踢击、打回子弹各不一样，连击音高往上爬）、看（红金溅射、闪光、分数蹦出，慢镜残影，拉近黑边）、触（刺约 42ms / 横约 52ms / 上勾约 70ms / 踢约 58ms 顿帧，慢镜与拉近再拉长，封顶约 80ms + 镜头踢）。击倒大溅射。慢镜子弹带青圈。连击升档金闪、大字 ×N，红侠状态弹出 VIEW!。失败与重开都是一键 R。
