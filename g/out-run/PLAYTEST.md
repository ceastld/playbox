玩法：标题页选「海岸」或「夜奔」。敞篷车停在画面底部，公路向消失点卷去。← → / A D 转向，↑ / W / 空格 / 按住画布加油门，↓ / S 刹车。点「重开」或 R 开新局（标题页 R 进海岸；局中或结算重开回当前模式）。M 静音，写入 playbox-out-run-mute。
场地与碰撞：虚拟场 800×450，伪 3D 路段长 200。玩家横向约 ±1 为路面，超过即冲出（减速、扬尘，不出局）。来车偏移与玩家横向差小于 0.3 且纵向约 210 内即擦碰：时速约剩 36%、弹开、70ms 顿帧，约 1.2 秒复原。撞车不会死。
分叉与路段：每段约 1080–1200 节。非终点段末路分成左右，靠左/靠右驶过检查门进入下一主题（海滩 / 峡谷 / 城市）。四段到终点：椰湾起，三岔后落日 / 霓虹 / 夜港 / 星湾之一。门上 CHECK / GOAL。
时间与分数：海岸开局 54 秒，过门 +18；夜奔 38 秒、+13，且顶速更高、车更多。超时才结束（车会滑停再弹层）。距离一直加分；超车 90×连超；疾风（时速 >82% 且在路上）每 0.72 秒一层；过门 700+；终点 2400+剩余时间。最高分按模式写入 playbox-out-run-best，JSON `{h,n}`（海岸 / 夜奔）。
胜利：第四段冲过 GOAL。失败：时间到 0。弹层不挡 R 与顶栏重开。
操作：方向键 / WASD；点按画布加速并按左右位置转向。标题页 Enter/空格/1 海岸，2 夜奔。结算 Enter 再开。无手柄。无自动。
限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏。触控画布 `touch-action: none`。标题页背后是演示驶，到门会重置，不算分。
爽感：高速速度线与车尾残影；擦碰弹跳+噪音声；过门金闪、加时数字、电台琶音；超车连击音高爬升；引擎转速跟时速。失败与重开都是一键 R。
什么变难：弯道离心力把车往外甩。夜奔更快、时间更紧、车流更密。冲出路面会掉速，检查门前必须选边。
