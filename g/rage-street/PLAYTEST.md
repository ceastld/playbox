玩法：标题页「怒街」。选「街区」打三关（霓虹街→码头→夜楼，关底 Boss）；选「无尽」一波接一波，每 5 波一头目，无终局胜利。沿街带状走（左右推进、上下换深度），空格 / X 跳，Z 三连拳，C 爆发（耗体力）。捡铁管近打、飞刀投掷、烤鸡回血。体力打空扣一命。点顶栏「重开」或按 R：标题页进街区；对局中或结束层重开同一模式。结束层「再来」同模式；失败「换模式」回标题；通关「无尽」开无尽。M 静音，写入 playbox-rage-street-mute。弹层打开时方向键不走路、Z 不出拳；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。可走带宽 y=222–322。镜头跟在人右前方，遇兵和 Boss 锁在当前段。人约 16 宽 30 高，走约 176，纵深约 112，空中约 0.88。起跳约 73 高。标题页背后演示右进出拳，不算分、不掉血。

街区三关：霓虹街（铁腕 150 血，有铁管/飞刀/烤鸡）/ 码头（钢拳 210 血，飞车更多）/ 夜楼（黑衣 280 血）。过关保留命、分、当前武器和体力。无尽同街景，波数递增，敌血约 +8%/波，每 5 波循环铁腕/钢拳/黑衣。

出拳：Z 三连（直→直→钩），第 3 击击飞。跳中 Z 为跳踢。铁管更远更重，8 次。飞刀 Z 投出，3 把。C 爆发半径清场，耗 18 体力，可把自己打空。爆发中无敌。

敌人：青皮近打 100；飞车冲撞 200。Boss 铁腕重拳、钢拳冲撞、黑衣压场。击破 Boss 再加 4000×倍率，过关 +2000×关。街区打掉黑衣后再加 8000，弹「夜楼清了」；无尽无终局。

得分：击杀基础分 × 连击倍率。连击为连续打中，约 1.4 秒无打中则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 20000 分 1UP，命上限 6。最高分写入 playbox-rage-street-best，不存盘面；本局超过即更新。

失败：挨打扣体力（无敌与爆发除外）。体力 0 或爆发耗尽扣一命。约 0.78s 倒地后原地满血重生，1.35s 闪烁无敌，武器变回拳头。三命（顶栏红点）扣完弹出「被打倒了 / 血空了 / 爆发耗尽 / 被飞车踢中了 / 被青皮打中了」等。弹层打开时方向键不再出拳；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → ↑ ↓ / WASD 走（上下换深度），空格 / X / J 跳，Z / K 出拳，C / Shift 爆发。点画布同出拳。触屏 上 / 下 / 左 / 右 / 拳 / 跳 / 爆。标题页 街区 / 无尽，Enter/空格/1 街区，2 无尽。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：出拳挥拳风声。打中：撞击音 + 粒子/火花 + 分数蹦出 + 约 40–72ms 顿帧（钩拳/铁管更长，爆发约 80ms）+ 镜头微震。连击数字往上窜，倍率跳时全屏 ×N。爆发：青金爆光、残影、全屏闪、震。捡武器金鸣。失败与重开都是一键 R。
