玩法：标题页选「营救」或「急流」。四幕：荡藤抓下一根、潜泳留气斩鳄、爬山躲滚石、跃过守卫救人。摔下或撞上扣一条命。点「重开」或 R 开新局（标题页 R 进营救；局中或结算重开回当前模式第 1 巡第 1 幕）。M 静音，写入 playbox-jungle-king-mute。

荡藤：七根藤各自摆。空格在两藤靠近时抓住下一根（下一根会亮金圈并出「抓！」）。抓空从藤上落下，掉进坑里丢命；最后一根朝河岸荡到位再跳，落到岸上过关。坠落途中仍可抓住前方的藤。

斩鳄：四向游，空格短距挥刀。鳄嘴张开时从正前方撞上会丢命；碰到身体也会。刀砍中鳄身即斩杀（张嘴正前方除外）。水下耗气，浮出水面回气，气尽溺水。游到右岸出水过关。急流有向左的暗流、气更短。

滚石：向右上山。小石跳过去，飞得高的大石按住「下」蹲过去。跳过或蹲过都记分。撞上石头丢命。跑到山顶过关。

救人：两名守卫长矛起落。矛落下时跳过身子；矛举起时跳也会被扎。锅是地面陷阱，需跳过去。落到同伴身边即救出，进入下一巡（四幕再来一遍，更快）。

得分：抓藤 +120×连击，斩鳄 +280×连击，跳石 +160×连击，蹲石 +140×连击，跳守卫 +220×连击。过关 +900+180×巡 + 剩余秒×8。救下再 +2400。连击约 1.42 秒内没有有效操作会断。最高分按模式分记，写入 localStorage 键 playbox-jungle-king-best，JSON `{c,r}`（营救 / 急流）。本局超过即更新。

模式：营救节奏正常。急流藤更快、气更短、鳄更密、石更勤、矛更快、时限更紧。两种模式不共用最高分。

操作：← → / A D 走（潜泳四向），↑ / W / 空格 跳或抓藤（潜泳空格挥刀，W 上浮），↓ / S 蹲或下潜。触屏左 / 下 / 上 / 跳 / 右。标题页 Enter/空格/1 营救，2 急流。R 重开，M 静音。无手柄。无自动。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏。触控棋盘 `touch-action: none`，避免页面跟着滚。弹层 `pointer-events: none`（面板除外），顶栏重开与 R 随时可用，弹层不挡重开。

爽感：抓藤必有三层——听（音高随连击往上爬）、看（叶绿屑、金环、抓！、分数蹦出）、触（约 40ms 顿帧 + 镜头微踢）。挥刀斩鳄约 70ms 顿帧、洋红炸开。入水溅射。跳石/跳守卫金屑 + 顿帧。失手洋红闪、约 80ms 顿帧并震一下。连击数字往上叠。失败与重开都是一键 R。
