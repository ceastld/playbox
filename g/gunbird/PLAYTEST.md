玩法：标题页「枪鸟」。先点「羽散」或「钢翼」选角色（默认羽散；C / Q 切换），再选「空战」打三关（羽镇 → 沙海 → 云阙），每关中 Boss 与关底 Boss；选「密弹」同三关但卷轴更快、敌弹更密、Boss 多约 22% 血、额外补波。点顶栏「重开」或按 R：标题页直接开空战（当前角色）；对局中或结束层重开同一模式与角色。结束层「再来」同模式同角色；舰毁「换模式」回标题；通关「密弹」开密弹（密弹通关则「换模式」回标题）。M 静音，写入 playbox-gunbird-mute。方向键 / WSD 八向移动（A 为自动），空格开火（可按住连射），Shift / Z 或顶栏「爆」扔角色爆弹。画布拖动跟舰，按下开火。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 空战、2 密弹。点「自动」或按 A 开关托管（开着时按钮呈按下态并显示「停下」）。开着时忽略方向键、W/S/D、空格、触屏跟舰；A / R / M / 重开仍可用。开关不写入存储，刷新后关闭；重开不会关掉自动。标题层会自动开空战，舰毁/通关层自动再来。速度滑条 1–4 为 慢 / 中 / 快 / 极快（默认快），写入 playbox-gunbird-auto-speed，改速立即生效。AI 会飞、连射、危急时爆弹、捡菱形羽/爆，不是左右晃。

场地：虚拟场 480×720。舰开局 y=630、x=240，夹在 22–458 / 40–692。空战巡航约 86（关卡与连击再加），密弹约 118；中/关底 Boss 在屏时降到约 28–36。移速约 276（密弹 318）再加火力等级。点按或按住空格开火。未解锁音频前无声。

角色：开局选定，对局中不换。羽散扇形金羽（1 级双发，2 三向，3 五向，MAX 六向；冷却约 0.112–0.064s）。钢翼贯穿光刃（1 束青激光穿甲，升到 2/3 束，MAX 再加侧刃；每发对同一机体只结算一次，冷却约 0.118–0.082s）。吃菱形「羽」胶囊强化当前角色到 MAX（3）；满级再吃 +500×倍率。运鸟循环掉 羽/羽/爆。坠机掉一枚「羽」且火力归零，角色不变。

爆弹：开局 3 枚，上限 6。Shift / Z 清掉全部敌弹、全体扣血，全屏闪、金环、约 78ms 顿帧，自身约 0.52s 无敌。羽散「凤凰」：金羽从顶雨落（约 0.72s）继续砸伤；钢翼「钢炮」：舰前宽光柱约 0.62s 持续穿甲。过关补 1 枚。用尽再按提示「爆弹用尽」。

关卡：第 1 关羽镇中 Boss「石狮」38 血、关底「羽神」92；第 2 关沙海「铁驼」50 / 「金甲」124；第 3 关云阙「殿卫」64 / 「枪鸟」168。密弹血量 ×1.22。中 Boss 在场时波次计时暂停。编队雀群、侧翼切入、俯冲金鸢、三发甲鸟、浮岛塔、灵火、运鸟。羽神半血后扇扫；金甲旋转弹幕；枪鸟双环弹+瞄准。浮岛塔是地面单位，可飞越，只吃它们的对空弹。空中机体相撞扣命。

得分：击杀基础分 × 连击倍率。雀 50、鸢 100、甲鸟 200、塔 150、灵 80、运鸟 300、中 Boss 2000、关底 4000+1500×关。连击为连续击杀，约 1.42 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。击坠关底再加 1500×关。三关打穿 +8000 并「枪鸟尽破」。每 20000 分 1UP，命上限 6。最高分写入 playbox-gunbird-best，不存盘面；本局超过即更新。

胜利：空战/密弹打掉第 3 关枪鸟后约 2.05s 结算胜利。
失败：敌弹碰到自己，或空中机体相撞，扣一命（重生无敌与爆弹期间除外）。约 0.95s 爆炸后重生，1.55s 闪烁无敌，场上敌弹清空。三命（顶栏橙点）扣完弹出「舰毁了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WSD 移，空格开火，Shift / Z 爆弹，A 自动。点按画布开火并跟舰。标题页 Enter/空格/1 空战，2 密弹，C / Q 换角色。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾、不闪炮。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 羽散升频方波 / 钢翼锯齿下滑。击中粒子爆开 + 短顿帧（约 34–72ms）+ 镜头微震 + 连击数字往上窜。羽散凤凰三层：听（噪声 + 上滑正弦）、看（金羽雨、翼影、金环）、触（约 78ms 顿帧 + 强震）。钢翼钢炮三层：听（低锯齿 rumble）、看（宽光柱、边框闪）、触（顿帧 + 强震）。吃羽金闪。坠机洋红大爆。失败与重开都是一键 R。
