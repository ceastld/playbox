玩法：标题页「豆陆」。选「回家」打四程（郊野→桥路→小镇→仙境），把每程尽头的仙子送到即过关；选「夜路」同一条路，鬼更多更快，能量豆更短。点「重开」或 R：标题页直接开回家；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-pac-land-mute。

场地：虚拟场 480×270，格 24px。横向卷轴，镜头略朝面朝方向预瞄。地面、单向台、弹簧板、深坑。头几格是 2 格宽的教学坑，之后大约 3–5 格可直接跳过；更宽的有弹簧或空中踏板。掉出地图底或栽进坑扣命。

跑跳：左右跑约 162px/s。跳跃初速 328、重力 1020，滞空约 0.64s，一跳约 53px 高、约 104px 远。硬跳：中途松手不收跳，空中左右加速只有落地的约 27%。土狼时约 0.055s、跳跃缓冲 0.1s。弹簧把你弹到约 107px 高、约 149px 远。

帽子：直升机帽约 11.2 秒，下落重力约 236、终端速度约 76，可漂过较宽缺口。火焰帽约 9.4 秒，自动朝面朝方向喷火（约 0.46 秒一发），↓ / S / 触屏「火」可立刻打。火球碰到实心墙消失，打中鬼按连击给分。两顶帽互相替换。顶栏「帽」条；帽子飞走有提示。

豆子与鬼：小豆沿路，能量豆惊吓（回家约 6.15 秒，夜路约 4.35 秒，末 1.6 秒闪白）。惊吓中撞鬼可反吃，连吃 200 / 400 / 800 / 1600。水果更高分。鬼分走路追和飞追；夜路额外补鬼、走路约 80、飞约 62（回家约 62 / 48）。被吃剩眼飞回出生点，约 2.4 秒再出来。

过关：碰到程末仙子即清关，约 0.95 秒后进下一程。四程送完弹出「仙子送到了」（夜路「夜路走通」）。过关保留分数和命。

得分：小豆 10×倍率，能量豆 50，水果 180×，帽子 160，火球打鬼 150×，反吃按连吃翻倍。清关 900+220×关卡。连击窗口约 1.12 秒，每 3 下升一档，最高 ×5。最高分按模式分记，写入 localStorage 键 playbox-pac-land-best，JSON `{h,n}`（回家 / 夜路）。本局超过即更新。不存盘面。

生命：3 条，顶栏黄点。撞鬼「撞上鬼了」，掉坑「掉进坑了」。扣命后约 0.72 秒摔出，再在最近安全落地处重生，约 1.15 秒闪烁无敌。三命用尽弹出「命尽」。惊吓结束、帽子飞走都有提示。

模式：回家正常出鬼。夜路每程额外补 1–3 只，更快，能量豆更短。两套最高分不共用。

操作：← → / A D 跑，空格 / ↑ / W 跳，↓ / S 喷火。点按画布跳。触屏左 / 跳 / 右 / 火。标题页 Enter/空格/1 回家，2 夜路。R 重开，M 静音。无手柄。第一稿没有自动玩。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏。触控棋盘 `touch-action: none`，避免页面跟着滚。弹层打开时顶栏重开与 R 随时可用，弹层 `pointer-events: none`（仅面板可点），不挡顶栏重开。

爽感：每颗豆都有三层——听（叮，音高随连击往上爬）、看（金屑、环、分数蹦出）、触（约 30ms 顿帧 + 画面微挤）。吃鬼约 65ms 顿帧、白闪、爆屑、连吃倍率。捡帽金/青/火闪光、粒子、顶栏字跳一下。弹簧弹起 Tonk + 青环。起跳尘 + 约 30ms 顿帧。掉坑/撞鬼洋红闪、约 80ms 顿帧并震一下。连击数字往上叠。失败与重开都是一键 R。
