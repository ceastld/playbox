玩法：标题页「打击」。选「空袭」打三关（港湾 → 雪原 → 要塞），每关中 Boss 与关底巨舰；选「机海」同三关但卷轴更快、编队更密、敌弹更勤、Boss 多约 22% 血、额外补波。点顶栏「重开」或按 R：标题页直接开空袭；对局中或结束层重开同一模式。结束层「再来」同模式；机毁「换模式」回标题；通关「机海」开机海（机海通关则「换模式」回标题）。M 静音，写入 playbox-striker-1945-mute。方向键 / WASD 八向飞，空格射击（可按住连射并蓄力），Shift / Z 或顶栏「爆」放爆弹。画布拖动跟机，按下开火，松手若蓄满则超射。触屏右下「爆」放爆弹。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 空袭、2 机海。

场地：虚拟场 480×720。机开局 y=630、x=240，夹在 22–458 / 40–692。空袭巡航约 86（关卡与连击再加），机海约 118；中/关底 Boss 在屏时降到约 26–34。移速约 276（机海 318）再加火力等级。点按或按住空格开火。未解锁音频前无声。双叉机双螺旋桨自转。火力 2 起两侧跟飞僚机。

火力：开局 0 级双发青弹（两根机身各一），冷却约 0.108s。吃菱形「火」胶囊升到 MAX（3）：1 加中弹 0.096s、2 五向+僚机 0.084s、MAX 七向+僚机斜射 0.072s。满级再吃 +500×倍率。运机循环掉 火/火/爆。坠机掉一枚「火」且火力归零，爆弹保留。顶栏火条跟等级走，MAX 时爆亮。

蓄力超射：按住空格连射同时蓄力，约 0.85s 蓄满（顶栏亮「超」、机周金环）。松手放出贯穿超射：三道金叉（火力 2 起再加两侧），每发 8 伤穿甲，约 56ms 顿帧 + 金闪。未蓄满松手只停射。坠机清空蓄力。

爆弹：开局 3 枚，上限 6。Shift / Z 清掉全部敌弹、全体扣血，金弹从顶雨落约 0.72s 继续砸伤，全屏闪、金环、约 78ms 顿帧，自身约 0.52s 无敌。过关补 1 枚。用尽再按提示「爆弹用尽」。

关卡：第 1 关港湾中 Boss「炮艇」42 血、关底「巨舰」100（半血变形伸出机械臂）；第 2 关雪原「铁甲」56 / 「冰堡」132；第 3 关要塞「潜影」70 / 「天门」176。机海血量 ×1.22。中 Boss 在场时波次计时暂停。编队侦察、侧翼切入、俯冲锥、重机、炮台（地面可飞越只吃对空弹）、运机。巨舰扇扫；冰堡旋转弹幕；天门双环弹+瞄准。变形后加侧射/环弹。空中机体相撞扣命。

得分：击杀基础分 × 连击倍率。侦察 50、战机 80、俯冲 110、重机 200、炮台 150、运机 300、中 Boss 2000、关底 4000+1500×关。连击为连续击杀，约 1.42 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。击坠关底再加 1500×关。三关打穿 +8000（机海 +10000）并「空袭尽破 / 机海尽破」。每 20000 分 1UP，命上限 6。最高分写入 playbox-striker-1945-best，不存盘面；本局超过即更新。

胜利：空袭/机海打掉第 3 关天门后约 2.05s 结算胜利。
失败：敌弹碰到自己，或空中机体相撞，扣一命（重生无敌与爆弹期间除外）。约 0.95s 爆炸后重生，1.55s 闪烁无敌，场上敌弹清空。三命（顶栏青机点）扣完弹出「机毁了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格射击蓄力，Shift / Z 爆弹。点按画布开火并跟机。标题页 Enter/空格/1 空袭，2 机海。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾、螺旋桨不夸张。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波（火力越高越厚）。击中粒子爆开 + 短顿帧（弹中约 22ms，击杀约 34–72ms）+ 镜头微震 + 连击数字往上窜。蓄满金环 + 升频提示音。超射三层：听（噪声 + 低锯齿 + 上滑正弦）、看（金叉贯穿、金环、边框闪）、触（约 56ms 顿帧 + 强震）。爆弹三层：听（噪声 rumble）、看（金弹雨、金环）、触（约 78ms 顿帧 + 强震）。吃火金闪。满级「MAX」蹦字。巨舰半血「变形」。坠机洋红大爆、约 78ms 顿帧。失败与重开都是一键 R。
