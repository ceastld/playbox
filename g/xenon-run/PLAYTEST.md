玩法：标题页「异星」。选「地表」变形关：建筑挡住坦克、顶棚挡住战机，炮台坦克可碾；选「空袭」更快、空敌更密、地面关更稀。点顶栏「重开」或按 R：标题页直接开地表；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-xenon-run-mute。←↑↓→ / WASD 移动，空格开火（可按住连射），C / Shift 变形。画布拖动跟舰，按下开火；右键变形。触屏「变」。结束层与标题层不挡顶栏重开，R 随时可用。

场地：虚拟场 480×720。世界 `cam` 向上滚，战舰钉在画面里可八向移动（夹在约 18–462 x、64–672 y）。地表巡航约 168、空袭约 248；核心在屏时再降到约 24–96。战机移速约 286（空袭 330），坦克约 198（空袭 230）。战机弹速 580、坦克 440。火力 0–3：单发 / 双管 / 三发散 / 速射三发，冷却约 0.16 / 0.13 / 0.11 / 0.075s。C、Shift、右键或触屏「变」切换形态，冷却 0.32s。未解锁音频前无声。

地形：噪声生成左右崖壁，两形态都撞壁。建筑/掩体挡坦克，战机飞过（可打，4 血）。顶棚挡战机，坦克潜入。炮台战机飞过，坦克碾碎。开局约 348 宽谷，约 420 单位后收窄。每 1680 世界单位一区，第 4 区后 `6720` 出核心。

敌人：炮台 50、碾碎 90、飞碟 70、建筑 20、核心 1200、道具 40，再乘连击倍率。炮台朝玩家斜射，飞碟正弦漂并开火，空袭更密更快。核心 18 血（空袭 16），左右游荡，三发散（半血后五发）。打掉飞碟/炮台约 16% 掉火力或 1UP 胶囊。

得分：击杀基础分 × 连击倍率。连击为连续打中（子弹飞出顶边则断），约 1.35 秒无击杀也断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 12000 分 1UP，命上限 6。最高分写入 playbox-xenon-run-best，不存盘面；本局超过即更新。

胜利：打爆核心弹出「核心毁了」（约 1.15s 爆炸后再弹层）。
失败：三命（顶栏紫梭）扣完弹出「舰毁了」。撞壁、撞建筑（坦克）、撞顶棚（战机）、撞飞碟/核心、中弹都扣一命。约 0.88s 爆炸后在当前谷中重生，1.4s 闪烁无敌（无敌撞壁会被推回谷内）。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 移，空格开火，C / Shift 变形。点按画布开火并跟舰，右键变形。触屏「变」。标题页 Enter/空格/1 地表，2 空袭。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 战机升频 / 坦克低方波。变形三层：听（战机上滑、坦克下滑+噪声）、看（全屏闪、环、粒子、形态徽章跳）、触（约 48ms 顿帧 + 镜头微震）。碾碎炮台：金爆、「碾碎」字、低锯齿 rumble、约 55ms 顿帧。击杀粒子 + 连击音高往上爬。坠机洋红大爆、约 72ms 顿帧并震屏。失败与重开都是一键 R。
