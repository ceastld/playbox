玩法：标题页「双驶」。选「双驶」三段推进（焰湾起，分叉进岩脊 / 霓港，再分叉落雪冠 / 森瀑 / 星环之一），每关路程约 76% 后出终段驶团；选「驶核」同路线但车更密、弯更甩、涡轮掉得更快、驶团更厚。点顶栏「重开」或按 R：标题页直接开双驶；对局中或结束层重开同一模式。结束层「再冲」同模式，「换模式」回标题。M 静音，写入 playbox-outrunners-mute。← → / A D 转向，↑ / W / 空格 / 按住画布加油门，↓ / S 刹车，Shift / Z 或顶栏「涡」或按住画布上半开涡轮。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。

场地与碰撞：虚拟场 800×450，左右各 400 宽分屏。左屏是你、右屏是对手，同一条伪 3D 路。路段长 200。玩家横向约 ±1.08 为路面，超过即冲出（减速、扬尘）；时速约 38% 以上冲出或横向 >1.52 即摔车。来车偏移与玩家横向差小于 0.28 且纵向约 195 内即碰上：没开涡轮则摔车；涡轮且时速 >38% 则顶飞（顿帧、爆粒子）。摔车时速约剩 16%、约 1.45 秒复原、70ms 顿帧，不会出局。对手同样会摔、会躲、会开涡轮。

分屏对开：对手是真 AI（压弯、躲车、落后开涡轮），不是乱抖。超车对手记「甩开」；被超提示「被超了」。顶栏显示领先 / 落后米数。涡轮贴上对手会顶飞并加连击。对手先冲门提示「对手先到」，你仍要自己过门才切关；你先过门加「先到」分。

分叉：非终点段末路分成左右，靠左/靠右驶过检查门进入下一主题。焰湾 → 岩脊 / 霓港；岩脊 → 雪冠 / 森瀑；霓港 → 森瀑 / 星环。三段到终点 GOAL。门上 CHECK / GOAL。

涡轮：槽 0–1。双驶每秒耗 0.32、回 0.22；驶核耗 0.46、回 0.16。低于 0.06 点不着。开涡轮顶速约 ×1.36、加速更快、离心更狠，尾焰+橙青速度线。过门回槽 +0.28。空了提示「涡轮空了」。

终段驶团：每关约 76% 路程刷一队。双驶 5 台 / 驶核 7 台，头车是双王（金框，血量 焰湾 3/4、中段 3/5、终点 4/6，驶核取后值）。双王会贴着你的横向堵路。涡轮顶上去扣血，血空才爆。不必清完也能冲门，但堵路。

时间与分数：双驶开局 48 秒，过门 +16；驶核 36 秒、+12，顶速更高、车更多。超时才结束（车会滑停再弹层）。距离一直加分；超车 80×连击×倍率；甩开对手 220×；涡轮顶飞 150×（双王击破 450×）；疾风（时速 >80% 且在路上）每 0.66 秒一层，涡轮时 0.50 秒；过门 800+（先到再 +360）；终点 2800+剩余时间（先到对手再 +800）。连击约 1.80 秒无超车/顶飞则断；自身摔车立刻断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。最高分按模式写入 playbox-outrunners-best，JSON `{c,m}`（双驶 / 驶核），不存盘面；本局超过即更新。

胜利：第三段冲过 GOAL。失败：时间到 0。弹层不挡 R 与顶栏重开。

操作：方向键 / WASD 转向+油门+刹车；空格油门；Shift / Z 涡轮。点按画布加速并按左右位置转向（两半屏均可），按住上半同时涡轮。标题页 Enter/空格/1 双驶，2 驶核。结算 Enter 再冲。无手柄。无自动。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、少粒子、无速度残影。触控画布 `touch-action: none`。标题页背后是分屏演示驶，到门会重置，不算分。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：左右分屏同时看自己和对手；甩开对手时青闪+顿帧+「甩开 ×N」蹦字；涡轮尾焰+橙青速度线+引擎拔高；顶飞顿帧约 36–78ms、爆粒子/环/「爆驶 ×N」，连击音高往上爬；摔车粒子+顿帧+引擎闷一下；过门金闪、加时数字。失败与重开都是一键 R。

什么变难：弯道离心力把车往外甩。开涡轮更快更滑。终段驶团堵路，双王会跟横向。对手会追、会超、会开涡轮。驶核更密、时间更紧、涡轮掉得快。冲出路面会摔，摔完要加速复原。分叉前必须选边。
