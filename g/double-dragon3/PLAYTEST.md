玩法：标题页「双截3」。选「双截3」打三关（纽约→京都→开罗，开罗尽头是石王）；选「截核」同三关但每包更密、更快、更肉。沿街带状走（左右推进、上下换深度），C / Shift 跳，空格 / Z 出拳三连，X 踢；空中再出拳是空拳，空中再踢是跳踢。砸木箱掉双截棍 / 釵 / 刀或烤鸡，兵器打中才耗耐久，断了回徒手。没有抓投、不救人。体力打空扣一命。点顶栏「重开」或按 R：标题页进双截3；对局中或结束层重开同一模式。结束层「再来」同模式；失败「换模式」回标题；通关「截核」开截核。M 静音，写入 playbox-double-dragon3-mute。弹层打开时方向键不走路、空格不出拳；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。可走带宽 y=224–324。镜头跟在人右前方，遇兵和 Boss 锁在当前段。人约 16 宽 30 高，走约 190，纵深约 116。跳约 91 高，空中可横移约 116。纽约霓虹楼、京都鸟居灯笼、开罗金字塔石柱。标题页背后演示右进跳拳踢，不算分、不掉血。

双截3 三关：纽约（黑拳 170 血，铁拳/棒手，箱出双截棍与烤鸡）/ 京都（刃影 230 血，忍/矛手更多，箱出釵）/ 开罗（石王 310 血，会射石矢并叫石卫，箱出刀）。过关保留命、分、体力和兵器。截核同街景，每包多 1～2 人，敌速约 ×1.12，血量约 ×1.16，石王血约 ×1.2。

出拳：空格三连（直→直→勾），第 3 击击晕。X 地面踢击倒。C 起跳，空中空格空拳、空中 X 跳踢（离地跳踢可躲飞镖）。双截棍快而多下（10 耐久），釵中距易晕（8），刀最长最重（6）。烤鸡回 36 体。飞镖/石矢用上下换深度或跳过躲开。

敌人：铁拳近打；棒手重挥；忍飞手里剑并会跳踢；矛手冲刺。Boss 黑拳冲撞、刃影跳踢并飞镖、石王射石矢并叫石卫。击破 Boss 再加 4200/5400/9200×倍率，过关 +2000×关。双截3 打掉石王后再加 8000，弹「开罗清了」；截核弹「截核清场」。

得分：击杀基础分 × 连击倍率。连击为连续打中，约 1.4 秒无打中则断。倍率 = 1 + min(4, floor((连击-1)/2))，即 1–2 连 1 倍、3–4 连 2 倍，最高 5 倍。每 18000 分 1UP，命上限 6。最高分写入 playbox-double-dragon3-best，不存盘面；本局超过即更新。

失败：挨打扣体力（无敌与跳踢离地除外）。体力 0 扣一命。约 0.82s 倒地后原地满血重生，1.28s 闪烁无敌。三命（顶栏橙点）扣完弹出「被打倒了 / 血空了 / 被铁拳打中了 / 被棒手撞了 / 中手里剑了 / 中石矢了」等。弹层打开时方向键不再出拳；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → ↑ ↓ / WASD 走（上下换深度），C / Shift 跳，空格 / Z / J 出拳，X / K 踢。点画布同出拳。触屏 上 / 下 / 左 / 右 / 跳 / 拳 / 踢。标题页 双截3 / 截核，Enter/空格/1 双截3，2 截核。R 重开，M 静音。无手柄。与双截不同：不救人、没有长鞭，核心是跳拳踢加兵器。与双截2不同：有体力条不是撞击即死，没有抓投甩人，Z 是出拳不是飞踢，关卡是纽约/京都/开罗不是停机坪/密林/罪府。与终斗不同：有跳有踢有兵器，没有抱摔旋扫，关卡不是香港/巴黎/罗马。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：出拳挥拳风声，兵器各有音色，踢/跳破空声。打中：撞击音 + 粒子/火花 + 分数蹦出 + 约 40–80ms 顿帧（勾拳/跳踢/刀更长）+ 镜头微震。击破爆炸粒子与光环。连击数字往上窜，倍率跳时全屏 ×N。跳踢：青金残影、落地重震。砸箱金鸣。失败与重开都是一键 R。
