玩法：标题页「拳台」。选「挑战」打三位拳手（青皮 → 铁腕 → 金拳）；选「连战」循环上场、预备更快、空档更短。点「重开」或 R：标题页直接开挑战；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-punch-bag-mute。

场地：对面站位。对手在擂台中央，你的手套在近处。对手出拳前有预备（肩扭、拳蓄、下蹲、感叹号、侧边色光）。躲开的那一记会从身边擦过，随后是空档。

躲闪与出拳：← / A 左躲，→ / D 右躲，↓ / S 下蹲。左钩躲右或蹲，右钩躲左或蹲，直拳躲左或右（蹲会被打到），上勾必须蹲，身体击必须左右躲（蹲会被打到）。硬接（站着）和躲错都掉 1 颗红心。Z / J / 点左手套左拳，X / K / 点右手套右拳。躲闪最多维持约 0.52 秒，不能一直蹲着。

耐力与倒地：对手耐力打空即倒地。三次倒地 TKO；星拳在倒地前打空耐力算 KO。你有 4 颗红心，打空倒地；倒地后连打 Z/X 起身（第二次更难），数到十起不来即 KO。三次倒下即负。打趴对手会回 1 颗红心。挑战打完金拳「卫冕」；连战直到你倒下。

得分：空档拳 80×连击倍率，星拳 240×倍率。连击每多一击倍率 +1，最高 ×5；挨打、打在防上或约 2.2 秒没打中会断。倒地 800，KO 2000，TKO 1500，赢一场 1200（连战 800），挑战通关再 +4000。完美空档（刚躲开就打）攒星，有星再打空档会消耗 1 颗星放出星拳。最高分写入 playbox-punch-bag-best，不存盘面。

模式：挑战三位，预备原速。连战同一批拳手循环，预备时间 ×max(0.5, 1−0.07×(场−1))，空档略缩。连战与挑战共用最高分。

操作：键盘方向 / WASD 躲，Z X 或 J K 出拳。触屏底栏 左 / 蹲 / 右 / 左拳 / 右拳。点画布手套出拳；点台下左右也可躲、中间蹲。标题 Enter/空格/1 挑战，2 连战。R 重开，M 静音。无手柄。弹层打开时方向键不进拳台；顶栏重开与 R 随时可用，弹层不挡。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不顿帧、不抖屏。触控画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：每次出拳有挥拳风声。打中：撞击音 + 星爆 + 分数蹦出 + 约 55ms 顿帧（星拳约 80ms）+ 镜头踢 + 观众闪。躲开：侧向擦拳 + 「空档」字 + 青环。硬接闷响。连击数字往上叠。倒下铃响、观众鼓噪。失败与重开都是一键 R。
