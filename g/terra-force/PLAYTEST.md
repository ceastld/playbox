玩法：标题页「陆力」。选「陆力」打三关（荒原 → 河谷 → 要塞），每关中 Boss 与关底 Boss；选「陆核」同三关但卷轴更快、履带更密、迫击更勤、Boss 多约 22% 血、额外补波。点顶栏「重开」或按 R：标题页直接开陆力；对局中或结束层重开同一模式。结束层「再来」同模式；机毁「换模式」回标题；通关「陆核」开陆核（陆核通关则「换模式」回标题）。M 静音，写入 playbox-terra-force-mute。方向键 / WASD 八向飞，空格开火（可按住连射），X / C 或顶栏「变」空陆变形，Shift / Z 或顶栏「爆」放陆爆。画布拖动跟机，按下开火。触屏右下「变」变形、「爆」陆爆。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 陆力、2 陆核。

场地：虚拟场 480×720。战车开局 y=630、x=240，夹在 22–458 / 40–692。陆力巡航约 84（关卡与连击再加），陆核约 116；中/关底 Boss 在屏时降到约 28–36。空形态移速约 282（陆核 320）再加火力等级，8 连再加 12；履带约 196（陆核 224）。点按或按住空格开火。未解锁音频前无声。空形态后燃约 88ms 一拍低频 rumble，履带约 100ms 更低的履带声。

两层：空中单位（截击、俯冲锥、运弹机）撞机扣命；地面单位（陆炮、坦克、碉堡、地行甲、中/关底 Boss）空形态可飞越，只吃它们的对空弹与迫击。履带形态可碾小炮台与地行甲。玩家弹打空打地都结算。履带打地额外 +1 伤。

变形：X / C / 顶栏「变」/ 触屏「变」在空（战机）与陆（履带）之间切换。着陆约 0.22s 变形、约 48ms 顿帧、金环、自身约 0.22s 无敌。水面（第 2 关河谷水色带）不能着陆，提示「水面不能着陆」；履带开进水色带会强制升空并溅水。顶栏「空 / 陆」。空形态前射针弹；履带按移动朝向八向炮弹。

火力：开局 0 级。吃菱形「陆」胶囊升到 MAX（4）。空：0 双针 0.110s、1 三向 0.099s、2 五向 0.088s、3 五向核心 0.077s、MAX 七向（伤 2）0.066s。履带：0 单炮 0.122s、1 三向、2 五向、3 五向核心、MAX 七向（伤 2）0.082s。满级再吃若爆未满则爆 +1，否则 +500×倍率。运弹机循环掉 陆/陆/爆。坠机掉一枚「陆」且火力归零，陆爆库存重置为 3，回到空形态。连击满 8 进入「陆压」：履带碾压更狠、后燃转金、移速略升。

陆爆：开局 3 枚，上限 6。Shift / Z 空形态抛出 3 枚震地弹（错开约 0.10–0.26s 落地），每枚炸出绿环（半径约 78）；履带则原地一发大坑（半径约 96）。环内清弹清迫击并扣血（近心地 4 / 空 2，边缘 1），全屏绿闪、金环、约 56ms 顿帧，自身约 0.48s 无敌。过关补 1 枚。用尽再按提示「陆爆用尽」。

关卡：第 1 关荒原中 Boss「陆台」42 血、关底「陆垒」98；第 2 关河谷「河卫」54 / 「峡闸」128；第 3 关要塞「堡卫」68 / 「陆核」176。陆核血量 ×1.22。中 Boss 在场时波次计时暂停。编队 V 字、侧翼切入、俯冲金侦、地行甲、地面陆炮、履带坦克、碉堡、运弹机。陆垒半血后扇扫夹迫击；峡闸旋转弹幕夹迫击；陆核双环弹+瞄准迫击。空中机体相撞扣命。河谷水色带履带不能开过去。

得分：击杀基础分 × 连击倍率。截击 50、俯冲 80、地行甲 140、陆炮 160、坦克 180、碉堡 150、运弹 300、中 Boss 2000、关底 4000+1500×关。连击为连续击杀，约 1.42 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。击坠关底再加 1500×关。三关打穿 +8000（陆核 +10000）并「陆力尽破 / 陆核尽破」。每 20000 分 1UP，命上限 6。最高分写入 playbox-terra-force-best，不存盘面；本局超过即更新。

胜利：陆力/陆核打掉第 3 关陆核后约 2.05s 结算胜利。
失败：敌弹或迫击爆心碰到自己，或空中机体相撞，扣一命（重生无敌、变形与陆爆期间除外）。约 0.95s 爆炸后重生，1.55s 闪烁无敌，场上敌弹与迫击清空。三命（顶栏绿点）扣完弹出「机毁了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格射击，X / C 变形，Shift / Z 陆爆。点按画布开火并跟机。标题页 Enter/空格/1 陆力，2 陆核。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾、后燃不闪、迫击无落影。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波（履带改锯齿低炮）。击中粒子爆开 + 短顿帧（约 34–72ms）+ 镜头微震 + 连击数字往上窜。变形三层：听（下滑锯齿 / 上滑方波）、看（空陆叠影、着陆/升空蹦字）、触（约 48ms 顿帧）。碾压：听（噪声+低锯齿）、看（「碾」字、金屑）、触（约 46ms 顿帧）。陆爆三连绿环清弹震地。吃陆金闪。满级「MAX」蹦字。陆压金后燃。坠机洋红大爆、约 78ms 顿帧。失败与重开都是一键 R。
