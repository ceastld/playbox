玩法：标题页「仿生」。选「钩关」打三关（废港→钢架→炮巢，关底炮塔）；选「机网」敌更快更密，炮塔更厚，生命只有 3 格。没有跳跃，只能走，用仿生臂钩住平台荡过去或拉上去，空格开枪。点顶栏「重开」或按 R：标题页进钩关；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「机网」开机网。M 静音，写入 playbox-bionic-mute。弹层打开时方向键不走路、空格不开火、Shift/Z 不钩；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72。没有起跳。仿生臂最长约 176，能从地面钩到高层底，也能钩中层后拉上去。镜头跟在人右前方，炮塔战时锁在关底。地面有缺口，掉出屏幕底丢命。中高层平台可落上。人宽约 14、高 24。走约 148（机网约 ×1.12）。标题页背后演示右进钩臂荡坑、开枪，不算分、不掉血。

钩关三关：废港（双管 22 血）/ 钢架（旋炮 28 血）/ 炮巢（联装 36 血）。过关保留命、生命、枪、分。机网同三关，速度约 ×1.28 并随关递增，额外补兵，炮塔血约 ×1.20，开局生命 3 格。

仿生臂：Shift / Z / 触屏「钩」射出，八向瞄准（方向键 / WASD，空档默认朝前上）。钩中平台底或侧面即锁住，人成钟摆荡；按上收回、拉到平台顶会爬上去；按下伸长；左右催荡。再按钩或再射臂松开，带着切向速度飞出。落空则收回。空中也可再钩。枪与臂分开：空格开枪，钩着也能射。

敌人：爬机贴地慢走 100；钩卫近身扑 120；翼机正弦飞 150；巢荚挂台下射 180；炮座原地打弹 200。关底双管对射、旋炮扇弹、联装扫射加坠弹。击破炮塔再加 4000×倍率，过关 +1500×关。钩关打掉联装后再加 8000，弹「废港已清」；机网弹「机网得手」。

生命：钩关 4 格、机网 3 格，顶栏条显示。挨打扣 1（炮塔 2），0 格丢一条命。坠崖直接丢命。三命（顶栏绿点）扣完弹出「生命耗尽了 / 坠入深渊了 / 被炮塔击倒了」。约 0.86s 后在最近扎实地面重生，满生命，1.18s 闪烁无敌。每 15000 分 1UP，命上限 6。最高分写入 playbox-bionic-best，不存盘面；本局超过即更新。

得分：击杀基础分 × 连击倍率。连击为连续命中，约 1.4 秒无动作则断；挨打立刻断。倍率 = 1 + min(4, floor((连击-1)/3))。

失败：生命归零 / 坠崖扣一命（无敌除外）。弹层打开时方向键不再走路；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑↓ / W S 瞄臂（不上跳），空格开枪，Shift / Z 钩臂。点按画布同空格。触屏 左 / 上 / 钩 / 右 / 射。标题页 钩关 / 机网，Enter/空格/1 钩关，2 机网。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：钩中必有三层——听（金属锁扣+电缆嗡）、看（青金爪火花、缆线拉亮）、触（约 30–45ms 顿帧 + 镜头微震）。开枪命中必有三层——听（击中尖鸣）、看（粒子爆、分数蹦出）、触（约 42–72ms 顿帧 + 镜头踢）。爆炸粒子、连击数字往上叠。失败与重开都是一键 R。
