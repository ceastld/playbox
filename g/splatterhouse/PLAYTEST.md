玩法：标题页「血屋」。选「血屋」打三关（西馆→地窟→祭堂，关底怨灵 / 锯汉 / 混沌）；选「尸潮」同三关，敌更快更密（额外补尸人，速度 ×1.28 并随关递增，头目血约 ×1.18）。侧向走跳，空中可改向。空格挥斩斧。第一刀把能打趴的怪打趴，再补一刀才斩死；蝠尸一刀即爆，头目只硬直需多刀。体力打空或坠入深坑扣一命。点顶栏「重开」或按 R：标题页进血屋；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「尸潮」开尸潮。M 静音，写入 playbox-splatterhouse-mute。弹层打开时方向键不走路、空格不斩（标题空格/Enter 开血屋）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 Y=322，中层平台 246。起跳约 83 高，能上一层平台。空中可改向（约 ×0.90 走速）。镜头跟在人右前方，头目出场后锁在关底擂台。地面有缺口，掉出屏幕底丢命。人宽约 16、高 28。走约 186。斩斧判定约在身前 48、上沿到头顶以上，跳起可砍蝠尸。标题页背后演示右进挥斩跳坑，不算分、不掉血。

血屋三关：西馆（怨灵 22 血，尸人、蝠尸、吊尸、蠕手，厅廊血月）/ 地窟（锯汉 30 血，坑更密，吊尸与蠕手、镜影）/ 祭堂（混沌 38 血，镜影与蝠尸更多）。过关保留命、分，补 3 点体力。尸潮同三关，速度 ×1.28 并随关递增，额外刷尸人。击破头目不立刻过关，约 1.6s 后进下一关；斩倒祭堂混沌后再加 8000，弹「血屋已清」；尸潮弹「尸潮平了」。

武器：斩斧近斩，触及约 48，挥斩 0.20s，有效帧约 0.045–0.145。第一刀对尸人 / 吊尸 / 蠕手 / 镜影打趴（约 1.12s），趴着再补一刀斩死；若等它们爬起来需再打趴。蝠尸无打趴、一刀爆。头目不打趴，需多刀。空中可斩。点按画布同空格。

敌人：尸人贴脸走 2 血，第一刀打趴；蝠尸飞正弦 1 血；吊尸悬梁，靠近才落下 2 血；蠕手贴地爬 3 血，需两次打趴；镜影更快 3 血。头目怨灵浮空喷汁并扑；锯汉冲撞与横扫；混沌喷汁并召蝠尸。体力条打空扣一命；约 0.82s 后在最近扎实地面满体重生，1.25s 闪烁无敌（尸潮 1.00s）。三命扣完弹出「被撕开了 / 坠入深渊了」。

得分：命中 40×连击倍率，打趴额外 20×倍率。击杀尸人 160 / 蝠尸 140 / 吊尸 200 / 蠕手 280 / 镜影 240 / 怨灵 4000 / 锯汉 5200 / 混沌 7200×倍率，过关 2000×关，补血 80，通关 8000。连击为连续命中，约 1.4 秒无命中则断。倍率 = 1 + min(4, floor((连击-1)/2))，即 1 连 1 倍、3 连 2 倍，最高 5 倍。每 16000 分 1UP，命上限 6。最高分写入 playbox-splatterhouse-best，不存盘面；本局超过即更新。

失败：挨打 / 撞兵 / 坠渊扣一命（无敌除外）。约 0.82s 后在最近扎实地面满体重生。三命（顶栏红点）扣完弹出「被撕开了 / 坠入深渊了」。弹层打开时方向键不再走路；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳（空格不跳），空格挥斩。点按画布同空格。触屏 左 / 跳 / 右 / 斩。标题页 血屋 / 尸潮，Enter/空格/1 血屋，2 尸潮。R 重开，M 静音。无手柄。与魔堡不同：没有丢枪、没有铠甲碎成内裤，是近斩打趴再补刀。与制裁不同：没有手枪霰弹、没有飞车，是面具斩斧的恐怖馆。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不顿帧、不抖屏、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：挥斩必有三层——听（刀风噪声+下扫；打趴闷响；斩死湿噪，各不一样）、看（霓虹汁粒子、刀弧、分数蹦出、趴/斩字）、触（命中约 36–48ms 顿帧，斩死约 58–72ms + 镜头踢）。连击升档金闪、大字 ×N。失败与重开都是一键 R。
