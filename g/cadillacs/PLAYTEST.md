玩法：标题页「恐龙」。选「荒原」打三关（废镇→密林→火山，关底头目）；选「兽潮」在废镇按潮出兵，迅猛更多更密，每 4 潮出角龙、每 6 潮出迅猛王、每 8 潮出暴龙。侧向走跳，空格出拳；地上有手枪/冲锋可捡，有弹时空格改开枪。废镇与密林各有一段凯迪拉克，走上车自动往右兜风，可顶飞敌人。点顶栏「重开」或按 R：标题页进荒原；对局中或结束层重开同一模式第 1 关 / 第 1 潮。结束层「再来」同模式；失败「换模式」回标题；荒原通关「兽潮」开兽潮。M 静音，写入 playbox-cadillacs-mute。弹层打开时方向键不走路、空格不打（标题空格/Enter/1 开荒原，2 开兽潮）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 Y=318，上跳约 62px。左右走、上跳，镜头跟在人右侧。荒原三关长度 2360 / 2680 / 2240。头目未倒走进其约 380 范围内镜头锁成擂台。兽潮场地宽 2100，潮次在镜头外左右刷出。

荒原三关：废镇（匪徒、枪手、迅猛，木箱与手枪/冲锋/急救，中后段短程兜风，尽头角龙 24 血会冲撞）/ 密林（迅猛与翼龙更多，中段长程兜风，尽头迅猛王 22 血连扑）/ 火山（混编，无车，尽头暴龙 32 血咬、踩、冲）。过关保留命、体、分、枪弹，补 4 点体力。兽潮同废镇景无车，第 n 潮人数 min(14, 4+⌊1.05n⌋)，速度约 ×(1+0.05×(n−1))，血量 ×(1+0.08×(n−1))。

杰克：拳三段（刺 / 横 / 上勾击倒），空中一拳。手枪 8 发伤害 2，冲锋 16 发伤害 1 射得更快。木箱打碎有时掉枪或急救，急救回 5 体。连击窗口约 1.42 秒。

凯迪拉克：废镇约 1480→1960，密林约 880→1520。走上即上车，自动右驶约 268。空格有枪则射击，没枪则鸣笛顶撞（ ram 伤害 3、击倒）。上键整车小跳躲翼龙。车体 8，打空则炸出并扣人 2 体。到终点自动下车。头目擂台会把人赶下车。

敌人：匪徒贴脸拳 3 血；枪手远射 3 血，子弹胸口高度，跳过去；迅猛 4 血前扑；翼龙 3 血俯冲；角龙冲撞 24 血，前摇后直线撞，跳起能躲；迅猛王 22 血更快连扑；暴龙 32 血近咬、踩地（站地吃全额）、远冲。体力条打空扣一命；约 0.82s 后原地满体重生，1.35s 闪烁无敌。三命扣完弹出「倒了」。

得分：拳命中 40×连击倍率（击倒约 ×1.4），枪命中 28×倍率，顶撞 50×倍率。击杀匪徒 160 / 枪手 220 / 迅猛 280 / 翼龙 240 / 迅猛王 3600 / 角龙 4000 / 暴龙 6000×倍率，过关 1500×关，清潮 600×潮，急救 120，木箱 80，捡枪 100。连击为连续命中，约 1.42 秒无命中则断。倍率 = 1 + min(4, floor((连击-1)/2))。每 20000 分 1UP，命上限 6。最高分写入 playbox-cadillacs-best，不存盘面；本局超过即更新。

失败：体力打空扣一命（无敌除外；车上先扣车体）。约 0.82s 后原地满体重生，1.35s 闪烁无敌。三命扣完弹出「倒了」。弹层打开时方向键不再打；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳，空格 / 点画布出拳或开枪。触屏 左 / 跳 / 右 / 拳。标题 Enter/空格/1 荒原，2 兽潮。R 重开，M 静音。无手柄。与神龟不同：没有四龟选角、没有井盖冒兵、没有披萨下水道；有地上捡枪和凯迪拉克兜风，打的是匪徒与恐龙。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不顿帧、不抖屏、少粒子。触控画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

爽感：出拳挥砍音。打中三层：听（拳风、枪声、恐龙溅射各不一样，连击音高往上爬）、看（恐龙绿黄溅射、闪光、分数蹦出）、触（刺约 42ms / 横约 52ms / 上勾约 70ms 顿帧 + 镜头踢）。恐龙击倒大溅射 + 低吼。上车引擎轰、顶撞尘土。连击升档金闪、大字 ×N。失败与重开都是一键 R。
