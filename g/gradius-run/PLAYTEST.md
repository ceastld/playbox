玩法：标题页「秘武」。选「远征」三关（火山 → 摩艾 → 要塞）打核心，武装槽含护盾；选「无护」没有盾槽、敌更密更快、核心多 6 血。点顶栏「重开」或按 R：标题页直接开远征；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-gradius-run-mute。←↑↓→ / WASD 八向移动，空格射击（可按住连射），C 或顶栏/触屏「选」点选当前高亮武装。画布拖动跟舰，按下开火；右键点选。结束层与标题层不挡顶栏重开，R 随时可用。

场地：虚拟场 720×400。舰钉在画面左侧可八向移动（夹在约 28–374 x，洞穴上下各留 12）。远征巡航约 98、无护约 126，关卡与连击再加；核心在屏时降到约 0–48。移速约 138+36×加速（无护 152 起，加速最高 5）。子弹向右 560，激光 820，导弹先下坠再贴地 340。空格冷却约 0.128s（激光 0.10s），导弹额外 0.30s。点按或按住空格开火。未解锁音频前无声。

武装槽：吃胶囊（橙卵）高亮右移一格：速 / 导 / 双 / 激 / 分 / 盾（无护无盾，到分后回到速）。C 点选当前格并清空高亮。加速可叠 5；导弹贴地；双重与激光互斥；分身最多 4 个，沿舰轨迹滞后抄射（含激光/双重/导弹）；护盾 3 层挡在舰首，先吃弹/撞。坠机掉光全部武装。首枚胶囊提示「C 点选武装」。

敌人：编队小舰 50（红领袖 100，常掉胶囊）、地面鸭 120、摩艾 400、火山石 20、摩艾环 40、核心 2500 再加 1500×关。火山喷石，摩艾吐可打掉的环，核心开合（张开才打得进核）。远征核心血 36 / 50 / 66，无护各 +6。核心约在世界 3400 / 7200 / 11200。

得分：击杀基础分 × 连击倍率。连击为连续打中，约 1.42 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。打穿三关 +8000。每 20000 分 1UP，命上限 6。最高分写入 playbox-gradius-run-best，不存盘面；本局超过即更新。

胜利：打爆第 3 关核心后约 1.2s 弹出「核心尽破」。
失败：三命（顶栏青梭）扣完弹出「舰毁了」。撞壁、撞舰/摩艾/火山/核心、中弹都扣一命；有盾先扣盾并给约 0.28s 闪避。约 0.92s 爆炸后重生，1.45s 闪烁无敌。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 移，空格开火，C 点选。点按画布开火并跟舰，右键点选。触屏「选」。标题页 Enter/空格/1 远征，2 无护。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波（激光另有锯齿下滑）。点选三层：听（各槽不同音色，分身琶音）、看（槽金闪、环、粒子、OPTION 字）、触（约 32–50ms 顿帧 + 镜头微震）。激光白芯青尾穿甲。击杀粒子 + 连击音高往上爬。护盾青环挡弹。坠机洋红大爆、约 72ms 顿帧并震屏，分身一起炸。失败与重开都是一键 R。
