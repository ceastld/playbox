玩法：标题页「忍魂」。选「斩关」打三关（赤林→魂桥→冥殿，关底守护者）；选「妖潮」同三关，生命 3 格（斩关 5），敌更快更密，守护者略厚。侧向走跳过断崖。空格同时近斩与丢手里剑，魂分身跟在身后同步斩、同步丢。点顶栏「重开」或按 R：标题页进斩关；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「妖潮」开妖潮。M 静音，写入 playbox-ninja-spirit-mute。A 或「自动」开关托管。弹层打开时方向键不走路、空格不斩（标题空格/Enter 开斩关）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 80 高，能上一层，不能从地面直上高层。镜头跟在人右前方，守护者战时锁在关底。地面有缺口，掉出屏幕底丢命。中高层平台可落上。人宽约 14、高 26。走约 148（妖潮约 ×1.12），空中可改向。标题页背后演示右进斩镖、跳坑，双魂分身同步出手，不算分、不掉血。

斩关三关：赤林（鬼面 16 血）/ 魂桥（天狗 22 血，坑更多）/ 冥殿（阎王 28 血）。过关保留命、生命、魂分身、分。妖潮同三关，速度约 ×1.26 并随关递增，额外补兵，守护者血约 ×1.18，开局生命 3 格。

斩与镖：空格挥一次约 0.20s，贴身刀弧约 38，同时朝面朝方向丢出手里剑。空中可斩。刀可打掉妖弹。魂分身（最多 2）跟在身后偏上/偏后，出手时一起斩、一起丢镖，并闪青白光。拾「魂」得分身；满魂再拾转生命。小鬼 1 下、鬼卒 2 下、重甲 3 下。守护者多下。

敌人：小鬼贴地蹦跳 100；飞颅正弦飞 150，会吐骨；蝠斜飞 150；鬼卒走 200，丢骨；重甲慢走 250。守护者鬼面走近砸地丢面具、天狗俯冲喷风、阎王瞬移丢高低弹。击破守护者再加 4000×倍率，过关 +1500×关。斩关打掉阎王后加 8000，弹「魂已归」；妖潮弹「妖潮得手」。

生命：斩关 5 格、妖潮 3 格，顶栏条显示。挨打扣 1（守护者 2，斩关会被打空），0 格丢一条命。坠崖直接丢命。三命（顶栏红点）扣完弹出「生命耗尽了 / 坠入深渊了 / 被守护者击倒了」。约 0.86s 后在最近扎实地面重生，满生命，1.18s 闪烁无敌。每 15000 分 1UP，命上限 6。最高分写入 playbox-ninja-spirit-best，不存盘面；本局超过即更新。

得分：击杀基础分 × 连击倍率。连击为连续命中，约 1.4 秒无动作则断；挨打立刻断。倍率 = 1 + min(4, floor((连击-1)/3))。

失败：生命归零 / 坠崖扣一命（无敌除外）。弹层打开时方向键不再走路；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / D 走，↑ / W 跳（空格不跳），空格斩并丢镖。A 为自动（不再当左移）。点按画布同斩。触屏 左 / 跳 / 斩 / 右。标题页 斩关 / 妖潮，Enter/空格/1 斩关，2 妖潮。R 重开，M 静音。无手柄。

自动：点「自动」或按 A 开关托管（开着时按钮呈按下态并显示「停下」）。标题页开启则自动开斩关；倒下/通关弹层仍开着则自动再开同一模式。开着时忽略方向键、W/D、触屏和底栏；A / R / M / 重开仍可用。开关不写入存储，刷新后关闭；重开不会关掉自动。速度滑条 1–4 为 慢 / 中 / 快 / 极快（默认快），写入 playbox-ninja-spirit-auto-speed，改速立刻生效。托管会往右走、跳过深坑、近斩并丢镖打妖、跳斩飞颅蝠、对守护者出手，斩关与妖潮都会真打，不是原地晃。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：挥斩必有三层——听（刀啸噪声+下扫，镖另有高音叮）、看（金弧+青镖、火花、分数蹦出；有魂时分身闪青白）、触（命中约 48–62ms 顿帧 + 镜头踢）。拾魂全屏青闪。连击数字往上叠。失败与重开都是一键 R。
