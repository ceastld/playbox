玩法：标题页「猿人」。选「救美」打三关（密林→深潭→岩殿，关底石猿 / 沼鳄 / 炎龙，岩殿打完走近被关的人即过关）；选「兽潮」敌更快更密（鸟不加倍），头目血约 ×1.25。侧向走跳，空中可改向。空格吐火球。水潭里 ↑ 上浮、↓ 下潜，火球仍能喷（略慢并上浮）。点顶栏「重开」或按 R：标题页进救美；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「兽潮」开兽潮。M 静音，写入 playbox-toki-mute。A 或「自动」开关托管。弹层打开时方向键不走路、空格不吐火（空格/Enter 在标题开救美、结束层再来）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=320，中层 248，高层 176，间距 72；起跳约 86 高，能上一层，不能从地面直上高层。空中可改向（约 ×0.88 走速）。镜头跟在人右前方，头目与救人时锁在关底。地面有缺口，掉出屏幕底丢命。水潭覆盖的缺口可游过去。人宽约 15、高 26。走约 210，空中约 ×0.88。水里水平 168，重力弱，缓沉。标题页背后演示右进吐火跳坑过水，不算分、不掉血。

救美三关：密林（石猿 12 血，猿巡逻、鸟飞吐、蛙跳，第一坑有浅水）/ 深潭（沼鳄 16 血，大片水域，鱼穿游，必须游过宽沟）/ 岩殿（炎龙 22 血，干坑带熔岩光，尽头笼子里的人）。过关保留命、分、烈火计时，体力回满。兽潮同三关，速度 ×1.30 并随关递增，额外补猿/蛙/鱼。

吐火：空格 / 点画布 / 触屏「喷」。冷却约 0.22 秒，屏上最多 3 发，略下坠。水里更慢、略上浮。烈火拾取后约 8.8 秒，冷却 0.16、屏上 4 发、双伤金火。空中仍按面朝方向喷。

体力：开局 100。挨打 / 中弹 / 撞敌各 −34（约三下见底）。到 0 丢一条命。蕉 +36 体并加分，并把检查点记在蕉附近。烈火只改喷，不回体。

敌人：猿贴地走 120；鸟正弦飞并吐籽 180；蛙起跳 200；鱼只在水里摆 160。头目石猿跳砸抛石；沼鳄水里冲咬；炎龙三向喷火。击破头目 +4200×倍率；过关 +1800×关。救美走近第三关的人后再加 8000（兽潮 12000），弹「救出来了」或「兽潮平了」。

得分：击杀/摘蕉/烈火基础分 × 连击倍率。连击为连续击杀或摘取，约 1.35 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 12000 分 1UP，命上限 6。最高分写入 playbox-toki-best，不存盘面；本局超过即更新。

失败：挨弹 / 撞兵 / 坠渊扣一命（无敌除外；体力先扣，扣空才丢命）。约 0.82s 后在最近扎实地面或摘蕉处重生，1.4s 闪烁无敌，体力回满。三命（顶栏橙点）扣完弹出「没救到 / 掉下去了 / 体空了」。弹层打开时方向键不再走路；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / D 走，↑ / W 跳（空格不跳；水里上浮），↓ / S 从平台掉落或水里下潜，空格吐火。A 为自动（不再当左移）。点按画布同空格。触屏 左 / 跳 / 喷 / 右。标题页 救美 / 兽潮，Enter/空格/1 救美，2 兽潮。R 重开，M 静音。无手柄。无出拳、无滑板、无商店。

自动：点「自动」或按 A 开关托管（开着时按钮呈按下态并显示「停下」）。标题页开启则自动开救美；倒下/通关弹层仍开着则自动再开同一模式。开着时忽略方向键、W/S/D、触屏和底栏；A / R / M / 重开仍可用。开关不写入存储，刷新后关闭；重开不会关掉自动。速度滑条 1–4 为 慢 / 中 / 快 / 极快（默认快），写入 playbox-toki-auto-speed，改速立刻生效。托管会往右走、跳过缺口、水里游、吐火打敌/头目，救美与兽潮都会真打，不是原地晃。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：吐火必有三层——听（噪声+下扫锯齿）、看（口焰、火星拖尾）、触（约 34ms 顿帧 + 画面挤压）。命中必有三层——听（噪声+升调）、看（火屑爆开、分数蹦出）、触（约 55ms 顿帧 + 镜头踢）。连击数字往上窜，倍率升调。摘蕉爆色、体条闪。烈火周身火环。头目倒下全屏金闪。失败与重开都是一键 R。
