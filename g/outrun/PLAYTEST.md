玩法：标题页选「海岸」或「夜奔」。红色跑车停在画面底部，公路向消失点卷去。← → / A D 转向，↑ / W / 按住画布加油门，空格 / ↓ / S 刹车。点「重开」或 R 开新局（标题页 R 进海岸；局中或结算重开回当前模式）。M 静音，写入 playbox-outrun-mute。
场地与碰撞：虚拟场 800×450，伪 3D 路段长 200。玩家横向约 ±1 为路面，超过即冲出（减速、扬尘，不出局）。来车偏移与玩家横向差小于 0.3 且纵向约 210 内即撞击：时速约剩 32%、弹开、70ms 顿帧，并扣时（海岸 -2.6 秒 / 夜奔 -3.4 秒）。撞击不会直接出局。
分叉与风景：五段三角分叉。蓝湾（海滨）起，靠左/靠右驶过检查门进入下一段风景：海滨、雪岭、沙海、葡园、湖谷。门上 CHECK / GOAL，路牌标下一段名。第五段冲 GOAL 胜利。可能终点：雪巅 / 镜湖 / 葡庄 / 沙塔 / 灯岬。
时间与分数：海岸开局 50 秒，过门 +15；夜奔 36 秒、+11，且顶速更高、车更快更密。超时才结束（车会滑停再弹层）。距离一直加分；超车 95×连超；疾风（时速 >80% 且在路上）每 0.7 秒一层并有速度呼啸；过门 760+；终点 2800+剩余时间。最高分按模式写入 playbox-outrun-best，JSON `{h,n}`（海岸 / 夜奔）。
胜利：第五段冲过 GOAL。失败：时间到 0。弹层 `pointer-events: none`，不挡 R 与顶栏重开。
操作：方向键 / WASD 转向+油门；空格刹车。点按画布加速并按左右位置转向。标题页 Enter/空格/1 海岸，2 夜奔。结算 Enter 再开。无手柄。无自动。
限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏。触控画布 `touch-action: none`。标题页背后是演示驶，到门会重置，不算分。
爽感：高速速度线与车尾残影；撞击粒子+顿帧+扣时数字；过门金闪、加时、检查点琶音；超车连击音高爬升；引擎转速跟时速；疾风呼啸。失败与重开都是一键 R。
什么变难：弯道离心力把车往外甩。夜奔车流更快更密、时间更紧。冲出路面掉速。撞击扣时，检查门前必须选边。雪岭弯急坡陡，沙海视距热浪。
