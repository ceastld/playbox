玩法：标题页「魂斗」。选「丛林」打三关（密林→河谷→要塞，关底 Boss）；选「突击」敌更快更密，Boss 更厚，速度约 ×1.32。侧向跑跳蹲，八向瞄准开火（空格按住连射）。一打即死，重生丢枪变回步枪。点顶栏「重开」或按 R：标题页进丛林；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「突击」开突击。M 静音，写入 playbox-contra-run-mute。弹层打开时方向键不走路、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 86 高，能上一层，不能从地面直上高层。镜头跟在人右前方，Boss 战时锁在关底。地面有缺口（河），掉出屏幕底丢命。中高层平台可落上，蹲下不掉穿。人宽约 14、立高 26、蹲高 14。走约 224，空中约 0.9。标题页背后演示右进开火，不算分、不掉血。

丛林三关：密林（碉门 28 血，有机枪鹰、散弹箱）/ 河谷（双联 36 血，激光鹰、火焰箱）/ 要塞（异核 48 血，散弹鹰，激光与火焰箱）。过关保留命、分、当前枪。突击同三关，速度 ×1.32 并随关递增，额外补兵（步兵/跑兵/狙），Boss 血约 ×1.22，开局仍是步枪。

武器：默认步枪 0.16s 一发、屏上约 4 发。M 机枪 0.06s 连射。S 散弹三向扇。L 激光穿敌。F 火焰落地弹跳、单发 2 伤。空中八向；落地按住空格+上可立定上射（不跳）；蹲下只打左右。死亡重生变回步枪。

敌人：步兵巡逻点射 100；跑兵冲脸 150；平台狙三向 200；飞兵抛弹 200；碉堡转向连射 300；炮台抛弹 250。红鹰 500，击落掉 M/S/L。Boss 碉门三向炮、双联高低管、异核放射弹（残血更密）。击破 Boss 再加 4000×倍率，过关 +2000×关。丛林打掉异核后再加 8000，弹「要塞捣毁了」；突击弹「突击得手」。

得分：击杀基础分 × 连击倍率。连击为连续击杀，约 1.35 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 15000 分 1UP，命上限 6。最高分写入 playbox-contra-run-best，不存盘面；本局超过即更新。

失败：挨弹 / 撞兵 / 坠河扣一命（无敌除外）。约 0.82s 爆炸后在最近扎实地面重生，1.4s 闪烁无敌，枪变回步枪。三命（顶栏红点）扣完弹出「被击中了 / 中弹了 / 坠入河里了 / 撞上了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳（按住空格且不走时可立定上射），↓ / S 蹲，空格开火。点按画布同空格按住。触屏 左 / 跳 / 射 / 右 / 蹲。标题页 丛林 / 突击，Enter/空格/1 丛林，2 突击。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：开火枪口闪 + 粒子 + 各枪不同音色。击杀/爆炸粒子 + 30–80ms 顿帧 + 镜头微震 + 连击数字往上窜。捡枪金鸣三音、全屏闪、toast。激光青束、散弹扇面、火焰弹跳拖尾。失败与重开都是一键 R。
