玩法：标题页「虚赛」。选「虚赛」三圈多边形封闭赛道（森直看台 → 右弯林坡 → 左下坡 → 双 S → 桥爬 → 湾桥左右 → 遗迹发卡 → 再弯回终点）；选「赛核」同场但车更密、弯更甩、喷掉得更快、终段车团更厚。点顶栏「重开」或按 R：标题页直接开虚赛；对局中或结束层重开同一模式。结束层「再冲」同模式，「换模式」回标题。M 静音，写入 playbox-virtua-racing-mute。← → / A D 转向，↑ / W / 空格 / 按住画布加油门，↓ / S 刹车，Shift / Z 或顶栏「喷」或按住画布上半开喷。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。

场地与碰撞：虚拟场 800×450，伪 3D 封闭赛道（左右弯、起伏、湾桥），路段循环。玩家横向约 ±1.08 为路面，超过即冲出（减速、扬尘）；时速约 38% 以上冲出或横向 >1.52 即撞出。来车偏移与玩家横向差小于 0.30 且纵向约 200 内即碰上：没开喷且没在高速吸力里则撞车减速；喷着或吸力时速 >62% 且时速 >36% 则顶飞（顿帧、爆多边形粒子）。撞车时速约剩 16%、约 1.42 秒复原、70ms 顿帧，不会出局。超时才结束。

吸力与喷：槽 0–1。贴在前车正后方（纵向约 80–2400、横向差 <0.24）进入吸力：顶速约 ×1.14、加速更快、槽每秒回 0.58（赛核 0.44），画面青线、提示「吸力」。没贴尾时槽每秒只回 0.08。Shift / Z 喷：低于 0.06 点不着；开喷顶速约 ×1.32、加速更快、离心更狠，尾焰+金色速度线，虚赛每秒耗 0.36、赛核 0.50。空了提示「喷空了」。过线回槽 +0.24。弯道外侧吃坡，离心被削。

终段赛团：末圈约 70% 路程刷一队。虚赛 7 台 / 赛核 10 台，头车是虚王（金框，血量 3 / 赛核 4）。虚王会贴着你的横向堵路。喷（或高速吸力）顶上去扣血，血空才爆。不必清完也能冲线，但堵路。

圈数：封闭多边形赛道 3 圈。过 START 线加时并进下一圈，第 3 圈过 GOAL 胜利。虚赛青森+湾桥+石柱；赛核同场夜灯。

时间与分数：虚赛开局 44 秒，过线 +14；赛核 33 秒、+11，顶速更高、车更多。超时才结束（车会滑停再弹层）。距离一直加分；超车 85×连击×倍率（吸力/喷中再 ×1.32）；喷顶飞 170×（虚王击破 500×，顶一层 110×）；疾风（时速 >80% 且在路上）每 0.64 秒一层，吸力 0.56、喷时 0.48；过线 850+；终点 3000+剩余时间。连击约 1.85 秒无超车/顶飞则断；自身撞车立刻断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。最高分按模式写入 playbox-virtua-racing-best，JSON `{c,m}`（虚赛 / 赛核），不存盘面；本局超过即更新。

胜利：第 3 圈冲过 GOAL。失败：时间到 0。弹层不挡 R 与顶栏重开。

操作：方向键 / WASD 转向+油门+刹车；空格油门；Shift / Z 喷。点按画布加速并按左右位置转向，按住上半同时喷。标题页 Enter/空格/1 虚赛，2 赛核。结算 Enter 再冲。无手柄。无自动。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、少粒子、无速度残影。触控画布 `touch-action: none`。标题页背后是演示驶，绕圈不算分。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：贴尾吸力青线+whoosh；喷尾焰+金色速度线+引擎拔高；顶飞顿帧约 38–78ms、爆多边形粒子/环/「爆虚 ×N」蹦字，连击音高往上爬；撞车粒子+顿帧+引擎闷一下；过线金闪、加时数字。失败与重开都是一键 R。

什么变难：左右弯离心把车往外甩，发卡弯更狠。开喷更快更滑。终段赛团堵路，虚王会跟横向。赛核更密、时间更紧、喷掉得快。冲出路面会减速，减速完要加速复原。不贴尾槽涨得慢。
