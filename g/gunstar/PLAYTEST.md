玩法：标题页「枪星」。选「突袭」打三关（晶原→矿脉→星门，关底巨物带发光弱点）；选「乱射」敌更快更密，弱点更厚，速度约 ×1.28。侧向跑跳，八向瞄准开火（空格按住连射）。Q / Tab / C 循环换枪：散弹 / 激光 / 火焰（开局就有，不靠捡枪）。Shift / Z 近斩。中弹扣体力，体力打空丢一命。点顶栏「重开」或按 R：标题页进突袭；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「乱射」开乱射。M 静音，写入 playbox-gunstar-mute。弹层打开时方向键不走路、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 86 高，能上一层，不能从地面直上高层。镜头跟在人右前方，Boss 战时锁在关底。地面有缺口（裂隙），掉出屏幕底丢命。中高层平台可落上。人宽约 14、立高 26。走约 228，空中约 0.92。没有蹲（与魂斗不同）。标题页背后演示右进开火换枪近斩，不算分、不掉血。

突袭三关：晶原（晶甲三核：左右肩+胸，身体挡弹）/ 矿脉（钻颚：绕核轨道 + 颚核开合才可打）/ 星门（金核：双肩先碎，胸核才开）。过关保留命、分、当前枪，补 4 点体力。乱射同三关，速度 ×1.28 并随关递增，额外补兵，弱点血约 ×1.26，开局仍是散弹。

武器：三把常驻循环。散弹五向扇、单发 1 伤。激光穿敌穿甲、单发 2、弱点约 ×1.5。火焰落地弹跳、熔甲（打在 Boss 躯干会把伤渗到最近开着的核）。空中八向；落地按住空格+上可立定上射（不跳）。死亡重生枪仍保留（与魂斗丢枪不同）。

近斩：Shift / Z，地面约 36 距、空中略短。命中窗口约 0.06–0.18s。斩杀加分 ×1.5，弹出「斩」。甲卫近斩破甲。弱点近斩约 ×1.5。砍在 Boss 装甲上弹「甲」。

敌人：星兵跳跃点射 120；甲冲冲脸 160；浮炮四向弹 240；晶蛛爬台 140；星弹抛星 180；甲卫厚甲四向 280。星核回 5 体。击杀掉落金星，拾取延连击并加分。Boss 躯干装甲挡散弹；必须打发光的核。击碎一核 +800×倍率，全核碎再加 4200×倍率，过关 +2000×关。突袭击碎金核后再加 8000，弹「星门粉碎了」；乱射弹「乱射清场」。

得分：击杀基础分 × 连击倍率。连击为连续命中（弹或斩或碎核），约 1.4 秒无命中则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 18000 分 1UP，命上限 6。最高分写入 playbox-gunstar-best，不存盘面；本局超过即更新。

失败：挨弹 / 撞兵 / 坠裂隙且体力打空扣一命（无敌除外）。约 0.82s 爆炸后在最近扎实地面重生，满体、1.25s 闪烁无敌，枪仍保留。三命（顶栏橙点）扣完弹出「被击碎了 / 中弹了 / 坠入裂隙了 / 撞上了 / 体力打空了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳（按住空格且不走时可立定上射），↓ / S 空中下瞄，空格开火，Shift / Z 近斩，Q / Tab / C 换枪，1/2/3 直选散弹/激光/火焰。点按画布同空格按住。触屏 左 / 跳 / 射 / 右 / 斩 / 换。标题页 突袭 / 乱射，Enter/空格/1 突袭，2 乱射。R 重开，M 静音。无手柄。

与魂斗不同：不是一打即死、不是捡 M/S/L/F，是体力条 + 三枪循环 + 近斩 + 弱点核。与合金不同：没有坦克、手雷、人质。与制裁不同：不是街头拳枪切弹药，近斩与射击是两套键，关底是巨物弱点而不是裂脸金王。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：开火枪口闪 + 粒子 + 散弹/激光/火焰各一音色。击杀/爆炸粒子 + 30–80ms 顿帧 + 镜头微震 + 连击数字往上窜。近斩洋红弧 + 斩字 + 更重顿帧。碎核金爆、全屏闪。失败与重开都是一键 R。
