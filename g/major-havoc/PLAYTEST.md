玩法：标题页「浩劫」。选「突袭」打四界（前哨 / 矿带 / 要塞 / 核心），每界先星域开火再对接空间站，再侧向跑进基地触堆、倒计时内逃回入口；选「狂奔」同四界但星域出敌更快、配额少 2、船更快，基地走速约 ×1.32、倒计时 ×0.76。点顶栏「重开」或按 R：标题页直接开突袭；对局中或结束层重开同一模式。结束层「再来」同模式；覆没「换模式」回标题；突袭通关「狂奔」开狂奔。M 静音，写入 playbox-major-havoc-mute。←↑↓→ / WASD 星域八向飞、基地左右跑、上跳。空格开火（可按住连射）；基地空格点按同时跳，按住只连射不连跳。触屏左/右/上/跳/射，画布拖动在星域跟船并开火，基地点按左右侧走动、偏上跳跃。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 突袭，2 狂奔。

场地：虚拟场 640×360。星域整场，船加速 540、阻力 3.1、最快约 248（狂奔 ×1.12），夹在 16–624 / 18–342。子弹沿朝向 430/s，冷却 0.12s，场上最多 3 发。基地地面 y=328，起跳约 86 高，走 168（狂奔约 222）。人宽 14、立高 22。镜头跟在人右前方。未解锁音频前无声。

星域：侦察青钻 80、战机金翼 120 会射击、旋刃品红十字 2 血 200。击坠达到配额（6/8/10/12，狂奔各少 2）后空间站从右侧滑入，飞进发光对接湾即可。对接 +500×第几界，青闪。命在星域与基地之间共享。

基地四界：前哨宽 1280、倒计时 16s，两坑约 60px，巡逻机/无人机/炮台。矿带 1420 / 14.5s，加激光门。要塞 1560 / 13s，双激光与更多炮台。核心 1680 / 11.5s，三激光、三无人机。触堆芯 +400 并进入撤离，顶栏核槽开始倒。逃回左侧「逃」门：+2000×界 + 剩余秒×80，再 +1200×界，反应堆大爆粒子 + 顿帧。倒计时归零「被核爆了」扣一命，若还有命则从入口重闯该界基地（不重打星域）。掉坑、激光、撞兵、中弹都扣命。

得分：击杀基础分 × 连击倍率。连击为连续打中，约 1.4 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，最高 5 倍。突袭打穿 +8000，狂奔 +10000。每 20000 分 1UP，命上限 6。最高分写入 playbox-major-havoc-best，不存盘面；本局超过即更新。

胜利：突袭/狂奔打完第 4 界核心逃出后结算「航线肃清」/「狂奔通关」。
失败：三命（顶栏青点）扣完弹出「全舰覆没 / 被击中了 / 坠入深渊了 / 被激光切了 / 被核爆了」等。约 0.9s 爆炸后重生，1.45s 闪烁无敌。星域在出生点重生并保留击坠数；基地从入口重开并重置机关。弹层打开时方向键不再走；顶栏重开与 R 随时可用。

操作：←↑↓→ / WASD 飞或跑跳，空格射击（基地点按兼跳）。点按画布：星域跟机开火；基地左右走。触屏 左 / 右 / 上 / 跳 / 射。标题页 突袭 / 狂奔，Enter/空格/1 突袭，2 狂奔。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不顿帧、不抖屏、少粒子。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波。击中粒子爆开 + 短顿帧（约 36–76ms）+ 镜头微震 + 连击数字往上窜。落地挤压回弹 + 顿声。对接青闪琶音。反应堆大爆：听（噪声+低频锯齿）、看（金粉品红粒子环、全屏闪）、触（约 78ms 顿帧 + 镜头踢）。撤离最后 5 秒警报。失败与重开都是一键 R。
