玩法：标题页选「救人」打八面平台，选「追击」同一套图但卵孵得更快、每面多怪。左右走（方向键 / D），上 / W 跳，空格丢炸弹。炸弹落地后炸开整列土和笼子，心弹出来再接住。碰到怪或踩进自己的烟都扣一命。心全接完进下一关。点「重开」或 R：标题页进当前所选模式；局中或结算层随时重开回当前模式第 1 关。M 静音，写入 playbox-chackn-pop-mute。A 为自动（不再当左移）。弹层打开时方向键不走路、空格不当丢弹；顶栏重开与 R 随时可用，弹层不盖住顶栏，overlay 自身 pointer-events: none。

棋盘：17×13。外圈墙。土和笼子可站、可炸；墙炸不掉。炸弹最多两枚，落地约 0.28 秒后炸整列。心从笼子里弹出后要接住才算救到。卵挂在空中，等太久会孵成紫怪。怪在台子上走，贴身会追。

救人：心田 → 双笼 → 井列 → 交错 → 卵窝 → 迷宫 → 危台 → 心海。卵孵时间递减。过关保留命、分和 EXTEND 进度。追击：同八面，孵化约 0.62 倍，移速约 1.42 倍，每面额外 1–3 只怪。

得分：炸土每格 +10，炸卵 +80，开笼 +200，接心 300×连救，炸怪 200 / 400 / 800 / 1600（同一柱），字母 +150，EXTEND +2000 并加一条命，清面 600+250×关 + 剩余时间奖。最高分写入 playbox-chackn-pop-best，不存盘面。

胜利：接完全部心弹出「心全救出」，前七面「下一关」，第八面「爱心归位 / 再来一轮」。失败：三命（顶栏心点）扣完弹出「命尽了」，只能再来或换模式。被炸或碰怪会顿帧、闪粉、抖屏，还有命则闪回出生点并短暂无敌。

自动（AUTOPLAY）：点「自动」或按 A 开关托管（开着时按钮呈按下态并显示「停下」）。默认关闭，开关不写入存储，刷新后关闭；重开不会关掉自动。开着时忽略方向键、W/S/D、空格丢弹、触屏滑向和底栏；A / R / M / 重开 / 速度滑条仍可用。标题页开自动会进当前所选模式（救人 / 追击）。命尽了或第八面通关弹层时自动停手；重开且自动仍开着则新局接着托管。前七面过关弹层约 0.55 秒后自动进下一关。速度滑条 1–4 为 慢 / 中 / 快 / 极快（默认快），写入 playbox-chackn-pop-auto-speed。慢/中放慢时间便于看清走跳丢弹，快为实时，极快约 3.4 倍步进并跳过顿帧。AI 走平台、跳上缺口、对准土柱/笼子丢弹炸列，躲开自己的烟，接住弹出的心，顺手捡字母，贴身怪会跳开或炸列。救人与追击都能托管。不是完美求解，卵孵贴身或窄台跟烟时仍可能丢命。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不顿帧、不抖屏、不大字。触控有左 / 跳 / 右 / 弹；滑动或点按棋盘时 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层打开时顶栏重开与 R 随时可用。

爽感：丢弹落地有火星。炸柱必有三层：听（轰一声 + 低频）、看（整列薄荷烟、土屑、粉闪光）、触（约 48–76ms 顿帧 + 镜头微震）。开笼另有心形钟声和洋红屑。连着接心数字往上叠（连救），一柱多目标出「连爆 ×N」。字母凑齐 EXTEND 有长琶音和加命。失败与重开都是一键 R。
