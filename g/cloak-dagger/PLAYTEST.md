玩法：标题页「斗篷」。选「潜入」打八室（门廊→撤离），选「追杀」一室接一室、守卫更多更快、视野更长。四向走，空格丢出唯一的匕首；匕飞出去扎进墙，走过去捡回来才能再丢。点按瞄准方向丢，拖动画布也能走。撞到守卫或踩雷掉一条命，掉光结束。点「重开」或 R：标题页进潜入；对局中或结束层重开同一模式。M 静音，写入 playbox-cloak-dagger-mute。弹层打开时方向键不走路、空格不丢匕（标题上空格开潜入）；顶栏重开与 R 随时可用，弹层 `pointer-events: none`，只给面板按钮，不挡住重开。

场地：21×13 格。外圈硬墙，内里随机房间加走廊。出生在西侧，出口三格在东墙（青/金框）。人半径约 0.28 格，速度约 4.42 格/秒。单向门只许沿箭头走，逆行当墙；匕飞过单向门，只撞实墙才停。

潜入：门廊 2 箱 2 卫 / 档案 3·3 / 库房 3·4 / 暗巷 4·4 / 机房 4·5 / 金库 5·5 / 楼顶 5·6 / 撤离 6·6。雷与单向门随层加。过室保留生命和分数。追杀：第 1 室约 4 卫、追得更快，之后加卫、加雷、视野拉长（卫上限约 10）。

匕首：场上只有一柄。空格或点按朝面朝方向飞出（约 16.8 格/秒），撞守卫击杀后继续飞，撞墙扎住并顿帧；走入约 0.52 格捡回。没匕时再按空格无效。命中守卫 30–80ms 顿帧 + 粒子。丢出后有短锁，避免刚扎就立刻捡起。

守卫：沿走廊巡逻，面向有视锥（约 6–8 格，需视线）。看见人会「发现了」警铃 + 红闪 + 顿帧，再追。丢失视线约 1.35s 后搜查，再回巡逻。贴身即抓。捡箱后有短暂斗篷（潜入约 0.92s / 追杀 0.55s），守卫看不见。被抓后回西侧出生，匕回手，已捡的箱保留，约 1.45s 无敌并带斗篷。

箱子：公文箱，踩到收集。粒子爆开 + 顿帧 + 金闪 + 斗篷。收齐该室全部箱子后出口变金，「出口开了」。未收齐走到东门会挡回并提示还缺几只。

炸弹：地面地雷，闪信管。人踩或匕命中爆炸（半径约 1.7 格），可炸守卫、连锁旁雷。守卫踩上也会引爆。

单向门：走廊里的青箭头格，只能顺箭头进出。

得分：箱子 120×倍率；守卫 90×（炸死 110×）；出口 180+层数加成，清光守卫再 +80。连击窗口 1.55s，倍率 = 1 + min(4, floor(连击/2))，最高 5 倍。最高分写入 playbox-cloak-dagger-best，不存盘面；本局超过即更新。

胜利：潜入从撤离出口弹出「撤出了」。追杀没有清盘。
失败：命耗光弹出「被抓住了 / 踩到雷了」。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、不连环大字。触控有十字键和「匕」；滑动或点按棋盘时 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：丢匕枪口金屑；扎墙叮一声 + 短顿；刺中守卫爆粒子 + 30–80ms 顿帧 + 镜头微震；捡箱金爆 + 斗篷残影；发现了警铃刺音 + 红闪；连环炸雷倍率上窜并弹出 ×N。
