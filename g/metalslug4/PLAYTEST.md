玩法：标题页「金弹4」。选「金弹4」打两段侧向欧巷 / 雨寺（各有分路），第三关智核锁镜打智核坦；选「弹核」敌更密更快，布雷德更挤，智核坦更厚，速度约 ×1.26。侧向跑跳，空格开火，Shift / Z 丢手雷。空中下落按上伞降。撞兵、中弹、坠坑或载具撞毁立刻丢一命。点顶栏「重开」或按 R：标题页进金弹4；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「弹核」开弹核。M 静音，写入 playbox-metalslug4-mute。弹层打开时方向键不走路、空格不开火、Shift 不丢雷；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72。起跳约 86 高，能上一层，不能从地面直上高层。镜头跟人右前方，并随下路下移；智核坦战时锁在关底。地面有缺口，掉出屏幕底丢命。走过缺口上方平台走屋脊 / 廊上，贴地走雨街 / 庭下。人宽约 14、立高 26、蹲高 14；布雷德更宽约 48。走约 224，布雷德约 196，空中约 0.9。下落按上张开伞降，落速约 95。标题页背后演示右进开火，不算分、不掉血。

金弹4 三关：欧巷（雨夜欧巷分屋脊 / 雨街 + 布雷德，捡火箭）/ 雨寺（灯笼雨寺分廊上 / 庭下，捡追弹）/ 智核（短突进后锁镜，智核坦 58 血）。过关保留命、分、手雷、当前枪；载具不带过关。弹核同三关，速度 ×1.26 并随关递增，额外补兵，智核坦血约 ×1.24，开局仍是手枪、手雷 6 枚（金弹4 8 枚）。

武器：默认手枪 0.15s 一发、屏上约 4 发。R 火箭慢而炸，落地或碰敌爆范围伤 2。C 追弹寻最近敌人。手雷弧线，落地或碰敌约 0.62s 内引爆，范围伤 3，上限 20。布雷德双炮，伤 2 可穿。死亡重生变回手枪，掉下载具。

载具：走过空布雷德即上车。布雷德跳更沉、炮管双伤可穿，轮式装甲车不是铁蛞。载具没有装甲：中弹、撞兵立刻撞毁丢一命（无敌除外）。布雷德不能伞降。

分路：欧巷在叉口（约 x=780）走上中高层是屋脊（伞兵），贴地是雨街（摩托）。雨寺走上方是廊上（忍兵），贴地是庭下（瓶兵）。HUD 显示当前路名。两条路在关尾汇合。智核不分路。没有陵道、没有潜道游泳。

敌人：巷兵巡逻点射 100；刀兵冲脸 150；巷炮转向 250；迫击抛弹 200；飞翼俯冲弹 200；摩托横撞 250（撞上丢命）；木箱 80，打破掉手雷 / R / C。伞兵从天伞降再射 160；忍兵闪身丢镖 180；瓶兵抛烧瓶 170。智核坦扫激光（蹲可躲）+ 履带弹，残血放环弹与地雷；弹核更密。击破智核坦再加 5000×倍率，过关 +2000×关。金弹4 打掉智核坦后再加 8000，弹「智核坦拆了」；弹核弹「弹核清场」。

得分：击杀基础分 × 连击倍率。连击为连续击杀，约 1.35 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 15000 分 1UP，命上限 6。最高分写入 playbox-metalslug4-best，不存盘面；本局超过即更新。

失败：挨弹 / 撞兵 / 撞摩托 / 载具撞毁 / 坠坑立刻丢一命（无敌除外，坠坑强制）。约 0.82s 爆炸后在最近扎实地面重生，1.2s 闪烁无敌，枪变回手枪，掉下载具。三命（顶栏橙点）扣完弹出「被击中了 / 中弹了 / 坠入坑里了 / 撞上了 / 载具撞毁了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳（空中再按上伞降），↓ / S 蹲，空格开火，Shift / Z 手雷。点按画布同空格按住。触屏 左 / 跳 / 射 / 右 / 蹲 / 雷。标题页 金弹4 / 弹核，Enter/空格/1 金弹4，2 弹核。R 重开，M 静音。无手柄。

与金弹不同：没有骆驼 / 飞艇，载具是布雷德；关卡是欧巷 / 雨寺 / 智核；枪是火箭 / 追弹不是喷火 / 铁蜥；头目是智核坦不是铁甲；有伞降。与金弹3不同：没有铁蛞、没有陵道木乃伊、没有潜道游泳、没有雪人；枪不是机枪 / 散弹；头目不是木星坦；分路是屋脊/雨街与廊上/庭下，不是沙道/陵道。与合金不同：没有体力条，坦克不会弹出保命；载具撞毁直接丢命；手雷是 Shift/Z 不是 C；没有人质。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 手枪 / 火箭 / 追弹 / 布雷德炮各一音色。击杀 / 爆炸粒子 + 30–80ms 顿帧 + 镜头微震 + 连击数字往上窜。伞降张开有风噪声。载具撞毁大爆。智核坦崩开金爆。失败与重开都是一键 R。
