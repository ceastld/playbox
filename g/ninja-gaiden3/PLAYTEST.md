玩法：标题页「忍影3」。选「忍影3」打三关（绝壁→血廊→古舰，闯到尽头舰主现身）；选「影核」同三关但敌更快更密，Boss 血约 ×1.22。侧向走跳，贴上墙壁会抓住并慢滑，再按跳蹬出去。空格 / Z 近处挥斩（可连斩两下，第二下真空弧更长）。贴墙时可下斩。闯到关底结界，头目激活。点顶栏「重开」或按 R：标题页进忍影3；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「影核」开影核。M 静音，写入 playbox-ninja-gaiden3-mute。弹层打开时方向键不走路、空格不斩；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 83 高，能上一层，不能从地面直上高层。墙是细霓虹立面，空中撞上即贴住，滑速约 84。蹬墙水平约 214、垂直约 452，冷却约 0.14s 避免贴回原墙，双墙夹道可左右连蹬爬上高层。镜头跟在人右前方，高层略上抬。地面有缺口，掉出屏幕底丢命。中高层平台可单向落（↓ / S 掉落），地面不能掉穿。闯到关底（约屏宽内）赤结界处头目现身，镜头锁在尽头。没有人质，不挡路。没有炎轮、没有忍术清屏、没有疾跑冲刺。

忍影3 三关：绝壁（岩魔 12 血，血玉）/ 血廊（血影 16 血，血囊柱、双拾取）/ 古舰（舰主 22 血，会瞬移、三向刃、召殖忍）。过关保留命、分。影核同三关，速度约 ×1.34，铳兵更勤，额外补兵，Boss 血 ×1.22。

斩：开局不带手里剑，空格 / Z 永远近斩。连斩两下，第二下真空弧约 58。贴墙斩弧朝下。刀可打掉敌刃。空中可斩。没有炎轮，没有月华，没有忍术。

敌人：徒巡逻 100；铳点射 200；蝠正弦飞 150；爪沿墙爬 180；殖两跳 250（2 血）。头目走动抛刃，残血更密，舰主会瞬移并召殖忍。击破头目再加 4500×倍率，过关 +1800×层。忍影3 打掉舰主后再加 8000，弹「古舰已破」；影核弹「影核得手」。

血玉：关内拾取，+400×倍率并叠连击。不是弹药。

得分：击杀/拾取基础分 × 连击倍率。连击为连续击杀或拾取，约 1.4 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))。每 15000 分 1UP，命上限 6。最高分写入 playbox-ninja-gaiden3-best，不存盘面；本局超过即更新。重生点随扎实落地点前移。

失败：挨打 / 中弹 / 坠崖扣一命（斩击打中该敌人的这一下不挨打；无敌除外）。约 0.80s 后在最近检查点重生，1.32s 闪烁无敌。三命扣完弹出「被击中了 / 中弹了 / 坠入深渊了」。弹层打开时方向键不再走路；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W / Shift 跳（空格不跳），↓ / S 从平台掉落或松墙，空格 / Z 近斩。点按画布同空格。触屏左 / 跳 / 斩 / 右。标题页 忍影3 / 影核，Enter/空格/1 忍影3，2 影核。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：斩必有三层——听（刀风噪声+下扫锯齿）、看（赤弧、血滴、金屑、分数蹦出）、触（约 55ms 顿帧 + 镜头踢）。第二下真空斩再加青弧与约 70ms 顿帧。贴墙必有三层——听（抓墙噪声+短嘀）、看（青爪火花）、触（约 22ms 顿帧）。蹬墙三层：听（噪声+上扫锯齿）、看（青屑+爆环）、触（约 30ms 顿帧 + 镜头侧踢）。连击数字往上叠。失败与重开都是一键 R。

区别：没有人质（不同于「忍」），没有疾跑残月冲与月华回刃（不同于「忍四」），没有滚场炎轮与三连斩（不同于「忍影」），没有生命条与忍术耗忍（不同于「影忍」）。忍术位空着：Shift 是跳跃。贴墙是本题，血滴是斩感。
