玩法：标题页选「登楼」或「狂风」。侧视大楼外墙，四列窗。按住上键一格一格扒上去，左右换列。窗会开合，开着的窗抓上去会掉；花盆从楼上砸下来；电招牌闪起来会电人；神鹰横掠会撞人。掉下去、砸到、电着或撞鸟都丢一条命。爬到顶上直升机即过关。点「重开」或 R 开新局（标题页 R 进登楼；局中或结算重开回当前模式第 1 栋）。M 静音，写入 playbox-crazy-climb-mute。

楼与窗：4 列，层距 46。第 0、1 层和顶层为钢窗，不开。其余窗会开合，同一层最多两扇同时大开。电招牌会先亮一下再放电。两侧偶有阳台花盆。相机跟着往上滚。

攀爬：↑ / W / 空格 / 触屏「上」按住则连续扒上一层（每层抓手有吸附）。← → / A D 换列。↓ / S 往下一层。换列或扒上时落到开窗、或人停在一扇正在打开的窗上，都会掉下去。

敌人与障碍：花盆沿列下落，砸中丢命，砸到地面碎开。同一列擦身而过算「险」加分。电招牌放电时站在那一扇会被电。神鹰从第五层左右开始横掠（狂风更早），撞上丢命。约 1.05 秒无敌后在最近安全窗重生；三命用尽弹出「命尽」。

过关：登楼共 3 栋，一层层加高加快，每栋顶上登机进入下一栋，第 3 栋登机算通关。狂风一栋 22 层，窗更快、花盆更密、神鹰更凶，登机即胜。

得分：每扒上一层 +50×连扒，擦身花盆 +80×连扒。登机 +1500+220×关+120×剩余命。连扒约 0.92 秒内不再往上抓会断。最高分按模式分记，写入 localStorage 键 playbox-crazy-climb-best，JSON `{s,g}`。本局超过即更新。

模式：登楼 3 栋关卡。狂风更快更密，不和登楼共用最高分。

操作：← → / A D 换列，↑ / W / 空格扒上，↓ / S 往下。触屏左 / 下 / 上 / 右。标题页 Enter/空格/1 登楼，2 狂风。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏。触控棋盘 `touch-action: none`，避免页面跟着滚。弹层 `pointer-events: none`（面板按钮除外），顶栏重开与 R 随时可用。

爽感：每次抓窗必有三层：听（抓手音高随连扒往上爬）、看（青屑、抓环、分数蹦出、身体挤压回弹）、触（约 32ms 顿帧 + 镜头微踢）。花盆砸碎约 50–70ms 顿帧、陶片炸开。电着金火星、约 80ms 顿帧并震一下。连扒数字往上叠。失败与重开都是一键 R。
