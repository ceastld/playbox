玩法：标题页「合金」。选「前线」打三关（荒原→废城→要塞，关底 Boss）；选「巷战」路更紧、平台更密、敌更快更密，开局手雷 16（前线 8）。侧向跑跳，空格开火，C 丢手雷。走过人质即救（弹 POW、掉补），走进空坦克上车。坦克有装甲，空格机枪、按住空格开炮；甲尽坦克炸、人弹出并短暂无敌。徒步有 4 点体力，打空丢一命。点顶栏「重开」或按 R：标题页进前线；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「巷战」开巷战。M 静音，写入 playbox-slug-run-mute。弹层打开时方向键不走路、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 86 高，能上一层，不能从地面直上高层。镜头跟在人右前方，Boss 战时锁在关底。地面有缺口，掉出屏幕底丢命（坦克则先炸再弹出）。中高层平台可落上，蹲下不掉穿。人宽约 14、立高 26、蹲高 14；坦克更宽约 40。走约 224，坦克约 168，空中约 0.9。标题页背后演示右进开火，不算分、不掉血。

前线三关：荒原（沙甲 36 血，有空坦克、重机箱、人质）/ 废城（城门 48 血，双坦克位、飞兵）/ 要塞（帝心 64 血）。过关保留命、分、体力、手雷、当前枪与是否在车上。巷战同三关但关宽约 ×0.86 并补平台与兵，速度 ×1.18 并随关递增，Boss 血约 ×1.15，开局 16 雷。

武器：默认手枪 0.16s 一发、屏上约 4 发。H 重机 0.055s 连射。C 手雷弧线，落地或碰敌约 0.62s 内引爆，范围伤 3，上限 20。坦克机枪 0.07s；按住空格约 0.3s 开炮，伤 4、带爆。死亡重生变回手枪，掉出坦克。

敌人：步兵巡逻点射 100；跑兵冲脸 150；投弹兵丢雷 150；炮台转向连射 300；迫击炮抛弹 250；飞兵俯冲弹 200；木箱 80，打破掉手雷。人质走过即救 1000，常掉手雷 / HP / 重机。Boss 沙甲机枪+炮弹、城门高低管、帝心放射弹（残血更密）。击破 Boss 再加 4000×倍率，过关 +2000×关。前线打掉帝心后再加 8000，弹「要塞捣毁了」；巷战弹「巷战清扫」。

坦克：空坦克走上去即上车（已在车上则忽略）。前线 8 甲、巷战 6 甲。甲被打光：坦克爆炸清一圈、人落地约 1.25s 无敌。坦克可跳（略矮），不能蹲。

得分：击杀基础分 × 连击倍率。连击为连续击杀/救人，约 1.35 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 15000 分 1UP，命上限 6。最高分写入 playbox-slug-run-best，不存盘面；本局超过即更新。

失败：徒步挨弹 / 撞兵 / 坠坑且体力打空扣一命（坦克扛打、无敌除外）。约 0.82s 爆炸后在最近扎实地面重生，1.15s 闪烁无敌，枪变回手枪，体力回满。三命（顶栏绿点）扣完弹出「被击中了 / 体力打空了 / 坠入坑里了 / 撞上了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳，↓ / S 蹲，空格开火（坦克按住开炮），C / G / F 手雷。点按画布同空格按住。触屏 左 / 跳 / 射 / 右 / 蹲 / 弹。标题页 前线 / 巷战，Enter/空格/1 前线，2 巷战。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子、坦克不履带嗡。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：开火枪口闪 + 粒子 + 手枪/重机/炮/雷各有音色。击杀/爆炸粒子 + 30–80ms 顿帧 + 镜头微震 + 连击数字往上窜。救人金鸣三音、POW 字蹦出、全屏闪。坦克开炮顿一下；炸车大爆 + 弹出。失败与重开都是一键 R。
