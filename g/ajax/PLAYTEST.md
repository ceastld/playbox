玩法：标题页「阿贾」。选「阿贾」打三关（云峡 → 海脊 → 核门），每关中 Boss 与关底，途中会自动切纵视/冲视；选「贾核」同三关但卷轴更快、编队更密、敌弹更勤、Boss 多约 22% 血、额外补波。点顶栏「重开」或按 R：标题页直接开阿贾；对局中或结束层重开同一模式。结束层「再飞」同模式；机毁「换模式」回标题；通关「贾核」开贾核（贾核通关则「换模式」回标题）。M 静音，写入 playbox-ajax-mute。方向键 / WASD 八向飞，空格射击（可按住连射），Shift / Z 或顶栏「爆」放爆弹，V / X 或顶栏「视」切换纵视/冲视。画布拖动跟机，按下开火。触屏右下「视」「爆」。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 阿贾、2 贾核。

场地：虚拟场 480×720。机开局 y=630、x=240，夹在 22–458 / 40–692。阿贾巡航约 82（关卡与连击再加），贾核约 114；中/关底 Boss 在屏时降到约 26–34。移速约 272（贾核 310）再加火力等级。点按或按住空格开火。未解锁音频前无声。冲视时后燃低频 rumble（约 88ms 一拍）。纵视是顶视卷轴；冲视把同一战场投到消失点（地平约 y=188），远处缩小、近处放大。切视是镜头，碰撞仍在世界坐标。

视切：V / X / 顶栏「视」/ 触屏「视」在纵↔冲之间切，冷却约 0.55s，过渡约 0.38s。切视约 42ms 顿帧、橙/青闪、吐司「纵视 / 冲视」。关卡波次里的 `swap` 会强制切（无视冷却）。第 1 关云峡开纵、约 15.4s 切冲；第 2 关海脊开冲、约 14.8s 切纵、36.8s 再切冲；第 3 关核门开纵，12.8 / 24.8 / 35.2s 三次切。系统开了减少动态时过渡瞬间完成。

火力：开局 0 级双发橙弹，冷却约 0.108s。吃菱形「火」胶囊升到 MAX（3）：1 加中弹 0.096s、2 五向 0.084s、MAX 七向 0.072s。满级再吃 +500×倍率。运机循环掉 火/火/爆。坠机掉一枚「火」且火力归零，爆弹保留。顶栏火条跟等级走，MAX 时爆亮。

爆弹：开局 3 枚，上限 6。Shift / Z 清掉全部敌弹、全体扣 6 血（地炮再加 4），金弹从顶雨落约 0.72s 继续砸伤（地对 3、空中 2），全屏闪、金环、约 78ms 顿帧，自身约 0.52s 无敌。过关补 1 枚。用尽再按提示「爆弹用尽」。地炮可飞越，只吃对空弹与爆弹。

关卡：第 1 关云峡中 Boss「峡台」40 血、关底「峡卫」96（半血变形）；第 2 关海脊「脊炮」52 / 「脊舰」126；第 3 关核门「门卫」66 / 「核门」168。贾核血量 ×1.22。中 Boss 在场时波次计时暂停。编队侦察 V 字、侧翼切入、俯冲锥、重机、地炮、运机。峡卫扇扫；脊舰旋转弹幕；核门双环弹+瞄准。变形后加侧射/环弹。空中机体相撞扣命。

得分：击杀基础分 × 连击倍率。侦察 50、战机 80、俯冲 110、重机 200、地炮 150、运机 300、中 Boss 2000、关底 4000+1500×关。连击为连续击杀，约 1.42 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。击坠关底再加 1500×关。三关打穿 +8000（贾核 +10000）再加剩余命×380 并「阿贾尽破 / 贾核尽破」。每 20000 分 1UP，命上限 6。最高分按模式写入 playbox-ajax-best，JSON `{a,k}`（阿贾 / 贾核），不存盘面；本局超过即更新。

胜利：阿贾/贾核打掉第 3 关核门后约 2.05s 结算胜利。
失败：敌弹碰到自己，或空中机体相撞，扣一命（重生无敌与爆弹期间除外）。约 0.95s 爆炸后重生，1.55s 闪烁无敌，场上敌弹清空。三命（顶栏橙菱）扣完弹出「机毁了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格射击，Shift / Z 爆弹，V / X 切视。点按画布开火并跟机。标题页 Enter/空格/1 阿贾，2 贾核。R 重开，M 静音。无手柄。无自动。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾、切视不过渡。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波（火力越高越厚）。击中粒子爆开 + 短顿帧（弹中约 22ms，击杀约 34–72ms）+ 镜头微震 + 连击数字往上窜。切视三层：听（噪声 + 锯齿扫频）、看（透视折叠、橙/青闪、吐司）、触（约 42ms 顿帧 + 折屏）。爆弹三层：听（噪声 rumble）、看（金弹雨、金环）、触（约 78ms 顿帧 + 强震）。吃火金闪。满级「MAX」蹦字。巨舰半血「变形」。坠机洋红大爆、约 78ms 顿帧。失败与重开都是一键 R。

什么变难：地炮瞄着射；俯冲机会扑脸；后关混出并出头目。贾核更密，弹更勤，头目更厚。连击会再略加快世界速。冲视里远处目标变小，要靠纵视读弹幕、冲视追纵深。
