玩法：标题页「双截」。选「巷战」打三关（夜巷→工厂→巢穴，巢穴打掉头目后走到玛丽身边救人）；选「无尽」在街上按波出兵，越往后越密越肉，每 5 波出头目。侧向皮带走位，空格起跳，Z 出拳、X 出脚，可连击；晕住的敌人贴近即抓住，再按 Z/X 甩出去。地上有铁棍、长鞭，走近捡起。点顶栏「重开」或按 R：标题页进巷战；对局中或结束层重开同一模式第 1 关 / 第 1 波。结束层「再来」同模式；失败「换模式」回标题；巷战通关「无尽」开无尽。M 静音，写入 playbox-dual-cut-mute。弹层打开时方向键不走路、Z/X 不打；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。皮带深度 z=4～88，画面 Y = 318 − z×0.72 − 跳高。左右走、上下走深浅，镜头跟在人右前方。巷战三关长度 2040 / 2280 / 2160。巢穴头目未倒时尽头洋红结界挡住，提示「先打倒头目」。无尽场地宽 2400，波次在镜头外左右刷出。

巷战三关：夜巷（混混、一名鞭女、一名壮汉，铁棍）/ 工厂（混混+鞭女+壮汉，铁棍与长鞭）/ 巢穴（杂兵后头目 22 血，救玛丽）。过关保留命、体、武器、分。无尽同街景，第 n 波人数 min(8, 2+⌊0.75n⌋)，速度约 ×(1+0.05×(n−1))，血量 ×(1+0.08×(n−1))；每 4 波地上补一件武器。

拳脚：Z 连击 刺拳→直拳→上勾（上勾击倒）；X 连击 踢→回旋（回旋击倒）。空中 Z/X 飞踢，一跳一次。拿着武器时 Z/X 都是挥武器：铁棍 3 伤、击倒、8 下碎；长鞭 2 伤、更远、10 下碎。被打约 22% 掉武器。晕住的非头目贴近即抓，抓住可走动，Z/X 投出；飞出的人撞到别人也算击倒。

敌人：混混贴脸拳 4 血；鞭女远抽 5 血；壮汉冲撞 8 血；头目 22 血（无尽随波加血），会拳会踢。体力条打空倒地再起身；起身一小段不挨打。击倒后有时掉棍或鞭。

得分：命中 50/80/110×连击倍率（拳/踢/武器），投 200×倍率，击杀混混 220 / 鞭女 320 / 壮汉 420 / 头目 4200×倍率，过关 1800×关，救人 8000，清波 700×波。连击为连续命中，约 1.55 秒无命中则断。倍率 = 1 + min(4, floor((连击-1)/2))。每 20000 分 1UP，命上限 6。最高分写入 playbox-dual-cut-best，不存盘面；本局超过即更新。

失败：体力打空扣一命（无敌除外）。约 0.85s 后原地满体重生，1.35s 闪烁无敌。三命扣完弹出「倒了」。弹层打开时方向键不再打；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 往后（深），↓ / S 往前（浅），空格 / C 跳，Z / J 拳，X / K 踢。点画布同拳。触屏 后 / 跳 / 前 / 踢 / 左 / 拳 / 右。标题 巷战 / 无尽，Enter/空格/1 巷战，2 无尽。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不顿帧、不抖屏、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：拳必有三层——听（拳风噪声+低击）、看（橙屑、闪光、分数蹦出）、触（约 45–70ms 顿帧 + 镜头踢）。踢更沉，棍有木裂粒子，鞭有洋红抽线。投出 80ms 顿帧。连击升档金闪、大字 ×N。失败与重开都是一键 R。
