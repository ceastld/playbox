玩法：标题页「仙童3」。选「仙童3」打三关（洞窟→瀑谷→魔巢，尽头头目）；选「童核」敌人更密更快、饿得更快、头目血更多、镜头推得更急，开局连炎并带护焰。侧向滑板走跳，空格 / Z 射炎弹。镜头一直往右推，被卷出左缘丢命。撞敌即丢命。点顶栏「重开」或按 R：标题页进仙童3；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「童核」开童核。M 静音，写入 playbox-wonder-boy3-mute。弹层打开时方向键不走路、空格不射（空格/Enter 在标题开仙童3、结束层再来）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=320，中层 248，高层 176，间距 72；起跳约 86 高，能上一层，不能从地面直上高层。镜头自动右推，高层略上抬。地面有缺口，掉出屏幕底丢命。中高层平台可单向落（↓ / S 掉落），地面不能掉穿。头目激活后镜头锁在关尾，人被关在约 520 宽的擂台。

三关：洞窟（蝠王 12 血）/ 瀑谷（水蟒 16 血）/ 魔巢（巢龙 22 血）。过关保留命、分、炎级、护焰，体力回满。童核同三关，饿速 7.8/秒（仙童3 4.6/秒），移速与推镜约 ×1.28，额外补兵，头目血约 ×1.28，开局连炎 + 护焰。

体力：开局 100。仙童3 约 22 秒见底，童核约 13 秒。低于 26 顶栏力条转洋红并心跳提示「饿了」。到 0 饿倒丢命。橙 +20/100 分，蕉 +28/200，瓜 +42/400，再乘连击倍率。摘果会把检查点记在果附近。

滑板：始终在板上，走速 248，轮下洋红火星。不是拾取物。必须自己往右滑，镜头约 104/秒（童核 128/秒，随关递增）往右推；被卷出左缘丢命。撞敌用护焰挡一次，否则丢命。

射击：空格 / Z / 点画布 / 触屏「射」，按住连射。单炎冷却约 0.22 秒；连炎约 0.12 秒；扇炎三向约 0.16 秒。命中黏怪/蝠/骨一发打死；刺球两发；头目多血。炎弹可打爆木箱、打消头目弹。

火晶：场上漂浮火晶，捡到升一级炎（单炎→连炎→扇炎）。木箱被炎弹打碎：约 42% 升炎、30% 护焰、其余补蕉。护焰挡一次撞击。炎级与护焰过关保留。

敌人：黏怪巡逻；蝠正弦飞；骨跳扑；刺球来回弹；火鸟俯冲（瀑谷起）。蝠王飞舞丢音环并吐弹；水蟒冲撞后跳砸吐水弹；巢龙跳砸喷火球并放地面冲击（跳过）。击破头目再加 5000×倍率，过关 +1800×层。打完魔巢再加 8000（童核 16000），弹「魔巢打通」或「童核打穿」。

得分：击杀/摘果/打箱/捡晶基础分 × 连击倍率。连击为连续击杀或摘果或打箱或捡晶，约 1.32 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))。每 12000 分 1UP，命上限 6。最高分写入 playbox-wonder-boy3-best，不存盘面；本局超过即更新。

失败：挨打（无护焰）/ 中弹或冲击 / 坠崖 / 饿倒 / 被镜头卷走扣一命（无敌除外）。约 0.82s 后在最近摘果或打箱处（或镜头前方）重生，1.4s 闪烁无敌，体力至少回到 42。三命扣完弹出「被撞到了 / 掉下去了 / 饿倒了 / 被卷走了」。弹层打开时方向键不再射；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，Shift / ↑ / W 跳（空格不跳），↓ / S 从平台掉落，空格 / Z 射炎。点按画布同空格按住。触屏左 / 跳 / 射 / 右。标题页 仙童3 / 童核，Enter/空格/1 仙童3，2 童核。R 重开，M 静音。无手柄。

与仙童不同：不是近砸、没有商店石锤，是自动推镜的跑射击，空格射炎、Shift 跳。与阿历不同：没有出拳砸砖、没有猜拳头目。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 炎粒子 + 方波下扫。打中必有三层——听（噪声+方波下扫，连击升调）、看（炎屑爆开、分数蹦出、木箱挤扁）、触（命中约 48ms / 爆箱约 50ms / 头目约 70ms 顿帧 + 镜头微踢）。摘果爆色、力条闪、连击升调。轮下洋红火星。头目倒下全屏金闪。连击数字往上叠。失败与重开都是一键 R。
