玩法：标题页「爆射」。选「爆射」打三关（云廊 → 炎带 → 宙门），每关中段出六角基、关底出堡；选「炎雨」同三关但卷轴更快、编队更密、敌弹更勤、Boss 多约 22% 血。点顶栏「重开」或按 R：标题页直接开爆射；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题（通关爆射时该钮变成「炎雨」）。M 静音，写入 playbox-blast-off-mute。←↑↓→ / WASD 八向飞，空格射击（可按住连发，按住约 0.38s 成球穿甲），X / C / Ctrl 或顶栏「式」切红蓝黄绿四式，Shift / Z 或顶栏「爆」扔爆射弹。画布拖动跟舰，按下开火。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 爆射、2 炎雨。

场地：虚拟场 480×720。舰开局 y=642、x=240，夹在 22–458 / 40–692。爆射巡航约 88（炎雨 124）；六角基在屏时降到 22。移速约 276（炎雨 318）。点射连发，弹速 740（成球 620），冷却约 0.1s（炎雨 0.085，成球再 +0.038）。未解锁音频前无声。三关名：云廊、炎带、宙门；顶栏在中 Boss 时改成「环巢 / 炎巢 / 六卫」，在 Boss 时改成「云堡 / 炎堡 / 爆核」。堡内自机画得更大（靠近基内）。

四式（坠机重置为红，无武装拾取）：
- 红：双环螺旋向前（默认）
- 蓝：一前一后（博斯遗法）
- 黄：前 + 左右丁字
- 绿：斜前两路 + 后
按住空格约 0.38s 成球：同方向更大实心球，穿甲 4 段，伤害约 2.15。屏上弹上限 12（成球 8）。顶栏「球」条跟按住时间走，满时爆亮。

爆弹：开局 3 枚，上限 6。Shift / Z 清掉全部敌弹、全体扣血并削六炮，全屏闪、金环、约 78ms 顿帧，自身约 0.52s 无敌。过关补 1 枚。运械掉「爆」。用尽再按提示「爆弹用尽」。

敌人：无人机 50 / 2 血、俯冲 80 / 2、E 弹 90 / 2、炮台 150 / 6、六角 120 / 5、精锐 240 / 10、运械 280 / 8、六炮 120、中基 2200、堡 4500。血量再乘炎雨 1.22。炎雨 V 字 +2、俯冲 +1、额外一只精锐；射速约 0.74 倍间隔、弹速约 186（爆射 146）。

Boss：六角基入场约 1.05–1.35s 后左右游荡并慢旋。六门炮绕核，可单独打爆；打爆一门核会顿约 1.15s 停火。打光六炮会直接拆基（额外半分）。核自己会瞄准 / 彩球环弹。高血三发散+偶发八环，半血十环兼瞄准，残血双环+五发散并吐无人机。打爆后约 1.35s 进下一关或结算。

得分：击杀基础分 × 连击倍率。连击为连续击杀/打炮/吃爆，约 1.4 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。过关 +1500×倍率。爆射打穿再 +8000，炎雨 +10000。每 18000 分 1UP，命上限 6。最高分写入 playbox-blast-off-best，不存盘面；本局超过即更新。

胜利：爆射/炎雨打爆爆核后约 1.35s 结算「宙门尽碎」/「炎雨通关」。
失败：三命（顶栏朱红六角点）扣完弹出「舰毁了」。敌弹（判定约 4.5）或撞空中机体/基核/六炮扣一命。约 0.92s 爆炸后底部重生，1.5s 闪烁无敌，场上敌弹清空，射式回到红。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格射击（按住成球），X / C / Ctrl 切式，Shift / Z 爆射。点按画布开火并跟舰。标题页 Enter/空格/1 爆射，2 炎雨。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 四式各有音色（红双音、蓝前后、黄和弦、绿锯齿；成球噪声加低频）。击中粒子爆 + 短顿帧（约 32–50ms）+ 镜头微震 + 连击数字往上窜。爆射弹三层：听（噪声 + 锯齿下滑 + 上滑正弦）、看（金环扩散、边框闪、BLAST OFF 蹦字）、触（约 78ms 顿帧 + 强震）。切式金闪。成球「球」条爆亮。坠机洋红大爆、约 72ms 顿帧。失败与重开都是一键 R。
