玩法：标题页「狂扫」。选「扫荡」打八波（入场→铁拳→球孵→脑袭→合围→狂潮→重压→终扫），清完弹出「扫清了」；选「护人」人类更多、铁拳和脑机更密，一波接一波直到没命。双摇杆：走和射分开。点「重开」或 R：标题页进扫荡；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-robotron-mute。A 或「自动」开关托管。弹层打开时方向键不走路、IJKL / 鼠标不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 720×480，四周墙厚约 20。人半径 9，移速约 188。弹速约 540，连射间隔约 0.066s，场上己弹最多 16。开局人在场心，机兵从四边刷，离人至少约 90。电极占格，烫人烫机（铁拳除外，铁拳从电极上碾过去）。标题页背后是演示扫场，不算分、不掉血。

扫荡八波：入场 8 机兵 + 4 人；铁拳加 2 铁拳；球孵出球机孵执法；脑袭出脑机改写人类并射追踪弹；后面合围 / 狂潮 / 重压 / 终扫把四种机兵叠上去。过波保留命和分数。护人：第 1 波约 9 人、铁拳和脑机都在，之后人更多（上限 14），无终局胜利。

机兵：机兵（Grunt）八向愣冲，碰到即死。铁拳（Hulk）慢、血厚约 16，子弹只能推开并一点点削血，很难秒掉；碾到人类即「没了」并重置救人倍率。球机（Spheroid）弹墙飞，约 1s 孵一只执法。执法（Enforcer）绕人点射。脑机（Brain）追人类改写成敌对「改写体」（Prog，更快），并向人发射可拦截的追踪脑弹。清波只要求杀掉铁拳以外的活机；铁拳可留。

人类：父 / 母 / 子三种，乱走并躲开铁拳和脑机。碰到人即救起。救人分 1000 / 2000 / 3000 / 4000 / 5000，同波连续救叠到 ×5；死人、改写、自己掉命或新一波都重置回 ×1。己弹穿过人类。

得分：击杀基础分 × 连击倍率。机兵 100、执法 150、球机 1000、脑机 500、改写体 100、铁拳 250、电极 / 脑弹 25。连击窗口 1.22s，倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 ×1、4–6 连 ×2，最高 ×5。清波 +200×波次×倍率。扫荡通关再 +5000。每 20000 分 1UP，命上限 6。最高分按模式分记，写入 playbox-robotron-best，JSON `{sweep,guard}`；本局超过即更新。

胜利：扫荡打完第 8 波终扫弹出「扫清了」。护人没有清盘。
失败：三命（顶栏青点）扣完弹出「撞上机兵了 / 铁拳碾过来了 / 电极烫到了 / 被射中了 / 脑弹追上了」等。还有命则在场心重生，约 1.45s 无敌闪烁。碰到机兵 / 铁拳 / 执法 / 脑机 / 改写体 / 电极 / 敌弹都扣一命。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：WASD / 方向键八向走，与射击完全分开。A 为自动（不再当左移；左移只用方向键，W/S/D 仍走）。鼠标瞄准（按住画布连射），或 IJKL 第二套方向键射（可八向），或空格朝当前瞄准连射。触屏左摇杆走、右摇杆射（右杆推开即连射）。手柄左摇杆走、右摇杆射。标题页 扫荡 / 护人。R 重开，M 静音。A 自动。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、不连环大字。触控画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。自动开关不写入存储，刷新后关闭。

自动：点「自动」或按 A 开关托管（开着时按钮呈按下态并显示「停下」）。开着时忽略方向键、W/S/D、鼠标开火、触屏摇杆和手柄；A / R / M / 重开仍可用。开关不写入存储，刷新后关闭；重开不会关掉自动。扫清了 / 没命弹层上停手，重开且自动仍开着则新局接着托管。标题页开自动会按当前模式开局（扫荡或护人）。速度滑条 1–4 为 慢 / 中 / 快 / 极快（默认快），写入 playbox-robotron-auto-speed。慢为实时，中/快/极快加快步进（约 2 / 4 / 10 倍），手玩仍是实时。AI 双摇杆：走和射分开。优先躲开近处机兵、铁拳、电极和来弹，安全时去救人叠倍率，边走边射球机 / 脑机 / 执法 / 机兵 / 改写体；铁拳血厚只在挡路或要碾人时推开，清波不必打死铁拳。不是完美求解，合围过密或贴墙时仍可能掉命。

爽感：开火枪口闪 + 短音；击中/爆炸粒子 + 30–80ms 顿帧 + 镜头微震 + 连击数字往上窜；救人金闪、上升音阶、倍率 chime、场上 +1000…+5000；铁拳中弹被推开并闷响。
