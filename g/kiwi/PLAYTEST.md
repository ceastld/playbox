玩法：标题页「奇异」。选「救人」打五面动物园小岛（鸟园 → 海豹池 → 气球谷 → 鲸湾 → 飞艇岛），救出全部笼中同伴再走进发光出口；选「追赶」同一套图，敌人更快更密。左右走，上跳，空格射箭。可跳上气球升空、骑气垫船过水、乘飞艇爬高。碰到敌人或掉进坑/水都扣一命。点顶栏「重开」或按 R：标题页进救人；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-kiwi-mute。弹层 `pointer-events: none`，只有面板按钮可点；顶栏重开与 R 随时可用，不被 overlay 挡住。

场地：虚拟视口 640×360，关卡比视口大，镜头跟在人右前方。平台可单向落（↓ / S 掉落）。地面有缺口，掉出世界底丢命。海豹池 / 鲸湾有水面，没骑气垫或飞艇没入即死。部分平台会平移。

跳跃：↑ / W 跳（空格不跳，空格是射箭）。落地可再跳；空中还能再扑腾一次（较弱）。点按跳会变矮跳，按住跳得更高，按住时落地会接着蹦。落地有下蹲尘。跳上气球即骑乘，再跳弹开（气球爆）。

射箭：空格 / 点画布 / 触屏「射」。冷却约 0.20 秒，场上最多 3 支。命中熊/海豹/鸟一发打死；射中笼子直接打开；大鲸跃起时可射退。

载具：气球落地骑上后上升，约 4.8 秒或顶到天花板会爆。气垫船左右快，水面安全，跳下离开。飞艇更稳、升得慢，可从飞艇岛底部一路抬上去。骑乘时仍能射箭。

救人：鸟园 2 笼 / 海豹池 2 笼 / 气球谷 3 笼 / 鲸湾 2 笼 / 飞艇岛 3 笼。碰笼子或射开都算救到，检查点记在刚打开的笼子。全救出后出口亮起，走进去进下一关。过关保留命、分和 EXTEND 进度。追赶：移速约 ×1.42，每面额外 1–2 只怪。

敌人：熊沿台巡逻，到边回头；海豹同走但更快；鸟正弦掠过。鲸湾/海豹池的大鲸在水面附近逗留约 0.85 秒会扑上来（提示「大鲸」），咬中即死；跃起时可射退。

得分：熊 200 / 海豹 250 / 鸟 150 / 鲸 500，开笼 500，果 120 / 240 / 400，再乘连击倍率。过关 +1200+300×关。打完飞艇岛再加 4000（追赶 8000），弹「岛链救通」或「追赶贯通」。连击窗口约 1.55 秒，倍率 1 + min(4, 连击-1)，最高 5 倍。每 15000 分 1UP，命上限 6。最高分写入 playbox-kiwi-best，不存盘面；本局超过即更新。扣命会断连。

生命：3 条（顶栏奇异鸟点）。撞敌、落坑、沉水或被鲸吞都扣一条。约 0.72 秒后在最近开笼处（或关首）重生，约 1.42 秒闪烁无敌（落坑 / 水 / 鲸不受无敌保护）。三命用尽弹出「被撞到了 / 掉下去了 / 沉下去了」。弹层打开时方向键不再走跳射；顶栏重开与 R 随时可用。

操作：← → / A D 走，↑ / W 跳，↓ / S 从平台掉落，空格射箭。点按画布同空格。触屏左 / 跳 / 射 / 右。标题 Enter/空格/1 救人，2 追赶。结束层 Enter/空格/1 再来，2 换模式。R 重开，M 静音。无手柄。无自动。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不顿帧、不抖屏、不大字。触控画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：每次起跳有跳声+尘+羽毛。箭中必有三层：听（噪声+音高随连击往上爬）、看（羽毛屑、金火花、分数蹦出）、触（约 55ms 顿帧 + 镜头踢）。开笼另有钟声琶音、金屑与约 70ms 顿帧。骑上气球有叮一声和青环。连击数字往上叠。失败与重开都是一键 R。
