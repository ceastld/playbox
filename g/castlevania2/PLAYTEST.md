玩法：标题页「魔城2」。选「魔城2」打三片区（乔瓦→死河→残堡，关底巨狼 / 河骸 / 伯爵，伯爵打空后化残魂再打一形态）；选「城核」敌更快更密，额外补鸦与泥人（狼不加倍），头目血约 ×1.22，昼夜周期 26 秒（魔城2 为 32 秒），入夜幽灵与狼更勤。侧向走跳，空中锁方向（硬跳）。没有 45° 楼梯，靠跳上一层。空格挥鞭，Shift / Z 丢副武器（耗心）。点顶栏「重开」或按 R：标题页进魔城2；对局中或结束层重开同一模式第 1 区。结束层「再来」同模式；失败「换模式」回标题；通关「城核」开城核。M 静音，写入 playbox-castlevania2-mute。弹层打开时方向键不走路、空格不挥鞭；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 80 高，能上一层，不能从地面直上高层。镜头跟在人右前方，Boss 战时锁在关底。地面有泥沼缺口，泥人从坑里跃出；掉出屏幕底丢命。人宽约 14、立高 26、蹲高 14。走约 132，空中速度锁定起跳时的水平速度。标题页背后演示右进挥鞭跳坑，不算分、不掉血。

昼夜：顶栏「昼 / 夜」，画布左下有日夜条。魔城2 整轮 32 秒（各 16 秒），城核 26 秒。入夜 toast「入夜了」+ 青闪 + 镜头踢，天亮「天亮了」+ 金闪。夜间：天空换月、细雨、雾更浓，坑上「鬼桥」实心可走（昼时只画虚线，踩上去会掉），敌人移速 ×1.22，额外刷幽灵穿屏与狼从镜头边冲入。白昼：村窗亮灯，鬼桥消散。过关保留当前昼夜进度。

魔城2 三区：乔瓦（巨狼 20 血，皮鞭→荆鞭、小刀/钻石，泥人与狼）/ 死河（河骸 26 血，圣水、木桩，鸦俯冲）/ 残堡（伯爵 34 血，化残魂后再约 16 血，瞬移喷火再俯冲）。击破头目掉遗物（肋骨 / 心脏 / 眼球），捡齐 3 件通关再加 3000。过关保留命、心、鞭长、副武器、遗物、分。城核同三区，速度 ×1.28 并随关递增，额外补兵，Boss 血约 ×1.22，开局仍是皮鞭。击破头目 +4500×倍率，过关 +2000×关。魔城2 打掉残魂后再加 9000，弹「昼夜已破」；城核弹「城核平了」。

鞭：空格挥一次约 0.28s，落地挥鞭时不能走。皮鞭 36 / 荆鞭 62（绿梢）/ 晨星 88，蜡烛掉「鞭」升级，晨星伤害 2。副武器：小刀直线、圣水落地燃池持续灼烧、钻石斜向弹地（可弹 3、穿 1）、木桩直线（对头目 3 伤，遗物齐全 4 伤），均耗 1 心。无副武器或心不够会 toast。蜡烛还掉小心、大心、烤肉（1UP，命满则心 +8）。

敌人：僵尸慢走 100；狼冲脸并可短跳 180；鸦正弦再俯冲 160；泥人从泥坑跃出再走 170；幽灵仅夜间正弦穿屏 200。Boss 巨狼冲跳、河骸抛骨、伯爵瞬移火球后化残魂俯冲。与魔城不同：不是爬 45° 梯打城门地窟伯爵，没有锁链鞭与十字斧，是昼夜鬼桥走乔瓦死河残堡，荆鞭绿梢，钻石弹地、木桩钉头目。与魔界不同：不是丢枪碎甲。与鬼铠不同：没有铠甲/金甲，空中不能改向，一碰丢命。

一碰丢命：没有生命条。挨弹 / 撞兵 / 坠渊立刻扣一条命（无敌除外）。约 0.82s 后在最近扎实地面重生（不把鬼桥当检查点），1.22s 闪烁无敌（城核 0.92s）。三命（顶栏紫点）扣完弹出「被击中了 / 坠入深渊了 / 被伯爵击倒了」。每 15000 分 1UP，命上限 6。最高分写入 playbox-castlevania2-best，不存盘面；本局超过即更新。

得分：击杀/打蜡基础分 × 连击倍率。连击为连续击杀或打蜡，约 1.36 秒无动作则断；挨打立刻断。倍率 = 1 + min(4, floor((连击-1)/3))。

失败：一碰 / 坠崖扣一命。弹层打开时方向键不再挥鞭；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳，↓ / S 蹲，空格挥鞭，Shift / Z 副武器。点按画布同空格。触屏 跳 / 鞭 / 副 / 左 / 下 / 右。标题页 魔城2 / 城核，Enter/空格/1 魔城2，2 城核。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：挥鞭必有三层——听（抽响噪声+下扫）、看（橙/绿/金鞭梢、蜡火爆开、分数蹦出）、触（约 34–72ms 顿帧 + 镜头踢）。打蜡金鸣+粒子爆。副武器出手全屏闪：小刀脆钢、圣水池紫焰、钻石青弹、木桩沉啸。入夜/天亮全屏色闪。连击数字往上叠。伯爵化残魂有变身轰鸣与全屏闪。失败与重开都是一键 R。
