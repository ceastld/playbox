玩法：标题页「侍秋」。选「秋叶」打三局短决斗再打秋王（叶侍 → 赤笠 → 夜鸦 → 秋王）；选「血月」同四人但更快、格挡窗更短、对手血量约 ×1.18。一对一拔刀，空格斩、Shift / Z 格挡，双点左/右闪步穿过。己方体力打空本局结束。点顶栏「重开」或按 R：标题页直接开秋叶；对局中或结束层重开同一模式。结束层「再来」同模式；刃折「换模式」回标题；秋叶通关「血月」开血月（血月通关则「换模式」回标题）。M 静音，写入 playbox-samurai-aki-mute。弹层打开时方向键不走、空格不斩（标题空格/Enter/1 开秋叶，2 开血月）；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。

场地：虚拟场 720×400。地面 Y=338。人开局 x=168 对 x=552，夹在 46–674。秋叶走速约 168，血月约 198。点按画布轻点斩，拖走，快滑闪步。触屏底栏 左 / 右 / 斩 / 挡 / 闪。未解锁音频前无声。秋叶缓落，血月更大更红。

对决：叶侍 36 血、斩慢前摇约 0.16s、几乎不格挡；赤笠 52 血、爱格挡（约 64% 读斩）；夜鸦 66 血、爱闪步穿过；秋王 128 血，半血后会放前摇更长的月斩（更宽更痛）。血月血量 ×1.18。斩命中约 15，格挡成功后 0.55s 内反斩约 ×1.6；闪步落地 0.22s 内出刀为闪斩。双方同时斩中则交刃，互不扣血。闪过对方斩得「闪读」。局间秋叶回 30 体、血月回 14。

得分：斩中 120×连斩倍率，反斩 280×，闪斩 200×，格挡 160×，闪读 90，交刃 40。击倒 800+400×局 + 速胜（最多约 700），血月击倒 ×1.25。连斩为连续命中/格挡，约 1.55 秒无则断，受伤清零。倍率 = 1 + min(4, floor((连斩-1)/2))。打穿秋王 +6000（血月 +9000）。最高分写入 playbox-samurai-aki-best，不存盘面；本局超过即更新。

胜利：秋叶/血月打掉秋王后约 1.05s 结算「秋尽」。
失败：己方体力打空（闪步无敌、受伤后约 0.34s 无敌除外）。倒下约 0.7s 后弹出「刃折」。弹层打开时方向键不再走；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，空格斩，Shift / Z 格挡，双点左/右闪步。点按画布斩，拖动走，快滑闪步。标题 Enter/空格/1 秋叶，2 血月。R 重开，M 静音。无手柄。与街霸不同：没有角色栏和波次技。与战斧/魂斗/双截不同：不是清街卷轴，是一对一拔刀。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、少叶子。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：出刀必有三层——听（刀风噪声 / 命中方波 / 格挡金属高音 / 交刃闷锯齿 / 闪步呼啸各不一样）、看（刀光弧、枫叶爆、格挡金环、连斩大字、分数蹦出）、触（斩约 50ms 顿帧，反斩约 64ms，格挡约 56ms，击倒约 72ms，加镜头微震）。连斩升档金闪、大字「N 斩」。失败与重开都是一键 R。
