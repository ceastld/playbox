玩法：标题页「双截2」。选「双截2」打三关（停机坪→密林→罪府，罪府尽头是影枭）；选「截核」同三关但每包更密、更快、更肉。沿街带状走（左右推进、上下换深度），空格出拳三连（第三下回旋踢击倒），Shift / Z 飞踢（起跳并踢，空中可微调）。晕住的非头目贴近即抓住，再空格 / 飞踢甩出去。没有铁棍长鞭，不救人。被打中、被冲撞、中飞刃或坠入停机坪缺口立刻丢一命。点顶栏「重开」或按 R：标题页进双截2；对局中或结束层重开同一模式。结束层「再来」同模式；失败「换模式」回标题；通关「截核」开截核。M 静音，写入 playbox-double-dragon2-mute。弹层打开时方向键不走路、空格不出拳；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。可走带宽 y=224–324。镜头跟在人右前方，遇兵和 Boss 锁在当前段。人约 16 宽 30 高，走约 196，纵深约 118。飞踢起跳约 91 高，空中可横移约 125。停机坪有两处缺口（宽 70 / 74），落到缺口即坠坪丢命。标题页背后演示右进出拳和飞踢，不算分、不掉命。

双截2 三关：停机坪（铁卫 48 血，巷匪/飞踢，缺口）/ 密林（林煞 64 血，斧手/飞踢更多）/ 罪府（影枭 90 血，会飞踢并叫打手）。过关保留命、分。截核同街景，每包多 1～2 人，敌速约 ×1.14，血量约 ×1.18，影枭血约 ×1.2。

出拳：空格三连（直→直→回旋踢），第 3 击击倒。飞踢是独立键，落地短硬直，飞踢中（离地）不挨撞击。贴近晕住的非头目即抓住，抓住可走动，再空格 / 飞踢甩出去；飞出的人撞到别人也算击倒，撞墙或坠坪额外伤害。飞刃用上下换深度躲开，飞踢跃过也可躲。

敌人：巷匪近打；飞踢会跳踢；斧手重挥；飞刃远掷。Boss 铁卫冲撞、林煞飞踢、影枭飞踢并叫打手。击破 Boss 再加 4000/5200/9000×倍率，过关 +2000×关。双截2 打掉影枭后再加 8000，弹「罪府清了」；截核弹「截核清场」。

得分：击杀基础分 × 连击倍率。连击为连续打中，约 1.4 秒无打中则断。倍率 = 1 + min(4, floor((连击-1)/2))，即 1–2 连 1 倍、3–4 连 2 倍，最高 5 倍。每 18000 分 1UP，命上限 6。最高分写入 playbox-double-dragon2-best，不存盘面；本局超过即更新。

失败：挨打 / 被冲撞 / 中飞刃 / 坠坪立刻丢一命（无敌与飞踢离地除外）。约 0.82s 爆炸后在最近扎实地面重生，1.28s 闪烁无敌。三命（顶栏橙点）扣完弹出「被撞了 / 被巷匪打中了 / 被飞踢了 / 中飞刃了 / 坠坪了」等。弹层打开时方向键不再出拳；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → ↑ ↓ / WASD 走（上下换深度），空格 / J 出拳，Shift / Z 飞踢。点画布同出拳。触屏 上 / 下 / 左 / 右 / 拳 / 踢。标题页 双截2 / 截核，Enter/空格/1 双截2，2 截核。R 重开，M 静音。无手柄。与双截不同：没有棍鞭、不是救人、空格是拳不是跳，飞踢是独立键，撞击即死没有体力条。与怒二不同：有跳有踢，没有升龙能量。与怒三不同：没有暴冲电旋，关卡是停机坪/密林/罪府。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：出拳挥拳风声，飞踢破空声。打中：撞击音 + 粒子/火花 + 分数蹦出 + 约 40–78ms 顿帧（回旋/飞踢/甩投更长）+ 镜头微震。击破爆炸粒子与光环。连击数字往上窜，倍率跳时全屏 ×N。飞踢：青金残影、落地重震。失败与重开都是一键 R。
