玩法：标题页「地平」。选「洞穴」三段：都市 → 溶洞 → 基地，炸毁基地核芯即胜；选「夜袭」同图更暗更快、油耗更高、弹更密。点「重开」或 R：标题页直接开洞穴；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-scram-run-mute。方向键 / WASD 八向慢移。空格开火（可按住连射）。下+空格 或 Z / X / B 投弹。画布拖动/悬停跟船，按下开火；右键投弹。触屏「射」「炸」。

场地：虚拟场 720×400。洞穴自动右滚：洞穴 128/136/142 px/s（都市/溶洞/基地），夜袭 182/192/200。船钉在画面左段 x=36–308，八向 110 px/s（斜向归一）。顶底贴壁约 11px 缓冲，撞岩壁、楼、炮、火箭、飞碟、核芯或敌弹即坠。燃油每秒 5.8（夜袭 7.4），空了即坠。

段落：都市 0–2500 敞空+楼房；溶洞 2500–5200 顶底咬合、缝越来越窄；基地 5200–7600 更窄的台阶洞。核芯在 x=7180，8 血，炮弹 1、炸弹 3，打爆即「捣毁了」。核芯后洞口封死。夜袭缝再缩约 10%，飞船周围一圈光，外头几乎看不见。

敌人与油：地面炮打斜弹，火箭靠近才升空，飞碟正弦漂并开火，夜袭多火球。油桶约每 540px 必出一桶，打中或炸中 +34 油并「+燃油」金闪。楼可炸。撞油桶也坠，必须开火或投弹。

得分：楼 20、火箭 50、炮 80、飞碟 100、火球 40、油桶 150、核芯 800，再乘连击倍率。连击 1.35s 无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。最高分按模式分记，写入 localStorage 键 playbox-scram-run-best，JSON `{c,n}`。本局超过即更新。

胜利：打爆核芯弹出「捣毁了」。
失败：三命（顶栏青梭）扣完弹出「坠机了」。撞壁、中弹、撞机、燃油耗尽都会扣命。约 0.72s 爆炸后在当前位置偏左的缝中重生，油补到至少 72，1.35s 闪烁无敌。弹层打开时顶栏重开与 R 随时可用。

操作：←↑↓→ / WASD 移，空格开火，下+空格 / Z 投弹。点按画布开火并跟船。触屏射 / 炸。标题页 Enter/空格/1 洞穴，2 夜袭。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay.hidden` 为 `pointer-events: none`。

爽感：每次开火都有炮口闪 + 青粒子 + 短促升频。投弹三层：听（低锯齿+低频 rumble）、看（金屑、橙爆）、触（镜头 rumble + 约 58ms 顿帧）。打油桶：金闪、油条脉冲、高音 ping、+燃油蹦出、约 55ms 顿帧。击杀粒子+连击音高往上爬。坠机洋红大爆、约 80ms 顿帧并震屏。失败与重开都是一键 R。
