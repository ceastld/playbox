玩法：标题页选「砸楼」或「狂怒」。侧视夜城，巨兽走街、扒楼侧面往上爬，空格砸当前高度的楼层。一层一层打到没层，整栋倒塌。街上的人、窗里的人都能吞，回血。军队开枪、直升机扔火箭、坦克打炮弹，躲开或一拳打爆。点「重开」或 R 开新局（标题页 R 进砸楼；局中或结算重开回当前模式第 1 城）。M 静音，写入 playbox-rampage-mute。

楼层与倒塌：城内 4～5 栋楼，高度 5～9 层（越往后越高）。贴楼侧面按上即爬，左右可松手跃向邻栋。砸中楼层扣耐久，底层更耐打；打空该层变黑洞并掉碎石。整栋层数清零后楼体倾斜下沉倒塌。爬在正在塌的楼上会被掀下去。站屋顶可左右走，按下沿边下去。

摔落与体力：从约两层以上摔到地面丢一条命；矮落只顿一下或掉一点血。子弹 / 火箭 / 炮弹打中扣血，血条见顶栏。血空也丢命。吞人立刻回血。约 1.1 秒无敌后在街道重生；三命用尽弹出「命尽」。城内进度保留。

过关：一城里所有楼都塌完即夷平，约 1.2 秒后进下一城，军队更快楼更高。城名轮换：夜城 / 港湾 / 钢区 / 霓虹 / 末都。

得分：砸裂 +40×连砸，砸穿 +120×连砸，整栋塌 +600+80×层，吞人 +200×连砸，打兵 +80、打直升机 +320、打坦克 +480，拦下炮弹 +20，夷平 +1200+250×城。连砸约 1.4 秒内不打中会断。最高分按模式分记，写入 localStorage 键 playbox-rampage-best，JSON `{c,r}`。本局超过即更新。

模式：砸楼为正常出兵节奏。狂怒军队出得更勤、弹更快略带追踪，坦克直升机上限更高。狂怒不和砸楼共用最高分。

操作：← → / A D 走，↑ / W 扒楼或上爬，↓ / S 下爬，空格砸。触屏左 / 下 / 上 / 右 / 砸。画布上半点击也砸。标题页 Enter/空格/1 砸楼，2 狂怒。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏。触控棋盘 `touch-action: none`，避免页面跟着滚。弹层 `pointer-events: none`（面板除外），顶栏重开与 R 随时可用。

爽感：每次砸中必有三层：听（低击 / 碎裂音色随连砸往上爬）、看（碎石、裂纹、分数蹦出、闪光）、触（约 48–70ms 顿帧 + 镜头微踢）。整栋倒塌约 80ms 顿帧、楼体倾斜下沉、大团瓦砾。吞人回血有咀嚼声和洋红环。中弹洋红闪并震一下。连砸数字往上叠。失败与重开都是一键 R。
