玩法：标题页「战刃」。选「战刃」打三局短决斗再打刃王（斥候 → 铁卫 → 血骑 → 刃王）；选「血月」同四人但更快、格挡窗更短、对手血量约 ×1.16。圆场八向走位，空格点斩、按住蓄重斩，Shift / Z 格挡，X / Ctrl 或双点方向冲步。己方体力打空本局结束。点顶栏「重开」或按 R：标题页直接开战刃；对局中或结束层重开同一模式。结束层「再来」同模式；刃折「换模式」回标题；战刃通关「血月」开血月（血月通关则「换模式」回标题）。M 静音，写入 playbox-warblade-mute。弹层打开时方向键不走、空格不斩（标题空格/Enter/1 开战刃，2 开血月）；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。

场地：虚拟场 720×420。圆场圆心 (360,214)，半径 168。人开局分站圆场两侧，夹在场内。战刃走速约 172，血月约 204。点按画布轻点斩，拖走，快滑冲步。触屏底栏 上/左/下/右/斩/挡/冲。未解锁音频前无声。血月场中有赤月，余烬更红。

对决：斥候 34 血、斩快、爱冲进来、几乎不格挡；铁卫 50 血、持盾、爱格挡（约 72% 读斩），重斩可破防；血骑 64 血、爱绕圈冲斩；刃王 122 血，半血后会放前摇更长的旋刃（360° 更痛）。血月血量 ×1.16。点斩命中约 13，蓄满重斩约 ×1.5 且破格挡；格挡成功后 0.55s 内反斩约 ×1.55；冲步落地 0.24s 内出刀为冲斩。双方同时斩中则交刃，互不扣血。冲过对方斩得「闪读」。局间战刃回 32 体、血月回 16。

得分：斩中 120×连斩倍率，反斩 280×，冲斩 200×，重斩 200×，破防 220×，格挡 160×，闪读 90，交刃 40。击倒 800+400×局 + 速胜（最多约 720），血月击倒 ×1.25。连斩为连续命中/格挡，约 1.5 秒无则断，受伤清零。倍率 = 1 + min(4, floor((连斩-1)/2))。打穿刃王 +6000（血月 +9000）。最高分写入 playbox-warblade-best，不存盘面；本局超过即更新。

胜利：战刃/血月打掉刃王后约 1.05s 结算「刃尽」。
失败：己方体力打空（冲步无敌、受伤后约 0.32s 无敌除外）。倒下约 0.7s 后弹出「刃折」。弹层打开时方向键不再走；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → ↑ ↓ / WASD 八向走，空格点斩、按住蓄重斩，Shift / Z 格挡，X / Ctrl 或双点方向冲步。点按画布斩，拖动走，快滑冲。标题 Enter/空格/1 战刃，2 血月。R 重开，M 静音。无手柄。与侍秋不同：不是侧视拔刀一维走位，是圆场顶视绕切，可蓄重斩破防。与月刃不同：不是天马射击。与魔剑不同：不是闯塔卷轴。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、少余烬。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：出刀必有三层——听（刀风噪声 / 命中方波 / 格挡金属高音 / 交刃闷锯齿 / 冲步呼啸 / 重斩低啸各不一样）、看（刀光弧、火星爆、格挡金环、蓄力圈、连斩大字、分数蹦出）、触（斩约 50ms 顿帧，反斩约 66ms，重斩约 70ms，格挡约 56ms，击倒约 74ms，加镜头微震）。连斩升档金闪、大字「N 斩」。失败与重开都是一键 R。
