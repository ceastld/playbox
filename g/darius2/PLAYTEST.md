玩法：标题页「大流2」。选「大流2」打三星（日冕 → 汞海 → 土环），每星短关之后出鱼舰（骨王 / 灯鮟 / 巨物）；选「流核」同三星但卷轴更快、编队更密、敌弹更勤、鱼舰多约 26% 血。点顶栏「重开」或按 R：标题页直接开大流2；对局中或结束层重开同一模式。结束层「再来」同模式；舰毁「换模式」回标题；通关「流核」开流核（流核通关则「换模式」回标题）。M 静音，写入 playbox-darius2-mute。方向键 / WASD 八向飞，空格开火（可按住连射），Shift / Z 或顶栏「爆」扔爆弹。画布拖动跟舰，按下开火。触屏「爆」。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 大流2、2 流核。

场地：虚拟场 1080×360（约 3:1，三屏横卷，画布上有 L/C/R 细线）。银鹰可在整幅三屏内八向飞（约 28–1052 x，20–340 y），不被钉死在左屏。大流2 巡航约 98（连击再加），流核约 142；鱼舰在屏时降到约 22–32。移速约 276（流核 318）。脉冲弹速 700 起。点按或按住空格开火。未解锁音频前无声。

路线：日冕 → 汞海 → 土环，直线三关，无航门分叉。日冕约 16.8 秒波次后出骨王；汞海约 16.4 秒后出灯鮟；土环约 17.0 秒后出巨物。打掉终关巨物即胜。顶栏关名在 Boss 时改成鱼舰名。

鱼舰与弱点：甲弹打在发光弱点上才是满伤，打躯干约 0.38 倍。骨王眼窝、灯鮟先灯后口、巨物先眼后口。半血后狂暴：节奏加快、弹更密。巨物张口时有吸力，会把银鹰往嘴里拉。

命：开局 3 命。中弹或撞机体（含鱼舰躯干）立刻扣一命，没有甲槽。约 0.92s 爆炸后重生，1.55s 闪烁无敌，敌弹清空，火力降 1 级。三命（顶栏青点）扣完弹出「银鹰坠了」。过关补 1 爆。

武装：默认火 0。吃菱形荚：火（1 发 → 双发+下导弹 → 三向+上下导弹 → 七向：前三向+后双射+上下导弹，冷却约 0.118–0.068s）、爆（+1）。火满级再吃 +400×倍率。运核机循环掉 火/爆。七向后弹向左打，清尾。

爆弹：开局 3 枚，上限 6。Shift / Z 清掉全部敌弹、全体扣血（普通 8 / 鱼舰 16），全屏闪、青环、约 78ms 顿帧，自身约 0.42s 无敌。过关补 1 枚。用尽再按提示「爆弹用尽」。

敌人：梭 50、环 80、刺 70、炮 90、鳐 120、运核 280、骨蛇 200、钻 60、鱼舰 5000，再乘连击倍率。弱点击中 +40×倍率并「弱点」金字。关清 1800，打穿 +6000。连击为连续击杀或打中弱点，约 1.32 秒无则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 16000 分 1UP，命上限 6。最高分写入 playbox-darius2-best，不存盘面；本局超过即更新。

胜利：大流2/流核打掉土环巨物后约 1.65s 结算「星路尽破」。
失败：三命扣完弹出「银鹰坠了」。中弹或撞击立刻扣命。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格开火，Shift / Z 爆弹。点按画布开火并跟舰。触屏「爆」。标题页 Enter/空格/1 大流2，2 流核。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波，导弹另有下滑锯齿。击中粒子爆开 + 短顿帧（约 30–52ms）+ 镜头微震 + 连击数字往上窜。打弱点：金闪、琶音、「弱点」蹦出、约 52ms 顿帧。爆弹三层：听（噪声 rumble + 下滑锯齿）、看（全屏青闪、金环、边框、敌弹碎光）、触（约 78ms 顿帧 + 强震）。七向解锁有提示与舰身金环。鱼舰大爆 + 更长顿帧。坠机洋红大爆。失败与重开都是一键 R。
