玩法：标题页「秘窟」。选「寻宝」打四窟（初窟 → 蛇窟 → 魔窟 → 龙窟），每窟六间房各一件宝物，收齐并回到走廊进下一窟；选「追逼」同样四窟，廊兽来得更早、更快、更多。四向走，空格朝面射击，场上同时只有一发。点「重开」或 R：标题页进寻宝；对局中或结束层重开同一模式。M 静音，写入 playbox-venture-mute。弹层打开时方向键不走路、空格不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：走廊 21×13。上下各三间房（5×4 箱），箱内不可走，只能从门格走进去切到房间视野。走廊在第 5–7 行贯通，人出生在 (10.5, 6.5)。人半径约 0.28 格，速度约 4.58 格/秒。进门切 17×11 房间，门在北或南墙正中；房间底栏有整窟小图。出门若门口有活怪或廊兽，会被顶回并提示「门被堵住了」。

寻宝：初窟廊兽 13.5s / 间隙 7.6s / 房内 16.5s / 移速 1.78 / 最多 2 只；蛇窟 12 / 6.8 / 15 / 1.96 / 2；魔窟 10.8 / 6.2 / 13.5 / 2.14 / 2；龙窟 9.6 / 5.4 / 12 / 2.34 / 3。过窟保留命和分数。追逼：计时 ×0.5（房内 ×0.56），廊兽移速 ×1.38，上限 +1，房怪移速 ×1.12。

房间：蛛厅 / 蛇窖 / 双头房 / 骸室 / 巨魔厅 / 龙巢，宝物金杯→王冠→神像→宝箱→钻石→圣物。怪会追人。双头、巨魔、龙要两发。廊兽不可击杀，箭打上只迸火花。廊里耽搁出廊兽；房里耽搁廊兽从门挤进来。

得分：击杀掉落×倍率（蛛 40 / 蛇 60 / 骸 80 / 双头 120 / 巨魔 140 / 龙 180）。宝物 (基础 + 窟×40)×倍率。连击窗口 1.52s，倍率 = 1 + min(4, floor(连击/2))，最高 5 倍。清窟 +500+120×窟号。打穿四窟按剩余命 ×200。最高分写入 playbox-venture-best，不存盘面；本局超过即更新。

胜利：寻宝打穿弹出「秘窟探尽」；追逼打穿弹出「追尽了」。
失败：三命（顶栏橙点）扣完弹出「撞上了 / 廊兽吞了 / 堵在门里」。还有命则闪回（房内回到门内侧，廊里回到中心），约 1.42s 无敌闪烁。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、不连环大字。触控有十字键和「射」；滑动或点按棋盘时 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：开火枪口粒子与箭光；命中splat粒子 + 50–80ms 顿帧 + 镜头微震；宝物金琶与爆光；廊兽出现刺音与板面 sting；连击倍率上窜并弹出 ×N；门口堵住有闷响。
