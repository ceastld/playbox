玩法：标题页「队长」。先点拳 / 忍 / 枪 / 婴（或 1–4）选队员，近战射程与短技不同。选「巷战」打三关（罪城→馆廊→星舰，罪城出巨腕、馆廊出铁卫、星舰出帝甲）；选「机潮」按潮出兵，越往后越密，机甲更多，每 4 潮出巨腕、每 6 潮出铁卫、每 8 潮出帝甲。侧向走跳，空格近战，Shift/Z 短技。点顶栏「重开」或按 R：标题页进巷战；对局中或结束层重开同一模式第 1 关 / 第 1 潮。结束层「再来」同模式；失败「换模式」回标题；巷战通关「机潮」开机潮。M 静音，写入 playbox-captain-commando-mute。弹层打开时方向键不走路、空格不打（标题空格/Enter 开巷战）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 Y=318，上跳约 62px。左右走、上跳，镜头跟在人右侧。巷战三关长度 2400 / 2560 / 2220。头目未倒走进其约 380 范围内镜头锁成擂台。机潮场地宽 2140，潮次在镜头外左右刷出，部分机甲从空中落下。

巷战三关：罪城（匪、铳、机甲、箱子与电池急救，尽头巨腕 24 血前摇后冲撞砸地）/ 馆廊（机甲更多，尽头铁卫 30 血胸口光加冲撞）/ 星舰（铳机混编，尽头帝甲 36 血三向光球并砸地）。过关保留命、体、能、分，补 4 点体力与 1 能。机潮同罪城街景，第 n 潮人数 min(16, 5+⌊1.1n⌋)，速度约 ×(1+0.05×(n−1))，血量 ×(1+0.08×(n−1))。

四队员：拳射程 32、挥得最快、短技火拳短弹；忍射程 48 最长、短技三枚手里剑；枪射程 40、近战是枪口短爆、短技飞刀；婴射程 28 最短但伤害高、短技滚撞穿人。空中打一次。连击窗口约 1.44 秒。能量上限 3，开局 2，电池 +1，约 16 秒回 1，击杀偶掉电池。箱子打爆有时掉电池或急救，急救回 5 体。

敌人：匪贴脸拳 3 血；铳远射 3 血，子弹胸口高度，跳过去；机甲走地 5 血胸口光，跳开再打；巨腕冲砸 24 血（机潮随潮加血），前摇后直线撞，跳起能躲；铁卫 30 血双光加冲；帝甲 36 血三向光球加砸地（站地吃全额）。体力条打空扣一命；约 0.82s 后原地满体重生，1.35s 闪烁无敌。三命扣完弹出「倒了」。

得分：命中 42×连击倍率（击倒约 ×1.4），击杀匪 170 / 铳 250 / 机 360 / 巨腕 3800 / 铁卫 5200 / 帝甲 7800×倍率，过关 1500×关，清潮 650×潮，电池 100，急救 130，箱子 80。连击为连续命中，约 1.44 秒无命中则断。倍率 = 1 + min(4, floor((连击-1)/2))。每 20000 分 1UP，命上限 6。最高分写入 playbox-captain-commando-best，不存盘面；本局超过即更新。选队员写入 playbox-captain-commando-hero。

失败：体力打空扣一命（无敌除外）。约 0.82s 后原地满体重生，1.35s 闪烁无敌。三命扣完弹出「倒了」。弹层打开时方向键不再打；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳，空格 / 点画布打，Shift / Z / 触屏「技」短技。触屏 左 / 跳 / 右 / 打 / 技。标题 1–4 选队员，Enter/空格巷战，顶栏或按钮开机潮。R 重开，M 静音。无手柄。与神龟不同：没有井盖冒兵、没有披萨，是队员短技、走地机甲和巨腕砸地。与变种不同：不是爪冰闪眼，是拳忍枪婴、火拳手里剑飞刀滚撞。与制裁不同：不是捡枪扫街，队员自带不同近战。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不顿帧、不抖屏、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

爽感：打必有三层——听（拳能爆 / 忍刃刮 / 枪口脆 / 婴机甲闷响各不一样）、看（队员色屑、闪光、分数蹦出）、触（约 46–70ms 顿帧 + 镜头踢）。短技更沉：火拳短弹、手里剑扇出、飞刀穿透、滚撞穿人。击倒更沉，机甲倒地金属响。连击升档金闪、大字 ×N。失败与重开都是一键 R。
