玩法：推箱子。人走进箱子就把它往同一方向推一格；没有拉。一次只能推一箱，前面是墙或另一箱就顶住。人不能穿墙、不能走进箱子（除非这一步把箱子推开）。所有箱子都压在印记上即过关，弹出「入位了」。点开先见标题，开推后开局。

操作：方向键或 WASD 走一格。棋盘上滑动（阈值 24px）或点邻格。点空地若走得到会自动绕路（不推箱）；点贴身且可推的箱子即推。U 或 Z 撤销本关任意步，撤销栈只活在本关。R 重开本关。M 静音，写入 playbox-soko-box-mute。触屏另有十字键。过关层回车 / 空格 = 下一关。

关卡模式：十二关手作，难度递增。直入 → 绕后 → 拐角 → 折墙 → 双印 → 分道 → 侧门 → 三连 → 夹壁 → 深巷 → 锁箱 → 终局。顶栏菱形点可进已过关与当前关。过关写入 playbox-soko-box-cleared 的 n（已过关数）。下一关按钮进下一关；第十二关后再来一轮从第一关。

每日：本地日历日做种子，生成 8×6 内场（外墙共 10×8）三箱三印。先随机内墙再从已解状态反拉，BFS 在时限内找不到解就丢弃；时限内反复失败则改用手作「闲局」。每日一图，过关记下日期。可重开今日，不能改种子。

限制：不能拉、不能推两箱、不能穿墙。本关撤销次数不限，换关或重开清空。减少动态时格子瞬移。声音要先有一次按键或点击。
