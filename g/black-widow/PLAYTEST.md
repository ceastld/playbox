玩法：标题页「黑蛛」。选「蛛网」打八波（入网→蚊群→甲行→产卵→雷虫→合围→狂孵→终网），清完弹出「网清了」；选「虫潮」虫子更快、一波接一波直到没命。双摇杆：WASD 走、方向键或 IJKL 射，完全分开。点「重开」或 R：标题页按当前模式开局（默认蛛网）；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-black-widow-mute。弹层打开时 WASD 不走路、方向键 / IJKL / 鼠标不开火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 720×540，正六角蛛网半径 248，尖顶朝上。人半径 11，移速约 198，只能在网内走。弹速约 540，连射间隔约 0.068s，场上己弹最多 14，出网即灭并拨弦。虫子从六边弹入，撞网边反弹并拨弦。标题页背后是演示游网，不算分、不掉血。

蛛网八波：入网 6 蚊 + 1 蛆；蚊群加甲；甲行加蜂；产卵蜂开始在「食」上生卵；雷虫出爆炸虫；后面合围 / 狂孵 / 终网叠清虫与雷虫。过波保留命和分数。虫潮：同类编制、移速约 ×1.28 且每波再加速，无终局胜利。

虫子：蚊（Mosquito）快、弹边飞，击中变「食」。甲（Beetle）追「食」吃掉，击中也变「食」。蜂（Hornet）追「食」并在其上产卵。卵（Egg）约 4.8s（虫潮约 3.4s）孵成蚊或蜂；人走过去推，子弹也能撞开；甩出网外得 500 / 1000 / 1500 / 2000 / 2500（本波连踢）。蛆（Grub）慢爬追人，越早打越高分（500 落到 50）。雷虫（Grenade）击中爆炸，半径内虫子和卵各 500。清虫（Bug Slayer）对人无害、无敌，抢食抢虫。碰到蚊 / 甲 / 蜂 / 蛆 / 雷虫即掉命；卵、「食」、清虫不伤人。清波只要求场上没有卵和除清虫以外的活虫。

食：击杀会掉「食」的虫子留下金色食饵，人碰到 +200×倍率。甲会吃掉，蜂会产卵。

得分：击杀基础分 × 连击倍率。蚊 100、甲 200、蜂 300、蛆 50–500、雷虫 400、爆炸波及 500、踢卵 500 起、食 200。连击窗口 1.24s，倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 ×1、4–6 连 ×2，最高 ×5。清波 +200×波次×倍率。蛛网通关再 +5000。每 20000 分 1UP，命上限 6。最高分按模式分记，写入 playbox-black-widow-best，JSON `{web,swarm}`；本局超过即更新。

胜利：蛛网打完第 8 波终网弹出「网清了」。虫潮没有清盘。
失败：三命（顶栏紫点）扣完弹出「撞上蚊子了 / 甲虫咬到了 / 黄蜂扎到了 / 蛆虫贴上了 / 雷虫撞上了」。还有命则在场心重生，约 1.55s 无敌闪烁。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：WASD 八向走，与射击完全分开。鼠标瞄准（按住画布连射），或方向键 / IJKL 第二套方向键射（可八向），或空格朝当前瞄准连射。触屏左摇杆走、右摇杆射（右杆推开即连射）。手柄左摇杆走、右摇杆射。标题页 蛛网 / 虫潮。顶栏可选模式；标题 Enter 按当前模式开局，1 蛛网、2 虫潮。R 重开，M 静音。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、不连环大字。触控画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：开火枪口闪 + 短丝弹音；击中splat粒子 + 30–80ms 顿帧 + 镜头微震 + 连击数字往上窜；虫子撞网边拨弦闪光 + 三角波拨弦音；踢卵出网金爆 + 上升音阶；雷虫范围炸。
