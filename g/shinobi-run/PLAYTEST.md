玩法：标题页「忍」。选「营救」打三层（码头→夜巷→据点，救完人质后头目现身）；选「夜袭」敌更快更密，每层只有 1 次忍术。侧向走跳，空格近处挥斩、远处掷手里剑。救出本层全部人质后尽头结界打开、头目激活。点顶栏「重开」或按 R：标题页进营救；对局中或结束层重开同一模式第 1 层。结束层「再来」同模式；失败「换模式」回标题；通关「夜袭」开夜袭。M 静音，写入 playbox-shinobi-run-mute。弹层打开时方向键不走路、空格不斩；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 86 高，能上一层，不能从地面直上高层。镜头跟在人右前方，高层略上抬。地面有缺口，掉出屏幕底丢命。中高层平台可单向落（↓ / S 掉落），地面不能掉穿。人质未救完时尽头洋红结界挡住，提示「还有人质」。

营救三层：码头（人质 4，赤面 10 血）/ 夜巷（人质 4，双刃 14 血，有忍术卷轴）/ 据点（人质 5，影忍 18 血，会瞬移，有卷轴）。过关保留命、分。夜袭同三层，速度约 ×1.34，枪兵更勤，额外补兵，开局忍术 1（营救 3），每层重新补满。

忍术：Z / X / Ctrl / 触屏「忍」。清掉镜头内杂兵，打掉头目 6 血，清敌镖。耗尽提示「忍术耗尽」。卷轴 +1，上限 5。

敌人：步兵巡逻 100；枪兵点射 200；跳忍两刀 300；追兵贴脸 150。头目走动抛镖，残血更密，据点会瞬移。击破头目再加 4200×倍率，过关 +1600×层。营救打掉据点头目后再加 8000，弹「城池已破」；夜袭弹「夜袭得手」。

得分：击杀/救人基础分 × 连击倍率。连击为连续击杀或救人，约 1.4 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))。每 15000 分 1UP，命上限 6。最高分写入 playbox-shinobi-run-best，不存盘面；本局超过即更新。

失败：挨打 / 中弹 / 坠崖扣一命（斩击打中该敌人的这一下不挨打；无敌除外）。约 0.78s 后在最近救出人质处（或层首）重生，1.35s 闪烁无敌。三命扣完弹出「被击中了 / 中弹了 / 坠入深渊了」。弹层打开时方向键不再斩；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳（空格不跳），↓ / S 从平台掉落，空格近斩远镖，Z 忍术。点按画布同空格。触屏左 / 跳 / 斩 / 右 / 忍。标题页 营救 / 夜袭，Enter/空格/1 营救，2 夜袭。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：斩必有三层——听（刀风噪声+下扫锯齿）、看（洋红弧、金屑、分数蹦出）、触（约 55ms 顿帧 + 镜头踢）。手里剑命中青响 ping、火花。忍术洋红闪、全屏环、约 80ms 顿帧。救人金鸣。连击数字往上叠。失败与重开都是一键 R。
