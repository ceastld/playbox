玩法：标题页「武装狮」。选「武装狮」走三关（狮原 → 钢脊 → 核庭）各打一个核心 Boss，最后碎狮核；选「狮核」同图更快更密、敌弹更勤、Boss 多约 22% 血。点顶栏「重开」或按 R：标题页直接开武装狮；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-r-type-leo-mute。←↑↓→ / WASD 八向飞，空格按住连发宽幅扇弹。Shift / Z / 右键 / 触屏「激」打出比特激光。画布按下跟舰并射击。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter/空格 武装狮、2 狮核。没有力爪，和武装 / 武装2 不是同一套。

场地：虚拟场 800×450。世界 `cam` 向右滚，战舰钉在画面左侧可八向移动（夹在约 24–360 x、18–432 y，并被谷壁再夹一层）。武装狮巡航约 104、狮核约 152；Boss 在屏时再降到约 12–20。移速约 270（狮核 312）。扇弹 640，比特弹 560。未解锁音频前无声。三关名：狮原、钢脊、核庭；顶栏在 Boss 时改成 Boss 名（金瞳 / 脊环 / 狮核）。

比特：开局双比特贴在舰上下约 20。没有力爪对接。开火时比特跟着打青色细弹，会略微朝最近敌人偏转。第三枚 B（激光已满时）加第三比特，停在舰后。比特半径约 11 挡普通小弹，挡不住 Boss 粗弹。撞比特不掉命，撞机体才掉命。

宽幅扇弹：空格按住连发，间隔约 0.085s（狮核约 0.067s）。扇 0 三向（约 ±0.20 rad），扇 1 五向，扇 2 五向且每发伤 2，扇 3 七向。吃金色 W 胶囊加一档，上限 3。坠机掉 1 档扇，比特留下。

比特激光：能量槽 0–1，回充约 0.34/s。Shift / Z / 右键 / 触屏「激」消耗约 0.52，打出约 0.44s 的双（或三）道贯穿激光，伤 3，穿无限。能量不够不出。出激光时顿帧、全屏青闪、顶栏徽章跳成「激射」。B 胶囊回约 0.55 能量。

地形：噪声生成上下谷。狮原金柱从顶或底伸出；钢脊锯齿；核庭台阶，Boss 进场谷至少约 410。每关约 1680 世界单位后出 Boss。地形撞机体即死；无敌时会被推回谷内。

敌人：战斗机 50、炮台 80、俯冲机 70、炮舰 160、旋晶 140、核螨 90、Boss 4000/6500/10000，再乘连击倍率。关清 +2000。武装狮打穿三关再 +4500。炮台贴壁瞄准。炮舰三发散。旋晶四向转弹。核螨开核才打。狮核模式多 1–2 架战斗机 / 俯冲 / 核螨，射速约 1.26 倍。

Boss：狮原「金瞳」78 血（狮核约 95），闭眼挡普弹，睁眼才是弱点，扇弹；比特激光可硬打闭眼。钢脊「脊环」96（约 117），环炮自转，半血后吐粗弹。核庭「狮核」132（约 161），六枚青比特盾绕核，盾可打掉；核张开才好打，激光可穿盾。半血后狂暴。过关 toast 用关名，如「狮原肃清」。

得分：击杀基础分 × 连击倍率。连击为连续打中（含削血），约 1.28 秒无击中则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 15000 分 1UP，命上限 6。最高分写入 playbox-r-type-leo-best，不存盘面；本局超过即更新。

胜利：武装狮/狮核打爆第 3 关狮核后约 1.35s 结算「狮核崩解」。结算前不再掉命。
失败：三命（顶栏金梭）扣完弹出「舰毁了」。撞壁、撞敌、中弹（比特未挡住的）都扣一命。约 0.90s 爆炸后在当前谷中重生，1.45s 闪烁无敌，敌弹清空。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格连发扇弹，Shift / Z 比特激光。点按画布跟舰并射击，右键激光。触屏「激」。标题页 Enter/空格/1 武装狮，2 狮核。R 重开，M 静音。无手柄。无自动。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、激光不拖波纹。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：扇弹枪口闪 + 升频方波。比特细弹三角波。激光三层：听（噪声+锯齿）、看（双道青金贯穿、全屏闪、徽章跳「激射」）、触（约 52ms 顿帧 + 镜头微震）。击杀粒子 + 连击数字往上窜、倍率金字。坠机橙红大爆、约 72ms 顿帧并震屏。失败与重开都是一键 R。
