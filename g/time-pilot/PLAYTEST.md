玩法：标题页「时飞」。选「时飞」打五个时纪（飞鸢纪 1910 → 铁鹰纪 1940 → 旋桨纪 1970 → 银箭纪 1982 → 星核纪 2001），每纪击坠够数出头目，打爆后跃迁下一纪；选「时核」同时纪但出机更密、射速更快、头目血更厚。点顶栏「重开」或按 R：标题页直接开时飞；对局中或结束层重开同一模式。结束层「再飞」同模式；机坠「换模式」回标题；时飞通关「时核」开时核。M 静音，写入 playbox-time-pilot-mute。←↑↓→ / WASD 环飞（机头转向并始终前飞，松开保持航向），空格 / 点按朝机头开火（可按住连射，场上最多 4 发）。画布拖动按相对场心方向飞。触屏左下摇杆环飞、右下开火。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 时飞、2 时核。

场地：虚拟场 800×480 横场。玩家钉在画面中心，世界反向卷动，不是纵版穿云、不是冲进画面、不是谷中爬升。航向 9.6 rad/s 转向，时飞常速 198、时核 226。子弹 520，寿命约 0.72s；时飞冷却 0.12s，时核 0.095s。未解锁音频前无声。世界坐标过大时整场回零，避免精度漂。

时纪与头目：飞鸢 / 双翼 / 飞鲸 18/26 血；铁鹰 / 战机 / 铁堡 22/32；旋桨 / 直升 / 旋巢 26/38；银箭 / 喷气 / 银鲨 30/44；星核 / 飞碟 / 时核 36/52。时核取更高血量。每纪击坠 16（时核 22）后出头目；编队（5 机 V 字，约 2.15s 后散开追）、王牌绕飞再俯冲、轰炸机 3 血会穿插。时核头目战会补护卫。

敌人：侦察 80、编队 100、王牌 150、轰炸 200、护卫 120；头目 2200/2800/3400/4200/5400。再乘连击。头目削血每次 +10。敌弹不可打，时飞场上最多 10、时核 16。约 22% 侦察/编队/王牌掉伞员，贴身救起 500×连击。

跃迁：打爆头目后清场，约 1.65s 时环外扩 + 全屏闪 + 纪名，过关 +600×纪号（飞鸢 600 … 星核 3000）。

得分：击杀基础分 × 连击倍率。连击为连续打爆或救伞，约 1.36 秒无击杀则断；自身中弹立刻断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。通关 +8000（时核 +10000）+剩余命×400。每 12000 分 1UP，命上限 6。最高分写入 playbox-time-pilot-best，不存盘面；本局超过即更新。

胜利：打爆星核纪头目「时核」后跃迁结算「时环打穿」/「时核通关」。
失败：三命（顶栏青点）扣完弹出「机坠了」。撞机体或中弹扣一命。约 0.92s 爆炸后原地续飞，1.65s 闪烁无敌，场上敌弹清空。弹层打开时方向键不再开打；顶栏重开与 R 随时可用。

操作：←↑↓→ / WASD 环飞，空格开火。点按画布开火并按场心方向飞。标题页 Enter/空格/1 时飞，2 时核。R 重开，M 静音。无手柄。无自动。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、子弹不拖尾。触控时画布与摇杆 `touch-action: none` 并 preventDefault，避免页面跟着滚。标题页是演示环飞，不算分。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波；击中粒子爆开 + 短顿帧（约 32–74ms）+ 镜头微震 + 连击数字往上窜；爆炸碎屑与光环；救伞金闪；跃迁时环拉长、全屏闪、纪名砸出。失败与重开都是一键 R。

什么变难：后纪机体更快、射更勤、同屏更多。王牌会绕圈再俯冲；轰炸 3 血并双发；头目各有游走/散射/环弹/冲掠。时核更密，弹更勤，头目更厚，头目战会补护卫。连击会让分数往上窜。
