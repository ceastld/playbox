玩法：标题页「魔城3」。选「魔城3」打三程（瓦村 → 分岔后的钟塔或沉船 → 血堡；关底木乃伊 / 时钟魔或船骸 / 伯爵，伯爵打空后化兽再打最终形态）；选「城核」敌更快更密，额外补跳蚤与夜枭（骨柱不加倍），头目血约 ×1.22。侧向走跳，空中锁方向（硬跳）。空格 / Z 挥鞭，X 丢副武器（耗心）。点顶栏「重开」或按 R：标题页进魔城3；对局中或结束层重开同一模式第 1 程。结束层「再来」同模式；失败「换模式」回标题；通关「城核」开城核。M 静音，写入 playbox-castlevania3-mute。弹层打开时方向键不走路、空格不挥鞭；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 80 高，能上一层，不能从地面直上高层。没有 45° 斜梯，是竖直木梯：贴梯按上攀、按下离开或下到地面。镜头跟在人右前方，Boss 战与择路时锁在关底。地面有缺口，掉出屏幕底丢一条命。沉船缺口里的海水会拍人（掉 2 血并弹起），站在实心地面上不会被淹。人宽约 14、立高 26、蹲高 14。特雷走约 132，格兰特 148，西法 118。空中速度锁定起跳时的水平速度。标题页背后演示右进挥鞭跳坑，不算分、不掉血。

血条：开局 16 血，顶栏「血」+ 细条，画布左下也有一条。撞兵 / 挨弹扣 2（骨柱与头目接触、头目弹 3），击退并约 1.05s 闪烁无敌（城核 0.78s）。血扣到 0 才丢一条命，约 0.82s 后在最近扎实地面重生并回满血。坠入深渊仍直接丢命。与魔城、魔城2 的「一碰丢命」不同。三命（顶栏紫点）扣完弹出「血耗尽了 / 坠入深渊了 / 沉进海里了 / 被伯爵击倒了」。每 15000 分 1UP，命上限 6。蜡烛可掉「药」回 6 血；烤肉回满血并 1UP（命满则心 +8）。最高分写入 playbox-castlevania3-best，不存盘面；本局超过即更新。

分岔：瓦村木乃伊倒下后不立刻过关，关底亮两座门。走进左门「钟塔」招募格兰特（可贴墙滑、再跳蹬出，攻击收成短刃）；走进右门「沉船」招募西法（挥鞭改冰术，冻敌约 1.15 秒）。C 或顶栏「换」在特雷与同伴之间切换。过关保留命、血、心、鞭长、副武器、同伴、分。城核同三程，速度 ×1.28 并随关递增，额外补兵，Boss 血约 ×1.22，开局仍是皮鞭、仍要在瓦村择路。击破头目 +4500×倍率，过关 +2000×关。魔城3 打掉最终伯爵后再加 9000，弹「魔城3已破」；城核弹「城核平了」。

鞭：空格或 Z 挥一次，落地挥鞭时不能走。特雷 皮鞭 36 / 锁链 58 / 火鞭 82（橙梢，伤害 2）；格兰特短刃约 0.72 倍长、出手更快；西法冰术固定约 54、伤害 1 并冻结。蜡烛掉「鞭」升级火鞭。副武器：飞斧抛物线（可穿 1、伤害 2）、匕首直线、圣水落地燃池持续灼烧，均耗 1 心；怀表耗 5 心，时停约 2.8 秒（敌与头目、敌弹冻结，人仍可走打）。无副武器或心不够会 toast。

敌人：僵尸慢走 100；跳蚤扑跳 160；夜枭正弦再俯冲 150；骨柱定点抛骨 220；幽灵仅沉船/血堡正弦穿雾 200。Boss 木乃伊甩绷带、时钟魔丢齿轮、船骸喷涎并可残血补幽灵、伯爵瞬移喷火 → 化兽冲撞 → 最终三向焰再俯冲。与魔城不同：不是 45° 梯打城门地窟，没有十字回旋，不是一碰丢命。与魔城2 不同：没有昼夜、鬼桥、荆鞭、钻石与木桩遗物。与鬼铠不同：没有碎甲内裤，是鞭/冰/短刃加血条。

钟塔：齿轮平台左右挪，人站上去会跟着走；墙柱可贴（仅格兰特）。沉船：海水起伏，细雨。血堡：红月，伯爵三形态。

得分：击杀/打蜡基础分 × 连击倍率。连击为连续击杀或打蜡，约 1.36 秒无动作则断；挨打立刻断。倍率 = 1 + min(4, floor((连击-1)/3))。

失败：血空 / 坠崖扣一命。弹层打开时方向键不再挥鞭；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳（梯口上楼），↓ / S 蹲或下梯，空格 / Z 挥鞭，X 副武器，C 换同伴。点按画布同挥鞭。触屏 跳 / 鞭 / 副 / 左 / 下 / 右，顶栏「换」切同伴。标题页 魔城3 / 城核，Enter/空格/1 魔城3，2 城核。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：挥鞭必有三层——听（抽响噪声+下扫；西法是冰晶铃）、看（橙火鞭梢 / 青短刃 / 冰柱、蜡火爆开、分数蹦出）、触（约 34–72ms 顿帧 + 镜头踢）。打蜡金鸣+粒子爆。挨打红闪+击退+「—n」数字。副武器出手全屏闪：飞斧沉啸、圣水池紫焰、怀表青停。连击数字往上叠。择路两座门脉动。伯爵化兽/最终有变身轰鸣与全屏闪。失败与重开都是一键 R。
