玩法：标题页「闪击」。选「闪击」打三关（霓虹湾 → 灯廊岛 → 闪核城），每关中 Boss 与关底 Boss；选「云海」同三关但卷轴更快、编队更密、敌弹更勤、Boss 多约 22% 血、额外补波。点顶栏「重开」或按 R：标题页直接开闪击；对局中或结束层重开同一模式。结束层「再来」同模式；机毁「换模式」回标题；通关「云海」开云海（云海通关则「换模式」回标题）。M 静音，写入 playbox-flash-gal-mute。方向键 / WASD 八向飞，空格开火（可按住连射），Shift / Z 或顶栏「闪」放闪爆。画布拖动跟机，按下开火。触屏右下「闪」放闪爆。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 闪击、2 云海。

场地：虚拟场 480×720。闪光女战机开局 y=630、x=240，夹在 22–458 / 40–692。闪击巡航约 80（关卡与连击再加），云海约 112；中/关底 Boss 在屏时降到约 26–34。移速约 274（云海 312）再加火力等级，8 连再加 12。闪光针相对机向上 700。点按或按住空格开火。未解锁音频前无声。机心金脉约 80ms 一拍高频 pulse。移动留金残影。

两层：空中单位（闪侦、金影俯冲、翼灯机、运闪）撞机扣命；地面单位（灯塔、霓虹拱、中/关底 Boss）可飞越，只吃它们的对空弹。玩家闪光针打空打地都结算。闪爆是机位径向闪光，不是投弹、不是穿云裂柱。

火力：开局 0 级双针，冷却约 0.108s。吃菱形「闪」胶囊加宽：1 三叉 0.097s、2 五向 0.086s、3 七向 0.075s、MAX 七向 + 双闪核（伤 2、记 2 痕）0.064s。满级再吃若闪未满则闪 +1（上限 6），否则 +500×倍率。运闪机必掉闪。被弹若有火力会掉一枚闪可再捡，火力归零，闪爆库存重置为 3。顶栏闪条跟等级走，MAX 时爆亮。

闪痕：每发命中记 1 痕（闪核记 2）。满 3 痕立刻爆链：额外 1 伤，金环跳到约 78 范围内邻机 +1 痕，可再爆。连跳蹦「N 闪链」。约 1.38 秒无击杀断连。

闪爆：Shift / Z / 顶栏「闪」/ 触屏「闪」，库存 3 枚（上限 6），冷却约 0.48s。机位半径约 210 白金闪光：清弹变星屑（捡 +15×倍率）、范围内眩敌约 0.92s（停射、描金环）、空中 3 伤 / 地面 4 伤并立刻满痕触发爆链。自身约 0.52s 无敌并爆残影。全屏白闪 + 金叉电 + 约 62ms 顿帧。过关补 1 枚。用尽再按提示「闪爆用尽」。

关卡：第 1 关霓虹湾中 Boss「湾灯台」44 血、关底「霓虹闸」104；第 2 关灯廊岛「灯廊炮」56 / 「灯塔堡」132；第 3 关闪核城「核门卫」70 / 「闪核」184。云海血量 ×1.22。中 Boss 在场时波次计时暂停。编队 V 字闪侦、侧翼切入、金影俯冲、翼灯机、灯塔、霓虹拱、运闪机。霓虹闸半血后扇扫；灯塔堡旋转弹幕；闪核双环弹+瞄准。空中机体相撞扣命。

得分：击杀基础分 × 连击倍率。闪侦 50、俯冲 90、翼灯 140、灯塔 160、霓虹拱 180、运闪 300、星屑 15、中 Boss 2000、关底 4000+1500×关。连击为连续击杀，约 1.38 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。击坠关底再加 1500×关。三关打穿 +8000（云海 +10000）并「闪击尽破 / 云海尽破」。每 20000 分 1UP，命上限 6。最高分写入 playbox-flash-gal-best，不存盘面；本局超过即更新。

胜利：闪击/云海打掉第 3 关闪核后约 2.05s 结算胜利。
失败：敌弹碰到自己，或空中机体相撞，扣一命（重生无敌与闪爆期间除外）。约 0.95s 爆炸后重生，1.55s 闪烁无敌，场上敌弹清空。三命（顶栏金星点）扣完弹出「机毁了」。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格射击，Shift / Z 闪爆。点按画布开火并跟机。标题页 Enter/空格/1 闪击，2 云海。R 重开，M 静音。无手柄。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾、残影不跟、闪爆不叉电。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 升频方波。击中粒子爆开 + 短顿帧（约 34–72ms）+ 镜头微震 + 连击数字往上窜。三记闪痕爆链金环跳闪。闪爆三层：听（噪声 + 低锯齿 rumble + 下滑方波）、看（白金全屏闪、叉电、残影爆）、触（约 62ms 顿帧 + 强震）。吃闪金闪。满级「MAX」蹦字。坠机洋红大爆、约 78ms 顿帧。失败与重开都是一键 R。
