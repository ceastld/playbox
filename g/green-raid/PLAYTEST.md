玩法：标题页「绿兵」。选「突围」打四营（哨所→港口→铁桥→监狱，狱长在监狱现身）；选「夜袭」敌更快，侧翼更密，狱长更厚。侧向走跳，Z 近处刺刀一击、远处有弹药则开火。步枪 8 发、火箭 3 发，打完回到匕首。点顶栏「重开」或按 R：标题页进突围；对局中或结束层重开同一模式第 1 营。结束层「再来」同模式；失败「换模式」回标题；通关「夜袭」开夜袭。M 静音，写入 playbox-green-raid-mute。弹层打开时方向键不走路、Z 不刺；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 86 高，能上一层，不能从地面直上高层。镜头跟在人朝向一侧，狱长战时锁在关底。地面有缺口（河），掉出屏幕底丢命。中高层平台可单向落（↓ / S 掉落），地面不能掉穿。人宽约 14、高 26。走约 226，空中约 0.9。标题页背后演示右进刺刀，不算分、不掉血。

突围四营：哨所（步枪箱）/ 港口（火箭、步枪）/ 铁桥（步枪、火箭）/ 监狱（狱长 20 血，夜袭 24）。过关保留命、分、当前枪弹。夜袭同四营，速度约 ×1.32 并随营递增，开局额外侧翼兵，侧翼刷新更快。

武器：默认匕首，近处一击斩。近处优先刺，远处有弹药才开火。步枪 0.15s 一发、屏上约 4 发。火箭 3 发，爆炸范围伤，狱长也吃。打空提示「匕首」。死亡重生丢枪变回匕首。

敌人：步兵巡逻 100；侧翼绕背 150；军犬贴地冲 150；迫击炮抛弧 200；碉楼点射 250；跑兵冲脸 120；军官 300。狱长走动射击，残血双弹并招侧翼。击破狱长再加 5000×倍率，过关 +1800×营。突围打掉狱长后再加 8000，弹「监狱已破」；夜袭弹「夜袭得手」。

得分：击杀基础分 × 连击倍率。连击为连续击杀，约 1.38 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))。每 15000 分 1UP，命上限 6。最高分写入 playbox-green-raid-best，不存盘面；本局超过即更新。

失败：正面被刺扣一格体力（两格扣完丢命）；背后偷袭 / 中弹 / 坠河直接丢一命（无敌除外）。约 0.8s 后在最近扎实地面重生，1.35s 闪烁无敌，枪变回匕首。三命（顶栏绿点）扣完弹出「被刺中了 / 背后偷袭了 / 中弹了 / 坠入河里了」。弹层打开时方向键不再刺；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳，↓ / S 从平台掉落，Z 刺或开火（空格同刺，标题页空格/Enter 开突围）。点按画布同 Z。触屏 左 / 跳 / 刺 / 右。标题页 突围 / 夜袭，Enter/空格/1 突围，2 夜袭。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：刺刀必有三层——听（刀风噪声+下扫锯齿）、看（金弧、绿屑、分数蹦出）、触（约 58ms 顿帧 + 镜头踢）。步枪枪口闪 + 低吼噪声。火箭爆开全屏闪、约 70ms 顿帧。捡枪金鸣。连击数字往上叠。失败与重开都是一键 R。
