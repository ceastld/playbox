玩法：标题页「侍魂」。选「侍魂」对樱巫，先赢两局（三局两胜，99 秒）；选「连斩」对燕刺，同样先赢两局但更快更密（70 秒、三连斩、花瓣更密）。点顶栏「重开」或按 R：标题页进侍魂；对局中或结束层重开同一模式第 1 局。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-samurai-spirits-mute。弹层打开时方向键不走路、空格不斩（标题空格/Enter/1 开侍魂，2 开连斩）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 720×400。地面 Y=340。人开局 x=168 对 x=552，夹在 42–678。侍魂走速约 152，连斩约 ×1.32。起跳约 90 高，可跃过地面下斩。点按画布轻点斩，上滑跳，左右滑走。触屏底栏 左 / 跳 / 右 / 蹲 / 斩 / 气。未解锁音频前无声。落日鸟居场，连斩花瓣更密更粉。

对决：魂丸 96 血（连斩 84）。樱巫 96 血、爱绕跳、会放弧月；燕刺 84 血、更快更凶、更会交刃砸锁。空格点斩，命中后可取消成二斩；连斩模式二斩命中后再取消三斩（击倒）。下+斩为下斩（低、击倒，可跳过）。跳中斩一次。刀光相交则进入刃锁约 0.85 秒，连砸空格比次数，胜者压刃可跟刀；次数相同则两立互推。怒气 0–100，主要靠挨打涨（也有少量打中），Shift / Z 花 50 放弧月斩（跃起上斩）；气满花 100 放旋风烈斩（近身三连旋斩）。伤害随当前怒气放大（满怒约 ×1.5）。气不足出刀提示「气不足」。出刀落空恢复很长，空斩会被罚。

回合：体力 0 即该局负，KO 后约 1.85 秒进下一局或结算。时间到比谁血多，平局重打该局不记分。先赢 2 局赢场。同归于尽重打该局。

得分：斩 90、二斩 140、三斩 180、跳斩 110、下斩 100、弧月 280、旋风每段 160，乘连斩倍率。刃锁胜 80，两立 40。连斩约 1.15 秒不断（连斩模式约 1.5），倍率 = 1 + min(4, floor((连斩-1)/2))，即 1–2 连 1 倍、3–4 连 2 倍，最高 5 倍。KO +1000，完美（自己满血）+2000，赢局 +400，时间胜 +600，侍魂赢场 +2200，连斩赢场 +2800。最高分按模式分记，写入 playbox-samurai-spirits-best，JSON `{v,l}`（侍魂 / 连斩）。本局超过即更新。不存盘面。

胜利：先拿 2 局后约 1.85s 结算「魂尽」（连斩「连尽」）。
失败：己方先被拿下 2 局弹出「魂折」。弹层打开时方向键不再走；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳，↓ / S 蹲，空格斩，Shift / Z 弧月或旋风。点画布斩，上滑跳。标题 Enter/空格/1 侍魂，2 连斩。R 重开，M 静音。无手柄。与末刃不同：不是月华飞波，是怒气弧月斩 / 旋风烈斩，怒气主要靠挨打涨，出刀落空恢复很长，交刃改成刃锁对砸。与侍秋不同：有跳、无格挡无闪步，是落日对刀而非一维拔刀。与红侠不同：不是清街慢镜，是一对一刀战。与战刃不同：不是圆场顶视蓄斩，是侧视跳斩 + 怒气特技。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、少花瓣。触控画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：出刀必有三层——听（刀风噪声 / 命中方波随连斩往上爬 / 刃锁金属高音 / 弧月锯齿 / 旋风低啸各不一样）、看（刀光弧、樱花、旋风尾、分数蹦出、HIT 字、大字 N 斩、满怒金气）、触（斩约 52ms / 二斩约 62ms / 弧月约 70ms / 旋风每段约 48ms / KO 约 80ms 顿帧 + 镜头微震）。刃锁金闪连砸。KO 大字 + 倒地砸屏 + 重低音。失败与重开都是一键 R。
