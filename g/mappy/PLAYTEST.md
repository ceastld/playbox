玩法：标题页选「搜家」或「群猫」。多层宅里左右走，走到地板缺口会落到蹦床上弹起；在弹到最高点时挪到邻层地板即可换层。空格甩身边的门，门板拍中猫会砸晕。搜刮收音机、电视、电脑、名画、保险箱、微波炉。碰到未晕的猫或从裂开的底层蹦床摔下去丢一条命。点「重开」或 R 开新局（标题页 R 进搜家；局中或结算重开回当前模式第 1 关）。M 静音，写入 playbox-mappy-mute。

蹦床：走到地板缺口会落到蹦床上弹起；在顶点挪到邻层地板即可上楼。↓ / S 从缺口落下（顶层走开也会落下），下落途中贴到下层地板即落地。连弹不落地会变色，第四下变成虹床（弹两层），第五下裂开约 2.2 秒；底层裂开再落下去会丢命。落地后磨损清零。虹床（关卡里的彩色井）永远弹两层、不裂。弹跳有顿挫、粒子和低音 thump。

甩门：靠近门按空格 / 触屏「门」。关门挡住走路，开门放行。甩门瞬间约 60px 宽的拍击盒打中猫会砸晕（约 55–72ms 顿帧，哥罗更短）。晕着的猫可以安全走过。连砸进连击。

赃物：走上物品即收。微波炉会微波定身全场猫约 4.4 秒，外加 1000 分和青波闪光。六件搜完过关，进入下一关（三张宅地图循环，猫加快）。摔下或撞猫扣一条命，约 0.95 秒无敌后在本关出生点重生；三命用尽弹出「命尽」。

得分：收音机 100 / 电视 200 / 电脑 300 / 名画 400 / 保险箱 500 / 微波炉 800，再乘连击。砸晕喵基 200×连击，砸晕哥罗 400×连击，微波额外 +1000，过关 +1000+250×关卡。连击约 1.52 秒内不收赃、不砸门会断。最高分按模式分记，写入 localStorage 键 playbox-mappy-best，JSON `{s,q}`（搜家 / 群猫）。本局超过即更新。

模式：搜家为三关循环的正常密度（含一只哥罗）。群猫同地图，额外猫与第二只哥罗、走得更快、晕得更短。两套最高分不共用。

操作：← → / A D 走（弹跳时也可左右挪），↓ / S 下落，空格甩门。触屏左 / 下 / 门 / 右；点画布左三一走左、右三一走右、中间甩门。标题页 Enter/空格/1 搜家，2 群猫。R 重开，M 静音。无手柄。无自动。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏。触控棋盘 `touch-action: none`，避免页面跟着滚。弹层 `pointer-events: none`（面板例外），顶栏重开与 R 随时可用。

爽感：每次弹床都有 thump + 挤压回弹 + 屑。甩门砸中必有三层：听（冲击随连击往上爬）、看（洋红 POW、金火花、分数蹦出）、触（约 55–72ms 顿帧 + 镜头踢）。收赃有 ping 和光环。微波炉定身有青波扫过。连击数字往上叠。失败与重开都是一键 R。
