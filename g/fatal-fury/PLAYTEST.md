玩法：标题页「饿狼」。选「饿狼」对白鹫，先赢两局（三局两胜，99 秒）；选「连打」对炎踢，同样先赢两局但更快更密（70 秒、三连拳、火星更密）。点顶栏「重开」或按 R：标题页进饿狼；对局中或结束层重开同一模式第 1 局。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-fatal-fury-mute。弹层打开时方向键不走路、空格不打（标题空格/Enter/1 开饿狼，2 开连打）；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 720×400。地面 Y=336。前街 / 后街双层，后街约高 22、人缩小约 0.84。人开局 x=168 对 x=552，夹在 42–678。饿狼走速约 176，连打约 ×1.3。起跳约 85 高，可跃过地面扫腿。点按画布轻点拳，上滑跳，下滑换线，左右滑走。触屏底栏 左 / 跳 / 右 / 蹲 / 拳 / 踢 / 换。未解锁音频前无声。南镇黄昏霓虹街，连打火星更密更红。

对决：赤狼 100 血（连打 86）。白鹫 100 血、爱放地波、更会换线；炎踢 86 血、更快更凶、更爱踢。空格点拳，命中后可取消成二拳；连打模式二拳命中后再取消三拳（击倒）。Shift / Z 踢。下+踢为扫腿（低、击倒，可跳过）。跳中拳或踢一次。X / C 换到另一条街：不同街的招打不中，超地波除外。气 0–100，下+拳花 40 放地面地波（贴地走，不飞空）；气满花 100 放超地波（更大、两条街都打得到）。拳+踢花 50 放燃拳（前冲拳，击倒）。气不足出波提示「气不足」。无格挡，靠换线躲。

回合：体力 0 即该局负，KO 后约 1.85 秒进下一局或结算。时间到比谁血多，平局重打该局不记分。先赢 2 局赢场。同归于尽重打该局。

得分：拳 70、二拳 110、三拳 150、踢 90、跳拳 80、跳踢 100、下拳 60、扫腿 85、地波 200、超地波 360、燃拳 280，乘连打倍率。对打 50。换线躲开正在出的招 +80。连打约 1.18 秒不断（连打模式约 1.52），倍率 = 1 + min(4, floor((连打-1)/2))，即 1–2 连 1 倍、3–4 连 2 倍，最高 5 倍。KO +1000，完美（自己满血）+2000，赢局 +400，时间胜 +600，饿狼赢场 +2000，连打赢场 +2500。最高分按模式分记，写入 playbox-fatal-fury-best，JSON `{v,l}`（饿狼 / 连打）。本局超过即更新。不存盘面。

胜利：先拿 2 局后约 1.85s 结算「狼胜」（连打「连尽」）。
失败：己方先被拿下 2 局弹出「狼败」。弹层打开时方向键不再走；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳，↓ / S 蹲，空格拳，Shift / Z 踢，X / C 换线。点画布拳，上滑跳，下滑换线。标题 Enter/空格/1 饿狼，2 连打。R 重开，M 静音。无手柄。与末刃不同：不是月下对剑，是拳踢 + 换线。与侍魂不同：没有怒气弧月、没有刃锁。与红侠不同：不是清街慢镜，是一对一双街对打。与街霸不同：没有站防蹲防、没有升龙，地波贴地走且可换线躲开，超地波才打两条街。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、少火星。触控画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：出拳必有三层——听（拳风噪声 / 踢更闷 / 命中方波随连打往上爬 / 对打金属高音 / 地波低锯 / 换线呼一声各不一样）、看（拳光弧、火星、贴地波、分数蹦出、HIT 字、大字 N 打、换线青圈）、触（拳约 38ms / 踢约 54ms / 地波约 64ms / 超波约 78ms 顿帧 + 镜头微震）。换线青闪。KO 大字 + 倒地砸屏 + 重低音。失败与重开都是一键 R。
