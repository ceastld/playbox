玩法：标题页「莱加」。选「盘击」打三关（荒丘→断崖→神殿，关底守护者）；选「疾行」敌更快、飞盘更勤，守护者更厚，生命只有 1 格——挨打即丢命。侧向走跳过断崖。J / Z 甩出飞盘，盘沿链飞到极限再收回，去程与回程各能打一次。点顶栏「重开」或按 R：标题页进盘击；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「疾行」开疾行。M 静音，写入 playbox-rygar-mute。弹层打开时方向键不走路、空格不跳、J/Z 不甩盘；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 80 高，能上一层，不能从地面直上高层。镜头跟在人右前方，守护者战时锁在关底。地面有缺口，掉出屏幕底丢命。中高层平台可落上。人宽约 14、高 26。走约 138（疾行约 ×1.12），空中可改向。标题页背后演示右进甩盘跳坑，不算分、不掉血。

盘击三关：荒丘（石兽 16 血，短盘起步）/ 断崖（翼龙 22 血，坑更多）/ 神殿（魔将 28 血）。过关保留命、生命、盘长、分。疾行同三关，速度约 ×1.30 并随关递增，额外补兵，守护者血约 ×1.20，开局生命 1 格。

飞盘：J / Z 甩一次。场上只能有一枚。去程约 420，触到极限稍停再飞回人手。短盘 82 / 长盘 108 / 神盘 136。敌人掉「盘」升级。去程与回程各算一次命中。甲兵 2 下、跳蜥 2 下、重甲 3 下、蠕虫/飞蜥 1 下。守护者多下。

敌人：蠕虫慢走 100；飞蜥正弦 150；甲兵走 200；跳蜥蹦向人 180；重甲慢走 250。守护者石兽砸地抛石、翼龙俯冲喷火、魔将丢盘冲刺。击破守护者再加 4000×倍率，过关 +1500×关。盘击打掉魔将后再加 8000，弹「荒丘已平」；疾行弹「疾行得手」。

生命：盘击 3 格、疾行 1 格，顶栏条显示。挨打扣 1（守护者 2，盘击会被打空），0 格丢一条命。坠崖直接丢命。三命（顶栏橙点）扣完弹出「生命耗尽了 / 坠入深渊了 / 被守护者击倒了」。约 0.86s 后在最近扎实地面重生，满生命，1.18s 闪烁无敌。每 15000 分 1UP，命上限 6。最高分写入 playbox-rygar-best，不存盘面；本局超过即更新。

得分：击杀基础分 × 连击倍率。连击为连续命中，约 1.4 秒无动作则断；挨打立刻断。倍率 = 1 + min(4, floor((连击-1)/3))。

失败：生命归零 / 坠崖扣一命（无敌除外）。弹层打开时方向键不再走路；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W / 空格跳，J / Z 飞盘。点按画布同飞盘。触屏 左 / 跳 / 盘 / 右。标题页 盘击 / 疾行，Enter/空格/1 盘击，2 疾行。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：甩盘必有三层——听（金属旋切+回收叮）、看（金盘链、火花、分数蹦出）、触（命中约 40–70ms 顿帧 + 镜头踢）。落地扬尘。连击数字往上叠。失败与重开都是一键 R。
