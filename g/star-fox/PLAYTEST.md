玩法：标题页「星狐」。选「星核」三短关推进（草星 → 岩带 → 隧廊），每关路程走完出头目；选「乱轨」同路线但出怪更密、冷却更短、头目血更厚、隧廊更窄。点顶栏「重开」或按 R：标题页直接开星核；对局中或结束层重开同一模式。结束层「再飞」同模式，「换模式」回标题。M 静音，写入 playbox-star-fox-mute。方向 / WASD 在二维平面飞，空格 / 点按往消失点开火（可按住连射，双管绿激光）。Shift / Z 或按住顶栏「冲」推进（耗推进槽，航线更快）。同一方向连点左右（约 0.24s 内）桶滚，约 0.46s 无敌并可打散近处敌弹。画布拖动/悬停跟机。结束层与标题层不挡顶栏重开，R 随时可用。

场地：虚拟场 800×450，伪 3D 沿轨冲进画面。玩家世界坐标 x∈[-0.92,0.92]、y∈[0.05,0.90]，钉在近景；景物从 z≈1.06 靠近，z<0.05 出画。草星是透视绿带山谷（不是棋盘），岩带是星空岩场，隧廊是回退方框且两侧会挤窄。隧廊 |x| 超过当前缝隙会撞墙扣命。未解锁音频前无声。

敌人与物：无人机 80、敌机 140（会射）、炮塔 120（2 血、地面射）、石柱 70（2 血、飞低会撞）、岩块 100（2 血）、地雷 90。金环 / 拱门 / 隧门不可打，穿心加分（200 / 250 / 180）并加连击；擦到拱柱或门框扣命。敌弹不可打，只能躲或桶滚打散（+40×连击）。头目在本关路程走完后出现，停在中距游走。

头目：草星「机甲」14/20 血，踏步瞄准弹；岩带「岩鲸」18/26 血，吐地雷并射弹；隧廊「魔面」26/36 血，四/五发散弹并偶出无人机。乱轨取更高血量。

得分：击杀基础分 × 连击倍率。连击为连续打爆或穿环，约 1.4 秒无击杀则断；自身中弹立刻断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。过关 +800。通关 +2500+剩余命×400。每 12000 分 1UP，命上限 6。最高分按模式写入 playbox-star-fox-best，JSON `{c,m}`（星核 / 乱轨），不存盘面；本局超过即更新。

胜利：打爆终关魔面，约 1.2s 爆炸后再弹「通关」。
失败：三命（顶栏橙点）扣完弹出「坠轨了」。撞近处实体、隧廊墙或中弹扣一命。约 0.8s 爆炸后重生，1.5s 闪烁无敌。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 飞，空格开火，Shift / Z 推进，连点左右桶滚。点按画布开火并跟机。标题页 Enter/空格/1 星核，2 乱轨。R 重开，M 静音。无手柄。无自动。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、机不拖尾。触控画布 `touch-action: none`。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火双管绿激光 + 升频方波。打中顿帧约 32ms 并迸绿屑。击杀粒子/环/分数蹦出，连击音高往上爬，约 42–78ms 顿帧。穿环金闪。推进时尾焰拉长、速度线加密。桶滚甩开近弹。坠轨洋红大爆、约 74ms 顿帧并震屏。僚机口头报（隼 / 蛙 / 老鸟）。失败与重开都是一键 R。

什么变难：岩带几乎没有地面可参考；隧廊两侧会挤；敌机会瞄着射；后关混出并出头目。乱轨更密，弹更勤，头目更厚。推进时航线更快、横向略钝。连击会再略加快世界速。
