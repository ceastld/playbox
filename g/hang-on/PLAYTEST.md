玩法：标题页选「赛道」或「雨夜」。摩托停在画面底部，公路向消失点卷去。← → / A D 压弯，↑ / W / 空格 / 按住画布加油门，↓ / S 刹车。点「重开」或 R 开新局（标题页 R 进赛道；局中或结算重开回当前模式）。M 静音，写入 playbox-hang-on-mute。
场地与碰撞：虚拟场 800×450，伪 3D 路段长 200。玩家横向约 ±1.08 为路面，超过即冲出（减速、扬尘）；时速约 40% 以上冲出或横向 >1.52 即摔车。来车偏移与玩家横向差小于 0.27 且纵向约 190 内即撞车。摔车时速约剩 16%、约 1.6 秒复原、65ms 顿帧，不会出局。
赛段：四段顺序 旷原 / 海崖 / 城环 / 终夜。每段约 760–920 节，段末 CHECK / GOAL 门。过门加时并切下一段，终夜冲 GOAL 胜利。
时间与分数：赛道开局 50 秒，过门 +16；雨夜 36 秒、+12，顶速更高、路更滑、车更多。超时才结束（车会滑停再弹层）。距离一直加分；超车 85×连超；疾风（时速 >82% 且在路上）每 0.7 秒一层；过门 650+；终点 2200+剩余时间。最高分按模式写入 playbox-hang-on-best，JSON `{c,r}`（赛道 / 雨夜）。
胜利：第四段冲过 GOAL。失败：时间到 0。弹层不挡 R 与顶栏重开。
操作：方向键 / WASD；点按画布加速并按左右位置压弯。标题页 Enter/空格/1 赛道，2 雨夜。结算 Enter 再冲。无手柄。无自动。
限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏。触控画布 `touch-action: none`。标题页背后是演示驶，到门会重置，不算分。
爽感：压弯时车身残影与镜头微倾；摔车粒子+顿帧+引擎闷一下；过门金闪、加时数字；超车连击音高爬升；引擎转速跟时速。失败与重开都是一键 R。
什么变难：弯道离心力把车往外甩，必须反向压弯。雨夜路滑（压弯更钝、离心更强）、更快、时间更紧、车流更密。冲出路面会摔，摔完要加速复原。
