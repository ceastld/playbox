玩法：标题页「忍四」。选「忍四」打三关（霓港→月廊→金殿，闯到尽头金主现身）；选「忍核」同三关但敌更快更密，Boss 血约 ×1.22，开局月华 1（忍四 3）。侧向走跳，按住方向约 0.16 秒进入疾跑；同向连点两次、C / Ctrl 或触屏「冲」做残月冲（约 0.22 秒短暂无敌，留下两枚残影，约 0.12 秒后爆开削 1 血）。空格永远近斩；疾跑或冲刺中斩变成更长的冲斩。空中斩中敌人会反跳，可连环空斩。闯到关底结界，族将激活。点顶栏「重开」或按 R：标题页进忍四；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「忍核」开忍核。M 静音，写入 playbox-shinobi4-mute。弹层打开时方向键不走路、空格不斩；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 256，高层 184，间距 72；起跳约 86 高，能上一层，不能从地面直上高层。镜头跟在人右前方，高层略上抬。地面有缺口，掉出屏幕底丢命。中高层平台可单向落（↓ / S 掉落），地面不能掉穿。闯到关底（约屏宽内）金结界处族将现身，镜头锁在尽头。没有人质，不挡路。

忍四三关：霓港（港将 12 血，月华勾玉）/ 月廊（月鬼 16 血，月盘柱、双拾取）/ 金殿（金主 22 血，会瞬移、三向刃、召矛卒）。过关保留命、分、月。忍核同三关，速度约 ×1.34，铳兵更勤，额外补兵，Boss 血 ×1.22。

月华：Shift / Z / 触屏「月」。放出一枚月华回刃，沿面向飞出约半屏后折返，去程与回程各算一次命中。途中杂兵每路过削 1 血（蟹 2 血）、族将每路过削 3 血、敌弹粉碎。不是清屏：刃没扫到的人还在。不是穿场火龙，也不是绕身雷罩，也不是滚场炎轮。耗尽提示「月华耗尽」。勾玉 +1，上限 5。同时在场回刃最多 1 枚。

残月冲：同向连点 ← → / A D，或 C / Ctrl，或触屏「冲」。约 0.22 秒高速前冲，起步留一枚残影、半途再留一枚；残影约 0.12 秒后爆开，范围内杂兵/族将削 1 血、敌弹粉碎。起步约 0.18 秒无敌。冷却约 0.42 秒。疾跑中空格为冲斩，刀弧约 64（站桩约 44）。没有手里剑。

空斩反跳：空中斩中敌人（含族将）会把竖直速度弹到约 -268，可连环跳斩。地面斩不弹。

敌人：徒巡逻 100；铳点射 200；蟹侧跳 250（2 血）；鸢 8 字飞 150；矛卒短突 150。族将走动抛弹，残血更密，金主会瞬移并召矛卒。击破族将再加 4500×倍率，过关 +1800×层。忍四打掉金主后再加 8000，弹「金殿已破」；忍核弹「忍核得手」。

得分：击杀/拾取基础分 × 连击倍率。连击为连续击杀，约 1.4 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))。每 15000 分 1UP，命上限 6。最高分写入 playbox-shinobi4-best，不存盘面；本局超过即更新。重生点随扎实落地点前移。

失败：挨打 / 中弹 / 坠崖扣一命（斩击打中该敌人的这一下不挨打；无敌、冲刺残影无敌段除外）。约 0.80s 后在最近检查点重生，1.32s 闪烁无敌。三命扣完弹出「被击中了 / 中弹了 / 坠入深渊了」。弹层打开时方向键不再斩；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走（按住疾跑，连点冲刺），↑ / W 跳（空格不跳），↓ / S 从平台掉落，空格近斩，Shift / Z 月华，C / Ctrl 冲。点按画布同空格。触屏左 / 跳 / 斩 / 右 / 冲 / 月。标题页 忍四 / 忍核，Enter/空格/1 忍四，2 忍核。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：斩必有三层——听（刀风噪声+下扫锯齿）、看（金弧、金屑、分数蹦出）、触（约 55ms 顿帧 + 镜头踢）。空斩再加反跳。残月冲三层：听（破风噪声+上扫）、看（金残影、爆月环）、触（约 48ms 顿帧 + 镜头踢）。月华三层：听（三角上扫 + 命中高叮）、看（金月牙去回、金环、爆屑）、触（约 62–70ms 顿帧 + 镜头踢）。连击数字往上叠。失败与重开都是一键 R。

区别：没有人质（不同于「忍」），没有贴墙蹬墙（不同于「影忍」），没有魂分身同斩（不同于「忍魂」），没有近斩远镖与穿场火龙（不同于「忍二」），没有绕身雷隐（不同于「忍三」），没有连斩三下与滚场炎轮（不同于「忍影」）。忍术是去回月华，空斩会反跳，冲刺留爆裂残影。
