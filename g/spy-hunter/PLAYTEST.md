玩法：标题页「谍猎」。选「谍猎」打三关（国道 → 林带 → 夜港）再接装甲猎 Boss；选「夜路」同三关但更密更快，Boss 更厚。俯视纵版公路，车钉在画面下方一带，路面向上卷。← → / A D 变道，↑ / W 加速，↓ / S 刹车，空格机枪，Shift / Z 泼油。贴上黄色 VAN 车尾进入补给：油补满、机枪变双管、得 3 发导弹。撞车、冲出护栏、被炸都丢一条命。点顶栏「重开」或按 R：标题页进谍猎；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式；失败「换模式」回标题；通关「夜路」开夜路。M 静音，写入 playbox-spy-hunter-mute。弹层打开时方向键不开车、空格不扫、Shift 不泼油；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 480×720。世界 Y 向北增加，镜头按车速北滚，人钉在离底约 72–248。国道路宽、林带更窄且弯更大、夜港偏暗有岸灯。冲出路面掉速；贴树/护栏过远即出局。标题页背后演示巡路开火，不算分、不掉血。

谍猎三关：国道（轿刀 / 民用 / 摩托，两辆补给车）/ 林带（摩托蛇行、加厚轿、出现装甲轿）/ 夜港（装甲轿与直升机丢弹，关底装甲猎）。过关保留命、分、武装。夜路同三关，速度约 ×1.34 并随关递增，约每包多补一只，Boss 血约 ×1.22。

武装：默认前向机枪，冷却约 0.11s。VAN 补给后双管齐射，导弹 3 发（有装甲轿 / 直升机 / Boss 在前方时随开火锁去，伤害 3）。油 3 罐开局，补给补到 5。油摊约 2.6 秒，敌车碾上会打转再爆。民用车与 VAN 不要打：打民用断连击并扣分；VAN 毁掉没有补给。死亡掉双管与导弹，油至少留 2，约 0.88s 爆炸后在路中重生，1.55s 闪烁无敌。

敌人：民用 不给分（误射 −160）；轿刀 120 / 1 血会贴上来撞；摩托 180 / 1 血蛇行；装甲轿 320 / 4+ 血；直升机 420 / 3 血悬停丢弹；炸弹碰身即死。Boss 装甲猎左右扫并后射双弹，残血加中路弹并放轿/摩托。击破 Boss +4200×倍率，过关 +1800×关。谍猎打掉装甲猎后再加 8000，弹「公路肃清了」；夜路 +10200，弹「夜路得手」。

得分：击杀基础分 × 连击倍率。连击为连续击杀，约 1.48 秒无击杀则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。油杀额外 +80。每 20000 分 1UP，命上限 6。最高分按模式写入 playbox-spy-hunter-best，JSON `{h,n}`（谍猎 / 夜路）。本局超过即更新。

失败：撞敌 / 撞民用 / 正面撞 VAN / 冲出护栏 / 中弹 / 被炸扣一命（无敌除外）。三命（顶栏橙点）扣完弹出「撞车了 / 冲出了 / 被炸了 / 被轧了」。弹层打开时方向键不再开车；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 变道，↑ / W 加速，↓ / S 刹车，空格开火，Shift / Z 泼油。点按或按住画布开火并跟车，指针左右改道、偏上加速、偏下刹车。触屏 左 / 上 / 右 / 下 / 射 / 油。标题页 谍猎 / 夜路，Enter/空格/1 谍猎，2 夜路。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子、子弹不拖尾。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：开火枪口闪 + 金弹拖尾。击中 30–80ms 顿帧 + 火花粒子 + 连击音高爬升 + 「×N」蹦字。爆炸火团 + 镜头微震。泼油紫摊、敌车打转再爆。补给金闪琶音。引擎转速跟时速。失败与重开都是一键 R。

什么变难：林带路窄弯大。夜港直升机丢弹。装甲轿要连打或导弹。装甲猎后射并补兵。夜路车流更密、更快、Boss 更厚。油有限，打空要等 VAN。冲出路面掉速，贴树即死。误伤民用断连击。
