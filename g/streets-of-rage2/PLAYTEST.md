玩法：标题页「怒二」。选「怒二」打三关（闹市→铁桥→罪巢，罪巢尽头是罪枭）；选「怒核」同三关但每包更密、更快、更肉。沿街带状走（左右推进、上下换深度），空格出拳三连，贴近晕住的人抓住再甩，Shift / Z 升龙（耗能量）。没有跳、不捡铁管飞刀。体力打空扣一命。点顶栏「重开」或按 R：标题页进怒二；对局中或结束层重开同一模式。结束层「再来」同模式；失败「换模式」回标题；通关「怒核」开怒核。M 静音，写入 playbox-streets-of-rage2-mute。弹层打开时方向键不走路、空格不出拳；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。可走带宽 y=222–322。镜头跟在人右前方，遇兵和 Boss 锁在当前段。人约 16 宽 30 高，走约 178，纵深约 114。标题页背后演示右进出拳抓投，不算分、不掉血。

怒二三关：闹市（铁门 160 血，混混/刀客，烤鸡）/ 铁桥（飞影 220 血，飞车/壮汉更多）/ 罪巢（罪枭 300 血，会开枪并叫保镖）。过关保留命、分、能量和体力。怒核同街景，每包多 1～2 人，敌速约 ×1.12，血量约 ×1.16。

出拳：空格三连（直→直→勾），第 3 击击晕。贴近晕住的非头目即抓住，抓住可走动，再空格 / 升龙甩出去；飞出的人撞到别人也算击倒，撞墙额外伤害。升龙耗 1 能（上限 3，开局 2，打中回能），半径清场，升龙中无敌。刀客飞刀用上下换深度躲开。

敌人：混混近打；刀客远掷；壮汉重拳；飞车冲撞。Boss 铁门重拳、飞影冲踢、罪枭开枪压场。击破 Boss 再加 4000/5200/9000×倍率，过关 +2000×关。怒二打掉罪枭后再加 8000，弹「罪巢清了」。

得分：击杀基础分 × 连击倍率。连击为连续打中，约 1.42 秒无打中则断。倍率 = 1 + min(4, floor((连击-1)/2))，即 1–2 连 1 倍、3–4 连 2 倍，最高 5 倍。每 20000 分 1UP，命上限 6。最高分写入 playbox-streets-of-rage2-best，不存盘面；本局超过即更新。

失败：挨打扣体力（无敌与升龙除外）。体力 0 扣一命。约 0.8s 倒地后原地满血重生，1.35s 闪烁无敌。三命（顶栏红点）扣完弹出「被打倒了 / 血空了 / 被飞车撞了 / 被混混打中了 / 中刀了 / 中弹了」等。弹层打开时方向键不再出拳；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → ↑ ↓ / WASD 走（上下换深度），空格 / J 出拳，Shift / Z / K 升龙。点画布同出拳。触屏 上 / 下 / 左 / 右 / 拳 / 龙。标题页 怒二 / 怒核，Enter/空格/1 怒二，2 怒核。R 重开，M 静音。无手柄。与怒街不同：没有跳、没有铁管飞刀、爆发不耗血，核心是抓投和升龙能量。与双截不同：没有踢、没有棍鞭，不是救人。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：出拳挥拳风声。打中：撞击音 + 粒子/火花 + 分数蹦出 + 约 40–76ms 顿帧（勾拳/甩投更长，升龙约 80ms）+ 镜头微震。连击数字往上窜，倍率跳时全屏 ×N。升龙：青金爆光、残影、全屏闪、震。抓投撞墙爆屑。失败与重开都是一键 R。
