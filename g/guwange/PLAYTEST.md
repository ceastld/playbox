玩法：标题页「弓眼」。选「狩灵」打三关（灯巷 → 鸟居 → 冥核），短关之后出弓眼；选「怨海」同三关但卷轴更快、编队更密、敌弹更勤、Boss 多约 22% 血。点顶栏「重开」或按 R：标题页直接开狩灵；对局中或结束层重开同一模式。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-guwange-mute。←↑↓→ / WASD 八向移动，空格射灵矢（可按住连发），Shift / Z 或顶栏「锁」放出式神锁定。画布拖动跟舰，按下开火。触屏右下「锁」按住放出式神。结束层与标题层不挡顶栏重开，R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点。标题页 1/Enter 狩灵、2 怨海。

场地：虚拟场 480×720。舰开局 y=642、x=240，夹在 22–458 / 40–692。狩灵巡航约 88（怨海 124）；弓眼在屏时降到 22。移速约 276（怨海 318）。灵矢弹速 760，冷却约 0.088s（怨海 0.078）；默认双矢，6 连后补中矢。未解锁音频前无声。三关名：灯巷、鸟居、冥核；顶栏在 Boss 时改成「弓眼」。

式神锁定：按住 Shift / Z（顶栏「锁」点按切换，触屏垫按住）放出式神。式神慢跟舰身、停在舰前约 168，半径约 86 内锁最近目标，狩灵最多 5、怨海 7。锁上后约 0.11s（怨海 0.09）对各锁敌射追踪灵弹（弹速约 420–460）。锁杀 1.25 倍分并掉魂。放开式神收回，锁环消失。舰不减速。

敌人：灯妖 50 / 2 血、飞怨 80 / 2、祠卫 120 / 5、鸟居 150 / 6、怨灵 240 / 10、侍从 280 / 12（怨海 16）、弓眼 8000 / 90（怨海 118）。血量再乘怨海 1.22（弓眼/侍从按上表）。怨海 V 字 +2、飞怨 +1、额外一只祠卫；射速约 0.74 倍间隔、弹速约 186（狩灵 146）。

Boss：弓眼入场约 1.35s 后左右游荡。高血五发散+偶发八环，半血十环螺旋兼瞄准，残血双环+三发散并吐灯妖。两侧侍从绕核瞄准。打爆后约 1.35s 结算。

得分：击杀基础分 × 连击倍率（锁杀再 ×1.25）。魂 30×倍率。灵矢击中弓眼削血 +10×倍率。连击为连续击杀/吃魂，约 1.4 秒无动作则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 3 链顿帧并蹦「N 链」。过关 +1500×倍率。狩灵打穿再 +8000，怨海 +10000。每 18000 分 1UP，命上限 6。最高分写入 playbox-guwange-best，不存盘面；本局超过即更新。

胜利：狩灵/怨海打爆弓眼后约 1.35s 结算「冥核尽碎」/「怨海通关」。
失败：三命（顶栏玫红灯笼点）扣完弹出「魂散了」。敌弹（判定约 4.6）或撞机体/弓眼扣一命。约 0.92s 爆炸后底部重生，1.5s 闪烁无敌，场上敌弹清空。弹层打开时方向键不再开火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：←↑↓→ / WASD 移，空格射箭，Shift / Z 锁定。点按画布开火并跟舰。标题页 Enter/空格/1 狩灵，2 怨海。A 自动，R 重开，M 静音。无手柄。

自动：点「自动」或按 A 开关托管（开着时按钮呈按下态并显示「停下」）。开着时忽略方向键、W/S/D、空格、Shift/Z、触屏和锁钮；A / R / M / 重开仍可用。开关不写入存储，刷新后关闭；重开不会关掉自动。标题页开着会自动开狩灵；结束层会自动再来。速度滑条 1–4 为 慢 / 中 / 快 / 极快（默认快），写入 playbox-guwange-auto-speed，改了立刻生效。慢/中减速看得见躲弹锁敌，极快约 2.5 倍步进。AI 扫格找安全点，对准灯妖/飞怨/祠卫/弓眼开火，安全时擦弹吃魂，式神锁群/Boss 当爆。不是完美求解，弹海残机会漏。

限制：没有暂停键。切走页面会暂停步进。声音要在一次按键或点击之后才有。系统开了减少动态时不顿帧、不抖屏、子弹不拖尾。触控画布 `touch-action: none`，避免页面跟着滚。弹层在舞台内，不挡顶栏重开；`.overlay` 与 `.overlay.hidden` 均为 `pointer-events: none`。

爽感：射箭枪口闪 + 弓弦方波。式神三层：听（切入正弦上滑 + 锁叮）、看（青魂、锁环、锁线、顶栏「锁」）、触（约 48ms 顿帧 + 镜头微震）。击中粒子爆 + 短顿帧（约 30–34ms）。锁杀掉魂 + 青爆。吃魂升频铃，三链蹦字。弓眼碎裂金环大爆、约 80ms 顿帧并震屏。坠机洋红大爆、约 72ms 顿帧。失败与重开都是一键 R。
