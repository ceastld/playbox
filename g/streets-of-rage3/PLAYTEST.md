玩法：标题页「怒三」。选「怒三」打三关（船坞→工地→核巢，核巢尽头是罪核）；选「怒核」同三关但每包更密、更快、更肉。沿街带状走（左右推进、上下换深度），空格出拳三连，贴近晕住的人抓住再甩，双击左/右暴冲穿场，Shift / Z 电旋（耗电量）。没有跳、不捡铁管飞刀。体力打空扣一命。点顶栏「重开」或按 R：标题页进怒三；对局中或结束层重开同一模式。结束层「再来」同模式；失败「换模式」回标题；通关「怒核」开怒核。M 静音，写入 playbox-streets-of-rage3-mute。弹层打开时方向键不走路、空格不出拳；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。可走带宽 y=222–322。镜头跟在人右前方，遇兵和 Boss 锁在当前段。人约 16 宽 30 高，走约 186，纵深约 118。标题页背后演示右进出拳和暴冲，不算分、不掉血。

怒三三关：船坞（铁卫 170 血，暴徒/机兵，烤鸡）/ 工地（影刃 230 血，飞车/重锤更多）/ 核巢（罪核 320 血，会开枪并叫机兵）。过关保留命、分、电量和体力。怒核同街景，每包多 1～2 人，敌速约 ×1.12，血量约 ×1.16。

出拳：空格三连（直→直→回旋），第 3 击击晕。贴近晕住的非头目即抓住，抓住可走动，再空格 / 电旋 / 暴冲甩出去；飞出的人撞到别人也算击倒，撞墙额外伤害。暴冲：0.24 秒内同向连点左或右（触屏「冲」），约 0.3 秒冲刺、无敌、打穿路径、打掉等离子，冷却约 0.68 秒。电旋耗 1 电（上限 3，开局 2，打中回电），原地旋转清场，电旋中无敌。机兵等离子用上下换深度躲开，暴冲/电旋也可拆弹。

敌人：暴徒近打；机兵远射等离子，击破会爆；重锤重拳；飞车冲撞。Boss 铁卫等离子压场、影刃冲踢、罪核开枪并叫机兵。击破 Boss 再加 4200/5400/9200×倍率，过关 +2000×关。怒三打掉罪核后再加 8000，弹「核巢清了」。

得分：击杀基础分 × 连击倍率。连击为连续打中，约 1.38 秒无打中则断。倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。每 20000 分 1UP，命上限 6。最高分写入 playbox-streets-of-rage3-best，不存盘面；本局超过即更新。

失败：挨打扣体力（无敌、暴冲与电旋除外）。体力 0 扣一命。约 0.8s 倒地后原地满血重生，1.35s 闪烁无敌。三命（顶栏红点）扣完弹出「被打倒了 / 血空了 / 被飞车撞了 / 被暴徒打中了 / 中等离子了 / 中弹了」等。弹层打开时方向键不再出拳；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → ↑ ↓ / WASD 走（上下换深度），空格 / J 出拳，Shift / Z / K 电旋，同向连点方向或 X / C / 触屏「冲」暴冲。点画布同出拳。触屏 上 / 下 / 左 / 右 / 拳 / 电 / 冲。标题页 怒三 / 怒核，Enter/空格/1 怒三，2 怒核。R 重开，M 静音。无手柄。与怒二不同：没有升龙，核心是暴冲穿场和原地电旋，机兵会爆，关卡是船坞/工地/核巢不是闹市/铁桥/罪巢。与怒街不同：没有跳、没有铁管飞刀，爆发不耗血。与怒火不同：不是八向跑打，不上坦克。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：出拳挥拳风声。打中：撞击音 + 粒子/火花 + 分数蹦出 + 约 40–68ms 顿帧（回旋/甩投更长，电旋约 80ms，暴冲约 56ms）+ 镜头微震。连击数字往上窜，倍率跳时全屏 ×N。暴冲：青金残影、拆弹、穿人。电旋：青金爆光、旋转残影、全屏闪、震。机兵击破爆屑。失败与重开都是一键 R。
