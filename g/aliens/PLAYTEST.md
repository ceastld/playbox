玩法：标题页「异形」。选「清巢」打三关（殖民地→通风管→巢穴，关底女王）；选「虫潮」同三关，敌约 ×1.35 更快，工蜂/爬管/战士各多 1 血，女王约 ×1.22 血，通风口掉虫更勤、额外补兵。侧向走跳，按住空格喷火（近距火锥）。被咬扣血，血空扣一命。点顶栏「重开」或按 R：标题页进清巢；对局中或结束层重开同一模式第 1 关。结束层「再来」同模式，「换模式」回标题。M 静音，写入 playbox-aliens-mute。弹层打开时方向键不走路、空格不喷火；顶栏重开与 R 随时可用，弹层不盖住顶栏，且 `pointer-events` 不挡住重开。

场地：虚拟场 640×360。地面 y=328，中层 248，通风高层 170；起跳约 97 高，能上一层，不能从地面直上高层。镜头跟在人右前方，女王战时锁在关底。地面有酸池缺口，掉出屏幕底丢命。中高层平台可落上，蹲下可掉穿。人宽约 14、立高 26、蹲高 16。走约 208，空中约 0.9。喷火射程约 108。标题页背后演示走喷，不算分、不掉血。

清巢三关：殖民地（工业廊，酸池，通风口掉抱脸虫，工蜂巡逻）/ 通风管（平台更密、爬管虫贴层、掉虫更勤）/ 巢穴（有机壁、卵，关底女王）。过关保留命、血、分、连击，并回 18 血。虫潮同三关。每关一至两包急救（+40 命）。

异虫：卵靠近会孵成抱脸虫，火烧可直接碾卵。抱脸虫贴地窜、近了就扑，撞上头会抱脸；抱上最多 2 只，走速变慢，生命约 16/秒（虫潮 22/秒）往下掉。左右变向、跳、喷火可挣脱/烧掉，满约 6 下甩开。工蜂追人扑咬；爬管虫贴中高平台，人走到下方会落下；战士厚血、扑得更狠。工蜂/战士/女王被烧穿会喷酸血，近身会溅到人。通风口定时掉抱脸虫。女王锁镜头后甩尾、喷酸、吐抱脸、内颚前扑。

得分：击杀基础分 × 连击倍率（卵 50 / 抱脸 80 / 爬管 100 / 工蜂 120 / 战士 220 / 女王 5000）。连击窗口 1.4s，倍率 = 1 + min(4, floor((连击-1)/3))，即 1–3 连 1 倍、4–6 连 2 倍，最高 5 倍。过关 +2000×关号×倍率。清巢 +3000 + 剩命×400 + 余血×2。每 15000 分 1UP，命上限 6。最高分写入 playbox-aliens-best，不存盘面；本局超过即更新。

胜利：巢穴放倒女王后弹出「巢清了 / 虫潮烧净了」。
失败：三命（顶栏绿点）扣完弹出「被抱脸了 / 被咬穿了 / 被撕开了 / 酸血溅到了 / 坠入酸池 / 被尾刺了 / 被撞上了 / 生命耗尽」。弹层打开时方向键不再喷火；顶栏重开与 R 随时可用。弹层 `pointer-events: none`，只有面板按钮可点，不挡重开。

操作：← → / A D 走，↑ / W 跳（按住空格且不走时可立定上抬喷火），↓ / S 蹲/掉穿平台，空格喷火。点按画布同空格按住。触屏 左 / 跳 / 喷 / 右 / 蹲。标题页 清巢 / 虫潮，Enter/空格/1 清巢，2 虫潮。R 重开，M 静音。无手柄。

限制：没有暂停。声音要在一次按键或点击之后才有。切走页面会暂停步进。系统开了减少动态时不抖屏、不停帧、少粒子。触控时画布 `touch-action: none` 并 preventDefault，避免页面跟着滚。

爽感：喷火枪口闪 + 橙黄火锥 + 呼啸噪声。烧中/击杀酸液粒子 + 30–80ms 顿帧 + 镜头微震 + 连击数字往上窜。抱脸洋红刺闪、生命条一抖、蜂鸣；甩开噗一声。失败与重开都是一键 R。
